## 二、关键文件详解

### 2.1 StateTreeTaskBase.h（Task 基类）

**位置**：`Source/StateTreeModule/Public/StateTreeTaskBase.h`

**关键内容**：
- `FStateTreeTaskBase` 结构体（约 130 行）
- 所有标志位定义（默认值）
- 5 个虚函数（EnterState、Tick、ExitState、StateCompleted、TriggerTransitions）
- `FStateTreeTaskCommonBase` 标记类

**该文件包含的关键源码片段**：

```cpp
FStateTreeTaskBase()
    : bShouldStateChangeOnReselect(true)
    , bShouldCallTick(true)              // ⭐ 5.7 默认 true
    , bShouldCallTickOnlyOnEvents(false)
    , bShouldCopyBoundPropertiesOnTick(true)
    , bShouldCopyBoundPropertiesOnExitState(true)
    , bShouldAffectTransitions(false)
    , bConsideredForScheduling(true)
    , bTaskEnabled(true)
#if WITH_EDITORONLY_DATA
    , bConsideredForCompletion(true)
    , bCanEditConsideredForCompletion(true)
#endif
{}

virtual EStateTreeRunStatus EnterState(
    FStateTreeExecutionContext& Context,
    const FStateTreeTransitionResult& Transition) const
{
    return EStateTreeRunStatus::Running;
}

    FStateTreeExecutionContext& Context,

    return EStateTreeRunStatus::Running;

```

### 2.2 StateTreeExecutionContext.h（执行上下文头文件）

**位置**：`Source/StateTreeModule/Public/StateTreeExecutionContext.h`（约 79KB）

**关键类**：
- `FStateTreeExecutionContext` —— 主执行上下文（Tick/Start/Stop 等入口）
- `FStateTreeReadOnlyExecutionContext` —— 只读版（用于查询）

**关键 API 索引**：

| API | 作用 |
|-----|------|
| `Start(Parameters)` | 启动 StateTree |
| `Stop(Status)` | 停止 |
| `Tick(DeltaTime)` | 主 Tick 入口 |
| `GetInstanceData<T>(Node)` | 获取节点实例数据 |
| `GetExternalData<T>(Handle)` | 获取外部数据 |
| `RequestTransition(...)` | 请求状态切换 |
| `FinishTask(Task, Type)` | 完成 Task |
| `SendEvent(Tag, Payload)` | 发送事件 |
| `BroadcastDelegate(Dispatcher)` | 广播委托 |
| `MakeWeakExecutionContext()` | 创建弱引用（异步用） |
| `GetNextScheduledTick()` | 查询下次 Tick 时间 |

### 2.5 StateTreeTypes.h（基础类型）

**位置**：`Source/StateTreeModule/Public/StateTreeTypes.h`（约 36KB）

**关键定义**：

```cpp
// 转换类型
enum class EStateTreeTransitionType : uint8 { None, Succeeded, Failed, GotoState, NextState, NextSelectableState };

// 转换触发器（位标志）
enum class EStateTreeTransitionTrigger : uint8
{
    None = 0,
    OnStateCompleted = 0x1 | 0x2,
    OnStateSucceeded = 0x1,
    OnStateFailed = 0x2,
    OnTick = 0x4,
    OnEvent = 0x8,
    OnDelegate = 0x10,
};

// 转换优先级
enum class EStateTreeTransitionPriority : uint8 { None, Low, Normal, Medium, High, Critical };

// 状态类型
enum class EStateTreeStateType : uint8 { State, Group, Linked, LinkedAsset, Subtree };

// 状态选择行为
enum class EStateTreeStateSelectionBehavior : uint8
{
    None,
    TryEnterState,
    TrySelectChildrenInOrder,
    TrySelectChildrenAtRandom,
    TrySelectChildrenWithHighestUtility,
    TrySelectChildrenAtRandomWeightedByUtility,
    TryFollowTransitions,
};

// 5.7 引入的状态选择规则（位标志）
enum class EStateTreeStateSelectionRules : uint32
{
    None = 0,
    CompletedTransitionStatesCreateNewStates = 1 << 0,
    CompletedStateBeforeTransitionSourceFailsTransition = 1 << 1,
    ReselectedStateCreatesNewStates = 1 << 2,
    Default = CompletedTransitionStatesCreateNewStates | CompletedStateBeforeTransitionSourceFailsTransition,
```

## 五、源码学习路径

### 入门级
1. 先看 **`StateTreeTaskBase.h`** —— 理解 Task 接口
2. 再看 **`StateTreeTypes.h`** 和 **`StateTreeExecutionTypes.h`** —— 理解所有枚举
3. 看 **`StateTreeTestSuite/`** 中的测试用例 —— 实际使用范例

### 进阶级
1. 通读 **`StateTreeExecutionContext.h`** —— 理解 API 全貌
2. 重点读 **`StateTreeExecutionContext.cpp`** 中：
   - `Tick` 函数 —— 主循环
   - `SelectState` —— 状态选择
   - `TriggerTransitions` —— 转换评估
   - `EnterState` / `ExitState` —— 状态切换
3. 看 **`StateTreeInstanceData.cpp`** —— 实例数据管理

### 深入级
1. 看 **`StateTreeAsyncExecutionContext.cpp`** —— 异步机制
2. 看 **`StateTreePropertyBindings.cpp`** —— 绑定系统
3. 看 **`StateTreeEditorModule\`** —— 编辑器实现
4. 对比不同 Schema 的实现差异（GameplayStateTree、Mass、Avalanche）
