## 12.2.1 ActorChannel 何时打开

```
Server 端 ServerReplicateActors:
   遍历每个 replicated actor:
      对每个 connection:
         if (该 actor 对该 connection relevant && 还没 channel)
            ActorChannel = OpenChannelForActor(Actor, Connection)
         
         if (有 channel)
            ReplicateActor(Channel)  // 生成 diff,加入发包
```

**首次 relevant** 时打开 channel。Channel 创建涉及:
- 分配 ChIndex
- 注册到 Connection.Channels[]
- 创建 actor 的初始 RepLayout + GUID 同步

## 12.2.2 ActorChannel 何时关闭

```cpp
enum class EChannelCloseReason : uint32
{
    Destroyed,         // actor 在 server 被销毁
    Dormancy,          // 进入 dormancy(休眠,无变化)
    LevelUnloaded,     // 关卡卸载
    Relevancy,         // 不再 relevant
    TearOff,           // 显式 tear off
    // ...
};
```

**关闭策略**:
- Actor 销毁 → 关
- Actor 远离 client(out of relevancy) → 关
- Actor 进入 dormancy(`bNetDormant = true`)→ 关,但不"销毁",client 仍持有 actor

## 12.2.3 Relevancy(相关性)

```cpp
// AActor 虚函数
virtual bool IsNetRelevantFor(const AActor* RealViewer, 
                                const AActor* ViewTarget, 
                                const FVector& SrcLocation) const;
```

默认实现:**距离 viewer < `NetCullDistanceSquared`** → relevant。

子类可重写:

```cpp
bool ARTSBuilding::IsNetRelevantFor(...) const
{
    // 同队 / 同视野的玩家才能看到
    return SameTeamAs(RealViewer) || HasFogOfWarVisibility(RealViewer);
}
```

实战:RTS 战争迷雾 + relevancy 配合,client 只看到可见区域 actor。

## 12.2.4 Dormancy(休眠)

```cpp
// AActor 字段
ENetDormancy NetDormancy;         // None / DormantAll / Awake / ...
bool bNetDormant;
```

休眠 = "我状态没变,这一段时间不复制"。Server 关闭 channel,但 client 仍持有 actor(冻结状态)。

```
Static 建筑(NetDormancy = DORM_Initial)→ 初始复制完即休眠
血条变化 → FlushNetDormancy() 唤醒一帧 → 复制变化 → 休眠
```

RTS 实战:大量"几乎不变"的 actor(资源点、装饰物)用 dormancy 减网络压力。

## 12.2.5 ReplicationFrame

```cpp
// UNetDriver 字段
uint32 ReplicationFrame;
```

每帧 ServerReplicateActors 时 `++ReplicationFrame`。每个 actor 记 `LastReplicationFrame`,用来判断"上次什么时候复制过"+ "该不该再复制"(NetUpdateFrequency 控制频率)。

```cpp
if (CurrentFrame - Actor->LastReplicationFrame >= 1.0f / Actor->NetUpdateFrequency)
{
    // 该复制了
}
```

`NetUpdateFrequency` 默认 100Hz,可调降低不重要 actor。

---

## 12.2.6 50K Actor 的 ChannelMap 内存

```
50K UActorChannel 对象 × ~1KB / 每个(含 RepLayout 缓存等)= ~50MB / connection

10 client 同时连入 → 500MB 仅 channel 内存
```

仅内存就难以接受。CPU 上 ServerReplicateActors 遍历 50K × 10 = 500K 次操作 / 帧 → 几十毫秒。

→ Mass 必须自定义复制。
