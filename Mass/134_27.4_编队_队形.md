## 27.4.1 编队(Formation)是什么

```
玩家选 100 单位 → "编队右键移动":
   不是 100 个单位都往一个点走
   而是 100 个单位保持队形(矩形 / 楔形 / 圆形)整体推进
```

## 27.4.2 数据结构

```cpp
USTRUCT()
struct FFormationFragment : public FMassFragment
{
    FGuid FormationId;            // 哪个编队
    int32 SlotIndex;              // 在编队里的槽位
    FVector2f LocalOffset;        // 相对编队中心的偏移(本地坐标)
};

class URTSFormationSubsystem : public UWorldSubsystem
{
    struct FFormation
    {
        FVector Center;
        FVector Forward;
        TArray<FVector2f> SlotOffsets;   // 每槽位的本地偏移
        FGuid FlowFieldId;
    };
    
    TMap<FGuid, FFormation> Formations;
};
```

## 27.4.3 移动逻辑

```cpp
class UMassFormationMovementProcessor : public UMassProcessor
{
    Execute(...)
    {
        for entity in chunk:
            FFormation& Form = Formations[entity.FormationId];
            
            // 1. 流场算编队中心朝向(target 方向)
            FVector2f FlowDir = FlowFieldSS->Sample(Form.FlowFieldId, Form.Center);
            
            // 2. 每 entity 期望位置 = Center + LocalOffset 旋转到 Forward
            FVector DesiredPos = Form.Center + Rotate(LocalOffset, Form.Forward);
            
            // 3. 推进 entity 朝 DesiredPos
            FVector2f Move = (DesiredPos - entity.Pos).GetSafeNormal2D();
            
            // 4. 加 RVO 避障
            entity.Pos += Move * Speed * DeltaT;
    }
};

// 单独的 processor 推进编队中心
class UMassFormationCenterProcessor : public UMassProcessor
{
    Execute(...)
    {
        for each formation:
            // 编队中心走流场方向
            FVector2f FlowDir = FlowFieldSS->Sample(Form.FlowFieldId, Form.Center);
            Form.Center += FlowDir * FormationSpeed * DeltaT;
    }
};
```

## 27.4.4 队形选择

```
矩形(Box):整齐易控,适合行军
楔形(Wedge):前尖后宽,适合冲锋
圆形(Circle):全方向防御,适合保护核心
散兵(Scatter):无队形,各自寻路(回退)
```

每个 Formation Trait 决定 SlotOffsets 排列。
