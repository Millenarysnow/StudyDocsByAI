# §17.2 FMassEntityManager — 数据中枢

> **本节地图**:模块四第 17 章第 2 节。`FMassEntityManager` 是 Mass 的数据中枢 — 持有所有 entity / archetype / chunk。每个 World 一个。
>
> **预备知识**:§17.1。
>
> **读完之后你能做到**:
> - 知道 EntityManager 在 UMassEntitySubsystem 内的位置
> - 用 EM 的关键 API(CreateEntity / DestroyEntity / IsEntityValid)
> - 看懂 EntityManager 的命令缓冲机制

---

## 17.2.1 EntityManager 的位置

```
World
  └─ UMassEntitySubsystem (UWorldSubsystem)
        └─ TSharedPtr<FMassEntityManager> EntityManager
              ├─ Entities 数组(FEntityData)
              ├─ Archetypes 数组(FMassArchetypeData)
              ├─ ObserverManager(变更监听)
              ├─ DefaultCommandBuffer(命令缓冲)
              └─ ...
```

EM 是 `TSharedPtr` 持有的 C++ 对象,**不是 UObject**。

```cpp
UMassEntitySubsystem* Sub = World->GetSubsystem<UMassEntitySubsystem>();
FMassEntityManager& EM = Sub->GetMutableEntityManager();
```

---

## 17.2.2 主要字段(简化)

```cpp
struct FMassEntityManager : public TSharedFromThis<FMassEntityManager>, public FGCObject
{
    // Entity 数据
    UE::Mass::FStorageType EntityStorage;     // chunked Entity array
    
    // Archetype 数组(每个唯一 fragment 组合一个)
    TArray<TSharedPtr<FMassArchetypeData>> AllArchetypes;
    TMap<uint32, FMassArchetypeHandle> ArchetypeHashLookup;
    
    // 命令缓冲(并行 worker 写,主线程 flush)
    FMassCommandBuffer DefaultCommandBuffer;
    
    // 观察者管理
    UE::Mass::ObserverManager Observers;
    
    // ...
};
```

## 17.2.3 关键 API

### 17.2.3.1 创建 Entity

```cpp
// 1. 从 archetype 直接创建
FMassEntityHandle E = EM.CreateEntity(Archetype);

// 2. 用 EntityBuilder(更友好)
UE::Mass::FEntityBuilder Builder(EM);
Builder.Add<FPositionFragment>();
Builder.Add<FVelocityFragment>();
Builder.AddTag<FActiveTag>();
FMassEntityHandle E = Builder.Commit();

// 3. 批量创建(性能优化)
TArray<FMassEntityHandle> Entities;
EM.BatchCreateEntities(Archetype, /*Count*/ 100, Entities);
```

### 17.2.3.2 销毁

```cpp
EM.DestroyEntity(E);

// 批量
EM.BatchDestroyEntities(Entities);
```

### 17.2.3.3 添加 / 移除 Fragment

```cpp
// 立即(非线程安全,要在 Mass tick 之外或 GameThread)
EM.AddFragmentToEntity(E, FFragmentType::StaticStruct());
EM.RemoveFragmentFromEntity(E, FFragmentType::StaticStruct());

// 推荐:走命令缓冲(线程安全 + deferred)
EM.Defer().AddFragment<FFragmentType>(E);
EM.Defer().DestroyEntity(E);
```

### 17.2.3.4 查询 / 访问 Fragment

```cpp
// 检查是否含
bool bHas = EM.HasFragment<FPositionFragment>(E);

// 取数据(读)
const FPositionFragment* P = EM.GetFragmentDataPtr<FPositionFragment>(E);

// 取数据(写)
FPositionFragment* P = EM.GetFragmentDataChecked<FPositionFragment>(E);
P->Position = NewLoc;
```

⚠️ 这些 API **慢**(几百纳秒,涉及 archetype lookup)。**hot path 走 Processor 的批量 ForEach,不要单 entity 查**。

## 17.2.4 命令缓冲

```cpp
// Processor 内部用 Ctx.Defer(),它指向 EntityManager 的 CommandBuffer
void URTSDamageProcessor::Execute(EntityManager, Context)
{
    Query.ForEachEntity(EntityManager, Context, [&](FMassExecutionContext& Ctx) {
        for entity in chunk:
            if (Health <= 0)
                Ctx.Defer().DestroyEntity(EntityHandle);   // 不立即销毁
    });
    
    // Processor Execute 末尾,Mass 框架自动 flush 命令
}
```

为什么延迟:
- Processor 执行期间不能改 entity composition(其它 worker 正在扫)
- 命令积累后**统一**flush(避免反复 archetype 迁移开销)

§5.5.4 详讲过这个机制。

## 17.2.5 Observer(变更监听)

// 注册:某 Fragment 添加 / 移除时通知
EM.Observers.GetOrCreateObserver<FMyFragment>(EMassObservedOperation::Add).AddLambda(...);

## 17.2.6 多线程 Entity 创建(5.x 新)

```cpp
// 默认 GameThread 安全,某些 5.x 操作支持并发(从 Processor 的 worker thread)
// 通过 FMassConcurrentReserveStorage 实现
```

`WITH_MASS_CONCURRENT_RESERVE` 编译宏控制(默认 1)。

**纪律**:仍然**优先**走 Defer 命令缓冲。直接调 EM 的修改 API 仅在 GameThread 安全。

## 17.2.7 实操与下一节预告

### 实操

```cpp
// 创建 100 个测试 entity
void URTSDebugSubsystem::SpawnTestEntities()
{
    UMassEntitySubsystem* Sub = GetWorld()->GetSubsystem<UMassEntitySubsystem>();
    FMassEntityManager& EM = Sub->GetMutableEntityManager();
    
    UE::Mass::FEntityBuilder Builder(EM);
    Builder.Add<FMassTransformFragment>();
    Builder.Add<FMassVelocityFragment>();
    Builder.AddTag<FActiveTag>();
    
    for (int32 i = 0; i < 100; ++i)
    {
        FMassEntityHandle E = Builder.Commit();
        FMassTransformFragment* T = EM.GetFragmentDataChecked<FMassTransformFragment>(E);
        T->GetMutableTransform().SetLocation(FVector(i * 100.0f, 0, 0));
    }
}
```
