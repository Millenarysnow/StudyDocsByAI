# §20.1 Mass LOD 系统

> **本节地图**:模块四第 20 章第 1 节。50K entity 不能每个都跑完整 AI / 渲染。LOD(Level of Detail)系统按距离玩家分档,远的 entity 简化处理。
>
> **预备知识**:§17 / §18。
>
> **读完之后你能做到**:
> - 用 MassLOD 模块给 entity 加 LOD
> - 区分 4 档 LOD
> - 写 Processor 按 LOD 分档处理

---

## 20.1.1 LOD 四档

```cpp
enum class EMassLOD : uint8
{
    High,     // 完整模拟 + 渲染(玩家附近)
    Medium,   // 完整模拟 + 简化渲染
    Low,      // 简化模拟 + 简化渲染
    Off,      // 不模拟 / 不渲染(超远)
    Max,
};
```

---

## 20.1.2 启用 LOD

加 Trait:

```
DA_Soldier:
   - UMassLODCollectorTrait        (收集距离信息)
   - UMassRepresentationTrait      (按 LOD 切换视觉)
   - UMassSimulationLODTrait       (按 LOD 切换 AI 频率)
```

每 entity 自动获得 `FMassLODFragment`。

---

## 20.1.3 LOD Processor 工作

```
UMassLODCollectorProcessor (PrePhysics):
   每 entity 计算到 viewer 距离
   设 FMassLODFragment.LOD
   
UMassRepresentationProcessor (FrameEnd):
   读 LOD,切换:
      High:   ISMC 详细 mesh
      Medium: ISMC 简化 mesh
      Low:    ISMC 远景 mesh / Niagara
      Off:    不渲染
```

---

## 20.1.4 LOD 距离配置

```cpp
// MassLOD 配置:
HighLODDistance = 0..2000     // 0-20m 玩家近距
MediumLODDistance = 2000..5000 // 20-50m 中距
LowLODDistance = 5000..10000   // 50-100m 远距
OffLODDistance = > 10000        // > 100m 不渲染
```

可在 Trait 配。

---

## 20.1.5 RTS 视角下的 LOD

```
50K Mass entity:
   - 玩家相机内 ~5K High LOD(近距,详细 + AI 完整)
   - 中圈 ~10K Medium LOD(简化 mesh)
   - 远圈 ~20K Low LOD(粗 mesh / 仅位置同步)
   - 战雾外 / 超远 ~15K Off LOD(隐藏 + AI 暂停)

→ 实际渲染压力 ~5K 个 high-quality mesh,可行
```

## 20.1.6 自定义 LOD Processor

```cpp
class URTSCustomLODProcessor : public UMassProcessor
{
    void Execute(...) override
    {
        Query.ParallelForEachEntityChunk(EM, Ctx, [](FMassExecutionContext& Ctx)
        {
            const auto LODs = Ctx.GetFragmentView<FMassLODFragment>();
            const auto Healths = Ctx.GetMutableFragmentView<FUnitHealthFragment>();
            
            for (int32 i = 0; i < Ctx.GetNumEntities(); ++i)
            {
                EMassLOD::Type LOD = LODs[i].LOD;
                
                // 按 LOD 简化逻辑
                if (LOD == EMassLOD::High) {
                    // 详细 AI tick
                } else if (LOD == EMassLOD::Low) {
                    // 仅基础移动
                } else if (LOD == EMassLOD::Off) {
                    // 跳过
                    continue;
                }
            }
        });
    }
};
```

或更激进:**Tag 区分 LOD**(整 archetype 跳过):

```cpp
USTRUCT() struct FLODHighTag : public FMassTag {};
USTRUCT() struct FLODOffTag : public FMassTag {};

// Query 仅处理 High LOD entity
Query.AddTagRequirement<FLODHighTag>(EMassFragmentPresence::All);
Query.AddTagRequirement<FLODOffTag>(EMassFragmentPresence::None);
```
