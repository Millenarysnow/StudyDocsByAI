## 20.3.1 Movement 核心 Fragment

```cpp
// MassCommon
USTRUCT() struct FMassVelocityFragment : public FMassFragment
{
    FVector Value;     // 当前速度
};

USTRUCT() struct FMassForceFragment : public FMassFragment
{
    FVector Value;     // 累计力(由 Steering 各 behavior 累加)
};

USTRUCT() struct FMassMoveTargetFragment : public FMassFragment
{
    FVector Center;       // 目标位置
    float Forward;        // 朝向
    float DesiredSpeed;
    EMassMovementAction IntentAtGoal;
};
```

## 20.3.2 移动 Tick 链

```
PrePhysics:
   URTSAIProcessor: 设 FMassMoveTargetFragment(目标位置)
   ↓
   UMassSteeringProcessor: 计算 Steering force(分离 / 对齐 / 跟随)
                            读 MoveTarget,写 ForceFragment
   ↓
   UMassMovementProcessor: 读 Force / Velocity,积分位置
                            FVelocity += Force * DT
                            FPosition += Velocity * DT
                            
PostPhysics:
   USteeringTrailProcessor: Steering 修正(避免穿墙)
```

## 20.3.3 Steering Behavior

经典 Steering(Craig Reynolds):
- **Seek**:朝目标
- **Flee**:远离
- **Arrive**:到目标减速
- **Separation**:与邻居保持距离(避撞挤一起)
- **Alignment**:对齐邻居方向
- **Cohesion**:向邻居中心靠拢
- **Pursue**:预测目标位置追

UE 自带 `UMassSteeringProcessor` 实现部分。自定义 Processor 加更多。

## 20.3.4 RTS 编队

```cpp
class URTSFormationProcessor : public UMassProcessor
{
    void Execute(...) override
    {
        Query.ForEachEntityChunk(...) [&](...)
        {
            // 取每 entity 在编队中的偏移
            const auto Formations = Ctx.GetFragmentView<FFormationFragment>();
            const auto Transforms = Ctx.GetFragmentView<FMassTransformFragment>();
            auto MoveTargets = Ctx.GetMutableFragmentView<FMassMoveTargetFragment>();
            
            for entity:
                FVector AnchorLoc = GetSquadAnchor(Formations[i].SquadID);
                FVector OffsetInFormation = Formations[i].Offset;
                
                // 设个体目标 = 锚点 + 偏移
                MoveTargets[i].Center = AnchorLoc + OffsetInFormation;
        });
    }
};
```

## 20.3.5 物理 vs 自定义 Mover

Mass entity **不参与 Chaos 物理**(物理 body 太重)。Movement Processor 自己积分位置 + 简单 capsule overlap query。

碰撞:用 `URTSSpatialIndexSubsystem`(自建 octree)替代物理引擎。
