## 26.4.2 Iris filter 用 Spatial Index

```cpp
class FRTSIrisFilter : public UNetObjectFilter
{
    URTSSpatialIndexSubsystem* SI;
    
    virtual bool IsObjectVisibleForConnection(...) override
    {
        FVector EntityLoc = GetEntityLocation(NetObject);
        FVector PlayerLoc = GetPlayerLocation(Connection);
        
        return FVector::Distance(EntityLoc, PlayerLoc) < BubbleRadius;
    }
};
```

或更激进:`IsObjectVisible` 调用 `SI->QueryRadius` 一次性算所有 entity 可见性。

## 26.4.3 自定义 ReplicationProcessor

```cpp
class URTSReplicationProcessor : public UMassProcessor
{
    void Execute(...) override
    {
        Query.ForEachEntityChunk(...) [&](FMassExecutionContext& Ctx)
        {
            // 量化 + push to Iris
            for entity in chunk:
                if (HasDirtyState(entity))
                    PushToIris(entity, QuantizedState);
        });
    }
};
```

## 26.4.4 总览图

```
[Server Mass tick]
   ↓ 每 entity 状态变化
URTSSpatialIndexSubsystem 更新 Grid
   ↓
URTSReplicationProcessor 扫 dirty
   ↓ 量化字段
Iris ReplicationSystem
   ├─ FRTSIrisFilter:每 connection × 每 entity 决定可见性
   ├─ Pri / Bandwidth budget
   ├─ Serialize
   └─ 发包
   ↓ 网络
[Client]
Iris 接收 → 更新本地 EntityView
   ↓
Mass tick(client side)→ Representation 渲染
```
