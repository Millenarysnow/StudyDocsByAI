## 25.2.2 GPU Scene

UE 5.x 的 GPU Scene 把所有 mesh primitive 统一管理:
- 每帧 GameThread 把变化的 instance transform 上传到 GPU
- GPU 端有"Primitive Buffer"(每 primitive 一项)+ "Instance Buffer"(每 instance 一项)
- Vertex Shader 读 InstanceID 索引数据

**渲染时**:GPU instancing,1 个 DrawCall 出 N 个 instance。

## 25.2.4 ISMC vs HISMC 选型

```
ISMC:
   ✓ 简单
   ✓ 适合中等数量(< 5000)
   ✓ instance 可变(add/remove/update 频繁)
   
HISMC:
   ✓ 大数量(> 5000)
   ✓ 自动 cluster + LOD
   ✗ Add/Remove 慢(要重建 cluster)
   ✗ 适合"变化不频繁"
```

RTS 50K 单位**频繁移动 + spawn / die** → 倾向 ISMC + 自己分组。

## 25.2.5 RTS ISMC 池

```cpp
class URTSISMCPool : public UWorldSubsystem
{
    // 每种 mesh 一个 ISMC
    TMap<UStaticMesh*, TObjectPtr<UInstancedStaticMeshComponent>> MeshToISMC;
    
public:
    int32 AcquireInstance(UStaticMesh* Mesh, const FTransform& T)
    {
        UInstancedStaticMeshComponent* ISMC = MeshToISMC.FindOrAdd(Mesh);
        if (!ISMC) {
            ISMC = NewObject<UInstancedStaticMeshComponent>(...);
            ISMC->SetStaticMesh(Mesh);
            ISMC->RegisterComponent();
            MeshToISMC[Mesh] = ISMC;
        }
        return ISMC->AddInstance(T);
    }
    
    void UpdateInstance(UStaticMesh* M, int32 Index, const FTransform& T)
    {
        if (auto* ISMC = MeshToISMC.FindRef(M))
            ISMC->UpdateInstanceTransform(Index, T, /*bWorldSpace*/ true, /*bMarkRenderStateDirty*/ false);
    }
    
    void RemoveInstance(UStaticMesh* M, int32 Index);
    
    void FlushUpdates()
    {
        // 每帧末尾批量 mark dirty(避免每 update 一次)
        for (auto& [Mesh, ISMC] : MeshToISMC)
            ISMC->MarkRenderStateDirty();
    }
};
```
