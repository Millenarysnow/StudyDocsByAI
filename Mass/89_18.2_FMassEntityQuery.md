# §18.2 FMassEntityQuery 过滤详解

> **本节地图**:模块四第 18 章第 2 节。Query 是 Processor 的"数据筛选器" — 决定该 Processor 处理哪些 entity。
>
> **预备知识**:§17.6 BitSet。
>
> **读完之后你能做到**:
> - 用 AddRequirement / AddTagRequirement 写完整 Query
> - 区分 ReadOnly / ReadWrite 访问
> - 区分 All / Any / None / Optional 出现性

---

## 18.2.1 Query 的两种 Add API

```cpp
// Fragment(数据)
Query.AddRequirement<FFragmentT>(EMassFragmentAccess::ReadWrite);
Query.AddRequirement<FFragmentT>(EMassFragmentAccess::ReadOnly);

// Tag(无数据,纯标记)
Query.AddTagRequirement<FTagT>(EMassFragmentPresence::All);    // 必须有
Query.AddTagRequirement<FTagT>(EMassFragmentPresence::None);   // 不能有
Query.AddTagRequirement<FTagT>(EMassFragmentPresence::Any);    // 可有可无
```

---

## 18.2.2 EMassFragmentAccess

```cpp
enum class EMassFragmentAccess : uint8
{
    None,
    ReadOnly,        // 只读(允许多 Processor 同时读)
    ReadWrite,       // 读写(独占,Mass 自动检测冲突)
};
```

**纪律**:**只读时一定标 ReadOnly**。允许 Processor 间并行。

---

## 18.2.3 EMassFragmentPresence

```cpp
enum class EMassFragmentPresence : uint8
{
    All,        // 必须有(Required)
    Any,        // 至少有一个(Optional in group)
    None,       // 不能有(Excluded)
    Optional,   // 可有可无,但若有可访问
};
```

---

## 18.2.4 实战 Query 写法

```cpp
void URTSCombatProcessor::ConfigureQueries(...)
{
    // 读写 Fragment
    Query.AddRequirement<FMassPositionFragment>(EMassFragmentAccess::ReadOnly);
    Query.AddRequirement<FUnitHealthFragment>(EMassFragmentAccess::ReadWrite);
    Query.AddRequirement<FUnitDamageFragment>(EMassFragmentAccess::ReadOnly);
    
    // 必须有的 Tag
    Query.AddTagRequirement<FActiveTag>(EMassFragmentPresence::All);
    
    // 不能有的 Tag(死了的不处理)
    Query.AddTagRequirement<FDeadTag>(EMassFragmentPresence::None);
    Query.AddTagRequirement<FStunnedTag>(EMassFragmentPresence::None);
    
    // 可选 Fragment(若 entity 有,允许访问)
    Query.AddRequirement<FBurnEffectFragment>(EMassFragmentAccess::ReadWrite, EMassFragmentPresence::Optional);
    
    Query.RegisterWithProcessor(*this);
}
```

## 18.2.6 Query 的执行

```cpp
void URTSCombatProcessor::Execute(FMassEntityManager& EM, FMassExecutionContext& Ctx)
{
    Query.ForEachEntityChunk(EM, Ctx, [&](FMassExecutionContext& InCtx)
    {
        // 这里处理本 chunk
        const auto Positions = InCtx.GetFragmentView<FMassPositionFragment>();
        auto Healths = InCtx.GetMutableFragmentView<FUnitHealthFragment>();
        const auto Damages = InCtx.GetFragmentView<FUnitDamageFragment>();
        
        // ConstSharedFragment 一个实例
        const FUnitTypeStats& Stats = InCtx.GetConstSharedFragment<FUnitTypeStats>();
        
        // Optional Fragment(检查是否有)
        TArrayView<FBurnEffectFragment> BurnEffects;
        if (InCtx.HasFragment<FBurnEffectFragment>())
            BurnEffects = InCtx.GetMutableFragmentView<FBurnEffectFragment>();
        
        // 处理
        const int32 N = InCtx.GetNumEntities();
        for (int32 i = 0; i < N; ++i)
        {
            // 战斗逻辑
        }
    });
}
```

## 18.2.7 多 Query 一个 Processor

一个 Processor 可有**多个 Query**,处理不同的 archetype 集:

```cpp
class URTSDamageProcessor : public UMassProcessor
{
    FMassEntityQuery LivingQuery;     // 活的
    FMassEntityQuery DeadQuery;       // 死的
    
    virtual void ConfigureQueries(...) override
    {
        LivingQuery.AddRequirement<FUnitHealthFragment>(EMassFragmentAccess::ReadWrite);
        LivingQuery.AddTagRequirement<FActiveTag>(EMassFragmentPresence::All);
        LivingQuery.RegisterWithProcessor(*this);
        
        DeadQuery.AddRequirement<FUnitHealthFragment>(EMassFragmentAccess::ReadOnly);
        DeadQuery.AddTagRequirement<FDeadTag>(EMassFragmentPresence::All);
        DeadQuery.RegisterWithProcessor(*this);
    }
    
    virtual void Execute(...) override
    {
        LivingQuery.ForEachEntityChunk(EM, Ctx, [](...) { /* 处理活 */ });
        DeadQuery.ForEachEntityChunk(EM, Ctx, [](...) { /* 处理死,如倒计时移除 */ });
    }
};
```
