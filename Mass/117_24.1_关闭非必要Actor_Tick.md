# §24.1 关闭非必要 Actor 的 PrimaryActorTick

> **本节地图**:模块五第 24 章第 1 节。Mass 接管大部分 Tick 后,**Actor Tick 应该被严格收窄**。这一节看具体纪律。
>
> **预备知识**:§8.3 / §8.5。
>
> **读完之后你能做到**:
> - 给 RTS 项目设定 Tick 关闭原则
> - 用 cvar 全局监控 Tick 数量

---

## 24.1.1 关闭原则

```
默认:
   - PrimaryActorTick.bCanEverTick = false
   - PrimaryComponentTick.bCanEverTick = false

仅在以下场景启用:
   ✓ 玩家 PC(处理输入帧)
   ✓ 玩家 CameraPawn(相机平滑插值)
   ✓ 重要 Hero(动画状态机更新)
   ✓ 关键 Subsystem(战斗 / 雾战已用 UTickableWorldSubsystem)

不启用:
   ✗ 关卡装饰物(地面 mesh)
   ✗ 资源点(用 Mass entity 或 Subsystem 检测)
   ✗ 大量 spawn 的小 actor(改 Mass)
   ✗ Trigger Volume(响应 BeginOverlap 即可,不需 tick)
```

---

## 24.1.2 默认配置

```cpp
UCLASS()
class ARTSBuildingActor : public AActor
{
    ARTSBuildingActor()
    {
        PrimaryActorTick.bCanEverTick = false;     // ★ 默认关
        // 仅在需要时(状态变化)主动开
    }
};
```

UE base AActor 默认 `bCanEverTick = false`,但**很多模板代码**(BP 默认创建的 Actor)开了。**审查每个新 Actor**。

## 24.1.3 Tick 监控 cvar

```cpp
// 启动加 cvar
DumpTicks
```

输出当前 World 所有 TickFunction:

```
TickFunctions: 156
   AActor PrimaryTick: 50
   UActorComponent PrimaryTick: 100
   By TickGroup:
      PrePhysics: 80
      ...
```

**RTS 健康项目 < 200 ticks**。> 1000 警惕,> 5000 已坏。

## 24.1.4 自定义"全 actor Tick 检查"

```cpp
static FAutoConsoleCommand CmdAuditTicks(TEXT("rts.AuditTicks"),
    TEXT("Audit which actors have ticking"),
    FConsoleCommandDelegate::CreateLambda([]()
    {
        TMap<UClass*, int32> TickCounts;
        for (TActorIterator<AActor> It(GWorld); It; ++It)
        {
            if (It->PrimaryActorTick.IsTickFunctionEnabled())
            {
                TickCounts.FindOrAdd(It->GetClass())++;
            }
        }
        
        // 排序输出
        TickCounts.ValueSort([](int32 A, int32 B) { return A > B; });
        for (const auto& Pair : TickCounts)
        {
            UE_LOG(LogTemp, Display, TEXT("  %s: %d ticking"),
                *Pair.Key->GetName(), Pair.Value);
        }
    }));
```

跑一次,看哪类 actor 占最多 tick。
