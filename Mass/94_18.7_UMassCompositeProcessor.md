# §18.7 UMassCompositeProcessor — Processor 组合

> **本节地图**:模块四第 18 章第 7 节。`UMassCompositeProcessor` 是"包含多个 Processor 的容器"。每 phase 自己一个 root composite,内部按 ExecutionOrder 排列子 Processor。
>
> **预备知识**:§18.5 / §18.6。

---

## 18.7.1 CompositeProcessor 是什么

`UMassCompositeProcessor` 是 `UMassProcessor` 子类,自身**不直接处理 entity**,而是**包含其它 Processor**:

```cpp
UCLASS()
class UMassCompositeProcessor : public UMassProcessor
{
    UPROPERTY()
    TArray<TObjectPtr<UMassProcessor>> ChildProcessors;
    
    virtual void Execute(...) override
    {
        // 按 DAG 顺序执行所有 child
        for (UMassProcessor* Child : ChildProcessors)
        {
            Child->Execute(EM, Ctx);
        }
    }
};
```

---

## 18.7.2 Phase 的 Composite

每 ProcessingPhase 有一个 root CompositeProcessor:

```
Phase = PrePhysics
   └─ CompositeProcessor_PrePhysics
         ├─ URTSCommandProcessor
         ├─ URTSAIProcessor
         ├─ URTSMovementProcessor
         └─ ...
```

`UMassSimulationSubsystem` 在 init 时:
1. 反射找所有 UMassProcessor 子类
2. 按 ProcessingPhase 分组
3. 每 phase 创建一个 Composite,加 child Processor
4. 按 DAG 排序 children

---

## 18.7.3 自定义 Composite(嵌套)

```cpp
UCLASS()
class URTSCombatComposite : public UMassCompositeProcessor
{
    URTSCombatComposite()
    {
        // 自动包含一组相关 Processor
        ChildProcessors.Add(URTSDamageProcessor::StaticClass());
        ChildProcessors.Add(URTSDeathProcessor::StaticClass());
        // ...
    }
};
```

可以**嵌套** Composite,实现层级化分组。
