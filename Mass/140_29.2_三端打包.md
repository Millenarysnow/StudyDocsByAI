## 29.2.1 三种 Target 类型

```
*.Target.cs:

UnrealGame:    standalone client(单机或客户端)
UnrealServer:  Dedicated Server(无渲染、无音频、纯逻辑)
UnrealClient:  纯 client(连接 DS,无 ListenServer 能力)
```

---

## 29.2.2 配置 Target.cs

```csharp
// MyGameClient.Target.cs
public class MyGameClientTarget : TargetRules
{
    public MyGameClientTarget(TargetInfo Target) : base(Target)
    {
        Type = TargetType.Client;
        ExtraModuleNames.AddRange(new[] { "MyGame" });
    }
}

// MyGameServer.Target.cs
public class MyGameServerTarget : TargetRules
{
    public MyGameServerTarget(TargetInfo Target) : base(Target)
    {
        Type = TargetType.Server;
        ExtraModuleNames.AddRange(new[] { "MyGame" });
    }
}
```

## 29.2.3 Server 优化

```
DS 不需要:
   - SkeletalMesh 渲染数据(去掉)
   - Niagara / Particle(关掉模拟)
   - Texture / Audio(全去)
   - Editor 模块

Server cook 配置(DefaultEngine.ini):
   [/Script/UnrealEd.ProjectPackagingSettings]
   CookAllMaps=False
   ServerOnly=True

DS 内存:
   - 50K Mass 单位 ≈ 12.8 MB
   - GameState / 玩家数据 ≈ 几十 MB
   - 一台 DS 跑 1 局战斗 ≈ 200-500 MB(VS Editor build 几 GB,瘦 10 倍)

DS CPU:
   - 单局 8 玩家 = 1 个 DS 进程
   - 一台 32 核服务器跑 16-32 局 = 容量
```

## 29.2.4 BuildCookRun 三端命令

```
# Server
RunUAT BuildCookRun -project=... -platform=Linux \
   -serverconfig=Shipping -cook -stage -package \
   -server -noclient -build

# Client
RunUAT BuildCookRun -project=... -platform=Win64 \
   -clientconfig=Shipping -cook -stage -package \
   -client -noserver
```
