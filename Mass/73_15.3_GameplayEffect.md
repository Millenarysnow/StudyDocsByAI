# §15.3 GameplayEffect 的 Modifier / Executions / Calculations 三层

> **本节地图**:模块三第 15 章第 3 节。GameplayEffect(GE)是 GAS 的核心 — 它表达"对 Attribute 的修改"。任何 buff / debuff / 伤害 / 治疗都是 GE。
>
> **预备知识**:§15.2。
>
> **读完之后你能做到**:
> - 写一个简单 GE(Instant 伤害)
> - 用 Modifier 表达 Add / Multiply
> - 区分 Instant / Duration / Infinite

---

## 15.3.1 GE 的三种 DurationPolicy

```cpp
enum EGameplayEffectDurationType
{
    Instant,        // 一次性应用,改 BaseValue(永久)
    HasDuration,    // 持续 N 秒(buff/debuff,期间改 CurrentValue)
    Infinite,       // 无限期(光环,需要主动移除)
};
```

实战:
- 伤害:Instant("减 50 Health")
- buff:HasDuration("Attack +20 持续 10 秒")
- 光环:Infinite(在 buff aura 范围内 +10 Defense)

## 15.3.2 Modifier(直接修改)

```cpp
// 一个 GE 可以有多个 Modifier
struct FGameplayModifierInfo
{
    FGameplayAttribute Attribute;       // 目标 attribute
    EGameplayModOp::Type ModifierOp;     // Add / Multiply / Override
    FGameplayEffectModifierMagnitude ModifierMagnitude;  // 数值(可固定 / 可配置)
};

enum EGameplayModOp::Type
{
    Additive,      // +N
    Multiplicitive, // ×N
    Division,      // /N
    Override,      // = N
};
```

实战:**伤害 GE**:
```
Modifiers:
   - Attribute: Health, Op: Additive, Magnitude: -50  ← 减 50 血
```

**buff GE**(攻击力 +20%):
```
Modifiers:
   - Attribute: AttackPower, Op: Multiplicitive, Magnitude: 1.2
DurationPolicy: HasDuration, Duration: 10 秒
```

## 15.3.3 Executions(自定义计算逻辑)

复杂伤害公式:

```cpp
UCLASS()
class URTSDamageExecution : public UGameplayEffectExecutionCalculation
{
    virtual void Execute_Implementation(const FGameplayEffectCustomExecutionParameters& Params, ...) const override
    {
        // 复杂公式:
        // 最终伤害 = 基础攻击 × (1 - 防御% / 100) × 暴击倍率 × 元素抗性
        
        float BaseAttack = ...;
        float Defense = ...;
        // ...
        
        float Damage = BaseAttack * (1 - Defense / 100) * CritMult * ElementResist;
        
        // 输出 Modifier
        OutExecutionOutput.AddOutputModifier(
            FGameplayModifierEvaluatedData(
                URTSHeroAttributeSet::GetHealthAttribute(),
                EGameplayModOp::Additive,
                -Damage));
    }
};
```

## 15.3.4 Calculations / ModifierMagnitude

`FGameplayEffectModifierMagnitude` 可以是:
- **ScalableFloat**(策划配的曲线,等级影响)
- **AttributeBased**(基于其它 attribute)
- **CustomCalculationClass**(完全自定义)

```cpp
// 例:伤害基于角色等级
ModifierMagnitude = ScalableFloat(等级曲线)  // Lv1=10, Lv5=30, ...
```

## 15.3.5 应用 GE

```cpp
// 创建 GE Spec
FGameplayEffectContextHandle Ctx = ASC_Source->MakeEffectContext();
FGameplayEffectSpecHandle Spec = ASC_Source->MakeOutgoingSpec(GE_Damage, /*Level*/ 1, Ctx);

// 应用到目标 ASC
ASC_Target->ApplyGameplayEffectSpecToSelf(*Spec.Data.Get());
```
