## 19.3.3 自定义 RTS Trait 示例

```cpp
UCLASS(Meta = (DisplayName = "RTS Combat Trait"))
class URTSCombatTrait : public UMassEntityTraitBase
{
    GENERATED_BODY()
    
    UPROPERTY(EditAnywhere, Category="Combat")
    int32 BaseHealth = 100;
    
    UPROPERTY(EditAnywhere, Category="Combat")
    int32 BaseDamage = 10;
    
    UPROPERTY(EditAnywhere, Category="Combat")
    float AttackRange = 200.0f;
    
    UPROPERTY(EditAnywhere, Category="Combat")
    float AttackCooldown = 1.5f;
    
    virtual void BuildTemplate(FMassEntityTemplateBuildContext& BuildContext, 
                                const UWorld& World) const override
    {
        BuildContext.AddFragment<FUnitHealthFragment>(FUnitHealthFragment{ BaseHealth, BaseHealth });
        BuildContext.AddFragment<FUnitDamageFragment>(FUnitDamageFragment{ BaseDamage });
        BuildContext.AddFragment<FUnitAttackFragment>(FUnitAttackFragment{ AttackRange, AttackCooldown, 0 });
        BuildContext.AddTag<FActiveTag>();
    }
};
```

## 19.3.4 Trait 排序

Trait 之间可有依赖(Trait B 需要 Trait A 提供的 Fragment)。Mass 编译 Template 时按**注册顺序**走 BuildTemplate。

```
DA_Soldier 中 Trait 顺序:
   1. MassMovementTrait     (基础 Velocity)
   2. URTSCombatTrait        (Combat 数据)
   3. URTSAggroTrait         (依赖 Combat 数据)
```

Trait 顺序错了 → Aggro 找不到 Health → 报错或行为异常。
