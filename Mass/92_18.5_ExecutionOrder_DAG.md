# §18.5 ExecutionOrder — Before / After / ExecuteInGroup 自动 DAG 构建

## 18.5.1 ExecutionOrder 字段

```cpp
USTRUCT()
struct FMassProcessorExecutionOrder
{
    UPROPERTY(EditAnywhere, Category = "Order")
    FName ExecuteInGroup;        // 我属于哪个组
    
    UPROPERTY(EditAnywhere, Category = "Order")
    TArray<FName> ExecuteBefore;  // 我必须在这些 Processor / Group 之前
    
    UPROPERTY(EditAnywhere, Category = "Order")
    TArray<FName> ExecuteAfter;   // 我必须在这些之后
};
```

---

## 18.5.2 用法示例

```cpp
class URTSCommandProcessor : public UMassProcessor
{
    URTSCommandProcessor()
    {
        ProcessingPhase = EMassProcessingPhase::PrePhysics;
        
        // 我属于 Command 组(便于其它 Processor 引用)
        ExecutionOrder.ExecuteInGroup = TEXT("Command");
        
        // 我必须在 PlayerInputProcessor 之后
        ExecutionOrder.ExecuteAfter.Add(TEXT("PlayerInput"));
        
        // 我必须在 AI 组之前(AI 读我设的 goal)
        ExecutionOrder.ExecuteBefore.Add(TEXT("AI"));
    }
};
```

---

## 18.5.3 拓扑排序

Mass 启动时:
1. 收集所有 Processor 的 ExecutionOrder
2. 构造有向图(节点 = Processor,边 = before / after 关系)
3. 拓扑排序 → 线性执行序列
4. 检测循环依赖(报错)

---

## 18.5.4 RW 冲突自动检测

Mass 还**自动**根据 BitSet 检测:

```
Processor A:写 FPosition
Processor B:读 FPosition
```

→ A 必须在 B 之前(自动加约束),无需手动 ExecuteOrder。

但:**Processor A 写 vs Processor B 写**(同字段) → Mass 报错(明确你要排顺序)。
