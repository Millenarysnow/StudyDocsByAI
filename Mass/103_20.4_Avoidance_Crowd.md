# §20.4 Avoidance / Crowd — RVO 局部避障

> **本节地图**:模块四第 20 章第 4 节。50K 单位走在一起会**重叠**(没有物理碰撞)。需要"局部避障"让它们互相绕开。
>
> **预备知识**:§20.3 Movement。

---

## 20.4.1 RVO 算法

**RVO**(Reciprocal Velocity Obstacles):
- 每 entity 计算"如果继续当前 velocity,几秒后会撞谁"
- 调整 velocity 避免预测碰撞
- 假设其他 agent 也在做同样调整(互相预期)

UE 自带 `MassAvoidance` 模块实现 RVO 类算法。

---

## 20.4.2 启用

加 Trait:
```
DA_Soldier:
   - UMassMovementTrait
   - UMassAvoidanceTrait     ← RVO 避障
```

每 entity 加 `FMassAvoidanceFragment` 等。

`UMassAvoidanceProcessor` 在 PostPhysics 跑,调整 velocity。

---

## 20.4.3 Crowd 模式

UE 也有 `MassCrowd`(群体)模块:
- 流场寻路(Flow Field)
- 人群密度感知
- 适合"几千人挤一个广场"场景

---

## 20.4.4 RTS 实战

```
小规模(~100 单位):
   ✓ RVO 局部避障,流畅
   
中规模(~1000 单位):
   ✓ RVO + 编队减少冲突
   
大规模(50K):
   ✓ RVO + 流场寻路 + LOD(远的 entity 关闭 RVO)
   或 简化:仅近 LOD entity 走 RVO,远 LOD 直接走线
```

---

## 20.4.5 性能

```
RVO 50K entity:
   每 entity 检测半径内 ~10 邻居 → 50K × 10 = 500K 操作 / 帧
   ~3-5 ms / 帧(并行)

可接受。但**远 LOD entity 关闭 RVO**(不计算)进一步省。
```
