## 11.3.1 `UMassEntitySubsystem` 是范例

`UMassEntitySubsystem`(`Engine/Source/Runtime/MassEntity/Public/MassEntitySubsystem.h`)是 `UWorldSubsystem`,UE 自家用法的"标准模板":

```cpp
class UMassEntitySubsystem : public UWorldSubsystem
{
public:
    virtual void Initialize(FSubsystemCollectionBase& Collection) override
    {
        Super::Initialize(Collection);
        
        // 创建 EntityManager(数据中枢)
        EntityManager = MakeShared<FMassEntityManager>(this);
        EntityManager->Initialize();
    }
    
    virtual void Deinitialize() override
    {
        EntityManager->Reset();
        EntityManager.Reset();
        Super::Deinitialize();
    }
    
    FMassEntityManager& GetMutableEntityManager() { return *EntityManager; }
    const FMassEntityManager& GetEntityManager() const { return *EntityManager; }

private:
    TSharedPtr<FMassEntityManager> EntityManager;
};
```

注意几点:
- **Subsystem 仅"持有"数据**,真正逻辑在 `FMassEntityManager`(非 UObject)
- Initialize 时创建 manager,Deinitialize 时销毁
- 提供 `GetMutableEntityManager` / `GetEntityManager` 访问

## 11.3.2 RTS 自定义 Subsystem 的范式

模仿 UMassEntitySubsystem 的设计:

```cpp
// 头文件
UCLASS()
class URTSCombatSubsystem : public UWorldSubsystem
{
    GENERATED_BODY()
public:
    virtual void Initialize(FSubsystemCollectionBase& Collection) override;
    virtual void Deinitialize() override;
    virtual bool ShouldCreateSubsystem(UObject* Outer) const override;
    
    // 接口
    void RegisterUnitDamage(FMassEntityHandle Entity, float Damage);
    
    DECLARE_MULTICAST_DELEGATE_OneParam(FOnUnitKilled, FMassEntityHandle);
    FOnUnitKilled OnUnitKilled;
    
private:
    TSharedPtr<FRTSCombatTracker> Tracker;   // 非 UObject 的数据/逻辑
    
    UPROPERTY()
    TObjectPtr<UMassEntitySubsystem> CachedMassSubsystem;
};

// 实现
void URTSCombatSubsystem::Initialize(FSubsystemCollectionBase& Collection)
{
    // 依赖 Mass(必须先 Init)
    Collection.InitializeDependency(UMassEntitySubsystem::StaticClass());
    
    Super::Initialize(Collection);
    
    Tracker = MakeShared<FRTSCombatTracker>();
    
    // 缓存 Mass Subsystem
    CachedMassSubsystem = GetWorld()->GetSubsystem<UMassEntitySubsystem>();
}

void URTSCombatSubsystem::Deinitialize()
{
    Tracker.Reset();
    Super::Deinitialize();
}

bool URTSCombatSubsystem::ShouldCreateSubsystem(UObject* Outer) const
{
    UWorld* W = Cast<UWorld>(Outer);
    if (!W || !W->IsGameWorld()) return false;
    
    // 仅 server(客户端不需要 Combat tracker)
    return W->GetNetMode() != NM_Client;
}
```

## 11.3.3 Mass Processor 调用 Subsystem

Mass Processor 内访问 Subsystem:

```cpp
class URTSCombatProcessor : public UMassProcessor
{
    UPROPERTY()
    TObjectPtr<URTSCombatSubsystem> CachedCombat;
    
    virtual void Initialize(UObject& Owner) override
    {
        Super::Initialize(Owner);
        
        UWorld* World = Cast<UWorld>(Owner.GetWorld());
        if (World)
        {
            CachedCombat = World->GetSubsystem<URTSCombatSubsystem>();
        }
    }
    
    virtual void Execute(FMassEntityManager& EntityManager, FMassExecutionContext& Context) override
    {
        EntityQuery.ForEachEntityChunk(EntityManager, Context, [this](FMassExecutionContext& Ctx)
        {
            // 处理 entity 战斗
            for (...) {
                if (HitDetected) {
                    CachedCombat->RegisterUnitDamage(Entity, Damage);
                }
            }
        });
    }
    
    FMassEntityQuery EntityQuery;
};
```

`UMassProcessor::Initialize` 是 Mass 框架的虚函数,Mass 启动时调。在这里缓存 Subsystem 指针。

## 11.3.4 Subsystem 调用 Mass

反方向:Subsystem 想操作 Mass entity:

```cpp
void URTSCommandSubsystem::EnqueueCommand(const FRTSCommand& Cmd)
{
    if (!CachedMassSubsystem) return;
    
    FMassEntityManager& EM = CachedMassSubsystem->GetMutableEntityManager();
    
    // 修改 entity Fragment
    for (FMassEntityHandle E : Cmd.Targets)
    {
        if (!EM.IsEntityValid(E)) continue;
        
        // 走命令缓冲(deferred,不直接改)
        EM.Defer().PushCommand<FMassDeferredSetCommand<FCommandQueueFragment>>(
            E, [&Cmd](FCommandQueueFragment& Frag)
            {
                Frag.Queue.Add(Cmd);
            });
    }
}
```

详细 Mass API §17 / §18 讲。这里关注 Subsystem ↔ Mass 接口模式:**Subsystem 持有 Mass Subsystem 引用,通过 EntityManager 操作**。

## 11.3.5 RTS 完整数据流

```
玩家鼠标点击
   ↓
ARTSPlayerController::OnCommand
   ↓
URTSSelectionSubsystem (LP)
   ↓
ARTSPlayerController::ServerIssueCommand RPC
   │
   ↓ (Server)
URTSCommandSubsystem (World)
   │ Enqueue 命令
   ↓
[Mass tick - PrePhysics]
URTSCommandProcessor::Execute
   │ 消费命令,改 FCommandQueueFragment
   ↓
[Mass tick - PrePhysics 之后]
URTSAIProcessor::Execute
   │ 读 FCommandQueueFragment,设 FMovementGoalFragment
   ↓
URTSMovementProcessor::Execute
   │ 读 FMovementGoalFragment,改 FTransformFragment
   ↓
URTSCombatProcessor::Execute
   │ 检测命中,调 URTSCombatSubsystem.RegisterUnitDamage
   ↓
URTSCombatSubsystem 收到伤害,触发 OnUnitKilled 委托
   ↓
其它 Subsystem 监听 OnUnitKilled:
   - URTSEconomySubsystem (server) → 给击杀奖励
   - URTSUIStateSubsystem (LP) → 显示击杀提示
   - 等等
```

每步在不同 Subsystem / Processor,职责清晰。**Subsystem 是协调中心,Mass 是工作引擎,Processor 是 Mass 内部逻辑**。

## 11.3.6 Subsystem ↔ Mass 通信模式总览

| 通信方向 | 模式 | 例子 |
|---|---|---|
| Subsystem → Mass | EntityManager.Defer() / 直接修改 | URTSCommandSubsystem 改 entity Fragment |
| Mass → Subsystem | 缓存 Subsystem 指针 + 直接调 | URTSCombatProcessor 调 CombatSubsystem |
| Subsystem ↔ Subsystem | MulticastDelegate 委托 | OnUnitKilled 多订阅者 |
| Subsystem → 玩家 UI | 委托广播 → UMG 监听 | 战斗结果显示 |
