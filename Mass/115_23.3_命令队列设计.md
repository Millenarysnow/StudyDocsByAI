# §23.3 单帧 vs 跨帧命令队列设计

> **本节地图**:模块五第 23 章第 3 节。命令缓冲的两种粒度。
>
> **预备知识**:§23.1 / §23.2。

## 23.3.1 全局 CommandSubsystem 命令队列

```cpp
class URTSCommandSubsystem : public UWorldSubsystem
{
    // 单帧入队的所有命令(MPSC,§5.4)
    TMpscQueue<FRTSCommand> IncomingCommands;
    
public:
    // server 端 RPC 接收命令
    void EnqueueCommand(int32 PlayerID, FRTSCommand Cmd)
    {
        IncomingCommands.Enqueue(MoveTemp(Cmd));
    }
    
    // 每帧 PrePhysics:Mass tick 之前 flush 命令
    void Tick(float DT)
    {
        FRTSCommand Cmd;
        while (IncomingCommands.Dequeue(Cmd))
        {
            ApplyCommandToEntities(Cmd);
        }
    }
};
```

**单帧粒度**:命令本帧到达,本帧应用到 entity FCommandQueueFragment。

## 23.3.2 Entity 层命令队列(跨帧)

```cpp
USTRUCT()
struct FMassCommandQueueFragment : public FMassFragment
{
    TArray<FRTSCommand, TFixedAllocator<8>> Queue;
    int32 CurrentIndex = 0;
};
```

**跨帧粒度**:entity 持有的命令列表,Processor 跨多帧执行(Move 命令到位后才进 next)。

---

## 23.3.3 两层关系

```
玩家发命令(Shift+Move)→ RPC → Server CommandSubsystem 入队
   ↓ (本帧 Mass tick 之前 flush)
   每个 entity 的 FMassCommandQueueFragment.Queue 添加该命令
   ↓ (Mass tick 期间)
   URTSCommandProcessor 读 Queue,根据 CurrentIndex 执行
   ↓ (命令完成,如到达目标位置)
   CurrentIndex++
   ↓ (跨多帧)
   下一命令开始执行
```

## 23.3.4 Shift+点击 = 加入队列

```cpp
void ARTSPlayerController::OnCommand(...)
{
    FRTSCommand Cmd = ...;
    Cmd.bQueue = IsShiftPressed();
    ServerIssueCommand(Cmd);
}
```

```cpp
// Server CommandSubsystem
void URTSCommandSubsystem::ApplyCommandToEntities(const FRTSCommand& Cmd)
{
    for (FMassEntityHandle E : Cmd.Targets)
    {
        FMassCommandQueueFragment& Q = EM.GetFragmentDataChecked<FMassCommandQueueFragment>(E);
        
        if (!Cmd.bQueue) {
            // 不加队列,清空当前 + 直接执行
            Q.Queue.Empty();
            Q.CurrentIndex = 0;
        }
        
        if (Q.Queue.Num() < 8) {     // 不超 capacity
            Q.Queue.Add(Cmd);
        }
    }
}
```
