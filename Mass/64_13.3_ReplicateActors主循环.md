## 13.3.1 浅入:每帧的"复制工作"

```cpp
// 简化:UNetDriver::ServerReplicateActors
int32 UNetDriver::ServerReplicateActors(float DeltaSeconds)
{
    SCOPE_CYCLE_COUNTER(STAT_NetServerRepActorsTime);
    
    // 1. 取所有 replicated actor 列表
    TArray<AActor*> Actors = GetAllRelevantActors();
    
    // 2. 对每个 connection,处理一遍
    for (UNetConnection* Conn : ClientConnections)
    {
        // 2.1 计算 actor 优先级 + relevancy
        TArray<FActorPriority> PrioritizedList = BuildPriorityList(Conn, Actors);
        
        // 2.2 按优先级遍历,直到 connection 带宽用完
        for (FActorPriority& Prio : PrioritizedList)
        {
            if (BandwidthUsed > Conn->CurrentNetSpeed) break;
            
            UActorChannel* Ch = GetOrCreateActorChannel(Conn, Prio.Actor);
            
            // 比较 + 复制 dirty
            int32 BitsSent = ReplicateActor(Ch);
            BandwidthUsed += BitsSent;
        }
    }
    
    return TotalBitsSent;
}
```

每个 client × 每个 actor × CmpAndCopy = 主开销。

## 13.3.2 优先级计算(`FActorPriority`)

```cpp
struct FActorPriority
{
    AActor* Actor;
    UActorChannel* Channel;
    int32 Priority;          // 越大越先发
};

float ARTSBuilding::GetNetPriority(...)
{
    // 默认:NetPriority * (1 / 距离)
    // 重写自定义:VIP actor 优先级高
    return NetPriority;
}
```

排序后,从 highest priority 开始发包,直到带宽用完。**低优先级 actor 这一帧不复制**。

`AActor::NetPriority`(默认 1.0):
- 玩家自己 Pawn → 3.0
- 重要 actor → 2.0
- 普通 → 1.0

## 13.3.3 NetUpdateFrequency

```cpp
// AActor 字段
float NetUpdateFrequency = 100;     // 默认 100 Hz
float MinNetUpdateFrequency = 2;    // 最低 2 Hz(无变化时)
```

每个 actor 不是每帧复制,按 frequency 节奏:

```cpp
if (TimeSinceLastReplicate < 1.0f / NetUpdateFrequency)
{
    skip;     // 还没到下次复制
}
```

**实战**:不重要 actor 调低(10-20Hz),省带宽。

---

## 13.3.4 NetCullDistanceSquared(距离剔除)

```cpp
float ANetCullDistanceSquared = 22500.0f * 22500.0f;   // 225m^2
```

actor 距离 viewer > 这个 → 不 relevant,不复制。

```cpp
bool AActor::IsNetRelevantFor(...)
{
    float DistSq = (Loc - SrcLocation).SizeSquared();
    return DistSq < NetCullDistanceSquared;
}
```

**实战**:RTS 关卡很大,设小 NetCullDistance(只复制玩家附近)+ 战争迷雾 → 少数 actor 实际复制。

## 13.3.5 带宽预算

每个 connection 有 `CurrentNetSpeed`(KB/s)。Server 每帧给该 connection 发的总字节数 ≤ NetSpeed / TickRate。

```cpp
// 默认
ConfiguredInternetSpeed = 10000;     // 10 KB/s
ConfiguredLanSpeed = 200000;          // 200 KB/s
```

可调,玩家网络好的 KB/s 高些。

### 13.3.5.1 RTS 估算

```
50K replicated actor + 10 client:
   每帧需要发送的总字节 = 巨大
   即使 NetSpeed = 1MB/s × 10 client = 10MB/s,远超
   实际带宽 = 单 actor 字段 × dirty 比例 × 复制频率
   
即使 99% 字段不变,1% dirty 也是 500 字段 × 几十字节 = 25KB/帧 × 10client = 250KB/帧 = 15MB/s
```

→ 必须自定义 + 量化 + 兴趣管理。详 §14。

## 13.3.6 完整流程图

```
ServerReplicateActors
   │
   ├─ 1. BuildConsiderList: 取所有 bReplicates 的 actor
   │
   ├─ 对每个 NetConnection:
   │   │
   │   ├─ 2. PrioritizeActors:
   │   │    - 计算 relevancy(IsNetRelevantFor)
   │   │    - 计算 priority(NetPriority * Distance)
   │   │    - 排序
   │   │
   │   ├─ 3. ReplicateActors:
   │   │    - 按 priority 遍历
   │   │    - 检查 NetUpdateFrequency
   │   │    - 获取 / 创建 ActorChannel
   │   │    - 调 RepLayout::CompareProperties → 找 dirty
   │   │    - 序列化 dirty 字段
   │   │    - 写入 connection 的 send buffer
   │   │
   │   └─ 直到 BandwidthUsed > NetSpeed,跳出
   │
   └─ 完成,返回总 bytes sent
```

每步都是 O(N) 或更高复杂度,N = actor 数。
