# §25.5 Niagara 系统作为表现层

> **本节地图**:模块五第 25 章第 5 节。某些 entity 用 Niagara 替代 ISMC 更优。
>
> **预备知识**:§25.4。

---

## 25.5.1 Niagara 适用场景

```
✓ 投射物(子弹、火箭) — 大量 + 简单 visual
✓ 群鸟 / 鱼群 — 不需精确控制
✓ 视觉特效(火焰、烟雾)
✓ Niagara 内 GPU sim 极致性能(数十万粒子)

✗ 需要精确游戏逻辑控制的单位 — 用 Mass + ISMC
✗ 需要 hit detection 的 entity — Niagara 检测不便
```

---

## 25.5.2 Mass + Niagara

```cpp
// Niagara System 通过 NiagaraComponent 引用
// 每 entity 不一定有 NiagaraComponent — 通常一个 system 跑数千粒子

// Mass Representation 路由到 Niagara:
class URTSProjectileRepProcessor : public UMassProcessor
{
    UNiagaraComponent* ProjectileEmitter;   // 整场战斗一个 emitter
    
    void Execute(...) override
    {
        // 收集所有 projectile entity 的位置 + 朝向
        TArray<FVector> Positions;
        TArray<FVector> Velocities;
        Query.ForEachEntityChunk(...) [&](FMassExecutionContext& Ctx) {
            for entity:
                Positions.Add(Transforms[i].GetLocation());
                Velocities.Add(Velocities[i]);
        });
        
        // 喂给 Niagara DataInterface(自定义)
        ProjectileEmitter->SetVariableArrayPosition(...);
    }
};
```

通过 Niagara `DataInterface` 把 entity 数据塞给 emitter。

---

## 25.5.3 Niagara 优劣

```
优势:
   - GPU sim,极致性能
   - 内置粒子物理
   - 内置 collision
   - 美术友好

劣势:
   - 与 game logic 同步麻烦(GPU 数据回 GameThread 慢)
   - hit detection / 关键字段不便
```
