# §24.2 Subsystem Tick 合理使用

> **本节地图**:模块五第 24 章第 2 节。Subsystem 不直接挂 TickGroup,但有自己的 tick 接口。
>
> **预备知识**:§7.5 UTickableWorldSubsystem。

---

## 24.2.1 三种 Subsystem Tick

```cpp
// 1. UTickableWorldSubsystem(自动每帧调)
class URTSFogOfWarSubsystem : public UTickableWorldSubsystem
{
    virtual void Tick(float DT) override { /* 每帧 */ }
};

// 2. 普通 UWorldSubsystem 注册自定义 TickFunction
class URTSCommandSubsystem : public UWorldSubsystem
{
    FTickFunction MyTickFunction;
    
    void Initialize(...) override {
        Super::Initialize(...);
        MyTickFunction.bCanEverTick = true;
        MyTickFunction.TickGroup = TG_PrePhysics;
        MyTickFunction.RegisterTickFunction(GetWorld()->PersistentLevel);
    }
};

// 3. FCoreDelegates::OnWorldTickStart 委托
class URTSDebugSubsystem : public UWorldSubsystem
{
    void OnWorldBeginPlay(UWorld& W) override {
        Super::OnWorldBeginPlay(W);
        FWorldDelegates::OnWorldTickStart.AddUObject(this, &ThisClass::OnTickStart);
    }
    void OnTickStart(UWorld* W, ELevelTick T, float DT) { /* 每 World tick */ }
};
```

---

## 24.2.2 选哪个

```
UTickableWorldSubsystem:
   ✓ 简单(只重写 Tick 即可)
   ✗ Tick 时机不可控(在 World->Tick 末尾,不属于具体 TickGroup)

自定义 FTickFunction + 注册到 TickGroup:
   ✓ 精确控制 TickGroup
   ✓ 可设 prerequisite(在某 actor 之后)
   ✗ 代码多

OnWorldTickStart 委托:
   ✓ 最早(World tick 之前)
   ✗ 仅一个固定时机
```

实战:**雾战 / 命令处理 → UTickableWorldSubsystem**(简单),**与 Mass 同步紧密的 → 自定义 TickFunction**。
