## 10.2.1 InputComponent Stack 的构造

每帧 `UPlayerInput::ProcessInputStack` 会构造一个 stack:

```
栈顶(先派发)
   ┌─────────────────────────────────┐
   │ PC.InputComponent                │  ← PC.SetupInputComponent 创建的
   ├─────────────────────────────────┤
   │ Pawn.InputComponent              │  ← Pawn.SetupPlayerInputComponent 创建的
   ├─────────────────────────────────┤
   │ Pawn 的 ChildActor 们的 IC      │
   └─────────────────────────────────┘
栈底(后派发)
```

事件按栈顶 → 栈底顺序派发。某层"消费"事件 → 后面不接收。

## 10.2.2 `BlockInput` —— 拦截后续

```cpp
// PC 内部 InputComponent
InputComponent->bBlockInput = true;
```

`bBlockInput == true` → 该 InputComponent 处理事件后,**不**让事件下传。

实战:打开 menu 时:

```cpp
void ARTSPlayerController::OnOpenMenu()
{
    // 创建一个临时 InputComponent 压栈
    UInputComponent* MenuIC = NewObject<UInputComponent>(this);
    MenuIC->BindAction("Confirm", IE_Pressed, this, &ThisClass::OnMenuConfirm);
    MenuIC->bBlockInput = true;    // 拦截
    
    // 加到 PC 的 InputStack(顶层)
    PushInputComponent(MenuIC);
    // 现在 game 输入(WASD)被拦截,只有 Confirm 键有效
}

void ARTSPlayerController::OnCloseMenu()
{
    PopInputComponent(MenuIC);    // 恢复 game 输入
}
```

`PushInputComponent` / `PopInputComponent` 是 PC 的方法。

## 10.2.3 InputComponent 优先级

### 10.2.3.1 默认优先级

PC > Pawn > 其它(子 component)

### 10.2.3.2 优先级 hint(InputComponent.Priority)

```cpp
InputComponent->Priority = 10;     // 数字大,越靠近栈顶
```

`UInputComponent::Priority` 字段允许微调。

---

## 10.2.4 `EnableInput` / `DisableInput`(Actor 层)

任何 Actor 想接收输入,可以:

```cpp
// 在 Actor::BeginPlay
EnableInput(GetWorld()->GetFirstPlayerController());
// 之后该 Actor 的 InputComponent 进 PC 的 stack
```

但**这种方式滥用会让 InputComponent stack 失控**(几十个 actor 都监听 input)。**纪律**:仅 PC 和当前 Pawn 监听 input,其它 Actor 通过 SubsystemDelegate 通信。

## 10.2.5 实操与下一节预告

### 实操

```cpp
// 看当前 InputComponent stack
static FAutoConsoleCommand CmdShowInputStack(TEXT("rts.ShowInputStack"),
    TEXT("Show current InputComponent stack"),
    FConsoleCommandDelegate::CreateLambda([]()
    {
        APlayerController* PC = GWorld->GetFirstPlayerController();
        if (!PC) return;
        
        UE_LOG(LogTemp, Display, TEXT("PC.InputComponent: %s,bBlockInput=%d"),
            PC->InputComponent ? *PC->InputComponent->GetName() : TEXT("null"),
            PC->InputComponent ? PC->InputComponent->bBlockInput : 0);
        
        if (PC->GetPawn() && PC->GetPawn()->InputComponent)
        {
            UE_LOG(LogTemp, Display, TEXT("Pawn.InputComponent: %s"),
                *PC->GetPawn()->InputComponent->GetName());
        }
    }));
```
