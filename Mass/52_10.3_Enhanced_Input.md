## 10.3.1 浅入:Enhanced Input 解决了什么

旧系统(`InputComponent::BindAction("Jump", IE_Pressed, ...)`)的痛点:
- ActionName 是 FName 字符串,没类型安全
- 无法表达"双击"、"长按 0.5s"等复杂输入
- 无法运行时切换映射(玩家一种模式映射变了)
- 死区 / 灵敏度 都要手动算

Enhanced Input 解决:
- **InputAction 是 UDataAsset**(类型安全 + Editor 编辑)
- **InputModifier**(死区、灵敏度、变换值)
- **InputTrigger**(双击 / 长按 / 同时按多键)
- **InputMappingContext**(动态切换映射)

---

## 10.3.2 四个核心概念

```
[输入硬件]
   ↓
InputMappingContext (UDataAsset)
   ├─ InputAction "Jump" ← Key "Space"
   │     ├─ Modifier: Smooth
   │     └─ Trigger: Pressed (默认)
   ├─ InputAction "Move" ← Key "WASD"(2D Axis)
   │     ├─ Modifier: SwizzleAxis (XY → YX)
   │     └─ Trigger: Down
   └─ InputAction "Sprint" ← Key "Shift"
         └─ Trigger: Hold (0.3s)
   ↓
[Enhanced Input 处理]
   ↓
你的回调被调
```

### 10.3.2.1 InputAction

```cpp
// IA_Move.uasset(UDataAsset 资产)
UCLASS()
class UInputAction : public UDataAsset
{
public:
    EInputActionValueType ValueType;    // Bool / Axis1D / Axis2D / Axis3D
    EConsumeInput ConsumeInput;
    bool bTriggerWhenPaused;
    // ...
};
```

`ValueType`:
- `Bool` — 按下 / 释放(Jump 等)
- `Axis1D` — 单轴值(Throttle 等)
- `Axis2D` — 双轴值(WASD 移动 / 摇杆)
- `Axis3D` — 三轴值(罕见)

### 10.3.2.2 InputMappingContext

```cpp
UCLASS()
class UInputMappingContext : public UDataAsset
{
    TArray<FEnhancedActionKeyMapping> Mappings;
};

// 每个 Mapping 是 (Key, InputAction) 的配对
struct FEnhancedActionKeyMapping
{
    FKey Key;                                    // "Space" / "W" / "MouseButtonLeft"
    TObjectPtr<const UInputAction> Action;      // IA_Jump
    TArray<TObjectPtr<UInputModifier>> Modifiers;
    TArray<TObjectPtr<UInputTrigger>> Triggers;
};
```

一个 Context 是一组 (Key, Action) 映射。可同时加载多个 Context(以优先级叠加)。

### 10.3.2.3 InputModifier(变换值)

变换"原始 input"成你想要的:

```
Modifier 例子:
   - Negate              ← Y 翻转(WASD 中 S 是负 Y)
   - SwizzleAxis         ← XY 互换
   - ScalarMultiplier    ← 灵敏度
   - DeadZone            ← 死区(摇杆中心一段无输入)
   - Smooth              ← 平滑(防抖)
```

每个 Modifier 是一个 UClass,可继承自定义。

### 10.3.2.4 InputTrigger(触发条件)

```
Trigger 例子:
   - Pressed             ← 按下瞬间
   - Released            ← 释放瞬间
   - Down                ← 持续按下
   - Hold(0.3s)          ← 长按 0.3 秒后才触发
   - Tap(0.2s)           ← 0.2 秒内按下并释放(双击的基础)
   - Combo               ← 连续按多键
   - ChordAction          ← 多键同时按
```

## 10.3.3 完整设置流程

### 步骤 1:创建 UInputAction 资产

Editor 里:
```
Content Browser → Right click → Input → Input Action
   命名:IA_Move
   ValueType: Axis2D
```

### 步骤 2:创建 UInputMappingContext 资产

```
Content Browser → Right click → Input → Input Mapping Context
   命名:IMC_RTSGameplay
   
打开 IMC,加 Mapping:
   IA_Move (Axis2D)
      Key: W → Modifier: Swizzle (X to Y)
      Key: S → Modifier: Swizzle + Negate
      Key: A → Modifier: Negate
      Key: D
   IA_Select (Bool)
      Key: MouseLeft → Trigger: Pressed
   IA_Command (Bool)
      Key: MouseRight → Trigger: Pressed
```

### 步骤 3:在 PC / Pawn 注册 Context

```cpp
void ARTSPlayerController::BeginPlay()
{
    Super::BeginPlay();
    
    if (UEnhancedInputLocalPlayerSubsystem* Subsystem = 
        ULocalPlayer::GetSubsystem<UEnhancedInputLocalPlayerSubsystem>(GetLocalPlayer()))
    {
        // 加载 Context(从 BP 配置或硬编码)
        Subsystem->AddMappingContext(IMC_Gameplay, /*Priority*/ 0);
    }
}
```

### 步骤 4:绑定 Action

```cpp
// PC 或 Pawn(典型 Pawn)
void ARTSCameraPawn::SetupPlayerInputComponent(UInputComponent* PIC)
{
    Super::SetupPlayerInputComponent(PIC);
    
    if (UEnhancedInputComponent* EIC = Cast<UEnhancedInputComponent>(PIC))
    {
        EIC->BindAction(IA_Move, ETriggerEvent::Triggered, this, &ThisClass::HandleMove);
        EIC->BindAction(IA_Select, ETriggerEvent::Started, this, &ThisClass::HandleSelect);
    }
}

void ARTSCameraPawn::HandleMove(const FInputActionValue& Value)
{
    FVector2D Move = Value.Get<FVector2D>();    // (X, Y) ∈ [-1, 1]
    AddMovementInput(...);
}
```

`UEnhancedInputComponent` 是 InputComponent 的 Enhanced 子类。Project Settings → Input → 设默认 InputComponentClass 为 EnhancedInputComponent。

## 10.3.4 `ETriggerEvent` 枚举

```cpp
enum class ETriggerEvent : uint8
{
    None,
    Triggered,        // 触发条件满足(每帧)
    Started,          // 第一次开始触发
    Ongoing,          // 触发中(连续)
    Canceled,         // 被取消
    Completed,        // 完成(松开)
};
```

每种 Action 用对应的 Event:
- 按下瞬间 → `Started`
- 持续按 → `Triggered`(每帧)
- 松开 → `Completed`

## 10.3.5 多 Context 切换

```cpp
// 上下文切换(玩家进入战斗)
void ARTSPlayerController::EnterCombatMode()
{
    auto* Sub = GetLocalPlayer()->GetSubsystem<UEnhancedInputLocalPlayerSubsystem>();
    Sub->RemoveMappingContext(IMC_Menu);
    Sub->AddMappingContext(IMC_Combat, 0);
}

void ARTSPlayerController::EnterMenuMode()
{
    auto* Sub = GetLocalPlayer()->GetSubsystem<UEnhancedInputLocalPlayerSubsystem>();
    Sub->RemoveMappingContext(IMC_Combat);
    Sub->AddMappingContext(IMC_Menu, 0);
}
```

每种"模式"一个 IMC,切换无缝。

## 10.3.7 RTS 输入设计

```
RTS 上下文:
   IMC_Gameplay (主战场)
      ├─ IA_MoveCamera (Axis2D)   ← WASD
      ├─ IA_RotateCamera (Axis2D) ← 中键拖
      ├─ IA_Zoom (Axis1D)         ← 鼠标滚轮
      ├─ IA_Select (Bool)         ← 鼠标左键
      ├─ IA_Command (Bool)        ← 鼠标右键
      ├─ IA_BoxSelect (Bool)      ← 左键拖框选
      ├─ IA_AddSelect (Bool)      ← Shift+左键加选
      └─ IA_QueueCommand (Bool)   ← Shift+右键命令队列
   
   IMC_Menu (菜单打开时)
      ├─ IA_NavUp / Down
      ├─ IA_Confirm (Enter)
      └─ IA_Cancel (Esc)
```
