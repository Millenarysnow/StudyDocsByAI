# §9.4 LocalPlayer / ULocalPlayer / FViewportClient — 客户端三件套

> **本节地图**:模块二第 9 章第 4 节。前面看 PlayerController 是"玩家代理人",但**它不是玩家本人**。"玩家本人"在 UE 里是 `ULocalPlayer`(每本地玩家一个)。这一节看客户端三件套:`UPlayer` / `ULocalPlayer` / `UGameViewportClient`。
>
> **预备知识**:§9.1 / §9.3。
>
> **读完之后你能做到**:

> - 看到 `LocalPlayer->GetSubsystem<...>()` 知道 LocalPlayerSubsystem 用法
> - 用 ULocalPlayer 在 RTS 项目存玩家本地状态

## 9.4.1 浅入:四个对象都跟"玩家"有关

```
UPlayer (基类)
   ├─ ULocalPlayer        ← 本地玩家(本机操作的)
   └─ UNetConnection      ← 网络远程"玩家"

APlayerController         ← 玩家在 World 里的代理(Actor)

UGameViewportClient        ← 屏幕视口(渲染目标)
```

**关系**:
- 每个本地玩家 → 1 个 ULocalPlayer
- 每个 ULocalPlayer → 关联 1 个 PlayerController
- 1 个 GameViewportClient → 持有所有 ULocalPlayer

## 9.4.2 `UPlayer`(基类)

```cpp
class UPlayer : public UObject
{
public:
    UPROPERTY()
    TObjectPtr<APlayerController> PlayerController;
    
    int32 CurrentNetSpeed;
    int32 ConfiguredInternetSpeed;
    int32 ConfiguredLanSpeed;
};
```

`UPlayer` 是抽象基类,代表"某种玩家"。子类:
- `ULocalPlayer` — 本机的人
- `UNetConnection` — 网络连过来的人(每个 client 都是 server 的一个 NetConnection)

---

## 9.4.3 `ULocalPlayer` —— 本机玩家

```cpp
class ULocalPlayer : public UPlayer
{
public:
    // 本玩家的 ViewportClient
    UPROPERTY()
    TObjectPtr<UGameViewportClient> ViewportClient;
    
    // 本玩家的 Subsystem 集合
    FSubsystemCollection<ULocalPlayerSubsystem> SubsystemCollection;
    
    // 渲染相关
    int32 ControllerId;       // 多本地玩家时:1st player = 0,2nd = 1
    
    // 视口位置(分屏时不同)
    FVector2D Origin;
    FVector2D Size;
    
    // ...
};
```

### 9.4.3.1 ULocalPlayer 的职责

ULocalPlayer = **"本机玩家的"控制中心""**:
- 持有 ULocalPlayerSubsystem(每玩家级单例)
- 视口配置(分屏位置 / 尺寸)
- ControllerId(分屏多人时识别第几个)

### 9.4.3.2 取 ULocalPlayer

```cpp
// 从 PC 取
APlayerController* PC = ...;
ULocalPlayer* LP = PC->GetLocalPlayer();
// 注意:server 上其它玩家的 PC 取 LP 是 nullptr(他们不是本地玩家)

// 从 GameInstance 取所有本地玩家
UGameInstance* GI = GetGameInstance();
TArray<ULocalPlayer*> LPs = GI->GetLocalPlayers();
// 通常 1 个,分屏时 2-4 个
```

## 9.4.4 `ULocalPlayerSubsystem` —— 本玩家级 Subsystem

§6.3.6.4 / §11(将讲)。

```cpp
UCLASS()
class URTSSelectionSubsystem : public ULocalPlayerSubsystem
{
    GENERATED_BODY()
public:
    UPROPERTY()
    TArray<FMassEntityHandle> SelectedUnits;
    
    void SelectUnits(...);
    void ClearSelection();
};

// 使用
ULocalPlayer* LP = PC->GetLocalPlayer();
URTSSelectionSubsystem* Sel = LP->GetSubsystem<URTSSelectionSubsystem>();
Sel->SelectUnits(NewSelection);
```

### 9.4.4.1 适合 ULocalPlayerSubsystem 的内容

```
✅ 本地玩家选中的单位(纯本地状态)
✅ 本地玩家 UI 状态(Mini-Map 当前位置、UI tab)
✅ Enhanced Input Subsystem(默认就是 ULocalPlayerSubsystem)
✅ 本玩家的视觉偏好(光标样式)

❌ 全局游戏状态(用 UGameInstanceSubsystem / UWorldSubsystem)
❌ 网络复制数据(放 PlayerState)
```

## 9.4.5 `UNetConnection` —— 网络"玩家"

```cpp
class UNetConnection : public UPlayer
{
public:
    TObjectPtr<UNetDriver> Driver;
    TObjectPtr<APlayerController> PlayerController;   // 服务器端,每个 client 一个 PC,通过此 NetConnection
    
    // ... 网络具体字段(包统计、通道列表、序列化状态)
};
```

### 9.4.5.1 NetConnection 的角色

Server 端:
```
UNetDriver
   ├─ UNetConnection 0 (本地玩家,如果 Listen Server)
   ├─ UNetConnection 1 (远程客户端 Alice)
   ├─ UNetConnection 2 (远程客户端 Bob)
   └─ ...
```

每个 NetConnection 对应一个连入的 client。Server 把"复制状态"通过 NetConnection 发给对应 client。

Client 端:
```
UNetDriver
   └─ UNetConnection 0(指向 Server)
```

Client 端只有一个连接 → server。

### 9.4.5.2 NetConnection 与 PC 的关系

Server 端:每个 NetConnection 对应一个 PC,管理该 client 玩家的复制 / RPC。

Client 端:本地 NetConnection 对应本地的 PC(连到 server 的 PC 镜像)。

§13 详细讲网络复制。

## 9.4.6 `UGameViewportClient` —— 视口

```cpp
class UGameViewportClient : public UScriptViewportClient
{
public:
    UPROPERTY()
    TObjectPtr<UWorld> World;
    
    // 子视口(分屏时多个)
    TArray<ULocalPlayer*> Game LocalPlayers;
    
    // 渲染目标
    FViewport* Viewport;
    
    // ...
};
```

### 9.4.6.1 ViewportClient 的职责

GameViewportClient = **"屏幕渲染 + 输入分发"**:
- 持有 ViewportSize / 当前 World
- 处理输入事件(键鼠先到这,再分发到 PlayerController)
- 管理分屏(`SplitscreenInfo`)
- 渲染 HUD(虽然每个 PC 有自己的 HUD)

### 9.4.6.2 取 ViewportClient

```cpp
UGameInstance* GI = ...;
UGameViewportClient* VPC = GI->GetGameViewportClient();
```

或:

```cpp
ULocalPlayer* LP = ...;
UGameViewportClient* VPC = LP->ViewportClient;
```

## 9.4.7 分屏(SplitScreen)

UE 支持 1-4 个本地玩家分屏:

```
[1 player]:           [2 player horizontal]:    [4 player quad]:
┌──────────┐           ┌──────────┐              ┌─────┬─────┐
│          │           │ Player 1 │              │ P1  │ P2  │
│ Player 1 │           ├──────────┤              ├─────┼─────┤
│          │           │ Player 2 │              │ P3  │ P4  │
└──────────┘           └──────────┘              └─────┴─────┘
```

每分屏:
- 一个 ULocalPlayer
- 一个 PlayerController
- 一个 Pawn
- 共享 GameViewportClient(通过 `Origin` / `Size` 区分子视口)

### 9.4.7.1 添加分屏玩家

```cpp
UGameInstance* GI = GetGameInstance();
APlayerController* SecondPC = UGameplayStatics::CreatePlayer(
    GetWorld(), 
    /*ControllerId*/ 1,    // 第二个手柄
    /*bSpawnPlayerController*/ true
);
```

`CreatePlayer` 内部:
- 新建 ULocalPlayer
- 加进 LocalPlayers 数组
- spawn PC + Pawn(走 Login 链)
- ViewportClient 重新计算分屏布局

### 9.4.7.2 RTS 是否支持分屏

RTS 通常**不支持分屏**(屏幕被切成 4 份就太小了,看不见单位)。但**沙盘 Boss 战 / 教学**可能想"主屏 + 副屏 mini map",这种用 UMG widget 而非真 SplitScreen。

## 9.4.8 GameInstance 持有所有 LocalPlayer

```cpp
class UGameInstance : public UObject
{
public:
    UPROPERTY()
    TArray<ULocalPlayer*> LocalPlayers;
    
    UGameViewportClient* GameViewportClient;
    
    // ...
};
```

GameInstance(进程 / 一局游戏)持有所有本机玩家。切关卡 / Travel 时 LocalPlayers **保留**(GameInstance 不变)。

这就是为什么 ULocalPlayerSubsystem 的"跨关卡持久"能力 —— 它跟 ULocalPlayer 一起存在,而 ULocalPlayer 跟 GameInstance 一起。

## 9.4.9 关系总图

```
进程
   │
   └─ GEngine
         │
         └─ UGameInstance(per session)
               │
               ├─ ULocalPlayer (本地玩家 1)
               │     ├─ ViewportClient
               │     ├─ PlayerController(指向当前 World 的 PC)
               │     └─ ULocalPlayerSubsystem ×N
               │
               ├─ ULocalPlayer (本地玩家 2)(分屏时)
               │     └─ ...
               │
               └─ UGameViewportClient(共享)
                     └─ 分屏布局
                     
   World 内:
       ├─ APlayerController 0(对应本地 LocalPlayer 0)
       │     └─ APawn(Possess 的)
       │
       ├─ APlayerController 1(本地 LocalPlayer 1,分屏)
       │     └─ APawn
       │
       ├─ APlayerController 2(远程 client Alice)
       │     └─ APawn
       │
       └─ ...

网络层:
   UNetDriver
      ├─ UNetConnection(client Alice)→ APlayerController(Alice)
      └─ UNetConnection(client Bob)
```

## 9.4.10 RTS 视角:LocalPlayer 用法

### 9.4.10.1 玩家选中单位 → ULocalPlayerSubsystem

```cpp
UCLASS()
class URTSSelectionSubsystem : public ULocalPlayerSubsystem
{
    GENERATED_BODY()
    
    UPROPERTY()
    TArray<FMassEntityHandle> SelectedUnits;
    
public:
    void Add(const FMassEntityHandle& E);
    void Remove(const FMassEntityHandle& E);
    void Clear();
    
    DECLARE_MULTICAST_DELEGATE(FOnSelectionChanged);
    FOnSelectionChanged OnSelectionChanged;
};

// 在 PlayerController 用
void ARTSPlayerController::HandleClick(...)
{
    URTSSelectionSubsystem* S = GetLocalPlayer()->GetSubsystem<URTSSelectionSubsystem>();
    S->Add(ClickedEntity);
}
```

**为什么放 ULocalPlayerSubsystem 而不是 PlayerController**?
- 数据**仅本地**(不需要 replicated)
- 跨关卡持久(玩家选了几个 unit,切关卡保留)
- BP 节点容易访问(`Get Subsystem` 节点)

### 9.4.10.2 RTS UI 状态

```cpp
UCLASS()
class URTSUIStateSubsystem : public ULocalPlayerSubsystem
{
    UPROPERTY()
    TObjectPtr<UUserWidget> CurrentMenu;
    
    UPROPERTY()
    bool bShowFog;
    
    UPROPERTY()
    int32 ActiveTabIndex;
};
```

## 9.4.11 Listen Server 的 LocalPlayer

Listen Server 同时是 server 和有 1 个本地玩家:
- **本地 PC**:LocalPlayer != nullptr,IsLocalController() == true
- **远程 PC**(其他玩家):LocalPlayer == nullptr,本地端代表他们的 PC

```cpp
// Listen Server 上
for (TActorIterator<APlayerController> It(World); It; ++It)
{
    if (It->GetLocalPlayer())
    {
        // 这是本地玩家
    }
    else
    {
        // 这是远程玩家(他自己的 client 上有 LocalPlayer,server 端无)
    }
}
```

## 9.4.12 实操与下一节预告

### 实操

```cpp
static FAutoConsoleCommand CmdInspectPlayers(TEXT("rts.InspectPlayers"),
    TEXT("Print local players info"),
    FConsoleCommandDelegate::CreateLambda([]()
    {
        UWorld* W = GWorld;
        if (!W) return;
        UGameInstance* GI = W->GetGameInstance();
        if (!GI) return;
        
        UE_LOG(LogTemp, Display, TEXT("=== LocalPlayers ==="));
        for (ULocalPlayer* LP : GI->GetLocalPlayers())
        {
            APlayerController* PC = LP->GetPlayerController(W);
            UE_LOG(LogTemp, Display, TEXT("  ControllerId=%d,PC=%s"),
                LP->GetControllerId(),
                PC ? *PC->GetName() : TEXT("null"));
        }
        
        UE_LOG(LogTemp, Display, TEXT("=== All PlayerControllers in World ==="));
        for (TActorIterator<APlayerController> It(W); It; ++It)
        {
            UE_LOG(LogTemp, Display, TEXT("  %s : LP=%p,Local=%d"),
                *It->GetName(),
                It->GetLocalPlayer(),
                It->IsLocalController());
        }
    }));
```
