## 19.2.1 EntityConfigAsset(资产)

Editor 里:Content Browser → Right Click → Mass → Mass Entity Config。命名 `DA_Soldier`。

```
DA_Soldier:
   Traits:
      ├─ MassMovementTrait        提供 FVelocity / FForce
      ├─ MassLODTrait              提供 FMassLODFragment
      ├─ MassRepresentationTrait   提供视觉(ISMC mesh)
      ├─ RTSCombatTrait            (你的)提供 FHealth / FDamage
      ├─ RTSNetworkingTrait        网络复制
      └─ ...
```

## 19.2.2 UMassEntityTraitBase

```cpp
UCLASS(Abstract, EditInlineNew)
class UMassEntityTraitBase : public UObject
{
    virtual void BuildTemplate(FMassEntityTemplateBuildContext& BuildContext, ...) const = 0;
};
```

Trait 的核心 API:**`BuildTemplate`** — 在创建 entity 时被调,**添加 Fragment / Tag / 配置**。

例:

```cpp
UCLASS()
class URTSCombatTrait : public UMassEntityTraitBase
{
    UPROPERTY(EditAnywhere)
    int32 MaxHealth = 100;
    
    UPROPERTY(EditAnywhere)
    int32 BaseDamage = 10;
    
    virtual void BuildTemplate(FMassEntityTemplateBuildContext& BuildContext, ...) const override
    {
        BuildContext.AddFragment<FUnitHealthFragment>(FUnitHealthFragment{ MaxHealth, MaxHealth });
        BuildContext.AddFragment<FUnitDamageFragment>(FUnitDamageFragment{ BaseDamage });
        BuildContext.AddTag<FActiveTag>();
    }
};
```

Trait UPROPERTY 字段 = 策划在 Editor 配的"参数"。`BuildTemplate` 把这些参数转成 Fragment 数据。

## 19.2.3 FMassEntityTemplate(运行时编译产物)

ConfigAsset 在 Runtime 被**编译为 FMassEntityTemplate**:

```cpp
struct FMassEntityTemplate
{
    FMassFragmentBitSet FragmentBitSet;
    FMassTagBitSet TagBitSet;
    
    TArray<FInstancedStruct> InitialFragments;     // Fragment 初始值
    
    FMassArchetypeHandle ArchetypeHandle;          // 关联 archetype
};
```

每个 Trait 的 `BuildTemplate` 都修改 Template,最后 Mass 创建 archetype + 缓存 Template。

之后 Spawn 时复用 Template,**很快**。

## 19.2.4 资产配置工作流

```
Editor 工作流(策划友好):
   1. 美术 / 策划 创建 DA_Soldier 资产
   2. 加 Trait 组件
   3. 设 Trait 参数(MaxHealth = 100,Mesh = SoldierMesh)
   4. 保存
   
   ↓
   
Runtime:
   1. UMassSpawner 引用 DA_Soldier
   2. BeginPlay 时:DA_Soldier 编译为 FMassEntityTemplate
   3. 创建对应 archetype(若不存在)
   4. SpawnEntity 用 Template 实例化
```

策划改 Trait 参数(BaseHealth = 150)→ 重新编译资产 → 下次 spawn 用新值。**不用重启 Editor / 改 C++**。

## 19.2.5 Trait 在 BP 编辑

某些 Trait 可以 BP 子类(给策划灵活配置):

```cpp
UCLASS(Blueprintable, BlueprintType)
class URTSAITrait : public UMassEntityTraitBase
{
    UPROPERTY(EditAnywhere, BlueprintReadOnly)
    UStateTreeAsset* AIBehavior;
    
    virtual void BuildTemplate(...) const override
    {
        BuildContext.AddFragment<FStateTreeFragment>(FStateTreeFragment{ AIBehavior });
    }
};
```

Editor 创建 BP_RTSAITrait 子类,设 AIBehavior 引用某 StateTree 资产。
