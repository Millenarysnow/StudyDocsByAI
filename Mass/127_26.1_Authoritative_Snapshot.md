## 26.1.1 Snapshot 完整流程

```
Server tick:
   ├─ Mass tick(50K entity 状态变化)
   ├─ Replication Processor:扫 entity dirty
   ├─ 量化:每 entity ~5-10 字节
   ├─ 兴趣管理:每 client 看 ~5K entity
   └─ Iris 序列化 + 发包(每 client ~1.5 KB / 帧)

Client 接收:
   ├─ Iris 反序列化
   ├─ 更新本地 Mass entity 镜像
   ├─ Local Mass tick(LOD / Representation)
   └─ 渲染
```

带宽:~90-150 KB/s / connection ✓

---

## 26.1.2 复制频率分级

```
关键字段(位置 / 朝向 / 状态):
   每帧 dirty 检测,~30 Hz 实际复制
   
不关键(攻击力 / 等级):
   仅启动时 + 状态变化时复制
   
完全不复制(本地 AI 状态):
   server 不发,client 不需要
```

通过 ConstSharedFragment(类型不变 → 不复制)+ Dirty Tag(只复制变化 entity)优化。
