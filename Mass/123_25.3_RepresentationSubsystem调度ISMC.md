# §25.3 RepresentationSubsystem 调度 ISMC

> **本节地图**:模块五第 25 章第 3 节。Mass `UMassRepresentationSubsystem` 怎么把 entity 数据 → ISMC instance。
>
> **预备知识**:§20.2,§25.2。

---

## 25.3.1 Mass Representation 流程

```
[Mass tick - FrameEnd]
UMassRepresentationProcessor:
   每 entity:
      取 LOD
      根据 LOD 选 mesh(High = 详细 mesh,Low = 远景 mesh)
      若 entity 还没分配 instance:
         向 RepresentationSubsystem 申请新 instance
         记 InstanceID 到 FRepresentationFragment
      更新 instance transform
   ↓
SubSystem.FlushUpdates:
   每个 ISMC 调 MarkRenderStateDirty(批量上传)
```

---

## 25.3.2 RTS 实战 Processor

```cpp
class URTSRepresentationProcessor : public UMassProcessor
{
    URTSISMCPool* ISMCPool;
    
    void Execute(...) override
    {
        Query.ForEachEntityChunk(...) [&](FMassExecutionContext& Ctx)
        {
            const auto Transforms = Ctx.GetFragmentView<FMassTransformFragment>();
            const auto LODs = Ctx.GetFragmentView<FMassLODFragment>();
            auto Reps = Ctx.GetMutableFragmentView<FRTSRepresentationFragment>();
            
            const auto& UnitConfig = Ctx.GetConstSharedFragment<FUnitTypeConfig>();
            
            for (int32 i = 0; i < Ctx.GetNumEntities(); ++i)
            {
                EMassLOD::Type LOD = LODs[i].LOD;
                
                if (LOD == EMassLOD::Off)
                {
                    if (Reps[i].InstanceID != INDEX_NONE)
                    {
                        ISMCPool->RemoveInstance(Reps[i].CurrentMesh, Reps[i].InstanceID);
                        Reps[i].InstanceID = INDEX_NONE;
                    }
                    continue;
                }
                
                UStaticMesh* Mesh = LOD == EMassLOD::High 
                    ? UnitConfig.HighDetailMesh 
                    : UnitConfig.LowDetailMesh;
                
                if (Reps[i].CurrentMesh != Mesh)
                {
                    // 切换 mesh(LOD 变化)
                    if (Reps[i].InstanceID != INDEX_NONE)
                        ISMCPool->RemoveInstance(Reps[i].CurrentMesh, Reps[i].InstanceID);
                    Reps[i].InstanceID = ISMCPool->AcquireInstance(Mesh, Transforms[i].T);
                    Reps[i].CurrentMesh = Mesh;
                }
                else
                {
                    ISMCPool->UpdateInstance(Mesh, Reps[i].InstanceID, Transforms[i].T);
                }
            }
        });
        
        // Phase 末尾批量 flush
        ISMCPool->FlushUpdates();
    }
};
```

## 25.3.3 性能

```
50K entity × ISMC update:
   每 entity ~50 ns(SetTransform + dirty mark)
   总 ~2.5 ms / 帧
   
+ ISMC RenderState dirty 1 次:
   GameThread → RenderThread upload ~1-2 ms
   
总:~3-5 ms / 帧 ✓ 在预算内
```
