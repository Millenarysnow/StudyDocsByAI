# §18.4 ProcessingPhase 与 TickGroup 映射

> **本节地图**:模块四第 18 章第 4 节。Mass Processor 跑在 UWorld TickGroup 上。这一节看映射。
>
> **预备知识**:§8.3-§8.4 TickGroup,§18.1。

---

## 18.4.1 映射表

```
EMassProcessingPhase     ETickingGroup
─────────────────────────────────────
PrePhysics            →  TG_PrePhysics
StartPhysics          →  TG_StartPhysics
DuringPhysics         →  TG_DuringPhysics
EndPhysics            →  TG_EndPhysics
PostPhysics           →  TG_PostPhysics
FrameEnd              →  TG_PostUpdateWork
```

每 phase 对应一个 TickFunction(由 `UMassSimulationSubsystem` 注册)。

---

## 18.4.2 Phase 内 Processor 排序

同 phase 内多个 Processor 通过 `ExecutionOrder` 排序:

```cpp
URTSCommandProcessor::URTSCommandProcessor()
{
    ProcessingPhase = EMassProcessingPhase::PrePhysics;
    ExecutionOrder.ExecuteInGroup = TEXT("CommandHandling");
    ExecutionOrder.ExecuteAfter.Add(TEXT("PlayerInput"));
    ExecutionOrder.ExecuteBefore.Add(TEXT("AIDecision"));
}
```

Mass 启动时拓扑排序,生成 DAG 调度。

---

## 18.4.3 跨 Phase 数据流

```
PrePhysics:
   ├─ CommandProcessor   修改 FCommandQueue
   ├─ AIProcessor        读 FCommandQueue,设 FMovementGoal
   └─ MovementProcessor  读 FMovementGoal,改 FVelocity

DuringPhysics:
   └─ (物理计算)

PostPhysics:
   ├─ SteeringProcessor  读 FVelocity + 物理结果,修正
   └─ AnimationProcessor 设动画状态

FrameEnd:
   ├─ LODProcessor       计算 LOD
   └─ RepresentationProcessor 更新 ISMC
```

每 phase 末尾 Mass 自动 flush 命令缓冲。
