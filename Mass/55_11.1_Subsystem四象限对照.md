## 11.1.1 四象限完整对照

```
┌──────────────────────┬─────────────────┬──────────────────┬──────────────────┬─────────────────────┐
│  Subsystem 类型       │  生命周期        │  Outer            │  Initialize 时机   │  Get API             │
├──────────────────────┼─────────────────┼──────────────────┼──────────────────┼─────────────────────┤
│  UEngineSubsystem     │  进程级,跨一切  │  GEngine          │  GEngine 创建后   │  GEngine->GetEngineSubsystem<T>() │
│                       │                  │                   │  (Init 阶段)      │                      │
├──────────────────────┼─────────────────┼──────────────────┼──────────────────┼─────────────────────┤
│  UGameInstanceSubs    │  一局游戏       │  GameInstance     │  GameInstance     │  GI->GetSubsystem<T>() │

├──────────────────────┼─────────────────┼──────────────────┼──────────────────┼─────────────────────┤
│  UWorldSubsystem      │  一关卡         │  UWorld           │  World->InitWorld │  World->GetSubsystem<T>() │
```

## 11.1.3 决策树

```
我要写个 X,该放哪种 Subsystem?

1. X 是进程级单例(跨整个 .exe)?
   ✓ → UEngineSubsystem
   ✗ → 下一步

2. X 是"一局游戏跨 World"(玩家档案、登录会话)?
   ✓ → UGameInstanceSubsystem
   ✗ → 下一步

3. X 是"一关卡内"(战斗、雾战、Mass)?
   ✓ → UWorldSubsystem(若需 tick → UTickableWorldSubsystem)
   ✗ → 下一步

4. X 是"本地玩家本人"(选择、UI 状态、Input)?
   ✓ → ULocalPlayerSubsystem
   ✗ → 重新设计(可能不该用 Subsystem,用 Subsystem 太重)
```

## 11.1.4 实操与下一节预告

### 实操

```cpp
// 在每种 Subsystem Init 里打日志
void URTSEngineSub::Initialize(...)     { UE_LOG(LogTemp, Display, TEXT("[Engine] Init")); }
void URTSGISub::Initialize(...)         { UE_LOG(LogTemp, Display, TEXT("[GI] Init")); }
void URTSWorldSub::Initialize(...)      { UE_LOG(LogTemp, Display, TEXT("[World] Init")); }
void URTSLPSub::Initialize(...)         { UE_LOG(LogTemp, Display, TEXT("[LP] Init")); }
```

PIE 启动看输出,顺序通常:Engine → GI → World → LP。
