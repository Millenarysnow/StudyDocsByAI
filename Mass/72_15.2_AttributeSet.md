## 15.2.1 AttributeSet 是什么

```cpp
UCLASS()
class URTSHeroAttributeSet : public UAttributeSet
{
    GENERATED_BODY()
public:
    UPROPERTY(BlueprintReadOnly, ReplicatedUsing=OnRep_Health)
    FGameplayAttributeData Health;
    ATTRIBUTE_ACCESSORS(URTSHeroAttributeSet, Health)
    
    UPROPERTY(BlueprintReadOnly, ReplicatedUsing=OnRep_MaxHealth)
    FGameplayAttributeData MaxHealth;
    ATTRIBUTE_ACCESSORS(URTSHeroAttributeSet, MaxHealth)
    
    UPROPERTY(BlueprintReadOnly, ReplicatedUsing=OnRep_AttackPower)
    FGameplayAttributeData AttackPower;
    ATTRIBUTE_ACCESSORS(URTSHeroAttributeSet, AttackPower)
    
    UFUNCTION()
    void OnRep_Health(const FGameplayAttributeData& OldHealth);
    // ...
};
```

`FGameplayAttributeData`:**float 字段** + 一些 metadata(BaseValue / CurrentValue,见 §15.3)。

### 15.2.1.1 双值结构

每个 Attribute 有两个 float:
- **BaseValue** — 不变的基础值(英雄 Lv1 Health = 100)
- **CurrentValue** — 当前值(BaseValue + 所有 GameplayEffect 修改)

```
HeroLv1: BaseHealth = 100
   + 装备 +20 → CurrentHealth = 120
   + buff +10 → CurrentHealth = 130
   - 受伤 50 → CurrentHealth = 80(BaseValue 仍 100)
```

## 15.2.2 ATTRIBUTE_ACCESSORS 宏

```cpp
ATTRIBUTE_ACCESSORS(MyClass, MyField)
```

展开为:
```cpp
static FGameplayAttribute Get##MyField##Attribute();
float Get##MyField() const;
void Set##MyField(float NewVal);
void Init##MyField(float NewVal);
```

简化访问:

```cpp
URTSHeroAttributeSet* AS = ...;
float HP = AS->GetHealth();          // 取 CurrentValue
AS->SetHealth(50);                    // 设 CurrentValue
AS->InitHealth(100);                  // 设 BaseValue
```

## 15.2.3 注册 AttributeSet

```cpp
class AHero : public ACharacter
{
    AHero()
    {
        ASC = CreateDefaultSubobject<UAbilitySystemComponent>(TEXT("ASC"));
        AttributeSet = CreateDefaultSubobject<URTSHeroAttributeSet>(TEXT("Attributes"));
    }
};
```

ASC 自动检测 owner Actor 的 UAttributeSet 子对象。

## 15.2.4 PreAttributeChange / PostAttributeChange Hook

```cpp
void URTSHeroAttributeSet::PreAttributeChange(const FGameplayAttribute& Attr, float& NewValue)
{
    Super::PreAttributeChange(Attr, NewValue);
    
    // 限制 Health 上限
    if (Attr == GetHealthAttribute())
    {
        NewValue = FMath::Clamp(NewValue, 0.0f, GetMaxHealth());
    }
}

void URTSHeroAttributeSet::PostAttributeChange(const FGameplayAttribute& Attr, float OldValue, float NewValue)
{
    if (Attr == GetHealthAttribute() && NewValue <= 0.0f)
    {
        // 死亡
        OnDeath.Broadcast();
    }
}
```

## 15.2.5 网络复制

每个 Attribute 用 `ReplicatedUsing` + 自定义 OnRep:

```cpp
void URTSHeroAttributeSet::OnRep_Health(const FGameplayAttributeData& OldHealth)
{
    GAMEPLAYATTRIBUTE_REPNOTIFY(URTSHeroAttributeSet, Health, OldHealth);
    // UI 更新
}
```
