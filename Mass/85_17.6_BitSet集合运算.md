## 17.6.2 Archetype 的 Composition

每个 Archetype 维护一组 BitSet(描述自己包含什么):

```cpp
struct FMassArchetypeCompositionDescriptor
{
    FMassFragmentBitSet Fragments;
    FMassTagBitSet Tags;
    FMassChunkFragmentBitSet ChunkFragments;
    FMassSharedFragmentBitSet SharedFragments;
    FMassConstSharedFragmentBitSet ConstSharedFragments;
};
```

每个 BitSet 是 N 位的位图(N = 已注册类型数)。

## 17.6.3 Query 的 BitSet

```cpp
struct FMassFragmentRequirements
{
    FMassFragmentBitSet RequiredAllFragments;       // 必须有这些
    FMassFragmentBitSet RequiredAnyFragments;       // 至少有其中一个
    FMassFragmentBitSet RequiredOptionalFragments;  // 可选(读 / 写访问声明)
    FMassFragmentBitSet RequiredNoneFragments;      // 不能有
    
    // Tag 类似
    FMassTagBitSet RequiredAllTags;
    FMassTagBitSet RequiredNoneTags;
    
    // ...
};
```

## 17.6.4 Query 匹配运算

```cpp
// 简化:archetype 是否匹配 query
bool DoesArchetypeMatch(const FMassArchetypeCompositionDescriptor& Composition, 
                         const FMassFragmentRequirements& Req)
{
    // 1. 必须有所有 RequiredAll
    if (!Composition.Fragments.HasAll(Req.RequiredAllFragments)) return false;
    
    // 2. 不能有任何 RequiredNone
    if (Composition.Fragments.HasAny(Req.RequiredNoneFragments)) return false;
    
    // 3. RequiredAny 至少一个
    if (Req.RequiredAnyFragments.IsEmpty() == false &&
        !Composition.Fragments.HasAny(Req.RequiredAnyFragments)) return false;
    
    // 4. Tag 同理
    if (!Composition.Tags.HasAll(Req.RequiredAllTags)) return false;
    if (Composition.Tags.HasAny(Req.RequiredNoneTags)) return false;
    
    return true;
}
```

每检查 = 几次 64 位 AND/OR + 比较 = **~5 ns / archetype**。

## 17.6.6 写 Query 的实战 API

```cpp
class URTSMovementProcessor : public UMassProcessor
{
    FMassEntityQuery Query;
    
    virtual void ConfigureQueries() override
    {
        // 必须有的(读 / 写访问)
        Query.AddRequirement<FMassPositionFragment>(EMassFragmentAccess::ReadWrite);
        Query.AddRequirement<FMassVelocityFragment>(EMassFragmentAccess::ReadOnly);
        
        // 必须含 Tag
        Query.AddTagRequirement<FActiveTag>(EMassFragmentPresence::All);
        
        // 不能含 Tag
        Query.AddTagRequirement<FDeadTag>(EMassFragmentPresence::None);
        Query.AddTagRequirement<FFrozenTag>(EMassFragmentPresence::None);
    }
};
```

每个 `AddRequirement<T>` / `AddTagRequirement<T>` 内部:
1. `T::StaticStruct()` 取反射指针
2. 通过 `FStructTracker` 取位 index
3. 设对应 BitSet 位

**ConfigureQueries 启动时调一次**,运行时直接用 BitSet 做匹配。

## 17.6.7 RW 冲突检测

Mass 通过 BitSet 检测**Processor 间 RW 冲突**(自动调度并行):

```
Processor A:写 FPositionFragment
Processor B:读 FPositionFragment
   → 冲突,B 必须等 A
   
Processor C:读 FPositionFragment  
Processor D:读 FPositionFragment(同读)
   → 不冲突,可并行
```

通过 BitSet AND 运算检测。详 §18.6。
