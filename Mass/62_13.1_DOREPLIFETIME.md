## 13.1.1 浅入:让一个字段网络复制

```cpp
UCLASS()
class ARTSPlayerState : public APlayerState
{
public:
    UPROPERTY(Replicated)        // ★ 声明
    int32 Resources;
    
    // 必须重写
    virtual void GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const override;
};

// .cpp
void ARTSPlayerState::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
    Super::GetLifetimeReplicatedProps(OutLifetimeProps);
    DOREPLIFETIME(ARTSPlayerState, Resources);
}
```

两步:
1. UPROPERTY 标记 `Replicated`
2. 在 `GetLifetimeReplicatedProps` 用 DOREPLIFETIME 注册

漏一步 → 不会复制(且无报错,容易混淆)。

## 13.1.2 `DOREPLIFETIME` 宏家族

```cpp
DOREPLIFETIME(ClassName, FieldName)
   // 默认:总是复制给所有 client

DOREPLIFETIME_CONDITION(ClassName, FieldName, ELifetimeCondition Cond)
   // 条件复制(下面)

DOREPLIFETIME_CONDITION_NOTIFY(ClassName, FieldName, Cond, ELifetimeRepNotifyCondition NotifyCond)
   // 复制 + 客户端 OnRep 触发条件
```

### 13.1.2.1 `ELifetimeCondition`

```cpp
enum ELifetimeCondition : int
{
    COND_None,                    // 总是复制
    COND_InitialOnly,             // 首次复制后不再
    COND_OwnerOnly,               // 仅复制给 owner
    COND_SkipOwner,               // 不复制给 owner
    COND_SimulatedOnly,           // 仅对 simulated proxies(其它玩家)
    COND_AutonomousOnly,          // 仅对 autonomous(本地玩家)
    COND_SimulatedOrPhysics,
    COND_InitialOrOwner,
    COND_Custom,                  // 自定义,通过 PreReplication 控制
    COND_ReplayOnly,              // 仅 replay
    COND_SimulatedOnlyNoReplay,
    COND_SkipReplay,
    // ...
};
```

实战:

```cpp
DOREPLIFETIME_CONDITION(ARTSPlayerState, PrivateData, COND_OwnerOnly);
   // 玩家自己的私密数据(仅自己看到,其他玩家看不到)
   
DOREPLIFETIME_CONDITION(AHero, AnimationState, COND_SimulatedOnly);
   // 仅同步给"看到这个 hero"的其他玩家(自己用本地动画状态)
```

## 13.1.3 `ReplicatedUsing` —— OnRep 回调

```cpp
UPROPERTY(ReplicatedUsing = OnRep_Health)
int32 Health;

UFUNCTION()
void OnRep_Health(int32 OldHealth);
```

Client 收到新 Health 值时,**自动**调 `OnRep_Health(OldValue)`。

实战:UI 更新血条 / 触发受伤特效。

```cpp
void AHero::OnRep_Health(int32 OldHealth)
{
    if (Health < OldHealth)
    {
        PlayHurtAnim();
        ShowDamageNumber(OldHealth - Health);
    }
}
```

## 13.1.4 RepNotify 条件

```cpp
DOREPLIFETIME_CONDITION_NOTIFY(MyClass, MyField, COND_None, REPNOTIFY_OnChanged);
```

`REPNOTIFY_OnChanged`(默认):仅值真变化时调 OnRep。
`REPNOTIFY_Always`:每次收到复制(即使值未变)都调。

99% 用默认。

## 13.1.5 Replicated Subobjects

`UActorComponent` 等子对象也可 replicate:

```cpp
UCLASS()
class UMyComp : public UActorComponent
{
    UPROPERTY(Replicated)
    int32 SomeField;
    
    virtual void GetLifetimeReplicatedProps(...) const override
    {
        DOREPLIFETIME(UMyComp, SomeField);
    }
};

// Owner Actor 必须设
class AMyActor : public AActor
{
    AMyActor()
    {
        bReplicates = true;
        bReplicateUsingRegisteredSubObjectList = true;   // 启用 subobject replication
    }
};
```

## 13.1.6 RTS 视角

class ARTSPlayerState : public APlayerState
{
    UPROPERTY(Replicated)

    int32 Resources;
    
    UPROPERTY(ReplicatedUsing = OnRep_UnitsAlive)
