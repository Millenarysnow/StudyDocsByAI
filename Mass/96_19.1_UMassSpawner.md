## 19.1.1 UMassSpawner 类

`UMassSpawner` 是个 actor,放在关卡里:

```cpp
UCLASS()
class UMassSpawner : public AActor
{
    UPROPERTY(EditAnywhere)
    TArray<FMassSpawnedEntityType> EntityTypes;     // spawn 哪些 entity 类型
    
    UPROPERTY(EditAnywhere)
    TArray<UMassSpawnDataGenerator*> SpawnDataGenerators;  // spawn 位置生成器
    
    UPROPERTY(EditAnywhere)
    int32 Count;
    
    UPROPERTY(EditAnywhere)
    bool bAutoSpawnOnBeginPlay;
    
    void DoSpawning();   // 触发 spawn
};
```

Editor 配置 + BeginPlay 自动 spawn(或 BP 触发 `DoSpawning`)。

## 19.1.2 FMassSpawnedEntityType

```cpp
USTRUCT()
struct FMassSpawnedEntityType
{
    UPROPERTY(EditAnywhere)
    TObjectPtr<UMassEntityConfigAsset> EntityConfig;   // 配置资产(Trait 组合)
    
    UPROPERTY(EditAnywhere)
    float Proportion;     // 在 Spawner 总数里的比例(混合 spawn)
};
```

可以 spawn **多种 entity 类型混合**(如 70% Soldier + 30% Worker)。

## 19.1.3 UMassSpawnDataGenerator

控制**spawn 位置 / 数据**:

```cpp
UCLASS(Abstract, EditInlineNew)
class UMassSpawnDataGenerator : public UObject
{
    virtual void Generate(...) = 0;   // 生成 spawn 位置数据
};
```

UE 自带几种:
- `UMassEntitySpawnDataGeneratorBase`(基础)
- `UMassEnvironmentSpawnDataGenerator`(在 Volume 内随机)
- `UMassNavMeshSpawnDataGenerator`(在 NavMesh 上随机)

自定义:

```cpp
UCLASS()
class URTSGridSpawnGenerator : public UMassSpawnDataGenerator
{
    UPROPERTY(EditAnywhere)
    int32 GridX = 10;
    
    UPROPERTY(EditAnywhere)
    int32 GridY = 10;
    
    UPROPERTY(EditAnywhere)
    float Spacing = 100.0f;
    
    virtual void Generate(...) override
    {
        for (int x = 0; x < GridX; ++x)
            for (int y = 0; y < GridY; ++y)
                AddSpawnTransform(FVector(x * Spacing, y * Spacing, 0));
    }
};
```

Editor 里把这个 generator 拖到 Spawner 的 SpawnDataGenerators 数组。

## 19.1.4 代码 spawn(无 Actor)

```cpp
UMassSpawnerSubsystem* SpawnerSub = World->GetSubsystem<UMassSpawnerSubsystem>();

UMassEntityConfigAsset* Config = LoadObject<UMassEntityConfigAsset>(...);
TArray<FTransform> Transforms;   // 你的位置列表

TArray<FMassEntityHandle> Spawned;
SpawnerSub->SpawnEntities(Config, Transforms, Spawned);
```

适合**运动时 spawn**(玩家造单位 / 援军到达)。

## 19.1.5 RTS Spawn 设计

```cpp
// 玩家点造兵
void URTSCommandSubsystem::ExecuteBuildCommand(EUnitType T, FVector Loc, int32 Count)
{
    UMassSpawnerSubsystem* Sub = GetWorld()->GetSubsystem<UMassSpawnerSubsystem>();
    UMassEntityConfigAsset* Config = GetUnitConfig(T);
    
    TArray<FTransform> Transforms;
    for (int32 i = 0; i < Count; ++i)
    {
        Transforms.Add(FTransform(Loc + GetRandomOffset()));
    }
    
    TArray<FMassEntityHandle> Spawned;
    Sub->SpawnEntities(Config, Transforms, Spawned);
    
    // 设玩家阵营
    for (FMassEntityHandle E : Spawned)
    {
        EM.GetFragmentDataChecked<FUnitOwnerFragment>(E).PlayerID = GetPlayerID();
    }
}
```
