## 8.1.1 浅入:SpawnActor 心理模型

```cpp
// 简单调用
AHero* H = GetWorld()->SpawnActor<AHero>(
    AHero::StaticClass(),
    FVector(100, 200, 0),
    FRotator(0, 90, 0)
);
```

这一行内部:
1. 验证 Class 不是 Abstract / Deprecated,可以 spawn
2. 决定 LevelToSpawnIn(默认 PersistentLevel)
3. NewObject<AHero>(走 §3.3 完整流程)
4. PostSpawnInitialize(初始化字段、Transform)
5. RegisterAllComponents(注册子组件)
6. PostInitializeComponents
7. DispatchBeginPlay(World 已 BeginPlay 时立即调,否则等 World BeginPlay)

每一步都有详细工作。

## 8.1.2 入口:`UWorld::SpawnActor`

`Engine/Source/Runtime/Engine/Private/LevelActor.cpp:455`:

```cpp
AActor* UWorld::SpawnActor(UClass* Class, FTransform const* UserTransformPtr, 
                            const FActorSpawnParameters& SpawnParameters)
{
    SCOPE_CYCLE_COUNTER(STAT_SpawnActorTime);
    
    // 1. 验证类合法
    if (!Class) return NULL;
    if (Class->HasAnyClassFlags(CLASS_Deprecated)) return NULL;
    if (Class->HasAnyClassFlags(CLASS_Abstract)) return NULL;
    if (!Class->IsChildOf(AActor::StaticClass())) return NULL;
    
    // 2. 选 Level
    ULevel* LevelToSpawnIn = SpawnParameters.OverrideLevel;
    if (!LevelToSpawnIn) LevelToSpawnIn = PersistentLevel;
    
    // 3. 选 Template(SpawnParameters.Template 或 CDO)
    AActor* Template = SpawnParameters.Template ?: Class->GetDefaultObject<AActor>();
    
    // 4. 检查碰撞(若 SpawnCollisionHandlingMethod = DontSpawnIfColliding)
    // ...
    
    // 5. NewObject<AActor>
    AActor* NewActor = NewObject<AActor>(LevelToSpawnIn, Class, NewActorName, ..., Template);
    
    // 6. 初始化(PostSpawnInitialize 等)
    NewActor->PostSpawnInitialize(UserTransform, SpawnParameters.Owner, ...);
    
    // 7. 如果不是 deferred,完成 spawning
    if (!SpawnParameters.bDeferConstruction)
    {
        NewActor->FinishSpawning(UserTransform);
    }
    
    return NewActor;
}
```

实际代码 200+ 行,处理无数边缘情况。这里的简化保留主干。

## 8.1.3 步骤详解

### 8.1.3.1 步 1:类合法性检查

```cpp
if (!Class) return NULL;
if (Class->HasAnyClassFlags(CLASS_Deprecated)) return NULL;
if (Class->HasAnyClassFlags(CLASS_Abstract)) return NULL;
if (!Class->IsChildOf(AActor::StaticClass())) return NULL;
```

防止 spawn 不可实例化的类。**`UCLASS(Abstract)` 标记的类**不能直接 spawn,只能 spawn 它的具体子类。

### 8.1.3.2 步 2:Level 选择

默认 `PersistentLevel`。可通过 `SpawnParameters.OverrideLevel` 指定其它 Level(典型:streaming 子关卡的 actor)。

或:**Owner 的 Level**(`SpawnParameters.Owner`),让 spawn 的 actor 跟 Owner 一起被 streaming 卸载。

### 8.1.3.3 步 3:Template 选择

`SpawnParameters.Template`:你显式指定一个 actor 实例作 template。
否则用 `Class->GetDefaultObject<AActor>()` —— **CDO**(§3.4)。

InitProperties 阶段从 template 拷字段。Template 决定"新 actor 的初始字段值"。

### 8.1.3.4 步 4:碰撞检测

`ESpawnActorCollisionHandlingMethod`:

```cpp
enum class ESpawnActorCollisionHandlingMethod : uint8
{
    Undefined,
    AlwaysSpawn,                              // 不检测
    AdjustIfPossibleButAlwaysSpawn,            // 试着调整,失败仍 spawn
    AdjustIfPossibleButDontSpawnIfColliding,   // 调整失败就不 spawn
    DontSpawnIfColliding,                      // 检测到碰撞直接失败
};
```

如果有碰撞处理,这里走 query / sweep。**这一步可能很慢**(物理 query 几十 μs)。RTS 大量 spawn 时**关闭碰撞检测**:`SpawnParameters.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn`。

### 8.1.3.5 步 5:NewObject

```cpp
AActor* NewActor = NewObject<AActor>(LevelToSpawnIn, Class, NewActorName, ...);
```

走 §3.3 完整 NewObject 流程。**这是最大开销之一**(几 μs - 几十 μs)。

NewObject 的 Outer 是 **Level**(不是 World),Actor 自动加进 `Level->Actors[]`。

### 8.1.3.6 步 6:PostSpawnInitialize

```cpp
void AActor::PostSpawnInitialize(FTransform const& UserSpawnTransform, AActor* InOwner, 
                                  APawn* InInstigator, bool bRemoteOwned, bool bNoFail, 
                                  bool bDeferConstruction, ESpawnActorScaleMethod TransformScaleMethod)
{
    // 1. 设置 Owner / Instigator
    SetOwner(InOwner);
    Instigator = InInstigator;
    
    // 2. 设置 Transform(放置 Actor 到指定位置)
    SetActorTransform(UserSpawnTransform);
    
    // 3. PreInitializeComponents 钩子
    PreInitializeComponents();
    
    // 4. 走构造脚本(BP 类的 ConstructionScript)
    if (!bDeferConstruction)
    {
        ExecuteConstruction(...);
    }
    
    // 5. 注册组件 RegisterAllComponents
    RegisterAllComponents();
    
    // 6. PostInitializeComponents 钩子
    PostInitializeComponents();
}
```

`RegisterAllComponents`:把 Actor 内嵌的 `UActorComponent` 都"激活" —— 加到 Tick 系统、加到渲染场景、初始化物理。这一步本身是大开销(§8.2 详讲)。

### 8.1.3.7 步 7:`FinishSpawning` + `DispatchBeginPlay`

```cpp
void AActor::FinishSpawning(...)
{
    // 完成构造脚本(BP)
    ExecuteConstruction(...);
    
    // 第一次复制(网络复制)
    InitializeNetwork(...);
    
    // 如果 World 已 BeginPlay,立即调 BeginPlay
    if (World->HasBegunPlay())
    {
        DispatchBeginPlay();
    }
    // 否则等 World BeginPlay 时再调
}

void AActor::DispatchBeginPlay()
{
    // 1. Component BeginPlay
    for (UActorComponent* C : GetComponents())
    {
        C->RegisterAllComponentTickFunctions(true);   // 启动 component tick
        C->BeginPlay();
    }
    
    // 2. Actor 自身 BeginPlay
    RegisterAllActorTickFunctions(true);   // 启动 actor tick
    BeginPlay();
}
```

到这里 Actor "活了":
- 在 Level.Actors 数组里
- Components 已注册到 World(渲染、物理、tick)
- BeginPlay 已调
- Actor 开始接受 Tick

## 8.1.4 SpawnActor 的 Deferred 模式

如果 spawn 时**还想配置一些 UPROPERTY**(BeginPlay 之前生效):

```cpp
// 1. Deferred spawn:不立即调 FinishSpawning
FActorSpawnParameters Params;
Params.bDeferConstruction = true;

AHero* H = GetWorld()->SpawnActor<AHero>(AHero::StaticClass(), Loc, Rot, Params);

// 2. 此时 Actor 已 NewObject + RegisterAllComponents,但还没 BeginPlay
H->TeamID = 1;
H->StartingHealth = 200;

// 3. 完成 spawn(调 FinishSpawning)
H->FinishSpawning(FTransform(Rot, Loc));
// 之后 BeginPlay 被调
```

**用例**:RTS 工厂生产单位 — 创建 unit + 配置 owner / team / 等级 → finish spawning → unit 才正式工作。

**简化版**(常用):

```cpp
AHero* H = GetWorld()->SpawnActorDeferred<AHero>(AHero::StaticClass(), FTransform(Rot, Loc));
H->TeamID = 1;
H->FinishSpawning(FTransform(Rot, Loc));
```

## 8.1.5 `FActorSpawnParameters` —— 完整参数

```cpp
struct FActorSpawnParameters
{
    FName Name;                              // 自定义名(默认自动生成)
    AActor* Template;                        // 模板对象
    AActor* Owner;                           // 所有者
    APawn* Instigator;                       // 触发者
    ULevel* OverrideLevel;                    // 哪个 Level
    UPackage* OverridePackage;                // 自定义 package
    UChildActorComponent* OverrideParentComponent;
    
    ESpawnActorCollisionHandlingMethod SpawnCollisionHandlingOverride;
    ESpawnActorNameMode NameMode;
    
    EObjectFlags ObjectFlags;                 // RF_Transient 等
    
    bool bNoFail : 1;                         // 不允许失败(强制 spawn)
    bool bDeferConstruction : 1;              // Deferred 模式
    bool bAllowDuringConstructionScript : 1;
    bool bForceGloballyUniqueName : 1;
    bool bCreateActorPackage : 1;             // Editor 用
    
    EObjectFlags ObjectFlags;
};
```

99% 用默认。少数场景指定 `Owner` / `OverrideLevel`。

## 8.1.6 性能成本

实测(Win64,Development build):

| Actor 类型 | SpawnActor 耗时 | 主要开销 |
|---|---|---|
| 简单 AActor(无 component) | ~5 μs | NewObject |
| AActor + 1 个 UStaticMeshComponent | ~30 μs | + RegisterComponent + 渲染场景 |
| AStaticMeshActor | ~50 μs | + Mesh 数据 |
| ACharacter(含 Mesh / Movement / Capsule) | ~100-200 μs | + 物理 + 多 component |
| 复杂 AHero(含 GAS / 武器 / Skin) | ~500 μs - 几 ms | 大量 component + GAS init |

**RTS 50K 单位测算**:
- 50K × 200 μs = **10 秒** spawn 时间 — 完全不可行
- 即使分摊 10 帧 spawn(每帧 5K),每帧 1 秒,**也卡爆**

**Mass `CreateEntity` 几百 ns**(§17 详讲),50K × 几百 ns = **几十毫秒**,可分摊到几帧。

## 8.1.7 RTS / Mass 视角下的 SpawnActor 纪律

### 8.1.7.1 OK 用 SpawnActor 的场景

```cpp
✅ 英雄、Boss(数量 < 100,生命周期长,需要复杂 BP 逻辑)
✅ Player Pawn(每玩家 1 个)
✅ 主基地、关键建筑(数量级 < 1000)
✅ 主菜单 UI 对应的 actor
```

### 8.1.7.2 不该用 SpawnActor 的场景

```cpp
❌ 大军单位(几千 - 几万)→ Mass entity
❌ 投射物(每帧几百)→ Mass entity
❌ 临时特效(粒子)→ Niagara,不是 Actor
❌ 装饰物(草、石头)→ ISMC + Mass(如有交互)
```

### 8.1.7.3 优化 SpawnActor 调用

如果你**必须** spawn 大量 actor(比如关卡加载时一次性 spawn 1000 个建筑):

1. **碰撞处理用 AlwaysSpawn**(关碰撞检测)
2. **Components 简化**(不需要的 component 删掉,RTS 建筑可能不需要 Capsule)
3. **延迟 BeginPlay**:`bDeferConstruction = true`,批量 spawn 完一次性 begin play
4. **Spawn 到 Hidden Level**:某些 actor 平时不可见,放到 Hidden streaming level

### 8.1.7.4 Pool(对象池)

频繁 spawn / despawn 同种 actor → 池化:

```cpp
class URTSActorPool : public UWorldSubsystem
{
    TArray<TObjectPtr<AHero>> AvailableHeroes;
    
public:
    AHero* Acquire()
    {
        if (AvailableHeroes.Num() > 0)
        {
            AHero* H = AvailableHeroes.Pop();
            H->Reset();           // 你的 reset 函数
            H->SetActorHiddenInGame(false);
            return H;
        }
        return GetWorld()->SpawnActor<AHero>();
    }
    
    void Release(AHero* H)
    {
        H->Deactivate();
        H->SetActorHiddenInGame(true);
        AvailableHeroes.Push(H);
    }
};
```

避免重复 NewObject + GC + NewObject 循环。

## 8.1.8 Spawn 失败的常见原因

```cpp
AActor* A = World->SpawnActor<AMyActor>(...);
if (!A)
{
    // 为什么 nullptr?
}
```

可能原因(按概率):
1. **类是 Abstract**:UCLASS(Abstract) 标记的不能直接 spawn
2. **碰撞失败**:DontSpawnIfColliding + 起始位置有碰撞
3. **类是 Deprecated**:`CLASS_Deprecated` flag
4. **World 在 Tearing Down**:关卡正在销毁
5. **SpawnInside 限制**:Class 的 `ClassWithin` 限制 Outer 类型,SpawnParameters.OverrideLevel 不匹配
6. **NeedsLoadForClient/Server 失败**:类配置只在 server / client 加载,你在错误端 spawn

`-log` 日志会输出 `LogSpawn: Warning: SpawnActor failed because ...`。

## 8.1.10 实操与下一节预告

### 实操

测一次 SpawnActor:

```cpp
static FAutoConsoleCommand CmdSpawnBench(TEXT("rts.SpawnBench"),
    TEXT("Bench SpawnActor"),
    FConsoleCommandDelegate::CreateLambda([]()
    {
        UWorld* W = GWorld;
        const int32 N = 1000;
        TArray<AStaticMeshActor*> Spawned;
        Spawned.Reserve(N);
        
        double Start = FPlatformTime::Seconds();
        for (int32 i = 0; i < N; ++i)
        {
            FActorSpawnParameters P;
            P.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;
            AStaticMeshActor* A = W->SpawnActor<AStaticMeshActor>(
                FVector(i * 100.0f, 0, 0), FRotator::ZeroRotator, P);
            Spawned.Add(A);
        }
        UE_LOG(LogTemp, Display, TEXT("SpawnActor x%d: %.2fμs/op"), 
            N, (FPlatformTime::Seconds() - Start) * 1e6 / N);
        
        for (AActor* A : Spawned) A->Destroy();
    }));
```

跑 `rts.SpawnBench`,看每个 SpawnActor 多少 μs。然后对照 Mass 数据(Mass `CreateEntity` 几百 ns),你会立刻看到差距。
