# §13.4 Replication Graph

> **本节地图**:模块三第 13 章第 4 节。前面看了传统 ReplicateActors 的 O(N) 扫描问题。**Replication Graph** 是 Epic 推出的优化方案 — 把 actor 按"流式空间"组织,减少每帧扫描量。
>
> Iris(§12.4)是更新一代,Replication Graph 是过渡期方案。但 Fortnite Battle Royale 至今用 Replication Graph,生产可用。

## 13.4.1 浅入:为什么需要 Graph

传统:
```
每帧每 connection × 所有 actor → 50K × 10 = 500K 次扫描
```

Replication Graph:
```
预先把世界划分网格 → 每 cell 一个"node"管自己 actor
每帧每 connection 只关心自己附近的 cell → ~几十个 actor
```

差**几个数量级**。

## 13.4.3 Graph Node 结构

```cpp
class UReplicationGraphNode_GridSpatialization2D : public UReplicationGraphNode
{
    // 2D 网格(适合俯视游戏 / RTS / Battle Royale)
    int32 CellSize;        // 网格大小
    
    // 每个 cell 一个 子 node 列表
    TMap<FCellLocation, UReplicationGraphNode*> CellMap;
    
    virtual void GatherActorListsForConnection(...) override
    {
        // 玩家位置 → 决定哪些 cell 在视野内 → 取那些 cell 的 actor 列表
    }
};
```

其它 node 类型:
- `UReplicationGraphNode_AlwaysRelevant_ForConnection`(总是 relevant 的,如 PC / GameState)
- `UReplicationGraphNode_DormancyNode`(休眠 actor 池)
- `UReplicationGraphNode_ConnectionDormancyNode`

每种 node 处理一类 actor。

## 13.4.4 自定义 RTS Graph

```cpp
class URTSReplicationGraph : public UReplicationGraph
{
    UReplicationGraphNode_GridSpatialization2D* GridNode;
    UReplicationGraphNode_AlwaysRelevant_ForConnection* AlwaysRelNode;
    
    virtual void InitGlobalGraphNodes() override
    {
        Super::InitGlobalGraphNodes();
        
        GridNode = CreateNewNode<UReplicationGraphNode_GridSpatialization2D>();
        GridNode->CellSize = 10000;        // 100m 一格
        AddGlobalGraphNode(GridNode);
        
        // 总是 relevant(GameState / 玩家自己 PC)
        AlwaysRelNode = CreateNewNode<UReplicationGraphNode_AlwaysRelevant_ForConnection>();
    }
    
    virtual void RouteAddNetworkActorToNodes(const FNewReplicatedActorInfo& Info, FGlobalActorReplicationInfo& Global) override
    {
        // 决定 actor 该进哪个 node
        if (Info.Class == AHero::StaticClass() || Info.Class == ABuilding::StaticClass())
        {
            GridNode->AddActor_Static(Info, Global);
        }
        else if (Info.Class == ARTSGameState::StaticClass())
        {
            AlwaysRelNode->NotifyAddNetworkActor(Info);
        }
    }
};
```

## 13.4.5 Replication Graph vs Iris vs 传统

| | 传统 | Replication Graph | Iris |
|---|---|---|---|
| 模型 | Polled,O(N) | Spatial node,O(K) | Pushed,只算 dirty |
| 适合规模 | < 1K actor | 几千 - 几万 | 几万到百万 |
| API | DOREPLIFETIME | 同 + Graph 配置 | DOREPLIFETIME + MARK_PROPERTY_DIRTY |
| 5.x 成熟度 | 稳 | 稳 | 生产可用 |
| 推荐 | 小项目 / 兼容 | Battle Royale 类 | 大规模 / RTS |

## 13.4.6 RTS 选型

```
小型 RTS(< 1K Actor):
   ✓ 传统 + 优化(NetUpdateFrequency / NetCullDistance / Dormancy)

中型 RTS(1K - 10K Actor):
   ✓ Replication Graph

大型 RTS(50K Mass entity):
   ✓ Iris + Mass 自定义复制(§14 / §21)
```
