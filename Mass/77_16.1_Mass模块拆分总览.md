## 16.1.3 核心模块详解

### 16.1.3.1 `MassEntity`(必备)

**位置**:`Engine/Source/Runtime/MassEntity/`(5.5 起合入 Engine)

**职责**:
- `FMassEntityHandle` 定义
- `FMassEntityManager`(Entity / Archetype / Chunk 数据中枢)
- `FMassFragment` / `FMassTag` 基类
- `UMassEntitySubsystem`(WorldSubsystem)
- `UMassProcessor` 基类
- `FMassEntityQuery`
- `FMassFragmentBitSet` / `FMassTagBitSet`
- 命令缓冲(`FMassCommandBuffer`)

**Build.cs**:`PublicDependencyModuleNames.Add("MassEntity");`

### 16.1.3.2 `MassCommon`(几乎必备)

**位置**:`Engine/Plugins/Runtime/MassGameplay/Source/MassCommon/`

**职责**:
- `FMassTransformFragment` 等通用 Fragment
- `FMassNetworkIDFragment`
- 共享 Trait(`UMassActorTrait`)

### 16.1.3.3 `MassSimulation`(必备)

**职责**:
- `UMassSimulationSubsystem` 调度 Processor
- ProcessingPhase 管理(PrePhysics / PostPhysics 等)
- Tick 入口

### 16.1.3.4 `MassActors`(若需 Actor ↔ Mass 桥接)

**职责**:
- `UMassActorSubsystem`(Mass entity ↔ Actor 双向映射)
- `UMassActorTrait`(让 entity "拥有"一个 Actor)

**RTS 用例**:Hero 是 Actor + 关联 Mass entity(混合模式)。

## 16.1.4 Gameplay 扩展模块

### 16.1.4.1 `MassMovement`

`FMassVelocityFragment` / `FMassForceFragment` / Steering Behavior(分离 / 对齐 / 内聚)。

### 16.1.4.2 `MassLOD`

`FMassLODFragment` + `UMassLODProcessor`,按距离玩家做四档 LOD(High/Medium/Low/Off)。RTS 必备。

### 16.1.4.3 `MassRepresentation`

`UMassRepresentationSubsystem` 决定 entity 用什么视觉(ISMC instance / Skeletal Actor / 隐藏)。

### 16.1.4.4 `MassReplication`

Mass 网络复制层,与 Iris 集成(§14.4)。

### 16.1.4.5 `MassSpawner`

`UMassSpawner`(放在关卡里的 actor)+ `UMassEntityConfigAsset`(资产配置 spawn 模板)。

## 16.1.5 调试 / Editor 扩展

```
MassGameplayDebug:    可视化 entity / Processor 状态
MassGameplayEditor:   Editor 工具(EntityConfig 编辑器)
MassGameplayTestSuite: 自动化测试
```

开发期开启,Shipping 关掉。

---

## 16.1.6 AI 扩展(可选)

```
MassAI:        AI 总集
MassAIBehavior: StateTree 集成(替代 Behavior Tree)
MassAvoidance:  RVO 局部避障
MassNavigation: 寻路
MassZoneGraph:  ZoneGraph 集成
```

RTS 大军走路 / 避障必备。

## 16.1.7 RTS 项目依赖建议

```cpp
// MyRTSMass.Build.cs
PublicDependencyModuleNames.AddRange(new string[] {
    "Core", "CoreUObject", "Engine",
    
    "MassEntity",            // 核心

    "MassSimulation",        // 调度
    "MassSignals",           // 事件
    "MassSpawner",           // 实体 spawn
    "MassMovement",          // 移动
    "MassLOD",               // LOD
    "MassRepresentation",    // 视觉
    "MassReplication",       // 网络
    
    // 可选:
    // "MassActors",          // Actor 桥接(英雄混合模式用)
    // "MassAI",              // AI 高层
    // "MassNavigation",      // 寻路
    // "MassAvoidance",       // 避障
});
```

## 16.1.8 Plugin 启用

`MyRTS.uproject` 启用相关 Plugin:

```json
{
    "Plugins": [
        { "Name": "MassEntity", "Enabled": true },
        { "Name": "MassGameplay", "Enabled": true },
        { "Name": "MassAI", "Enabled": true }
    ]
}
```

注:5.5+ MassEntity 已合入 Engine,启不启用 plugin 都可(plugin 只是历史占位)。
