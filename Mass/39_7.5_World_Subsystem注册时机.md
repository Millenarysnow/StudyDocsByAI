## 7.5.1 `UWorldSubsystem` 完整接口

`Engine/Source/Runtime/Engine/Public/Subsystems/WorldSubsystem.h:14`:

```cpp
UCLASS(Abstract, MinimalAPI)
class UWorldSubsystem : public USubsystem
{
public:
    UWorldSubsystem();
    
    virtual UWorld* GetWorld() const override final;
    UWorld& GetWorldRef() const;
    
    // 创建过滤
    virtual bool ShouldCreateSubsystem(UObject* Outer) const override;
    
    // 生命周期 5 个 hook
    virtual void Initialize(FSubsystemCollectionBase& Collection) override;
    virtual void PostInitialize();
    virtual void OnWorldBeginPlay(UWorld& InWorld);
    virtual void OnWorldEndPlay(UWorld& InWorld) {}
    virtual void Deinitialize() override;       // 来自 USubsystem
    
    // 其它 hook
    virtual void PreDeinitialize() {}
    virtual void OnWorldComponentsUpdated(UWorld& World) {}
    
protected:
    virtual bool DoesSupportWorldType(const EWorldType::Type WorldType) const;
    
    bool bHasCalledPostInitialize : 1 = false;
    bool bHasCalledBeginPlay : 1 = false;
};
```

### 7.5.1.1 五个生命周期 hook

```
World 创建:
   World->InitWorld
      ├─ SubsystemCollection.Initialize
      │     ├─ Subsystem::Initialize        ★ hook 1
      │     ├─ Subsystem::PostInitialize    ★ hook 2(所有 Subsystem 都 Init 完后)
      │     └─ ...

World 进入游戏:
   World->BeginPlay
      ├─ Subsystem::OnWorldBeginPlay         ★ hook 3
      ├─ Actor::BeginPlay 链
      └─ ...

[运行时 Tick]

World 准备销毁:
   World->BeginTearingDown
      ├─ Subsystem::OnWorldEndPlay           ★ hook 4
      ├─ Subsystem::PreDeinitialize
      └─ ...

World 销毁:
   ├─ Subsystem::Deinitialize                ★ hook 5
   └─ Subsystem 被 GC 回收
```

## 7.5.2 hook 1:`Initialize`

```cpp
virtual void Initialize(FSubsystemCollectionBase& Collection)
{
    Super::Initialize(Collection);
    
    // World 已存在但还没 BeginPlay
    // - 可以访问 GetWorld()
    // - 可以创建对象、注册委托
    // - 不能访问 GameMode / GameState(还没 spawn)
    // - 不能访问其它 Subsystem(它们可能还没 Init)
}
```

`FSubsystemCollectionBase& Collection` 让你声明依赖:

```cpp
virtual void Initialize(FSubsystemCollectionBase& Collection) override
{
    // 声明:我必须在 URTSCoreSubsystem 之后初始化
    Collection.InitializeDependency<URTSCoreSubsystem>();
    
    Super::Initialize(Collection);
    
    // 现在 URTSCoreSubsystem 一定已 Initialize
    URTSCoreSubsystem* Core = GetWorld()->GetSubsystem<URTSCoreSubsystem>();
    Core->RegisterMe(this);
}
```

`InitializeDependency<T>` 强制依赖关系。**避免循环依赖**(A 依赖 B,B 依赖 A → 死循环)。

## 7.5.3 hook 2:`PostInitialize`

```cpp
virtual void PostInitialize()
{
    // 所有 WorldSubsystem 都已 Initialize
    // - 可以安全访问任何其它 Subsystem
    // - 但 World 还没 BeginPlay
}
```

实战:**Subsystem 间相互访问的初始化**放这里。

```cpp
class URTSCommandSubsystem : public UWorldSubsystem
{
    virtual void PostInitialize() override
    {
        // 此时所有 Subsystem 已就绪
        URTSCombatSubsystem* Combat = GetWorld()->GetSubsystem<URTSCombatSubsystem>();
        URTSFogSubsystem* Fog = GetWorld()->GetSubsystem<URTSFogSubsystem>();
        
        // 注册回调
        Combat->OnUnitKilled.AddUObject(this, &ThisClass::HandleKill);
    }
};
```

## 7.5.6 hook 5:`Deinitialize`

```cpp
virtual void Deinitialize()
{
    // World 销毁时调
    // - 释放外部资源(线程、文件、网络)
    // - 解除委托(避免 dangling)
```

## 7.5.7 `ShouldCreateSubsystem` —— 创建过滤

`WorldSubsystem.cpp` 默认实现:

```cpp
bool UWorldSubsystem::ShouldCreateSubsystem(UObject* Outer) const
{
    if (!Super::ShouldCreateSubsystem(Outer))
        return false;
    
    UWorld* World = Cast<UWorld>(Outer);
    return World && DoesSupportWorldType(World->WorldType);
}

bool UWorldSubsystem::DoesSupportWorldType(const EWorldType::Type WorldType) const
{
    // 默认:Game / PIE 都支持,Editor / Inactive 不支持
    return WorldType == EWorldType::Game 
        || WorldType == EWorldType::PIE;
}
```

**含义**:默认 WorldSubsystem **只**在 Game 和 PIE World 创建。Editor World 默认**不**创建。

### 7.5.7.1 重写 `DoesSupportWorldType`

如果你 Subsystem 在 Editor World 也要创建(典型:可视化工具):

```cpp
class URTSDebugVisualizerSubsystem : public UWorldSubsystem
{
    virtual bool DoesSupportWorldType(const EWorldType::Type WorldType) const override
    {
        // Editor + Game + PIE 都创建
        return WorldType == EWorldType::Game 
            || WorldType == EWorldType::PIE
            || WorldType == EWorldType::Editor;
    }
};
```

### 7.5.7.2 重写 `ShouldCreateSubsystem` 自定义逻辑

```cpp
class URTSCombatSubsystem : public UWorldSubsystem
{
    virtual bool ShouldCreateSubsystem(UObject* Outer) const override
    {
        UWorld* W = Cast<UWorld>(Outer);
        if (!W || !W->IsGameWorld()) return false;
        
        // 仅在战斗关卡创建(主菜单关卡不需要)
        if (W->GetMapName().Contains(TEXT("Menu"))) return false;
        
        return true;
    }
};
```

## 7.5.8 `UTickableWorldSubsystem` —— 自带 Tick

`WorldSubsystem.h:74`:

```cpp
class UTickableWorldSubsystem : public UWorldSubsystem, public FTickableGameObject
{
public:
    // FTickableGameObject 接口
    virtual UWorld* GetTickableGameObjectWorld() const override;
    virtual ETickableTickType GetTickableTickType() const override;
    virtual bool IsAllowedToTick() const override final;
    virtual void Tick(float DeltaTime) override;
    virtual TStatId GetStatId() const override = 0;     // 必须实现
    
    virtual void Initialize(FSubsystemCollectionBase& Collection) override;
    virtual void Deinitialize() override;
    virtual void BeginDestroy() override;
    
    bool IsInitialized() const { return bInitialized; }
};
```

`UTickableWorldSubsystem` 继承自 `FTickableGameObject`(§6.4.10.4),提供"自动每帧 tick"。

### 7.5.8.1 用法

```cpp
UCLASS()
class URTSFogOfWarSubsystem : public UTickableWorldSubsystem
{
    GENERATED_BODY()
public:
    virtual void Tick(float DeltaTime) override
    {
        // 每帧调
        UpdateVisibilityMatrix(DeltaTime);
    }
    
    virtual TStatId GetStatId() const override
    {
        RETURN_QUICK_DECLARE_CYCLE_STAT(URTSFogOfWarSubsystem, STATGROUP_Tickables);
    }
};
```

注:**没有显式 Tick 注册** —— 继承 `UTickableWorldSubsystem` 即开启每帧 tick。Initialize 后 tick 启动,Deinitialize 后停止。

### 7.5.8.2 与 Actor Tick 的区别

`UTickableWorldSubsystem::Tick` 在 `World->Tick` 末尾被调,**不属于任何 TickGroup**。如果你需要"PrePhysics 之前 / DuringPhysics 期间" tick,Subsystem Tick **不合适**,要用 Actor / Component 的 PrimaryActorTick。

## 7.5.9 `UMassEntitySubsystem` —— 实战示例

```cpp
class UMassEntitySubsystem : public UWorldSubsystem
{
public:
    virtual void Initialize(FSubsystemCollectionBase& Collection) override
    {
        Super::Initialize(Collection);
        
        // 创建 EntityManager(数据中枢)
        EntityManager = MakeShared<FMassEntityManager>(this);
        
        // 收集所有 Fragment / Tag 类型,分配 BitSet 索引
        EntityManager->Initialize();
    }
    
    virtual void OnWorldBeginPlay(UWorld& InWorld) override
    {
        Super::OnWorldBeginPlay(InWorld);
        
        // World 已 BeginPlay,可以让 Mass Spawner 开始 spawn entity
    }
    
    virtual void Deinitialize() override
    {
        // 销毁所有 entity
        EntityManager->Reset();
        EntityManager.Reset();
        
        Super::Deinitialize();
    }
    
    TSharedPtr<FMassEntityManager> EntityManager;
};
```

§17 / §18 详讲 Mass 内部。这里你只需要建立"`UMassEntitySubsystem` 是 `UWorldSubsystem`,完全标准 hook 链"的认知。

## 7.5.10 `GetSubsystem` 的访问

```cpp
// 在 UObject 类内部
class UMyObject : public UObject
{
    void Foo()
    {
        // 取当前 World 的 Subsystem
        URTSCombatSubsystem* C = GetWorld()->GetSubsystem<URTSCombatSubsystem>();
        if (C) C->DoStuff();
    }
};

// Actor 内
AActor::Foo()
{
    URTSCombatSubsystem* C = GetWorld()->GetSubsystem<URTSCombatSubsystem>();
}

// 全局(罕见,需要 World 参数)
URTSCombatSubsystem* C = SomeWorld->GetSubsystem<URTSCombatSubsystem>();
```

`GetSubsystem<T>()` 是 O(1) 查找(`TMap<UClass*, USubsystem*>`)。

## 7.5.12 Subsystem 间通信模式

### 7.5.12.1 直接调用(同 World)

```cpp
class URTSCombatSubsystem : public UWorldSubsystem
{
    void OnUnitDies(const FUnitInfo& Info)
    {
        // 通知经济 Subsystem 给击杀奖励
        URTSEconomySubsystem* Eco = GetWorld()->GetSubsystem<URTSEconomySubsystem>();
        Eco->RewardKill(Info);
    }
};
```

### 7.5.12.2 委托(松耦合)

```cpp
class URTSCombatSubsystem : public UWorldSubsystem
{
public:
    DECLARE_MULTICAST_DELEGATE_OneParam(FOnUnitKilled, const FUnitInfo&);
    FOnUnitKilled OnUnitKilled;
    
    void OnUnitDies(const FUnitInfo& Info)
    {
        OnUnitKilled.Broadcast(Info);
    }
};

class URTSEconomySubsystem : public UWorldSubsystem
{
    virtual void PostInitialize() override
    {
        URTSCombatSubsystem* Combat = GetWorld()->GetSubsystem<URTSCombatSubsystem>();
        Combat->OnUnitKilled.AddUObject(this, &ThisClass::OnUnitKilled);
    }
    
    void OnUnitKilled(const FUnitInfo& Info) { RewardKill(Info); }
};
```

委托模式更好:Combat 不需要知道哪些 Subsystem 在听,Economy / FogOfWar / UI 都可挂。

## 7.5.13 关键纪律总结

```
✅ Subsystem 职责单一,< 500 行
✅ 用 InitializeDependency<T> 声明强依赖
✅ Subsystem 间用委托(MulticastDelegate)解耦
✅ ShouldCreateSubsystem 过滤不需要的 World 类型
✅ Deinitialize 必须解除所有委托(防止 dangling)
✅ 需要 tick 用 UTickableWorldSubsystem
✅ 需要存档配置用 UDeveloperSettings(配合 UEngineSubsystem)

❌ 不要在 Initialize 里访问其它 Subsystem(用 PostInitialize)
❌ 不要在 Initialize 里访问 GameMode(用 OnWorldBeginPlay)
❌ 不要让 Subsystem 持有 50K Actor 引用(GC mark 慢)
❌ 不要在 hot path Tick 里 GetSubsystem(缓存指针)
```
