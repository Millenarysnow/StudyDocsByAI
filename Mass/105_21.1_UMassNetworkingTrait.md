## 21.1.1 Mass Replication 的"目标"

让 entity 状态:
- Server 计算 → Client 看到
- 兴趣管理(每 client 仅看自己 bubble 内 entity)
- 量化压缩(节省带宽)
- 与 Iris 集成

---

## 21.1.2 Trait

```
DA_Soldier:
   - UMassNetworkingTrait        分配 NetID + 复制配置
   - UMassReplicationTrait       具体复制策略
```

每 entity 加 `FMassNetworkIDFragment` + `FMassReplicatedFragment`。

---

## 21.1.3 NetID Fragment

```cpp
USTRUCT()
struct FMassNetworkIDFragment : public FMassFragment
{
    int32 NetID;           // server 分配的紧凑 ID(几字节)
};
```

紧凑 ID(4 字节)替代 NetGUID(几十字节)。50K entity × 4 字节 = 200KB 网络元数据,可接受。

---

## 21.1.4 ReplicatedFragment

```cpp
USTRUCT()
struct FMassReplicatedFragment : public FMassFragment
{
    int32 BubbleID;       // 在哪个 bubble 内
    EReplicationState State;
};
```

Server 端管理 bubble,client 端跟着 bubble 接收。
