## 24.3.1 GameMode 启动 Mass 战场

```cpp
void ARTSGameMode::HandleMatchHasStarted()
{
    Super::HandleMatchHasStarted();
    
    UMassSpawnerSubsystem* Spawner = GetWorld()->GetSubsystem<UMassSpawnerSubsystem>();
    
    // 给每队 spawn 起始单位
    for (int32 TeamID = 0; TeamID < TeamConfigs.Num(); ++TeamID)
    {
        // 起始 worker
        TArray<FTransform> WorkerSpawns = GetTeamSpawnPoints(TeamID, EUnitType::Worker, 5);
        TArray<FMassEntityHandle> Workers;
        Spawner->SpawnEntities(DA_Worker, WorkerSpawns, Workers);
        AssignTeam(Workers, TeamID);
        
        // 起始建筑
        SpawnTeamHQ(TeamID);
    }
    
    // 启动战斗 Subsystem
    URTSCombatSubsystem* Combat = GetWorld()->GetSubsystem<URTSCombatSubsystem>();
    Combat->StartMatch();
}

void ARTSGameMode::HandleMatchHasEnded(...)
{
    Super::HandleMatchHasEnded(...);
    
    // 销毁所有 entity
    UMassEntitySubsystem* MS = GetWorld()->GetSubsystem<UMassEntitySubsystem>();
    FMassEntityManager& EM = MS->GetMutableEntityManager();
    
    EM.BatchDestroyAllEntities();    // 或选择性销毁
    
    URTSCombatSubsystem* Combat = GetWorld()->GetSubsystem<URTSCombatSubsystem>();
    Combat->EndMatch();
    
    // 显示比分屏
}
```

## 24.3.2 World BeginPlay → Mass 启动顺序

```
Map Loaded
   ↓
World->InitWorld
   ├─ WorldSubsystem::Initialize(包括 Mass Subsystem)
   ↓
World->BeginPlay
   ├─ Subsystem::OnWorldBeginPlay
   ├─ Actor::BeginPlay 链
   │     └─ ARTSGameMode::BeginPlay → HandleMatchHasStarted
   │           └─ Spawner->SpawnEntities
   ↓
[第一帧 Mass tick]
   Processor 处理 entity
```
