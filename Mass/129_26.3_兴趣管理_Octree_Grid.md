## 26.3.1 Spatial Index 数据结构选型

```
Grid(均匀网格):
   ✓ 简单
   ✓ insert / remove O(1)
   ✓ 适合均匀分布
   ✗ 大 cell 浪费

Octree(八叉树):
   ✓ 适合非均匀
   ✓ query 快(深度 log N)
   ✗ insert / remove 略慢

Sparse Grid:
   ✓ 大场景 + 局部稠密
   ✓ 仅 cell 有 entity 时分配
```

RTS 通常用 **Grid**(战场分布相对均匀)+ cell 大小 ~50m。

## 26.3.2 RTS Spatial Index Subsystem

```cpp
class URTSSpatialIndexSubsystem : public UWorldSubsystem
{
    // Grid:cell 包含 entity 列表
    TMap<FIntPoint, TArray<FMassEntityHandle>> Grid;
    
    static constexpr float CellSize = 5000.0f;      // 50m
    
public:
    void UpdateEntity(FMassEntityHandle E, FVector OldPos, FVector NewPos)
    {
        FIntPoint OldCell = ToCell(OldPos);
        FIntPoint NewCell = ToCell(NewPos);
        if (OldCell != NewCell) {
            Grid[OldCell].Remove(E);
            Grid[NewCell].Add(E);
        }
    }
    
    TArray<FMassEntityHandle> QueryRadius(FVector Center, float Radius)
    {
        TArray<FMassEntityHandle> Result;
        // 遍历相关 cells
        FIntPoint MinC = ToCell(Center - FVector(Radius, Radius, 0));
        FIntPoint MaxC = ToCell(Center + FVector(Radius, Radius, 0));
        for (int32 X = MinC.X; X <= MaxC.X; ++X)
            for (int32 Y = MinC.Y; Y <= MaxC.Y; ++Y)
                if (auto* List = Grid.Find(FIntPoint(X, Y)))
                    Result.Append(*List);
        return Result;
    }
};
```

每帧 Mass MovementProcessor 末尾更新位置。

## 26.3.3 性能

```
50K entity:
   - 每 entity 移动 → 检测 cell 变化(~10 ns)
   - 仅 cell 变时更新 Grid
   - 50K × 10 ns = 0.5 ms / 帧

Query:
   - 5km 半径 = 100 × 100 = 10000 cells(50m cell)
   - 但 RTS 玩家相机 1km 半径 = 20 × 20 = 400 cells
   - 每 cell 平均几个 entity → 几千 entity 命中
   - 几 μs / query
```
