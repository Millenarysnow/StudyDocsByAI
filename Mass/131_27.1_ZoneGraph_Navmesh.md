# §27.1 ZoneGraph 与 Navmesh 对比

> **本节地图**:模块五第 27 章第 1 节。寻路系统选型。
>
> **预备知识**:§20.3-§20.5。

---

## 27.1.1 Navmesh

```
经典寻路:
   - 关卡内 mesh 表示"可走区域"
   - A* 搜索找路径
   - 每个 agent 一次 query
```

适合:
- ✓ 普通 NPC(100 个以内)
- ✗ 50K Mass 单位每个 query 太慢

---

## 27.1.2 ZoneGraph

```
ZoneGraph:
   - 把世界抽象成"lane"(车道线)
   - Agent 沿 lane 移动
   - 适合"道路 / 巡逻"场景
```

适合:
- ✓ 城市 / 道路系统
- ✓ Lane-based 移动(Crowd 模拟)
- ✗ 自由战场移动(RTS 不太适合)

---

## 27.1.3 流场(Flow Field)

```
流场:
   - 计算"每 cell 该往哪走"(向量场)
   - 一次性计算,所有 agent 共享
   - 大规模 group 寻路 ★ RTS 推荐
```

详 §27.3。

---

## 27.1.4 RTS 寻路选型

```
小队 / 寻路精度高 → A* + Navmesh
中等规模 → ZoneGraph(道路 RTS)
大规模 group(几百单位同往一目标)→ 流场
   
混合:
   - 单位整体方向用流场
   - 局部避障用 RVO(§20.4)
```
