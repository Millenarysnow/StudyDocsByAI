## 29.1.1 Cook 是什么

```
Editor 资产(.uasset 含调试数据 / Editor only 字段) 
   ↓ Cook
Cooked 资产(优化、打包、移除 Editor 字段)
   ↓ Stage
Stage 目录(可执行 + 资产 + 配置)
   ↓ Package
Pak 文件(单文件压缩)+ Installer
```

---

## 29.1.2 BuildCookRun 命令

```
Engine/Build/BatchFiles/RunUAT.bat BuildCookRun \
   -project=Path/To/Project.uproject \
   -platform=Win64 \
   -clientconfig=Shipping \
   -cook -stage -package -archive \
   -archivedirectory=PackagedBuilds/
```

参数:
- `-cook`:执行 cook
- `-stage`:整理到 staging 目录
- `-package`:打 pak / installer
- `-archive`:输出到指定目录

---

## 29.1.3 RTS Cook 注意

```
Cook 时间:
   - 50 GB 工程 cook 一次 ~ 几小时
   - DDC(Derived Data Cache)缓存:第二次 cook 几分钟
   - 共享 DDC 服务器(团队):每人都从缓存拉
   
平台特定:
   - Windows / Linux Server / Linux Client / Mac
   - 每平台一次 cook(资产格式不同)

Cook 失败排查:
   - Saved/Logs/Cook-*.log
   - 常见:某资产引用空引用 → check + 跳过
```

---

## 29.1.4 Mass / RTS 资产 cook 关注点

```
- Mass EntityConfig 是 UDataAsset,正常 cook
- Mass Trait 是 UClass,正常 cook
- StaticMesh / Niagara / Material 大头(占 cook 时间 80%)
- Texture streaming pool / mip level 配置在 DefaultEngine.ini
```
