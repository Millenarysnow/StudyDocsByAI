## 18.8.1 Mass 调度时序

```
World->Tick (PrePhysics)
   ↓
UMassSimulationSubsystem 的 PrePhysics TickFunction 被调
   ↓
SimulationSubsystem 取该 phase 的 root CompositeProcessor
   ↓
CompositeProcessor.Execute
   ├─ 按 DAG 启动 child Processor task
   │     ├─ ProcessorA (UE::Tasks::Launch)
   │     ├─ ProcessorB (UE::Tasks::Launch,等 A 完成)
   │     └─ ...
   ├─ Wait 所有 task
   └─ Flush 命令缓冲
   ↓
返回 GameThread
```

每 child Processor 是一个 UE::Tasks task。Mass 用 `Prerequisites` 表达依赖。

## 18.8.2 ParallelForEachEntityChunk 内部

```cpp
// 简化伪代码
void Query::ParallelForEachEntityChunk(EM, Ctx, Func)
{
    TArray<FArchetypeChunk*> Chunks = FindMatchingChunks(EM);
    
    TArray<UE::Tasks::TTask<void>> Tasks;
    for (FArchetypeChunk* Chunk : Chunks)
    {
        Tasks.Add(UE::Tasks::Launch(UE_SOURCE_LOCATION,
            [Chunk, &Ctx, &Func]() {
                FMassExecutionContext ChunkCtx = MakeChunkContext(Ctx, Chunk);
                Func(ChunkCtx);
            }));
    }
    
    UE::Tasks::Wait(Tasks);
}
```

每 chunk 一个 UE::Tasks task。worker pool 自动并行。

## 18.8.5 第 18 章总结

到这里第 18 章完整闭环。Mass 调度核心:

```
UMassProcessor 子类 (ConfigureQueries + Execute)
   ↓
UMassSimulationSubsystem 启动时收集所有 Processor
   ↓
每 ProcessingPhase 一个 Composite
   ↓
DAG 排序(ExecutionOrder + RW 冲突自动)
   ↓
World->Tick 触发 phase TickFunction
   ↓
Composite Execute → 启动 child Processor tasks
   ↓
ParallelForEachEntityChunk → 每 chunk 一个 worker task
   ↓
命令缓冲 flush → 应用 archetype 迁移 / 销毁
```
