## 28.3.1 Memory Insights

```
trace channel:
   - Memory(分配 / 释放)
   - LoadTime(资产加载)

启动:
   UnrealEditor.exe -trace=Memory,LoadTime
```

Insights 显示:
- 每帧总分配 / 释放
- 按"tag"分组(每模块、每子系统)
- 内存泄漏检测(只增不减的 tag)

---

## 28.3.2 stat 命令

```
stat memory                 # 内存总览
stat memorystaticmesh        # static mesh 内存
stat memoryskeletalmesh
stat unitmemory              # 各模块内存
stat memoryprofiler          # 启用 mem profiler
```

实时数字显示在屏幕。

---

## 28.3.3 GC 监控

```
gc.MultithreadedDestructionEnabled 1   # 多线程 GC 销毁(默认开)
gc.IncrementalGCEnabled 1               # 5.x 增量 GC
gc.IncrementalReachabilityTimeLimit 0.002   # 每帧 GC 预算 2ms

stat gc                     # GC 耗时
gc.DumpRefsToObj <Name>      # dump 某 UObject 的引用链(找泄漏)
obj list                    # 列出所有 UObject(注意:几百万行)
obj list class=AActor        # 只列 Actor
```

---

## 28.3.4 RTS 内存预算

```
RTS 50K Mass + 100 Hero + 几千 Building:

Mass entity 数据:
   50K × 256 字节 = 12.8 MB
Mass Archetype 容器:
   ~10 MB
Hero / Building Actor:
   100 + 几千 = ~5K UObject × 几 KB = ~50 MB
渲染 / Mesh / 材质 / 贴图:
   1-2 GB
关卡资源:
   500 MB

总:~ 2-3 GB(典型 RTS,可控)
```

---

## 28.3.5 GC 性能

```
GC 总开销 = mark + sweep
Incremental GC 把 mark 拆到多帧:
   50K Mass entity 不在 GUObjectArray(Mass 不是 UObject)
   ☆ Mass 单位完全不增加 GC 开销 ★
   
+ 几千 Actor + ~10K UObject 子对象
   GC 每分钟跑一次:< 5 ms / GC pass(Incremental 拆 4-5 帧)
   
   每帧 GC overhead ≈ 1-2 ms
```

**Mass 重构后 GC 完全不是瓶颈**。
