## 15.5.1 GameplayTag

`FGameplayTag` 是层级化的 FName,用于:
- 状态标记(`State.Stunned` / `State.Burning`)
- 技能 ID
- 玩家关系(`Team.Red` / `Team.Blue`)

```ini
; DefaultGameplayTags.ini
+GameplayTagList=(Tag="Ability.Fireball")
+GameplayTagList=(Tag="State.Burning")
+GameplayTagList=(Tag="State.Stunned")
+GameplayTagList=(Tag="Team.Red")
+GameplayTagList=(Tag="Team.Blue")
```

```cpp
FGameplayTag Tag = FGameplayTag::RequestGameplayTag(TEXT("State.Burning"));
ASC->AddLooseGameplayTag(Tag);
ASC->RemoveLooseGameplayTag(Tag);

if (ASC->HasMatchingGameplayTag(Tag)) { /* */ }
```

### 15.5.1.1 RTS 用例

不止 GAS — Mass 也用 GameplayTag:

```cpp
// Mass Tag
USTRUCT()
struct FBurningTag : public FMassTag {};   // Mass 自带 Tag 系统
```

但 GameplayTag 是 GAS 专属(uid string-based),不要混用。

## 15.5.2 GameplayCue

视觉 / 音频反馈层。Server 触发,所有 client 自动播放(无 RPC 烦恼)。

```cpp
// Server 端
ASC->ExecuteGameplayCue(FGameplayTag::RequestGameplayTag("GameplayCue.Hit.Spark"));
```

```cpp
// 客户端定义 cue handler
UCLASS()
class URTSGameplayCue_HitSpark : public UGameplayCueNotify_Static
{
    virtual bool OnExecute_Implementation(...) override
    {
        SpawnEmitter(EmitterTemplate, Loc);
        return true;
    }
};
```

通过 `Tag → CueHandler` 注册,Server 调 ExecuteGameplayCue 触发。
