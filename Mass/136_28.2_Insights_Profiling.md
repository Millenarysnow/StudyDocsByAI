## 28.2.1 Insights 启动

```
# 1. 启动 Insights 
Engine/Binaries/Win64/UnrealInsights.exe

# 2. 游戏端开启 trace(命令行)
UnrealEditor.exe Project.uproject -trace=Cpu,Frame,Bookmark,Mass,Net

# 3. 或运行时
trace.start Cpu Frame Mass Net
trace.stop
```

数据流到 Insights,可视化每帧 CPU 时序。

---

## 28.2.2 关键 Trace Channel

```
Cpu       — 函数调用时序(SCOPE_CYCLE_COUNTER 自动着色)
Frame     — 帧边界
Bookmark  — 自定义标记
Mass      — Mass processor / phase
Net       — 网络 RPC / replication
GPU       — GPU 调用
Memory    — 分配 / 释放
RHI       — 渲染命令
```

只开需要的,trace 数据多了影响性能。

---

## 28.2.3 实战:50K Mass tick 分析

```
打开 Insights → Timing
找到一帧(~16 ms 长方形)
   ├─ FEngineLoop.Tick
   │   ├─ World.Tick
   │   │   ├─ Mass.PhaseStartFrame    [200 μs]
   │   │   ├─ Mass.PrePhysics          [3.2 ms] ← 找瓶颈
   │   │   │   ├─ MovementProcessor    [1.8 ms]   ★
   │   │   │   ├─ AvoidanceProcessor   [1.0 ms]
   │   │   │   └─ DamageProcessor      [0.4 ms]
   │   │   ├─ Physics                  [2 ms]
   │   │   ├─ Mass.PostPhysics         [1 ms]
   │   │   ├─ Render submission         [3 ms]
```

定位到 MovementProcessor 1.8 ms,展开看是不是某个 entity 走慢路径。

## 28.2.4 自定义 SCOPE

```cpp
void URTSCommandSubsystem::ProcessCommandQueue()
{
    TRACE_CPUPROFILER_EVENT_SCOPE(URTSCommandSubsystem_ProcessCommandQueue);
    // ...
}
```

或简化版:

```cpp
SCOPED_NAMED_EVENT(MyEvent, FColor::Red);
```

`TRACE_CPUPROFILER_EVENT_SCOPE` 自动加颜色与时长,Insights 直接看。
