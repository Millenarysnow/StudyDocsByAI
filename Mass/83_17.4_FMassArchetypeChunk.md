## 17.4.1 Chunk 是什么

Archetype 的 entity 数据被分割到多个 chunk:

```
Archetype A(N=2184 entity / chunk):

   Chunk 0  ← Entity 0..2183 在这
   Chunk 1  ← Entity 2184..4367
   Chunk 2  ← ...
   ...
```

每个 Chunk **独立分配**一段连续 128KB 内存(`FMemory::Malloc`,§1.2)。

---

## 17.4.2 Chunk 内 SoA 排布

```
Chunk 内部布局:

   ┌─────────────────────────────────┐ ← Chunk 起始
   │                                  │
   │  [Fragment A 数组 × N]            │  Fragment A 偏移 0
   │  比如 FPosition × 2184            │  
   │  (Pos[0], Pos[1], ..., Pos[2183]) │
   │                                  │
   ├─────────────────────────────────┤
   │  [Fragment B 数组 × N]            │  Fragment B 偏移 X
   │  FVelocity × 2184                 │
   │                                  │
   ├─────────────────────────────────┤
   │  [Fragment C 数组 × N]            │  Fragment C 偏移 Y
   │  FHealth × 2184                   │
   │                                  │
   ├─────────────────────────────────┤
   │  ... 其它 fragment ...           │
   │                                  │
   ├─────────────────────────────────┤
   │  [可能尾部空白 / padding]         │
   │                                  │
   └─────────────────────────────────┘ ← Chunk 末尾(128KB 处)
```

**SoA**:同 fragment 类型的所有 entity 数据**紧密连续**。

---

## 17.4.3 偏移计算

每个 fragment 在 chunk 内的偏移由 archetype 配置决定:

```cpp
// 简化:Archetype 计算
FMassArchetypeFragmentConfig FragmentConfigs[N_FRAGMENTS];
for (FragmentType : Fragments) {
    FragmentConfigs[i].Offset = CurrentOffset;
    FragmentConfigs[i].Size = FragmentType->Size;
    CurrentOffset += FragmentType->Size * EntityCountPerChunk;
}
```

固定一次,后续运行时不变。

## 17.4.4 访问 Fragment 数据

```cpp
// 给一个 entity 的 Position 字段地址
FMassPositionFragment* GetPosition(FMassEntityHandle E)
{
    int32 ChunkIndex = ...;       // 算 entity 在哪 chunk
    int32 IndexInChunk = ...;     // chunk 内 index
    
    FMassArchetypeChunk& Chunk = Archetype.Chunks[ChunkIndex];
    int32 PositionOffset = Archetype.FragmentConfigs[/*FPosition slot*/].Offset;
    
    uint8* Base = Chunk.GetMemory();
    FMassPositionFragment* PositionArray = (FMassPositionFragment*)(Base + PositionOffset);
    
    return &PositionArray[IndexInChunk];
}
```

`Base + Offset + Index * sizeof` 一次寻址。**单 entity 访问 ~10 ns**,但 hot path 用 Processor 批量(快得多)。

## 17.4.5 Processor 内的批量访问

```cpp
class URTSMovementProcessor : public UMassProcessor
{
    void Execute(EntityManager, Context)
    {
        Query.ForEachEntityChunk(EntityManager, Context, [&](FMassExecutionContext& Ctx)
        {
            // ★ 关键:拿到本 chunk 的 fragment 数组
            const TArrayView<FMassPositionFragment> Positions = Ctx.GetMutableFragmentView<FMassPositionFragment>();
            const TConstArrayView<FMassVelocityFragment> Velocities = Ctx.GetFragmentView<FMassVelocityFragment>();
            
            const int32 N = Ctx.GetNumEntities();
            const float DT = Ctx.GetDeltaTimeSeconds();
            
            for (int32 i = 0; i < N; ++i) {
                Positions[i].Position += Velocities[i].Velocity * DT;
            }
        });
    }
};
```

`GetMutableFragmentView<T>` / `GetFragmentView<T>` 返回 chunk 内连续数组的 ArrayView。**O(1) 拿到指针,然后顺序循环 = 极致快**。

## 17.4.6 Chunk 内存利用率

```
Chunk 大小 = 128 KB
SumOfFragmentSizes = 60 字节 / entity
Theoretical EntityCountPerChunk = 128 * 1024 / 60 = 2184

实际:
   N × 60 = 131,040 字节
   尾部空白 = 131,072 - 131,040 = 32 字节
   利用率 99.97% ✓
```

利用率非常高。但**fragment 总和过大**(几百字节)→ entity 数变少(20-100 / chunk),利用率仍 95%+。

**纪律**:Fragment 设计要"瘦"。每字段省 1 字节 × 50K = 50KB。

---

## 17.4.7 SharedFragment(每 chunk 一份)

`SharedFragment` 不每 entity 一份,而是**每 chunk 一份**:

```cpp
USTRUCT()
struct FMyChunkConfig : public FMassChunkFragment
{
    int32 LODLevel;
    float UpdateInterval;
};

// 在 chunk 内偏移:某个固定位置(单实例,非数组)
```

减少冗余存储(LODLevel 不需要每 entity 一份)。

## 17.4.8 实操与下一节预告

### 实操

```cpp
// Processor 内 ForEachEntityChunk 与 ForEachEntity 区别
Query.ForEachEntity(EntityManager, Context, [](FMassExecutionContext& Ctx, FMassEntityHandle E) {
    // 单 entity API,慢
});

Query.ForEachEntityChunk(EntityManager, Context, [](FMassExecutionContext& Ctx) {
    // chunk 级,快(SoA 数组直接访问)
    auto Positions = Ctx.GetMutableFragmentView<FPositionFragment>();
    for (int32 i = 0; i < Ctx.GetNumEntities(); ++i) Positions[i].X += DT;
});
```

**99% 用 ForEachEntityChunk**。
