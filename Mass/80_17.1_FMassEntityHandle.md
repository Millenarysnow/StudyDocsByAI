## 17.1.1 完整定义

`Engine/Source/Runtime/MassEntity/Public/MassEntityHandle.h:11`:

```cpp
USTRUCT()
struct alignas(8) FMassEntityHandle
{
    GENERATED_BODY()

    int32 Index = 0;
    int32 SerialNumber = 0;
    
    // 8 字节,完美对齐
};

static_assert(sizeof(FMassEntityHandle) == sizeof(uint64), "...");
```

**8 字节** = 一个指针的大小。比 UObject 头(40 字节)+ 任何字段都小得多。

---

## 17.1.2 Index 的含义

`Index` 是 Entity 在 `FMassEntityManager` 内部数组的下标:

```cpp
// FMassEntityManager 持有
TArray<FEntityData> Entities;     // 简化版

struct FEntityData
{
    FMassArchetypeHandle ArchetypeHandle;   // 在哪个 archetype
    int32 IndexInArchetype;                  // archetype 内位置
    int32 SerialNumber;                       // 当前 SN
};
```

`Entities[Handle.Index]` 拿到 entity 元数据。**O(1)** 查找。

---

## 17.1.3 SerialNumber 的防悬空

类似 `FUObjectItem.SerialNumber`(§3.2.5):

```
Entity 创建:Index 5,SN 1000
   ...
Entity 销毁:Index 5 的 entity 死了,Entities[5].SerialNumber 重置 / 递增

旧 handle 还持有 (Index=5, SN=1000)
新 entity 创建复用 Index 5,新 SN = 1001
   旧 handle 解析时:Entities[5].SN = 1001 != 1000 → INVALID
```

防止"旧 handle 引用到新 entity"的问题。

## 17.1.4 Validity 判断

```cpp
FMassEntityHandle E = ...;

if (E.IsSet())                               // 仅本地检查(Index != 0 && SN != 0)
{
    if (EM.IsEntityValid(E))                 // 完整检查(SN 与 Manager 内对照)
    {
        // 此 handle 指向真实存在的 entity
    }
}
```

## 17.1.5 转 uint64 / 跨网络传输

```cpp
FMassEntityHandle E = ...;
uint64 N = E.AsNumber();    // 8 字节整数

// 网络发送 N
// 接收端
FMassEntityHandle E2 = FMassEntityHandle::FromNumber(N);
```

注意:**SerialNumber 跨进程无效**(每进程独立计数器)。网络端要发 entity 时用 Mass NetID(§14.4),不是 raw EntityHandle。
