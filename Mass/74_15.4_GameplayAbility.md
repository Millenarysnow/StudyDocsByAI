## 15.4.1 GameplayAbility 是什么

```cpp
UCLASS()
class URTSFireballAbility : public UGameplayAbility
{
    GENERATED_BODY()
public:
    virtual void ActivateAbility(...) override
    {
        // 1. 检查冷却 / 资源
        if (!CommitAbility(...)) {
            EndAbility(...);
            return;
        }
        
        // 2. 启动 task(异步选目标 + 等待动画)
        UAbilityTask_PlayMontageAndWait* PlayTask = 
            UAbilityTask_PlayMontageAndWait::CreatePlayMontageAndWaitProxy(this, "Cast", FireballMontage);
        PlayTask->OnCompleted.AddDynamic(this, &ThisClass::OnAnimDone);
        PlayTask->ReadyForActivation();
    }
    
    UFUNCTION()
    void OnAnimDone(...)
    {
        // 3. 释放火球
        SpawnFireball(...);
        
        // 4. 应用伤害(对碰到敌人)
        // ...
        
        // 5. 结束
        EndAbility(...);
    }
};
```

## 15.4.2 AbilityTask(异步任务)

GAS 内置很多 AbilityTask:
- `UAbilityTask_WaitDelay`(等 N 秒)
- `UAbilityTask_PlayMontageAndWait`(播动画 + 等完)
- `UAbilityTask_WaitGameplayEvent`(等事件)
- `UAbilityTask_WaitTargetData`(选目标)
- ...

任务式:`Create...` + 设委托 + `ReadyForActivation()`。

## 15.4.3 TargetActor(选目标)

```cpp
UAbilityTask_WaitTargetData* TargetTask = 
    UAbilityTask_WaitTargetData::WaitTargetData(this, "TargetSelection",
        EGameplayTargetingConfirmation::Instant,
        ATargetActor_GroundTrace::StaticClass());
TargetTask->ValidData.AddDynamic(this, &ThisClass::OnTargetSelected);
TargetTask->ReadyForActivation();
TargetTask->StartTargeting(this);
```

`ATargetActor` 子类(GroundTrace / SphereSelect / Cone 等)处理玩家选择目标。

## 15.4.4 给 Ability + 激活

```cpp
// Server 端:给英雄添加 ability
FGameplayAbilitySpec Spec(URTSFireballAbility::StaticClass(), 1);
ASC->GiveAbility(Spec);

// 玩家按键激活
ASC->TryActivateAbilityByClass(URTSFireballAbility::StaticClass());
```

## 15.4.5 网络复制

Ability 自带网络复制(`InstancingPolicy` / `NetExecutionPolicy`):
- ServerOnly:服务器执行
- ClientOnly:客户端执行(限本地)
- LocalPredicted:本地预测,服务器纠正
- ServerInitiated:服务器主动触发,广播
