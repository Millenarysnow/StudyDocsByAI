## 18.1.2 一个最简 Processor

```cpp
UCLASS()
class URTSMovementProcessor : public UMassProcessor
{
    GENERATED_BODY()
public:
    URTSMovementProcessor()
    {
        ProcessingPhase = EMassProcessingPhase::PrePhysics;
        ExecutionOrder.ExecuteAfter.Add(UMassPlayerInputProcessor::StaticClass()->GetFName());
    }
    
    virtual void ConfigureQueries(const TSharedRef<FMassEntityManager>& EntityManager) override
    {
        Query.AddRequirement<FMassPositionFragment>(EMassFragmentAccess::ReadWrite);
        Query.AddRequirement<FMassVelocityFragment>(EMassFragmentAccess::ReadOnly);
        Query.AddTagRequirement<FActiveTag>(EMassFragmentPresence::All);
        
        Query.RegisterWithProcessor(*this);
    }
    
    virtual void Execute(FMassEntityManager& EM, FMassExecutionContext& Ctx) override
    {
        Query.ForEachEntityChunk(EM, Ctx, [&](FMassExecutionContext& InCtx)
        {
            const TArrayView<FMassPositionFragment> Pos = InCtx.GetMutableFragmentView<FMassPositionFragment>();
            const TConstArrayView<FMassVelocityFragment> Vel = InCtx.GetFragmentView<FMassVelocityFragment>();
            const float DT = InCtx.GetDeltaTimeSeconds();
            
            for (int32 i = 0; i < InCtx.GetNumEntities(); ++i)
            {
                Pos[i].Position += Vel[i].Velocity * DT;
            }
        });
    }
    
private:
    FMassEntityQuery Query;
};
```

5 部分:
1. ctor 设 ProcessingPhase + ExecutionOrder
2. `ConfigureQueries` 配置 Query
3. `Execute` 实际工作
4. `Query.ForEachEntityChunk` 批量遍历
5. 在 lambda 内访问 Fragment

## 18.1.3 Processor 自动注册

```cpp
bAutoRegisterWithProcessingPhases = true;   // 默认
```

启用后,`UMassSimulationSubsystem` 在 init 时自动**反射找出所有 UMassProcessor 子类**,实例化 + 加入对应 phase。

→ 你**只需要写**子类,**不需要**手动注册。

## 18.1.4 EMassProcessingPhase

```cpp
enum class EMassProcessingPhase : uint8
{
    PrePhysics,       // ★ 主要:玩家输入、AI 决策、命令处理
    StartPhysics,
    DuringPhysics,    // ★ 与物理并行:不依赖物理结果的逻辑
    EndPhysics,
    PostPhysics,      // ★ 物理后:基于物理结果的逻辑
    FrameEnd,         // ★ 末尾:LOD / Representation
    MAX,
};
```

每 phase 映射到 UWorld TickGroup(§8.3 / §8.4):
```
PrePhysics → TG_PrePhysics
DuringPhysics → TG_DuringPhysics
PostPhysics → TG_PostPhysics
FrameEnd → TG_PostUpdateWork
```

## 18.1.5 RTS Processor 的 phase 分布

```
PrePhysics:
   - URTSCommandProcessor       消费命令队列
   - URTSAIProcessor             AI 决策
   - URTSMovementProcessor      移动意图(Velocity)
   - URTSSelectionUpdateProcessor 玩家选择 sync

DuringPhysics:
   - URTSCombatProcessor         战斗(与物理并行)

PostPhysics:
   - URTSSteeringProcessor       Steering 调整(基于物理结果)
   - URTSSpawnProcessor           动态 spawn 处理

FrameEnd:
   - URTSLODProcessor            LOD 计算
   - URTSRepresentationProcessor 视觉更新(ISMC instances)
```
