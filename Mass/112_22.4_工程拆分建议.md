## 22.4.2 模块依赖

   ↓ 依赖

## 22.4.3 各层职责

| 模块 | 职责 |
|---|---|
| MyRTSCore | Fragment / Tag 数据结构 |
| MyRTSMass | Processor / Trait 逻辑 |
| MyRTSRender | VAT / ISMC 渲染剥离 |
| MyRTSNetwork | 自定义复制(若有) |
| MyRTS(主) | GameMode / Subsystem / Hero |
| MyRTSEditor | Editor 工具 |

迭代频率不同 → 拆开能让"高频改动"不触发"基础模块"重编。
