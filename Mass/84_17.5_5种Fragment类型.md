## 17.5.1 五种类型对照

```
┌─────────────────────────────┬─────────────────┬─────────────────────────┐
│  类型                        │  存储级别        │  用途                    │
├─────────────────────────────┼─────────────────┼─────────────────────────┤
│  FMassFragment               │  每 entity 一份  │  实例数据(Position / HP) │
│  FMassTag                    │  无数据          │  状态标签(Active / Dead) │
│  FMassChunkFragment          │  每 chunk 一份  │  chunk 共享配置(LOD)    │
│  FMassSharedFragment         │  跨 archetype   │  跨多组共享数据(可写)   │
│  FMassConstSharedFragment    │  跨 archetype   │  共享常量(只读)          │
└─────────────────────────────┴─────────────────┴─────────────────────────┘
```

---

## 17.5.2 FMassFragment(实例数据)

最常见。每 entity 一份:

```cpp
USTRUCT()
struct FMassPositionFragment : public FMassFragment
{
    GENERATED_BODY()
    FVector Position;
};
```

50K entity → 50K × sizeof 内存。

---

## 17.5.3 FMassTag(0 字节,纯类型标记)

```cpp
USTRUCT()
struct FBurningTag : public FMassTag {};   // 没字段!
```

Tag 不存数据,只**改 archetype**:
- entity 加 Tag → 进新 archetype(组合多了 Tag)
- entity 移 Tag → 回原 archetype

Query 用 Tag 过滤:

```cpp
Query.AddTagRequirement<FBurningTag>(EMassFragmentPresence::All);    // 必须含
Query.AddTagRequirement<FFrozenTag>(EMassFragmentPresence::None);    // 不能含
```

**比 Fragment 内 enum 更快**(整 archetype 跳过,不需运行时分支)。

---

## 17.5.4 FMassChunkFragment(每 chunk 一份)

```cpp
USTRUCT()
struct FMyChunkData : public FMassChunkFragment
{
    int32 LODLevel;
    float UpdateInterval;
};
```

每 chunk **一个实例**(不是一个 entity 一个)。chunk 内所有 entity 共享。

适用:
- chunk-level LOD 配置
- chunk-level 调试可视化标记
- 优化"每 entity 都一样的字段" 节省内存

---

## 17.5.5 FMassSharedFragment(跨 archetype 共享,可写)

```cpp
USTRUCT()
struct FUnitTypeData : public FMassSharedFragment
{
    UPROPERTY()
    TObjectPtr<UStaticMesh> Mesh;
    
    UPROPERTY()
    float MaxSpeed;
};
```

**跨 archetype 共享**:多个 archetype 引用同一 SharedFragment 实例。

```cpp
// 创建 / 取
FMassSharedFragment* Shared = EM.GetOrCreateSharedFragment<FUnitTypeData>(...);

// archetype 引用
FMassArchetypeCompositionDescriptor Comp;
Comp.SharedFragments.Add(*Shared);
FMassArchetypeHandle Archetype = EM.CreateArchetype(Comp);
```

适用:**单位类型配置数据**(每种单位一个 SharedFragment,而不是每 entity 一份)。

---

## 17.5.6 FMassConstSharedFragment(只读共享)

```cpp
USTRUCT()
struct FUnitTypeImmutable : public FMassConstSharedFragment
{
    int32 BaseHealth;
    float MaxSpeed;
};
```

跟 SharedFragment 类似,但**只读**。运行时不可改。

适用:配置数据(基础属性)+ archetype 整生命周期内不变。

---

## 17.5.7 数据分类决策

```
                   是 entity 实例数据(各自不同)?
                       /                     \
                      Yes                     No
                      ↓                        ↓
                FMassFragment             跨 archetype 共享?
                                              /        \
                                             Yes        No(每 archetype/chunk)
                                             ↓           ↓
                                       运行时可变?    每 chunk 还是每 entity 类型?
                                       /        \
                                     Yes         No
                                     ↓             ↓
                              SharedFragment   ConstSharedFragment

                      是状态标记(无数据)?
                              ↓
                          FMassTag
```

## 17.5.8 RTS 实战分类

```cpp
// 实例数据 → Fragment
USTRUCT() struct FUnitHealthFragment : public FMassFragment { int32 HP; };
USTRUCT() struct FUnitTransformFragment : public FMassFragment { FTransform T; };

// 状态 → Tag
USTRUCT() struct FActiveTag : public FMassTag {};
USTRUCT() struct FDeadTag : public FMassTag {};
USTRUCT() struct FBurningTag : public FMassTag {};
USTRUCT() struct FFrozenTag : public FMassTag {};

// 单位类型配置 → ConstSharedFragment(只读)
USTRUCT() struct FUnitTypeStats : public FMassConstSharedFragment
{
    int32 BaseHealth = 100;
    int32 BaseDamage = 10;
    float MaxSpeed = 5.0f;
};

// 单位 Mesh → SharedFragment(也可 ConstShared)
USTRUCT() struct FUnitVisualConfig : public FMassSharedFragment
{
    UPROPERTY() TObjectPtr<UStaticMesh> Mesh;
};

// LOD 状态 → ChunkFragment(每 chunk 一份)
USTRUCT() struct FChunkLODFragment : public FMassChunkFragment
{
    EMassLOD::Type CurrentLOD;
};
```

## 17.5.9 实操与下一节预告

### 实操

设计 RTS 单位的完整 Fragment 集:
- Position / Velocity → Fragment
- HP → Fragment
- 单位类型(Soldier / Worker / Boss)→ Tag
- 状态(Active / Dead / Burning) → Tag
- 单位基础属性表 → ConstSharedFragment(每种类型 1 份)
- Mesh → SharedFragment

**1 万 Soldier × 10 状态组合 = 10 archetype × 几个 chunk** = 设计紧凑。
