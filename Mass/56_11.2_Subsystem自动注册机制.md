# §11.2 Subsystem 自动注册机制 — `GetSubsystem<T>()` 的模板分发

> **本节地图**:模块二第 11 章第 2 节。这一节看 Subsystem **怎么自动被实例化** —— 你写一个 UCLASS 子类,UE 自动:
> 1. 启动时实例化
> 2. 调 Initialize
> 3. 通过 `GetSubsystem<T>()` 提供访问
>
> 不需要任何手动注册代码。这是 UE 反射 + 模板的精妙应用。
>
> **预备知识**:§2(反射)、§11.1。
>
> **读完之后你能做到**:
> - 看 `FSubsystemCollection<T>::Initialize` 内部怎么遍历所有子类
> - 用 `ShouldCreateSubsystem` 自定义创建过滤
> - 用 `InitializeDependency<T>` 表达依赖

## 11.2.1 自动实例化的核心:遍历所有子类

```cpp
// 简化伪代码:FSubsystemCollection<UWorldSubsystem>::Initialize
void FSubsystemCollection::Initialize(UObject* InOuter)
{
    // 1. 用反射 API 找出所有 UWorldSubsystem 子类(§2.3)
    TArray<UClass*> SubsystemClasses;
    GetDerivedClasses(BaseClass, SubsystemClasses);
    
    for (UClass* C : SubsystemClasses)
    {
        if (C->HasAnyClassFlags(CLASS_Abstract)) continue;
        
        // 2. 检查 ShouldCreateSubsystem(走 CDO)
        USubsystem* CDO = GetDefault<USubsystem>(C);
        if (!CDO->ShouldCreateSubsystem(InOuter)) continue;
        
        // 3. 实例化(NewObject)
        USubsystem* Inst = NewObject<USubsystem>(InOuter, C);
        
        // 4. Init
        Inst->Internal_Initialize();
        
        // 5. 加进 collection
        Subsystems.Add(C, Inst);
    }
}
```

**关键**:**反射(GetDerivedClasses)+ 模板(GetSubsystem<T>)= 自动注册**。你写 UCLASS,UE 反射时已经知道了。

## 11.2.2 `GetDerivedClasses` 的实现

```cpp
// 简化
void GetDerivedClasses(UClass* BaseClass, TArray<UClass*>& OutDerivedClasses)
{
    // 遍历整个 GUObjectArray 找所有 UClass
    for (TObjectIterator<UClass> It; It; ++It)
    {
        UClass* C = *It;
        if (C->IsChildOf(BaseClass) && C != BaseClass)
        {
            OutDerivedClasses.Add(C);
        }
    }
}
```

`TObjectIterator<UClass>` 遍历所有 UClass 反射对象。在所有 Module 加载完(LoadingPhase=PostEngineInit 之后)调用,能找到所有反射注册的 Subsystem 子类。

## 11.2.3 `GetSubsystem<T>()` 模板分发

```cpp
// UWorld
template<typename T>
T* GetSubsystem() const
{
    UClass* SearchClass = T::StaticClass();
    return Cast<T>(SubsystemCollection.Get(SearchClass));
}

// FSubsystemCollection
USubsystem* Get(UClass* C) const
{
    return Subsystems.FindRef(C);
}
```

`SubsystemCollection` 内部是 `TMap<UClass*, USubsystem*>`,O(1) 查找。

### 11.2.3.1 缓存调用结果

```cpp
// 慢:每次 GetSubsystem
void Tick(float DT)
{
    auto* S = GetWorld()->GetSubsystem<URTSCombatSubsystem>();   // 每帧 hash 查找
    S->DoStuff();
}

// 快:成员缓存
class URTSPathfindingSubsystem : public UWorldSubsystem
{
    UPROPERTY()
    TObjectPtr<URTSCombatSubsystem> CachedCombat;
    
    virtual void PostInitialize() override
    {
        CachedCombat = GetWorld()->GetSubsystem<URTSCombatSubsystem>();
    }
    
    void Tick(float DT)
    {
        CachedCombat->DoStuff();    // 直接指针,免查找
    }
};
```

## 11.2.4 `ShouldCreateSubsystem` 过滤

§7.5.7 已讲。这里整合:

```cpp
class URTSCombatSubsystem : public UWorldSubsystem
{
    virtual bool ShouldCreateSubsystem(UObject* Outer) const override
    {
        UWorld* W = Cast<UWorld>(Outer);
        if (!W) return false;
        
        // Editor World 不创建
        if (!W->IsGameWorld()) return false;
        
        // 仅服务器(client 不需要 Combat)
        if (!W->GetNetMode() == NM_DedicatedServer && 
            !W->GetNetMode() == NM_ListenServer)
        {
            return false;
        }
        
        return true;
    }
};
```

注意:`ShouldCreateSubsystem` 通过**CDO**调用,所以你不能在里面访问实例字段。

## 11.2.5 `InitializeDependency<T>` 表达依赖

```cpp
class URTSCommandSubsystem : public UWorldSubsystem
{
    virtual void Initialize(FSubsystemCollectionBase& Collection) override
    {
        // 我必须在 URTSPathfindingSubsystem 之后初始化
        Collection.InitializeDependency<URTSPathfindingSubsystem>();
        
        Super::Initialize(Collection);
        
        // 此时 PathfindingSubsystem 一定已 Initialize
        URTSPathfindingSubsystem* P = GetWorld()->GetSubsystem<URTSPathfindingSubsystem>();
        P->RegisterMe(this);
    }
};
```

**避免循环依赖**:A 依赖 B,B 依赖 A → infinite recursion。

---

## 11.2.6 Subsystem 重启?

UE 不支持 Subsystem 运行时"销毁后重建"。Subsystem 跟着 Outer 生死:
- World 切换 → 旧 World Subsystem 销毁,新 World 重建
- GameInstance 不变(切关卡)→ GameInstanceSubsystem 不重启

如果你想"运行时重置 RTS Combat 状态",在 Subsystem 内部加 `Reset()` 方法,**不要**销毁/重建 Subsystem 本身。
