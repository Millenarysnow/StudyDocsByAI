# §25.6 GPU Driven 渲染与 Nanite / Lumen 协作

## 25.6.1 GPU Scene(5.x 默认)

5.x **GPU Scene** 把所有 mesh primitive 在 GPU 端紧凑管理:
- Primitive Buffer(每 mesh 一项)
- Instance Buffer(每 instance 一项)
- GPU 视锥剔除 + LOD 选择
- GPU instancing draw

**Mass + ISMC 自动用 GPU Scene**。无需配置。

---

## 25.6.2 Nanite

**Nanite** 是 5.x 的虚拟几何体 — 自动 LOD 到极致细节。

```
ISMC + Nanite:
   - Nanite-enabled StaticMesh
   - ISMC instance 也享受 Nanite LOD
   - 50K instance × 高细节 mesh 仍然能跑(Nanite 自动 simplify)
```

启用:Mesh Asset → Build Nanite。

**纪律**:Nanite 适合**静态 mesh**(建筑、地面、装饰)。**动画 mesh(VAT)** 5.x 部分支持(Nanite Skinning),实验阶段。

RTS 用 Nanite:
- ✓ 建筑 / 地形 / 装饰
- ✗ 动画单位(用 ISMC + VAT)

---

## 25.6.3 Lumen

**Lumen** 是 5.x 全局光照 + 反射。

```
RTS + Lumen:
   - 室外大场景动态光照
   - 单位 ISMC instance 接受 Lumen 间接光
   - 性能:~3-5 ms / 帧 GPU(取决于硬件)
```

低端设备可关 Lumen → 退化到 Static Lighting / Baked GI。

---

## 25.6.4 GPU Driven 渲染

5.x 的 GPU Driven Renderer:
- CPU 仅提交"全局命令"
- GPU 自己做剔除 / LOD / batching
- DrawCall 数量极少(几十)

**RTS 50K instance + GPU Driven 渲染 = 几十 DrawCall + 几 ms GPU**。
