# §9.3 Possess / UnPossess / RestartPlayer

> **本节地图**:模块二第 9 章第 3 节。§9.2 看了登录,这一节看玩家**切换控制 Pawn** 的机制 — `Possess` / `UnPossess`。
>
> RTS 项目里这条机制用得不多(玩家通常 possess 一个固定相机 Pawn),但理解它对调试 / 切换视角 / 临时控制英雄很重要。

## 9.3.1 浅入:Possess 是"绑定 Controller 与 Pawn"

```cpp
APlayerController* PC = GetWorld()->GetFirstPlayerController();
APawn* NewPawn = GetWorld()->SpawnActor<ACharacter>(...);

PC->Possess(NewPawn);    // 把 PC 绑定到 NewPawn
```

效果:
- `PC->Pawn = NewPawn`
- `NewPawn->Controller = PC`
- 之后 PC 接收到的输入路由到 NewPawn

`UnPossess` 反向:解除绑定,Pawn 没人控制(变 NPC)。

## 9.3.2 `Possess` 完整流程

```cpp
// AController(PlayerController 父类)的实现
void AController::Possess(APawn* InPawn)
{
    // 1. 检测合法性
    if (!InPawn || !HasAuthority()) return;
    
    // 2. 如果当前已 possess 别的 Pawn,先 UnPossess
    if (Pawn) UnPossess();
    
    // 3. 设置双向引用
    SetPawn(InPawn);
    Pawn->Controller = this;
    
    // 4. 通知 Pawn(虚函数)
    Pawn->PossessedBy(this);
    
    // 5. PlayerController 特殊:setup input
    if (APlayerController* PC = Cast<APlayerController>(this))
    {
        // 6. 调 Pawn 的 SetupPlayerInputComponent
        Pawn->SetupPlayerInputComponent(PC->InputComponent);
        
        // 7. 触发 OnPossess 委托
        OnPossessedPawnChanged.Broadcast(/* old */ nullptr, /* new */ Pawn);
    }
}
```

每一步都是 hook 点。

## 9.3.3 `Pawn::PossessedBy`

```cpp
virtual void APawn::PossessedBy(AController* NewController)
{
    SetOwner(NewController);     // 网络 Owner
    Controller = NewController;
    
    // 触发 OnPossessed 委托
    OnPawnControllerChanged.Broadcast(...);
    
    // 如果 NewController 是 PlayerController + 本地玩家
    if (APlayerController* PC = Cast<APlayerController>(NewController))
    {
        if (PC->IsLocalPlayerController())
        {
            // 本地控制 setup
            ReceivePossessed(NewController);    // BP 事件
        }
    }
}
```

子类重写做 RTS 自定义:

```cpp
void ARTSCameraPawn::PossessedBy(AController* NewController)
{
    Super::PossessedBy(NewController);
    
    // RTS 玩家"接管"相机
    if (APlayerController* PC = Cast<APlayerController>(NewController))
    {
        // 启用相机控制
        SetActorTickEnabled(true);
    }
}
```

## 9.3.4 `UnPossess`

```cpp
void AController::UnPossess()
{
    if (!Pawn) return;
    
    APawn* OldPawn = Pawn;
    
    // 1. 通知旧 Pawn(虚函数)
    Pawn->UnPossessed();
    
    // 2. 解除引用
    Pawn->Controller = nullptr;
    Pawn = nullptr;
    
    // 3. 触发 OnUnPossess 委托
    OnPossessedPawnChanged.Broadcast(OldPawn, nullptr);
}
```

`Pawn::UnPossessed` 通常做"清理 input 绑定"等。

## 9.3.5 切换控制(常见场景)

### 9.3.5.1 玩家死亡后重生

```cpp
void ARTSGameMode::OnPawnKilled(APawn* DeadPawn)
{
    AController* C = DeadPawn->GetController();
    
    // 1. UnPossess 旧 Pawn
    C->UnPossess();
    DeadPawn->Destroy();
    
    // 2. 等待重生倒计时
    GetWorldTimerManager().SetTimer(RespawnTimer, [this, C]()
    {
        // 3. RestartPlayer(spawn 新 Pawn 并 Possess)
        RestartPlayer(C);
    }, RespawnDelay, false);
}
```

`RestartPlayer` 内部 spawn 新 Pawn + Possess。§9.2.5 已讲。

### 9.3.5.2 玩家临时接管英雄(RTS 偶尔)

```cpp
// 玩家从 RTS 相机切到第三人称英雄
void ARTSPlayerController::SwitchToHero(AHero* Hero)
{
    APawn* OldPawn = GetPawn();   // 旧的相机 Pawn
    
    // 1. UnPossess 相机
    UnPossess();
    
    // 2. Possess 英雄
    Possess(Hero);
    
    // 3. 切换 Camera Component
    SetViewTargetWithBlend(Hero, 0.5f);
}

void ARTSPlayerController::SwitchBackToCamera()
{
    AHero* H = GetPawn<AHero>();
    UnPossess();
    
    Possess(MyCameraPawn);
    SetViewTargetWithBlend(MyCameraPawn, 0.5f);
}
```

这是"RTS + ARPG 混合"模式,玩家平时俯视,关键时刻接管英雄第三人称。

## 9.3.6 网络中的 Possess

```
Server:
   PC.Possess(Pawn)
      ↓
   Pawn.Owner = PC(replicated)
   Pawn.Controller = PC(NOT replicated,但 client 能从其它信息推断)
      ↓
   Replication 自动让 client 知道 Pawn 的 Owner
```

**关键**:`Pawn::Controller` 字段**不直接 replicated**。Client 端通过 PC 的 `AcknowledgePossession` RPC 收到通知,本地设置 Pawn->Controller = LocalPC。

详见 §13 / §14 网络复制。

## 9.3.8 RTS 视角

### 9.3.8.1 RTS 玩家不需要传统 Pawn

RTS 玩家就是"顶视相机 + 鼠标点击"。Pawn 几乎只是个相机载体:

```cpp
UCLASS()
class ARTSCameraPawn : public APawn
{
    GENERATED_BODY()
public:
    ARTSCameraPawn()
    {
        UCameraComponent* Cam = CreateDefaultSubobject<UCameraComponent>(TEXT("Cam"));
        SetRootComponent(Cam);
        bUseControllerRotationYaw = false;
    }
    
    virtual void SetupPlayerInputComponent(UInputComponent* IC) override
    {
        // 绑定 WASD 移动相机
        IC->BindAxis("CamForward", this, &ARTSCameraPawn::MoveForward);
        IC->BindAxis("CamRight", this, &ARTSCameraPawn::MoveRight);
        // 绑定鼠标点击 → PC 的命令处理
    }
};
```

### 9.3.8.2 玩家 Possess CameraPawn 一直不换

整局游戏 PC 始终 possess 同一个 CameraPawn。死亡 / 重生 / 关卡切换都不换 — RTS 玩家"不会死"(Pawn 不可被攻击)。

### 9.3.8.3 RTS 单位 NOT possessed by player

50K Mass 单位**没有任何 Controller**,完全 AI 驱动。它们不是 Pawn,**不参与 Possess 体系**。

少数英雄/Boss 是 ACharacter,但通常**被 AI Controller possess**(`AAIController`),不是 PlayerController。

```cpp
// Hero 由 AI 控制
AAIController* AI = NewObject<AAIController>(...);
AI->Possess(Hero);

// 玩家不直接 possess Hero
```

特殊场景(玩家临时操作 Hero)再走 §9.3.5.2 那条切换逻辑。
