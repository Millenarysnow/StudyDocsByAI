## 21.3.1 Mass ↔ Iris 桥接

```
Mass entity dirty
   ↓
UMassReplicationProcessor 通知 Iris 桥接
   ↓
Iris ReplicationBridge 把 entity 当作 ReplicatedObject
   ↓
Iris filter / pri / serialize / 发包
   ↓
Client Iris 接收 → MassEntityView 创建 / 更新
```

---

## 21.3.2 启用

`DefaultEngine.ini`:

```ini
[/Script/Engine.GameModeBase]
GameNetDriverReplicationSystem = 1   ; Iris

[/Script/MassReplication.MassReplicationSettings]
bUseIrisReplication = true
```

---

## 21.3.3 Iris filter 自定义(空间)

```cpp
class FRTSMassFilter : public UNetObjectFilter
{
    virtual bool IsObjectVisible(...) override
    {
        // 检查 entity 是否在 connection 的 bubble 内
        return bubble.Contains(entity.Position);
    }
};
```

## 21.3.4 性能

```
Mass + Iris 50K entity + 10 client:

Server:
   - Mass tick:7 ms
   - Replication push to Iris:1 ms(只 dirty entity)
   - Iris filter / serialize:2 ms
   总:~10 ms / 帧 ✓
   
带宽:
   - 每 client ~75 KB/s ✓
   - Iris 量化 + delta 压缩极致
```
