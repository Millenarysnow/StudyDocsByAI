## 8.3.1 浅入:Tick 不是免费的

```cpp
class AMyActor : public AActor
{
public:
    AMyActor()
    {
        PrimaryActorTick.bCanEverTick = true;     // 我要 tick
    }
    
    virtual void Tick(float DeltaTime) override
    {
        // 每帧调
    }
};
```

看似简单。背后:
- `PrimaryActorTick` 是个 `FActorTickFunction`,继承 `FTickFunction`
- BeginPlay 时它被注册到 `World->TickTaskManager`
- 每帧 `World->Tick` 遍历 TickGroup,执行匹配 group 的 TickFunction
- `Tick(DeltaTime)` 通过虚函数被调

**单 tick 调度开销**:几十纳秒(查 group → 调虚函数)。
**1 万 tick / 帧**:几百微秒(累计可观)。
**5 万 tick**:几毫秒。**这就是为什么 Mass 要架空 actor tick**。

## 8.3.2 `FTickFunction` 是什么

`Engine/Source/Runtime/Engine/Classes/Engine/EngineBaseTypes.h`:

```cpp
struct FTickFunction
{
    ETickingGroup TickGroup;                          // 在哪个 group
    ETickingGroup EndTickGroup;                       // 完成时机
    
    bool bCanEverTick : 1;                            // 总开关
    bool bStartWithTickEnabled : 1;                   // 启动时启用
    bool bTickEvenWhenPaused : 1;                     // 暂停时也 tick
    bool bAllowTickOnDedicatedServer : 1;
    bool bRunOnAnyThread : 1;                         // 可在 worker 线程跑
    
    float TickInterval;                               // 0 = 每帧,>0 = 限频
    
    TArray<FTickPrerequisite> Prerequisites;          // 依赖列表
    
    virtual void ExecuteTick(...) = 0;                // 子类实现
};

// Actor 用的
struct FActorTickFunction : public FTickFunction
{
    UClass* Target;
    virtual void ExecuteTick(...) override
    {
        Target->Tick(DeltaTime);    // 调 AActor::Tick 虚函数
    }
};

// Component 用的
struct FActorComponentTickFunction : public FTickFunction
{
    UActorComponent* Target;
    virtual void ExecuteTick(...) override
    {
        Target->TickComponent(DeltaTime, ...);
    }
};
```

每个 Actor / Component 至少有一个 PrimaryTick(`PrimaryActorTick` / `PrimaryComponentTick`)。可以加额外 tick(`Actor::SecondaryActorTick` 等,罕见)。

## 8.3.3 `ETickingGroup` 完整列表

`EngineBaseTypes.h:83`:

```cpp
enum ETickingGroup : int
{
    TG_PrePhysics,       // ★ 物理之前(大多数 game logic 在这)
    TG_StartPhysics,     // 物理开始(隐藏,系统用)
    TG_DuringPhysics,    // 物理同时(并行)
    TG_EndPhysics,       // 物理结束(隐藏)
    TG_PostPhysics,      // 物理之后
    TG_PostUpdateWork,   // 渲染 / 网络复制 之前的最后一阶段
    TG_LastDemotable,    // catch-all
    TG_NewlySpawned,     // 重复执行,直到没有新 spawn
    TG_MAX,
};
```

### 8.3.3.1 各 TickGroup 用例

| TickGroup | 典型用法 |
|---|---|
| `TG_PrePhysics` | 玩家输入处理、AI 决策、移动意图 |
| `TG_DuringPhysics` | 与物理无关的中间逻辑(可与物理并行) |
| `TG_PostPhysics` | 基于物理结果的逻辑(碰撞响应) |
| `TG_PostUpdateWork` | 网络复制前最后处理、UI 更新 |
| `TG_LastDemotable` | 实在不知道放哪的 catch-all |

### 8.3.3.2 RTS Mass Processor 的位置

Mass Processor 通过 `ProcessingPhase` 配置,内部映射到 TickGroup:

```cpp
EMassProcessingPhase::PrePhysics    → TG_PrePhysics
EMassProcessingPhase::DuringPhysics → TG_DuringPhysics
EMassProcessingPhase::PostPhysics   → TG_PostPhysics
EMassProcessingPhase::FrameEnd      → TG_PostUpdateWork
```

## 8.3.4 Tick 注册流程

```cpp
// SpawnActor → RegisterAllComponents → BeginPlay
AActor::DispatchBeginPlay()
{
    // Component tick
    for (UActorComponent* C : GetComponents())
    {
        C->RegisterAllComponentTickFunctions(true);
    }
    
    // Actor tick
    RegisterAllActorTickFunctions(true);
}

void AActor::RegisterAllActorTickFunctions(bool bRegister)
{
    if (PrimaryActorTick.bCanEverTick && bRegister)
    {
        PrimaryActorTick.SetTickFunctionEnable(PrimaryActorTick.bStartWithTickEnabled);
        PrimaryActorTick.RegisterTickFunction(GetLevel());
    }
}
```

`RegisterTickFunction(Level)` 内部把 TickFunction 加到 `Level->TickTaskLevel`。`UWorld::TickTaskManager` 持有所有 TickTaskLevel。

## 8.3.5 Tick 依赖图(Prerequisites)

`Actor::AddTickPrerequisiteActor` / `AddTickPrerequisiteComponent`:

```cpp
// A.Tick 必须在 B.Tick 之后
A->AddTickPrerequisiteActor(B);
```

内部把 B 的 PrimaryActorTick 加到 A 的 PrimaryActorTick.Prerequisites 列表。

调度时:**TickFunction 只能在所有 Prerequisites 完成后才执行**。形成 DAG。

### 8.3.5.1 实战:玩家先动,跟随 AI 后动

```cpp
class AHero : public APawn { /* PrimaryActorTick TG_PrePhysics */ };

class AFollowerAI : public AActor
{
    AFollowerAI()
    {
        PrimaryActorTick.bCanEverTick = true;
        PrimaryActorTick.TickGroup = TG_PrePhysics;
    }
    
    void BeginPlay() override
    {
        Super::BeginPlay();
        AddTickPrerequisiteActor(MyHero);   // 我 tick 之前 Hero 必须先 tick
    }
};
```

调度系统自动保证顺序。

## 8.3.7 Tick 控制 API

```cpp
// 启用 / 禁用 tick(运行时)
SetActorTickEnabled(bool bEnabled);              // Actor 总开关
PrimaryActorTick.SetTickFunctionEnable(bool);    // 同上更细
PrimaryComponentTick.SetTickFunctionEnable(bool); // Component

// 限频
PrimaryActorTick.TickInterval = 0.1f;   // 10 Hz tick(每 100ms 一次)

// 是否在暂停时 tick
PrimaryActorTick.bTickEvenWhenPaused = true;
```

实战:**RTS Game 暂停时,某些 Actor(UI 主菜单)需要继续 tick**,设 `bTickEvenWhenPaused = true`。

## 8.3.8 关闭 Tick 的纪律

**不需要 tick 的 Actor / Component 务必关闭 tick**:

```cpp
AMyActor::AMyActor()
{
    PrimaryActorTick.bCanEverTick = false;     // ★ 关
}

UMyComp::UMyComp()
{
    PrimaryComponentTick.bCanEverTick = false; // ★ 关
}
```

**性能差异**:
- 100 个 actor 都 tick = 100 次虚函数调用 / 帧 = ~10 μs / 帧(每个 100 ns)
- 100 个 actor **关 tick** = 0 / 帧

UE 默认 `AActor::PrimaryActorTick.bCanEverTick = false`(基类),你子类**显式开**才 tick。但很多老教程让你随手开,RTS 项目要严格审查。

## 8.3.9 RTS / Mass 视角下的 Tick 纪律

### 8.3.9.1 Mass Processor 不是 TickFunction

Mass Processor 通过 `UMassSimulationSubsystem` 调度,**不**是每个 Processor 一个 TickFunction。Subsystem 自己一个 TickFunction(挂在某 TickGroup),内部跑全部 Processor:

```
World->Tick (PrePhysics phase)
   ├─ TickActors(PrePhysics)
   ├─ TickComponents(PrePhysics)
   └─ Mass Subsystem TickFunction
         ├─ Processor A
         ├─ Processor B(并行)
         └─ ...
```

### 8.3.9.2 RTS 重要单位允许 tick,杂兵不允许

```cpp
// 英雄 - 允许 tick
class AHero : public ACharacter
{
    AHero()
    {
        PrimaryActorTick.bCanEverTick = true;
    }
};

// 杂兵 - 不存在(走 Mass)
// 没有 AMinion 类 → 没有 Tick 调度开销
```

50K 杂兵走 Mass = 1 个 Mass Subsystem TickFunction,内部并行跑 50K entity。**而不是 50K TickFunction**。

### 8.3.9.3 用 TickInterval 限频

某些"不那么重要"的 tick 用 TickInterval:

```cpp
class ARTSAmbientSound : public AActor
{
    ARTSAmbientSound()
    {
        PrimaryActorTick.bCanEverTick = true;
        PrimaryActorTick.TickInterval = 0.5f;   // 0.5 秒 / 次
    }
};
```

低频 tick 单位适合"环境特效、装饰物的状态轮询"。

## 8.3.11 实操与下一节预告

### 实操

```cpp
static FAutoConsoleCommand CmdCountTicks(TEXT("rts.CountTicks"),
    TEXT("Count active TickFunctions"),
    FConsoleCommandDelegate::CreateLambda([]()
    {
        UWorld* W = GWorld;
        if (!W) return;
        
        int32 ActorTickCount = 0;
        int32 CompTickCount = 0;
        for (TActorIterator<AActor> It(W); It; ++It)
        {
            if (It->PrimaryActorTick.IsTickFunctionRegistered() && 
                It->PrimaryActorTick.IsTickFunctionEnabled())
            {
                ActorTickCount++;
            }
            for (UActorComponent* C : It->GetComponents())
            {
                if (C->PrimaryComponentTick.IsTickFunctionRegistered() && 
                    C->PrimaryComponentTick.IsTickFunctionEnabled())
                {
                    CompTickCount++;
                }
            }
        }
        UE_LOG(LogTemp, Display, TEXT("Active Actor Ticks: %d"), ActorTickCount);
        UE_LOG(LogTemp, Display, TEXT("Active Component Ticks: %d"), CompTickCount);
    }));
```

跑 `rts.CountTicks` 在 PIE 中,看你项目的 tick 总数。
