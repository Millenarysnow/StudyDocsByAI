## 12.1.1 浅入:三层结构

```
UNetDriver(每个 World 一个)
   ├─ ServerConnection: UNetConnection*  (我连到的 server,client 模式)
   │     └─ Channels[]: UChannel*(每条信道一个 channel)
   │           ├─ UControlChannel(连接控制)
   │           ├─ UActorChannel(每个 replicated actor 一个)
   │           ├─ UVoiceChannel(语音)
   │           └─ ...
   │
   └─ ClientConnections: TArray<UNetConnection*>  (server 模式,每个 client 一个)
         └─ 每个 connection 都有自己的 Channels[]
```

**Server 模式**:`ServerConnection == nullptr`,`ClientConnections` 列出所有连入 client。
**Client 模式**:`ServerConnection != nullptr`(我连到 server),`ClientConnections` 空。

## 12.1.2 `UNetDriver` —— 网络驱动

`Engine/Source/Runtime/Engine/Classes/Engine/NetDriver.h:798`:

```cpp
class UNetDriver : public UObject, public FExec
{
public:
    // World
    UPROPERTY()
    TObjectPtr<UWorld> World;
    
    // Server 端
    UPROPERTY()
    TArray<TObjectPtr<UNetConnection>> ClientConnections;
    
    // Client 端
    UPROPERTY()
    TObjectPtr<UNetConnection> ServerConnection;
    
    // GUID 缓存(对象 → 网络 ID 映射)
    TSharedPtr<FNetGUIDCache> GuidCache;
    
    // 分类
    UPROPERTY(Config)
    FName NetDriverName;       // "GameNetDriver" / "DemoNetDriver"
    
    // Channel 配置
    UPROPERTY(Config)
    TArray<FChannelDefinition> ChannelDefinitions;
    
    // 关键 API
    virtual void TickFlush(float DeltaSeconds);   // 每帧发包
    virtual void TickDispatch(float DeltaSeconds); // 每帧收包
    
    virtual int32 ServerReplicateActors(float DeltaSeconds);   // 复制核心
    
    // ...
};
```

### 12.1.2.1 NetDriver 的职责

NetDriver = **"网络层主控制器"**:
- 持有所有 NetConnection
- 调度复制(每帧 ServerReplicateActors)
- 管理 NetGUID(对象 ↔ ID 映射)
- 决定哪些 Actor 该复制

### 12.1.2.2 NetDriverName

UE 支持**多个 NetDriver**:

```cpp
NetDriverName = "GameNetDriver";    // 主游戏网络
NetDriverName = "DemoNetDriver";    // 录制 / 回放
NetDriverName = "BeaconNetDriver";  // 大厅 / 匹配
```

`UWorld::NetDriver` 指向**主 GameNetDriver**。其它 NetDriver 通过 `UWorld::FindNetDriver(Name)` 拿。

## 12.1.3 `UNetConnection` —— 一个客户端连接

```cpp
class UNetConnection : public UPlayer

    TObjectPtr<UNetDriver> Driver;

    TArray<TObjectPtr<UChannel>> Channels;

    int32 InPackets, OutPackets;
    int32 InBytes, OutBytes;
    
    // 状态
    EConnectionState State;        // Pending / Open / Closed
    
    // 玩家身份(对 server)
    FUniqueNetIdRepl PlayerId;
    
    // 网络速度
    int32 CurrentNetSpeed;
    
    // ...
};
```

### 12.1.3.1 NetConnection 角色对照

```
Server 端的 UNetConnection:
   - 持有 server 端的 PlayerController(为该 client 服务)
   - 跟踪复制状态(对 client 可见 / 已发送)
   - PacketHandler(加密 / 压缩)

Client 端的 UNetConnection(ServerConnection):
   - 跟踪从 server 收到的对象
   - PackageMap 反向解析 NetGUID → UObject
```

### 12.1.3.2 ENetMode 与 NetConnection

```cpp
ENetMode {
    NM_Standalone,     // 单机,无网络
    NM_DedicatedServer, // 专用服务器(无本地玩家)
    NM_ListenServer,    // Listen 服务器(本地玩家 + 远程玩家)
    NM_Client,          // 客户端
};
```

```
Standalone:    NetDriver=nullptr    NetConnection=不存在
DedicatedServer: NetDriver=有       ClientConnections=[远程玩家们]
ListenServer:   NetDriver=有        ClientConnections=[远程玩家们,本地玩家无 connection]
Client:         NetDriver=有        ServerConnection=连到 server
```

## 12.1.4 `UChannel` —— 数据流分类

```cpp
class UChannel : public UObject
{
public:
    TObjectPtr<UNetConnection> Connection;
    int32 ChIndex;                // 0, 1, 2, ...
    EChannelType ChType;          // Control, Actor, Voice
    
    EChannelCloseReason CloseReason;
    
    bool bClosed;
    bool bOpenedLocally;
    
    virtual void Tick();
};
```

### 12.1.4.1 三种主要 Channel

```
UControlChannel(ChIndex = 0)
   - 连接握手、登录、用户验证
   - "Hi I'm Alice with UniqueId X" 类型消息
   - 整个 connection 1 个

UActorChannel(每个 replicated actor 1 个)
   - 复制 actor 状态
   - RPC 收发
   - dynamically open/close,数量级 == replicated actor 数

UVoiceChannel(可选)
   - 实时语音
   - 通常 ChIndex = 1
```

## 12.1.5 NetGUID —— 对象的网络 ID

`FNetworkGUID` 是个 32 位整数。每个**网络可见 UObject**(replicated actor、Mesh 资产、PlayerController)被分配一个 GUID。

```cpp
struct FNetworkGUID
{
    uint32 Value;
    bool IsValid() const { return Value > 0; }
};
```

### 12.1.5.1 `FNetGUIDCache`

```cpp
class FNetGUIDCache
{
public:
    TMap<FNetworkGUID, FNetGuidCacheObject> ObjectLookup;
    TMap<TWeakObjectPtr<UObject>, FNetworkGUID> NetGUIDLookup;
    
    FNetworkGUID GetOrAssignNetGUID(UObject* Object);
    UObject* GetObjectFromNetGUID(FNetworkGUID NetGUID);
};
```

### 12.1.5.2 静态 vs 动态 GUID

- **Static**(资产):Mesh、Material、Class 等。GUID 在所有端**相同**(由 path hash)。
- **Dynamic**(运行时 spawn):每个 actor 一个动态 GUID。Server 分配,Client 通过 control channel 接收 mapping。

### 12.1.5.3 RTS 视角:GUID 爆炸

50K Actor × 几个 component = 200K NetGUID。GUID 表的内存 + 查找开销显著。Mass entity **不分配 GUID**(它们不是 UObject),省去这部分。

## 12.1.6 一帧的 NetDriver 工作

```cpp
// 简化伪代码 - GameThread 主循环
World->Tick(...)
   ├─ NetDriver->TickDispatch(DeltaTime)        // 收包
   │     ├─ 从 socket 读包
   │     ├─ 分发到对应 NetConnection
   │     └─ Connection 处理 Channels(分发 RPC / 状态更新)
   │
   ├─ ... World logic Tick ...
   │
   ├─ NetDriver->ServerReplicateActors(DT)       // 仅 server,生成复制状态
   │     ├─ 遍历所有 replicated actor
   │     ├─ 计算 relevancy(该 client 能看到吗?)
   │     ├─ 计算 NetUpdateFrequency(该复制了吗?)
   │     ├─ Compare actor state vs 上次,生成 dirty diff
   │     └─ 写入对应 Connection 的 Channels
   │
   └─ NetDriver->TickFlush(DT)                   // 发包
         └─ Channels 打包数据 → Connection → socket
```

## 12.1.7 RTS 视角:50K 单位的网络挑战

```
50K replicated Actor:
   - 50K NetGUID
   - 50K UActorChannel(每个 actor 一个)
   - ServerReplicateActors 遍历 50K
   - 每个的 RepLayout 比较 + 生成 diff
   - 每个的 NetUpdateFrequency 检查
   
预估开销:
   - 内存:50K UActorChannel × 几 KB = 几百 MB
   - CPU:50K × ~100 ns = ~5 ms / 帧(仅扫描,不算实际 diff)
   - 网络:每帧 50K × 几字节 = 几 MB / s 或更多
```

完全不可行。RTS 必须**绕开传统 Replication**:
- Mass 自己定义复制机制(`UMassReplicationProcessor`)
- 用 BitSet + Delta encoding,不一对一 actor channel
- 与 Iris(5.x 新一代 Replication)集成

§14 详细论证。

## 12.1.8 实操与下一节预告

### 实操

```cpp
static FAutoConsoleCommand CmdInspectNet(TEXT("rts.InspectNet"),
    TEXT("Print NetDriver info"),
    FConsoleCommandDelegate::CreateLambda([]()
    {
        UWorld* W = GWorld;
        if (!W || !W->NetDriver) {
            UE_LOG(LogTemp, Display, TEXT("No NetDriver (Standalone)"));
            return;
        }
        
        UNetDriver* ND = W->NetDriver;
        UE_LOG(LogTemp, Display, TEXT("NetDriver: %s"), *ND->GetClass()->GetName());
        UE_LOG(LogTemp, Display, TEXT("ServerConnection: %s"),
            ND->ServerConnection ? TEXT("yes (client)") : TEXT("no (server)"));
        UE_LOG(LogTemp, Display, TEXT("ClientConnections: %d"), ND->ClientConnections.Num());
        
        for (UNetConnection* C : ND->ClientConnections)
        {
            UE_LOG(LogTemp, Display, TEXT("  Conn: PC=%s, Channels=%d, In/Out=%d/%d KB"),
                C->PlayerController ? *C->PlayerController->GetName() : TEXT("?"),
                C->Channels.Num(),
                C->InBytes / 1024,
                C->OutBytes / 1024);
        }
    }));
```
