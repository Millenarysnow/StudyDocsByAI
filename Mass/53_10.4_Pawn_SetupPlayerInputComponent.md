## 10.4.1 `SetupPlayerInputComponent` 时机

```cpp
class APawn
{
public:
    virtual void SetupPlayerInputComponent(UInputComponent* PlayerInputComponent);
};
```

调用时机:`AController::Possess(this)` 内部:

```cpp
void AController::Possess(APawn* InPawn)
{
    // ...
    Pawn->PossessedBy(this);
    
    if (APlayerController* PC = Cast<APlayerController>(this))
    {
        // ★ 调 Pawn 的 SetupPlayerInputComponent
        Pawn->SetupPlayerInputComponent(PC->InputComponent);
    }
}
```

**这一刻**起,Pawn 通过 PC 的 InputComponent 接收输入。

## 10.4.2 标准实现

```cpp
void ARTSCameraPawn::SetupPlayerInputComponent(UInputComponent* PIC)
{
    Super::SetupPlayerInputComponent(PIC);
    
    if (UEnhancedInputComponent* EIC = Cast<UEnhancedInputComponent>(PIC))
    {
        EIC->BindAction(IA_MoveCamera, ETriggerEvent::Triggered, this, &ThisClass::MoveCamera);
        EIC->BindAction(IA_Zoom, ETriggerEvent::Triggered, this, &ThisClass::ZoomCamera);
        EIC->BindAction(IA_RotateCamera, ETriggerEvent::Triggered, this, &ThisClass::RotateCamera);
    }
}

void ARTSCameraPawn::MoveCamera(const FInputActionValue& Value)
{
    FVector2D V = Value.Get<FVector2D>();
    
    // 相机沿 X / Y 移动(投影到水平面)
    FVector Forward = GetActorForwardVector();
    FVector Right = GetActorRightVector();
    Forward.Z = 0; Forward.Normalize();
    Right.Z = 0; Right.Normalize();
    
    AddActorWorldOffset((Forward * V.Y + Right * V.X) * CamSpeed * GetWorld()->GetDeltaSeconds());
}
```

## 10.4.3 UnPossess 时输入切换

`AController::UnPossess` 调 `Pawn->UnPossessed`,Pawn 解除控制。**InputComponent 不自动清** — 你 SetupPlayerInputComponent 时绑定的 lambda 留在 PIC 里。

UE 的解决方法:**Possess 新 Pawn 时,新 Pawn 的 SetupPlayerInputComponent 重新绑定**。但旧绑定可能"未清理":

实战:Pawn 的 `UnPossessed` 重写解绑:

```cpp
void ARTSCameraPawn::UnPossessed()
{
    if (Controller && Controller->InputComponent)
    {
        Controller->InputComponent->ClearActionBindings();   // 清所有 Action 绑定
        Controller->InputComponent->ClearAxisBindings();
    }
    
    Super::UnPossessed();
}
```

或者每次 Possess 之前 PC 自己 ClearBindings。

## 10.4.4 RTS 实战:为什么相机控制放 Pawn

经典 FPS / TPS:Pawn 是身体,Pawn 接收 WASD 的"自身移动"。
RTS:Pawn 是相机,Pawn 接收 WASD 的"相机移动"。

逻辑一致,但 RTS Pawn 没有"行走"概念。

**为什么不放 PlayerController**?
- PC 已经处理"游戏命令"输入(Select / Command)
- 分屏多玩家时,PC 是"网络命令通道"(server / client),Pawn 是本地相机 — 分离职责
- BP 节点里 Pawn 的 input 比 PC 的更直观

但**纯本地输入**(不走 RPC)放 PC 更符合"PC 是输入处理者"原则。两种都行,纪律一致即可。
