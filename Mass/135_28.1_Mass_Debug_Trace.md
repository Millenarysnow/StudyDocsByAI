---

## 28.1.1 Mass Debug Console 命令

```
mass.debug                    # Mass debug 总开关
mass.debug.entity              # 显示 entity ID 在 entity 头顶
mass.debug.entity.fragment     # 显示 fragment 字段
mass.debug.archetype           # 列出所有 archetype 与 entity 数
mass.debug.processor           # 列出 processor 执行顺序与耗时
mass.debug.LOD                 # 显示每 entity 当前 LOD level
```

---

## 28.1.2 Mass Visualization

```
mass.debug.visualize.archetype  # 不同 archetype 用不同颜色画框
mass.debug.visualize.lod        # LOD level 用色编码
mass.debug.visualize.lane       # ZoneGraph lane(如用)
```

游戏画面会叠加 debug 信息:每 entity 的 ID / fragment 值 / LOD / 当前 archetype。

---

## 28.1.3 Mass Trace(Insights)

```
trace channel: Mass

启动:
   UnrealEditor.exe -trace=Mass,Bookmark,Frame,Cpu

或运行时:
   trace.start Mass
```

Mass 在 Insights 里显示:
- 每个 Processor 的耗时
- 每个 Phase 的总耗时
- ParallelForEachEntityChunk 的 task 拆分

---

## 28.1.4 Mass.GameThreadTickInterval

```
mass.GameThreadTickInterval 0.5  # Mass 每 0.5 秒 tick 一次(测试用)
mass.GameThreadTickInterval 0    # 默认每帧 tick
```

测性能时可以"暂停 Mass"看其它系统开销。
