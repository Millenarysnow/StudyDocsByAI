## 17.7.1 CreateEntity 流程

```cpp
FMassEntityHandle EM.CreateEntity(FMassArchetypeHandle Archetype)
{
    // 1. 找 chunk(优先有空位的 chunk)
    FMassArchetypeChunk* Chunk = FindChunkWithSpace(Archetype) 
                                   ?: AllocateNewChunk(Archetype);
    
    // 2. 在 chunk 末尾占一个 slot
    int32 IndexInChunk = Chunk->NumEntities++;
    
    // 3. 分配 EntityHandle
    FMassEntityHandle E = AllocateNewEntityHandle();
    E.Index = ...;
    E.SerialNumber = ++GlobalSerialCounter;
    
    // 4. 关联 (Index → Archetype + IndexInChunk)
    Entities[E.Index] = { Archetype, Chunk, IndexInChunk };
    
    // 5. 默认初始化 Fragment(每个 Fragment 调 ctor 或 zero)
    InitializeFragments(Chunk, IndexInChunk);
    
    // 6. 通知 Observer
    Observers.NotifyAdd(E, Archetype);
    
    return E;
}
```

**典型耗时**:几百 ns - 1 μs / entity。

## 17.7.2 BatchCreateEntities(批量优化)

```cpp
EM.BatchCreateEntities(Archetype, /*Count*/ 100, OutEntities);
```

内部:
- 一次性分配 chunk(多 chunk 如果 100 装不下)
- 一次性分配所有 EntityHandle
- 一次性 Observer 通知(批量,不每 entity 一次)

**100 entity 批量 vs 100 次单个**:批量快 ~5-10 倍(摊薄开销)。

## 17.7.3 DestroyEntity

```cpp
void EM.DestroyEntity(FMassEntityHandle E)
{
    // 1. 检查 valid
    if (!IsEntityValid(E)) return;
    
    // 2. 通知 Observer(给 fragment 调"即将销毁"hook)
    Observers.NotifyRemove(E);
    
    // 3. Fragment 析构
    for (FragmentType : Archetype.Fragments) {
        FragmentType->DestroyStruct(GetFragmentPtr(E, FragmentType));
    }
    
    // 4. swap-remove(把 chunk 末尾 entity 移到这个空位,N--)
    int32 LastIndex = Chunk->NumEntities - 1;
    if (LastIndex != IndexInChunk) {
        // 拷贝最后 entity 的所有 fragment 到 IndexInChunk 处
        SwapEntities(Chunk, IndexInChunk, LastIndex);
    }
    Chunk->NumEntities--;
    
    // 5. 重置 SerialNumber(防悬空)
    Entities[E.Index].SerialNumber = INVALID;
    
    // 6. EntityHandle 入 free list,等下次复用
    FreeEntityIndices.Push(E.Index);
}
```

**Swap-remove 是关键**:不"挖空洞",而是把最后一个 entity 移到删的位置。chunk 内仍连续(SoA 不破坏)。

## 17.7.4 MoveEntityToAnotherArchetype(Add / Remove Fragment / Tag)

```cpp
void EM.MoveEntityToAnotherArchetype(E, NewArchetype)
{
    FMassArchetypeHandle OldArchetype = GetArchetype(E);
    
    // 1. 在 NewArchetype 里分配新位置
    int32 NewIndex = NewArchetype.AllocateSlot();
    
    // 2. 拷贝公共 Fragment(两 archetype 都有的)
    for (FragmentType : Common(Old, New)) {
        Memcpy(NewSlot, OldSlot, FragmentType->Size);
    }
    
    // 3. 新 Fragment 初始化(只 New 有,Old 没的)
    for (FragmentType : New - Old) {
        FragmentType->InitializeStruct(NewSlot);
    }
    
    // 4. 旧 Fragment 析构(只 Old 有,New 没的)
    for (FragmentType : Old - New) {
        FragmentType->DestroyStruct(OldSlot);
    }
    
    // 5. swap-remove 旧位置
    OldArchetype.RemoveSlot(OldIndex);
    
    // 6. 更新 EntityData 引用
    Entities[E.Index] = { NewArchetype, NewIndex };
}
```

**典型耗时**:1-5 μs(取决于 fragment 数量 + 大小)。

**纪律**:hot path 内不要 add/remove。批量做 / 用 Tag 状态切换(Tag 是 0 字节,迁移略快)。

## 17.7.5 命令缓冲 vs 立即修改

```cpp
// 立即(GameThread 安全,Processor Execute 期不安全)
EM.AddFragment<FBurningTag>(E);     // 直接迁移 archetype

// 推荐:命令缓冲
EM.Defer().AddTag<FBurningTag>(E);   // Processor 末尾批量 flush

// 在 Processor 内部
void Execute(...) {
    Query.ForEachEntityChunk(EM, Ctx, [&](FMassExecutionContext& Ctx) {
        for entity:
            if (HP <= 0)
                Ctx.Defer().AddTag<FDeadTag>(Entity);   // ★ 用 Defer
    });
    // Mass 框架自动 flush 命令
}
```
