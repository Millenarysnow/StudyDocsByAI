## 9.2.1 浅入:玩家加入服务器的"心理时序"

```
玩家点 "Join Server"
   ↓
Client 发起网络连接
   ↓
Server 接收连接
   ↓ Server 端调:
   ├─ 1. PreLogin(允许? 拒绝?)
   ├─ 2. Login(创建 PlayerController)
   ├─ 3. PostLogin(注册到 GameState)
   └─ 4. HandleStartingNewPlayer(spawn Pawn,可玩了)
   ↓
Client 端开始接收复制 → 看到游戏世界
```

每一步都是 GameMode 虚函数,可重写。

## 9.2.2 步 1:`PreLogin`

`GameModeBase.h:293`:

```cpp
virtual void PreLogin(
    const FString& Options,                     // URL 选项 ("?team=red")
    const FString& Address,                     // 客户端 IP
    const FUniqueNetIdRepl& UniqueId,           // 平台账号 ID(Steam / EOS)
    FString& ErrorMessage                       // out:不为空表示拒绝
);
```

时机:**网络握手 + UniqueId 验证之后**,**实际创建 PC 之前**。

### 9.2.2.1 拒绝连接

```cpp
void ARTSGameMode::PreLogin(const FString& Options, const FString& Address, 
                             const FUniqueNetIdRepl& UniqueId, FString& ErrorMessage)
{
    Super::PreLogin(Options, Address, UniqueId, ErrorMessage);
    
    // 拒绝条件
    if (IsBanned(UniqueId)) {
        ErrorMessage = TEXT("You are banned");   // 设这字段 = 拒绝
        return;
    }
    
    if (CurrentNumPlayers >= MaxPlayers) {
        ErrorMessage = TEXT("Server full");
        return;
    }
    
    if (GetGameState<ARTSGameState>()->Phase != EMatchPhase::WaitingForPlayers) {
        ErrorMessage = TEXT("Match already started, cannot join");
        return;
    }
    
    // 不设 ErrorMessage = 允许
}
```

`ErrorMessage` 非空 → 玩家被拒,server 关闭这条连接,client 看到 "Connection failed: <message>"。

### 9.2.2.2 异步 PreLogin

`GameModeBase.h:303`:

```cpp
virtual void PreLoginAsync(const FString& Options, const FString& Address, 
                            const FUniqueNetIdRepl& UniqueId, 
                            const FOnPreLoginCompleteDelegate& OnComplete);
```

如果验证需要查数据库 / 调外部 API(检测 ban、查权限),用 PreLoginAsync 异步。完成后调 `OnComplete.Execute(ErrorMessage)`。

## 9.2.4 步 3:`PostLogin`

`GameModeBase.h:326`:

```cpp
virtual void PostLogin(APlayerController* NewPlayer);
```

时机:PC 已 spawn 并初始化,但还**没**有 Pawn。玩家在"幽灵"状态(无身体)。

### 9.2.4.1 PostLogin 的典型工作

```cpp
void ARTSGameMode::PostLogin(APlayerController* NewPlayer)
{
    Super::PostLogin(NewPlayer);
    
    // 1. 加进 GameState 的玩家列表(自动)
    
    // 2. RTS 特定:分配阵营 / 队伍
    ARTSPlayerState* PS = NewPlayer->GetPlayerState<ARTSPlayerState>();
    PS->TeamID = AssignNextAvailableTeam();
    PS->Resources = StartingResources;
    
    // 3. 通知所有人"新玩家加入"
    GetWorld()->GetSubsystem<URTSChatSubsystem>()->Broadcast(
        FString::Printf(TEXT("%s joined"), *PS->GetPlayerName()));
    
    // 4. 检测是否所有玩家就绪,可以开始
    if (GetNumPlayers() >= RequiredPlayerCount && Phase == EMatchPhase::WaitingForPlayers)
    {
        StartMatch();
    }
}
```

**关键**:RTS 项目"玩家加入"的核心逻辑放这里。

### 9.2.4.2 `OnPostLogin` 委托(`GameModeBase.h:334`)

```cpp
virtual void OnPostLogin(AController* NewPlayer);
```

这是 5.x 加的"通用 hook",用于 GameMode 内部派发到子类的 `Bot Login` / `PlayerLogin` 等。99% 用 PostLogin 就够。

## 9.2.5 步 4:`HandleStartingNewPlayer` / `RestartPlayer`

`GameModeBase.h:441`:

```cpp
virtual void RestartPlayer(AController* NewPlayer);
```

时机:玩家应该"开始游戏" — spawn Pawn。

### 9.2.5.1 何时被调

- PostLogin 末尾(`AGameMode` 的 `HandleStartingNewPlayer` 调用 `RestartPlayer`)
- 玩家死亡后重生(`HandleStartingNewPlayer_Implementation`)
- 关卡切换 / Travel 后

### 9.2.5.2 默认实现

```cpp
// 简化伪代码
void AGameModeBase::RestartPlayer(AController* NewPlayer)
{
    // 1. 找出 spawn point
    AActor* StartSpot = ChoosePlayerStart(NewPlayer);
    
    // 2. 决定 Pawn 类
    UClass* PawnClass = GetDefaultPawnClassForController(NewPlayer);
    
    // 3. spawn Pawn
    APawn* NewPawn = SpawnDefaultPawnAtTransform(NewPlayer, StartSpot->GetActorTransform());
    
    // 4. Possess
    NewPlayer->Possess(NewPawn);
}
```

### 9.2.5.3 RTS 自定义

```cpp
void ARTSGameMode::RestartPlayer(AController* NewPlayer)
{
    // 玩家不需要 Pawn(RTS 玩家是俯视相机)
    // 但仍然 spawn 一个 CameraPawn 让 Possess 有意义
    
    Super::RestartPlayer(NewPlayer);
    
    // RTS 特定:为玩家 spawn 主基地 + 起始单位
    SpawnPlayerInitialBase(NewPlayer);
    SpawnPlayerInitialUnits(NewPlayer);
}
```

### 9.2.5.4 `ChoosePlayerStart` —— 选 spawn 点

```cpp
virtual AActor* ChoosePlayerStart(AController* Player);
```

默认实现:遍历关卡所有 `APlayerStart` actor,挑一个。RTS 可以自定义:

```cpp
AActor* ARTSGameMode::ChoosePlayerStart(AController* Player)
{
    // 按 TeamID 选对应 spawn point
    int32 TeamID = Cast<ARTSPlayerState>(Player->PlayerState)->TeamID;
    
    for (TActorIterator<APlayerStart> It(GetWorld()); It; ++It)
    {
        APlayerStart* Start = *It;
        if (Start->PlayerStartTag == FName(*FString::Printf(TEXT("Team%d"), TeamID)))
        {
            return Start;
        }
    }
    return nullptr;
}
```

## 9.2.6 完整时序图

```
玩家网络连接到达
   ↓
Server::AcceptConnection → 触发 GameMode 流程
   │
   ├─ AGameModeBase::PreLogin / PreLoginAsync
   │     ├─ Plugin / 平台 ID 验证
   │     ├─ ban 检测 / max player 检测
   │     ├─ 自定义验证逻辑
   │     └─ 设 ErrorMessage 拒绝 / 通过
   │
   ├─ Login
   │     ├─ Spawn APlayerController
   │     ├─ 关联 NetConnection
   │     └─ 创建 PlayerState(自动)
   │
   ├─ PostLogin
   │     ├─ PlayerState 初始化(team / resources)
   │     ├─ 通知 GameState
   │     ├─ 触发 OnPostLogin 委托
   │     └─ HandleStartingNewPlayer
   │
   └─ HandleStartingNewPlayer → RestartPlayer
         ├─ ChoosePlayerStart
         ├─ Spawn Pawn
         ├─ Possess
         └─ Pawn->BeginPlay
   ↓
玩家正式可玩
```

## 9.2.7 玩家退出:`Logout`

```cpp
// GameModeBase.h
virtual void Logout(AController* Exiting);
```

时机:玩家断线 / 主动退出。

### 9.2.7.1 默认行为

```cpp
void AGameModeBase::Logout(AController* Exiting)
{
    // 通知 GameState 移除 PlayerState
    AGameStateBase* GS = GameState;
    if (GS && Exiting->PlayerState) {
        GS->RemovePlayerState(Exiting->PlayerState);
    }
    
    // PC 销毁(GC 之后)
    Exiting->Destroy();
}
```

### 9.2.7.2 RTS 自定义

```cpp
void ARTSGameMode::Logout(AController* Exiting)
{
    // 玩家退出时,他的所有单位:
    //   选项 A:转给 AI(玩家挂机模式)
    //   选项 B:全部销毁(挂线扣分)
    //   选项 C:暂存(允许重连恢复)
    
    ARTSPlayerState* PS = Exiting->GetPlayerState<ARTSPlayerState>();
    if (PS) {
        TransferUnitsToAI(PS->TeamID);
    }
    
    Super::Logout(Exiting);
}
```

## 9.2.8 重连(reconnect)

UE 默认**不**支持"重连恢复 PlayerState"。玩家断线 → Logout → PlayerState 销毁。重连 → 新 PlayerState(失去之前的资源 / 分数)。

RTS 想支持重连:
1. **PlayerState 不立即销毁**,在 GameMode 的 `Logout` 里临时挂起,记 UniqueId
2. 重连时 `PreLogin` 里检测 UniqueId 是否在挂起列表,如果是 → 恢复 PlayerState

```cpp
TMap<FUniqueNetIdRepl, FRTSDisconnectedPlayer> SuspendedPlayers;

void ARTSGameMode::Logout(AController* Exiting)
{
    if (PlayerState && CanReconnect()) {
        // 暂存,而不是销毁
        SuspendedPlayers.Add(GetUniqueId(Exiting), { PS, Time });
        // 不调 Super::Logout(避免销毁)
        return;
    }
    Super::Logout(Exiting);
}

void ARTSGameMode::PreLogin(...)
{
    if (FRTSDisconnectedPlayer* Saved = SuspendedPlayers.Find(UniqueId)) {
        // 重连
        // 在 PostLogin 阶段恢复 PlayerState
    }
    Super::PreLogin(...);
}
```

实现细节复杂(PlayerState 引用、replicate timing),RTS 项目根据需求选做。

## 9.2.9 Seamless Travel(无缝切关卡)

普通切关卡:`UEngine::LoadMap` 卸载所有 World + 加载新 → 玩家**断线重连**(client 看 "Loading...")。

**Seamless Travel**(`AGameModeBase::bUseSeamlessTravel = true`):
- 用一个**临时 World**(transition map)中转
- PlayerController / PlayerState 通过特殊机制保留
- 玩家**不**断线,体验流畅

代价:**复杂**,要求 PC / PlayerState 支持 `GetSeamlessTravelActorList`。RTS 项目通常关卡切换不频繁,Seamless 不必要。

## 9.2.10 Listen Server vs Dedicated Server 的登录

### 9.2.10.1 Dedicated Server

每个加入的玩家都是"远程",走完整 PreLogin / Login / PostLogin 链。Server 自身**没有本地玩家**。

### 9.2.10.2 Listen Server

服务器进程同时有 server 和 1 个本地玩家:
- 本地玩家**不走**网络登录链(直接 SpawnPlayerController + Possess)
- 远程玩家走完整链

实战:Listen Server 的本地玩家要在 `BeginPlay` 主动调 `RestartPlayer(LocalPC)` 让本地玩家也走 spawn 流程。
