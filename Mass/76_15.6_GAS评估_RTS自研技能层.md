## 15.6.1 GAS 的固定开销

```
每个 ASC = 1 UObject + 网络复制 + Ability spec 数组
每个 Ability = 1 UObject + 实例(每激活一个)
每个 GameplayEffect 实例 = 1 UObject

50K Mass 单位 × 每单位 ASC + 几个 ability + 几个 effect:
   = 50K ASC + 200K Ability + 100K Effect = 350K UObject
   ❌ GUObjectArray 灾难
```

**结论:Mass 杂兵不能用 GAS**。

---

## 15.6.2 RTS 混合方案

```
英雄(数量 < 50):
   ✓ GAS(完整功能,BP 友好)
   - ASC,AttributeSet,Abilities,Effects,Cues
   - 复杂技能(投掷物,光环,combo)
   - 玩家 UI 显示

Mass 杂兵(50K):
   ✓ 自研轻量"技能层"
   - Fragment 持数据
   - Tag 表达状态
   - Processor 处理逻辑
   - 不参与 GAS,但视觉反馈走 Niagara / GameplayCue
```

## 15.6.3 Mass 自研技能层

```cpp
// 数据
USTRUCT()
struct FUnitStatsFragment : public FMassFragment
{
    int32 Health;
    int32 MaxHealth;
    int32 AttackPower;
    int32 Defense;
};

USTRUCT()
struct FCooldownFragment : public FMassFragment
{
    float NextAttackTime;
    float NextSkillTime;
};

// Tag 表达状态
USTRUCT() struct FBurningTag : public FMassTag {};
USTRUCT() struct FStunnedTag : public FMassTag {};

// Processor 处理伤害
class URTSDamageProcessor : public UMassProcessor
{
    void Execute(...) override
    {
        // 处理所有 entity 的伤害队列
        for entity in chunk:
            Stats.Health -= IncomingDamage;
            if (Stats.Health <= 0) MarkEntityForDeath(entity);
    }
};

// Buff 用 Tag + Fragment
USTRUCT()
struct FBurnEffectFragment : public FMassFragment
{
    float TickInterval = 1.0f;
    float NextTick = 0.0f;
    int32 DamagePerTick = 5;
    float Duration = 5.0f;
};

// 加 Tag + Fragment 表示"中毒"
EM.AddTag<FBurningTag>(Entity);
EM.AddFragmentInstanced(Entity, FBurnEffectFragment{});
```

**核心**:**用 Mass 数据驱动**替代 GAS 的 OOP 抽象。Fragment + Tag + Processor 的组合简洁高效。

## 15.6.4 性能对比

```
RTS 50K 单位场景 - 战斗 tick:

GAS 路线(假设可行):
   - ASC TickComponent × 50K = ~50 ms / 帧
   - Effect tick(多个 active effect)= ~30 ms
   - Network replication = ~50 ms
   总:~ 130 ms / 帧 ❌

Mass 自研:
   - DamageProcessor 扫 chunk × 几 ms
   - BuffProcessor 扫 chunk × 几 ms
   - 总:~ 5 ms / 帧 ✓
```

差**几个数量级**。

## 15.6.5 GAS 用在英雄上的好处

```
英雄(50 个):
   - GAS 提供 BP 友好的技能编辑(策划友好)
   - AttributeSet 数值 + Modifier 系统成熟
   - Cooldown / Cost 自动管理
   - GameplayCue 视觉效果
   - Network replication 内置

50 ASC × 一些开销 ≈ 几 ms / 帧,完全可行
```

## 15.6.6 接口:Hero ASC ↔ Mass 单位

```
Hero 释放群体技能(攻击 50 个杂兵):
   Hero.ASC 调 Ability::ActivateAbility
      ↓
   AbilityTask_WaitTargetData(锥形选目标)
      ↓ 命中 50 个 Mass entity
      ↓
   对每个 entity:
      不要 ApplyGameplayEffect(没 ASC)
      改成:
      URTSCommandSubsystem::EnqueueDamage(entity, 100)
         ↓
      Mass DamageProcessor 处理
```

英雄一边走 GAS,杂兵一边走 Mass。中间通过 Subsystem 桥接。
