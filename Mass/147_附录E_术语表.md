# 附录 E — 术语表

> 全指南出现的关键术语 — 字母序。

---

## A

- **Archetype**:Mass 中"具有相同 Fragment + Tag 集合的 entity 群"。同 archetype 的 entity 共用 chunk 内存。
- **AActor**:UE 游戏世界中可被 spawn 的对象基类。
- **Authoritative Snapshot**:RTS 网络主流方案,server 是权威,定期发 state 给 client。
- **AbilitySystemComponent (ASC)**:GAS 核心组件,挂在每个有技能的 actor 上。

## B

- **BehaviorTree (BT)**:经典 NPC AI 决策树,5.x 起被 StateTree 替代。
- **BeginPlay**:Actor 生命周期事件,在 World BeginPlay 之后调。
- **Bubble**:RTS 网络兴趣管理 — 玩家"看得到"的范围。

## C

- **CDO (Class Default Object)**:每个 UClass 一个 default 实例,作为 NewObject 模板。
- **Chunk**:Mass archetype 内的内存块,SoA 布局。
- **Cook**:把 Editor 资产打包成 Shipping 格式。
- **CrashReportClient**:UE 自带崩溃上报。

## D

- **DataOriented Programming (DOP)**:数据优先编程,Mass 哲学。
- **Dedicated Server (DS)**:无渲染纯逻辑服务器进程。
- **DOREPLIFETIME**:声明属性 replicated 的宏。
- **DAG**:有向无环图,Mass ExecutionOrder 用。

## E

- **ECS (Entity-Component-System)**:数据驱动架构。
- **Editor World**:`EWorldType::Editor`,Editor 中编辑的 World。
- **Enhanced Input**:5.x 新输入系统。

## F

- **FRepLayout**:Replication 子系统的属性布局描述。
- **Flow Field**:RTS 大规模寻路用的"向量场",所有单位共享。
- **FFastArraySerializer**:动态数组的高效 replication。
- **Fragment**:Mass 中 entity 持有的数据(POD)。

## G

- **GAS (Gameplay Ability System)**:UE 技能 / 属性 / Buff 框架。
- **Garbage Collection (GC)**:UObject 自动内存管理。
- **GameMode**:每 World 一个,服务器游戏规则。
- **GameState**:每 World 一个,公共状态(replicated)。
- **GUObjectArray**:全局 UObject 索引数组。

## I

- **Incremental GC**:5.x 增量 GC,把 mark 拆到多帧。
- **Iris**:5.x 新 replication 系统,push-based。
- **ISMC (InstancedStaticMeshComponent)**:实例化静态网格,GPU 一次画上千个。

## L

- **Lockstep**:RTS 同步方案,所有 client 跑相同确定性逻辑,只同步输入。
- **LocalPlayer**:本地玩家(每分屏一个)。
- **LOD**:Level of Detail,Mass 也有 LOD 系统降频。

## M

- **Mass**:5.x 的 ECS 框架,大规模 entity 的核心方案。
- **Module**:UE 编译单元,一个 `.Build.cs` 一个 module。
- **MallocBinned2/3**:UE 内存分配器实现。

## N

- **Navmesh**:导航网格寻路。
- **NetDriver**:UWorld 的网络驱动。
- **Niagara**:UE 粒子系统。

## O

- **OOP (Object-Oriented Programming)**:对象导向,UE 默认风格。

## P

- **Pak**:UE 资产打包格式。
- **PIE (Play In Editor)**:Editor 中运行游戏。
- **Pawn**:玩家 / AI 控制的 actor。
- **Processor**:Mass 中处理逻辑的 UObject 子类。

## Q

- **Quantization**:量化,把 float 转 16/8 bit 整数节省带宽。

## R

- **Replication**:网络复制,server → client 状态同步。
- **Replication Graph**:5.x 之前的兴趣管理框架。
- **RHI**:Render Hardware Interface,跨 GPU API 抽象。
- **RPC**:远程过程调用,server ↔ client 函数调用。
- **RVO (Reciprocal Velocity Obstacle)**:多 agent 局部避障算法。

## S

- **SoA (Structure of Arrays)**:CPU cache 友好的布局,Mass chunk 用。
- **SpawnActor**:UWorld 接口,创建并初始化 actor。
- **StateTree**:5.x 状态机框架,Mass 友好。
- **Streaming Level**:动态加载 / 卸载的子关卡。
- **Subsystem**:UE 的"无 Actor 的全局对象",4 种作用域。

## T

- **Tag (Mass)**:零字节标记 fragment,用于 archetype 区分状态。
- **Tick**:每帧调用 hook,UWorld / Actor / Component 都有。
- **Trait (Mass)**:Mass entity 模板的"功能模块"。
- **TStructTypeBitSet**:Mass 中 archetype 匹配的位集。

## U

- **UBT (UnrealBuildTool)**:C# 编写的构建工具。
- **UClass**:UObject 反射元数据。
- **UHT (UnrealHeaderTool)**:C# 反射代码生成器。
- **UObject**:UE 反射 / GC 体系的基类。
- **UPROPERTY / UFUNCTION / USTRUCT**:UHT 反射宏。
- **UWorld**:游戏世界容器。

## V

- **VAT (Vertex Animation Texture)**:用纹理存动画,GPU 蒙皮代替 CPU。

## W

- **WorldPartition**:5.x 替代 Streaming Level 的开放世界系统。
- **WorldSubsystem**:Subsystem 之一,World 作用域。
