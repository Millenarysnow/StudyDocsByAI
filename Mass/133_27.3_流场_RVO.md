## 27.3.1 流场(Flow Field)原理

```
1. 玩家点目标(target cell)
2. 从 target 反向 BFS / Dijkstra 计算每 cell 的"成本"和"方向"
3. 每 cell 存:
   - cost: 到 target 的距离
   - direction: 该往哪走(8 向或连续向量)
4. 单位移动时直接读 cell.direction 即可
```

**核心优势**:**1000 单位**走向同一目标 → **只算一次流场**,所有单位共享。

## 27.3.2 实现框架

```cpp
class URTSFlowFieldSubsystem : public UWorldSubsystem
{
    struct FFlowField
    {
        FVector Target;
        TArray<FVector2f> Directions;    // 每 cell 一个方向
        TArray<float> Costs;
        FIntPoint GridDim;
    };
    
    TMap<FGuid, TSharedPtr<FFlowField>> ActiveFields;
    
public:
    FGuid CreateField(FVector Target, /* obstacles */)
    {
        auto Field = MakeShared<FFlowField>();
        ComputeBFS(Field, Target);
        FGuid Id = FGuid::NewGuid();
        ActiveFields.Add(Id, Field);
        return Id;
    }
    
    FVector2f Sample(FGuid FieldId, FVector Pos)
    {
        auto* F = ActiveFields.Find(FieldId);
        if (!F) return FVector2f::ZeroVector;
        return (*F)->Directions[ToCell(Pos, (*F)->GridDim)];
    }
};
```

每个被指挥的"小队"持一个 FlowFieldId。

## 27.3.3 流场 + RVO 双层

```
单位移动 = 流场方向(全局) + RVO 调整(局部避障)

class UMassMovementProcessor : public UMassProcessor
{
    Execute(...)
    {
        for entity in chunk:
            // 1. 流场全局方向
            FVector2f FlowDir = FlowFieldSS->Sample(entity.FlowFieldId, Pos);
            
            // 2. RVO 邻居避障
            FVector2f Avoidance = RVOSubsystem->ComputeAvoidance(entity);
            
            // 3. 加权混合
            FVector2f FinalDir = FlowDir * 0.7 + Avoidance * 0.3;
            
            // 4. 推进
            Pos += FinalDir * Speed * DeltaT;
    }
};
```

## 27.3.4 性能

```
50K 单位 + 5 个 active flow field(5 个小队):

流场计算:
   - 每个 field 一次 BFS = 几 ms / field
   - 5 × 5 ms = 25 ms (一次性,玩家点击瞬间)
   - 不每帧重算

每帧:
   - 每 entity 采样流场 = ~10 ns
   - 50K × 10 ns = 0.5 ms ✓
   - + RVO ~5-7 ms ✓
   - 总:~10 ms / 帧 ✓
```
