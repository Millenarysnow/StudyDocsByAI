## 20.5.1 StateTree

`StateTree` 是 5.x 推荐的"层级状态机",替代 BehaviorTree。

```
RTS Soldier 状态:
   Root
      ├─ Idle
      ├─ Move(目标:Position)
      ├─ Attack
      │     ├─ AcquireTarget
      │     ├─ ChaseTarget
      │     └─ AttackTarget
      └─ Dead
```

每个状态是 `UStateTreeState`,转换条件 + 进 / 出动作。

---

## 20.5.2 Mass + StateTree

```
DA_Soldier:
   - UMassStateTreeTrait
       └─ ST_SoldierBehavior(StateTree 资产)
```

每 entity 关联一个 StateTree 实例。`UMassStateTreeProcessor` 每帧 tick StateTree,根据 Fragment 数据决定状态转换。

---

## 20.5.3 Smart Objects

`USmartObjectSubsystem`:游戏世界中的"可交互对象"。

```
RTS 例子:
   - 资源点(SmartObject:Worker 来这采集)
   - 建筑(SmartObject:Worker 来这建造)
   - 防御工事(SmartObject:Soldier 来这驻防)
```

每个 SmartObject 描述"什么单位 + 什么行为"。

---

## 20.5.4 Mass + SmartObject

```
DA_Worker:
   - UMassSmartObjectTrait
   
Worker 状态:
   Idle → Find Resource SO → Claim → Move to SO → Mine → Return
```

`UMassClaimedSmartObjectFragment` 持有 Worker 当前 claim 的 SO。

---

## 20.5.5 RTS 实战

```
StateTree 场景:
   ✓ 单位行为:Idle → Move → Attack → Dead
   ✓ Worker 工作循环
   ✓ Boss AI(多阶段)

Smart Object 场景:
   ✓ 资源点(Worker 找最近 → claim → 走过去 → 采)
   ✓ 防御位(Soldier 找到驻防点)
   ✓ 治疗站(伤兵找到 → 治疗)
```
