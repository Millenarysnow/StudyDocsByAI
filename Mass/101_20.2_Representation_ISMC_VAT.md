## 20.2.1 四档视觉

```
High LOD:    Skeletal Actor(完整骨骼动画 / 物理)
Medium:      ISMC + 简化动画(VAT)
Low:         ISMC 静态(无动画)
Off:         不渲染
```

每帧 `UMassRepresentationProcessor` 检查 entity LOD,**切换**视觉。

---

## 20.2.2 ISMC(Instanced Static Mesh Component)

`UInstancedStaticMeshComponent` 一个 Component **画 N 个 instance**(同 mesh,不同 transform)。GPU 端用 `GPUScene` 紧凑存储。

```
50K Soldier 用 ISMC:
   1 个 ISMC(Soldier mesh)
   50K instance(每 entity 一个 transform)
   GPU 一次 DrawCall 出 50K 个
```

性能:**几个 DrawCall** vs 50K StaticMeshActor 的 **50K DrawCall**。**几个数量级差异**。

---

## 20.2.3 RepresentationSubsystem

```cpp
class UMassRepresentationSubsystem : public UWorldSubsystem
{
    // 管理 ISMC 池
    TArray<UInstancedStaticMeshComponent*> ISMCPool;
    
    int32 AcquireInstance(UStaticMesh* Mesh, FTransform T);
    void ReleaseInstance(int32 InstanceID);
    void UpdateInstance(int32 InstanceID, FTransform T);
};
```

每帧 RepresentationProcessor:

```cpp
// 简化伪代码
void UMassRepresentationProcessor::Execute(...)
{
    Query.ForEachEntityChunk(...) [&](FMassExecutionContext& Ctx)
    {
        auto Reps = Ctx.GetMutableFragmentView<FMassRepresentationFragment>();
        auto LODs = Ctx.GetFragmentView<FMassLODFragment>();
        auto Transforms = Ctx.GetFragmentView<FMassTransformFragment>();
        
        for entity:
            EMassLOD::Type LOD = LODs[i].LOD;
            
            switch (LOD) {
                case High:
                    // 切换到 SkeletalActor(若需)
                    if (Reps[i].CurrentRepresentation != HighRep) {
                        SwitchToSkeletalActor(...);
                    }
                    break;
                case Medium / Low:
                    // ISMC instance
                    if (Reps[i].CurrentRepresentation != ISMCRep) {
                        Reps[i].ISMCInstanceID = RepSub->AcquireInstance(Mesh, T);
                    }
                    RepSub->UpdateInstance(Reps[i].ISMCInstanceID, Transforms[i].T);
                    break;
                case Off:
                    if (Reps[i].CurrentRepresentation != NoneRep) {
                        SwitchToNoRep(...);
                    }
                    break;
            }
    });
}
```

## 20.2.4 VAT(Vertex Animation Texture)

ISMC 不支持骨骼动画。**VAT** 是把骨骼动画**烘焙到纹理**,顶点着色器按帧采样:

```
预处理:
   - 玩 SoldierIdle 动画 30 帧
   - 每帧每顶点位置 → 纹理 RGB
   - 30 × NumVertices × 12 字节 → 一张 VAT
   
Runtime:
   - ISMC + VAT 纹理 + 自定义 Material
   - Vertex Shader: SamplePositionFromVAT(InstanceID, FrameTime)
   - 每 instance 独立动画时间(InstanceCustomData)
```

效果:50K 单位**各自**播动画,但**仍然 1-2 DrawCall**。

UE 5.x 自带 `Vertex Animation Tools` 插件 / 第三方工具(Houdini export)生成 VAT。

§25 详讲 VAT 在 RTS 中的应用。

## 20.2.5 Niagara(粒子)

某些 entity 适合 Niagara(投射物、特效):
- 不需要复杂 mesh
- 大量同类型(子弹、火花)
- GPU sim

`URepresentationProcessor` 也可以路由到 Niagara emitter,设 instance data。

---

## 20.2.6 RTS 视角

```
单位类型           视觉策略
──────────────────────────────────────────
英雄 / Boss (10)     SkeletalActor(完整骨骼动画 + 物理)
精英单位 (~100)      VAT-based(高质量预烘焙动画)
普通杂兵 (50K)       ISMC + VAT(简化动画)
投射物 / 特效        Niagara
建筑                  StaticMesh / ISMC
```
