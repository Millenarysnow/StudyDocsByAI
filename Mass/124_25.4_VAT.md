# §25.4 VAT(Vertex Animation Texture)— 烘焙骨骼到纹理

> **本节地图**:模块五第 25 章第 4 节。VAT 让 ISMC 也能播放骨骼动画。
>
> **预备知识**:§25.2 / §25.3。

---

## 25.4.1 VAT 原理

```
预处理(Editor 期):
   - SkeletalMesh + AnimSequence(Idle / Walk / Attack...)
   - 每帧每顶点 → 计算位置(由骨骼变换驱动)
   - 写入纹理:
     R, G, B = X, Y, Z(顶点位置 / 偏移)
     纹理大小 = NumFrames × NumVertices
   - 法线 / 旋转可烘到第二张纹理

Runtime:
   - ISMC + 自定义 Material
   - Vertex Shader:SamplePositionFromTexture(VertexID, FrameIndex / Time)
   - 每 instance 用 InstanceCustomData 存"当前帧 / 动画 ID"
   - 顶点着色器读纹理取位置
```

效果:**ISMC + VAT = 50K 单位各自播动画,1-2 DrawCall**。

## 25.4.3 Material 配置

```hlsl
// VAT material(简化)
float TextureFrames = 60;             // 总帧数
float CurrentFrame = AnimTime * 30;   // 30fps 动画

float2 UV;
UV.x = (float)VertexID / NumVertices;
UV.y = CurrentFrame / TextureFrames;

float3 PositionOffset = SamplePositionTexture(UV);
float3 NormalOffset = SampleNormalTexture(UV);

// 顶点位置 = 原始位置 + PositionOffset
WorldPosition = OriginalPosition + PositionOffset;
```

每 instance 通过 `PerInstanceCustomData` 传入"动画索引 + 当前时间"。

## 25.4.4 RTS 集成

```cpp
USTRUCT()
struct FRTSAnimFragment : public FMassFragment
{
    int32 CurrentAnimID;     // 0=Idle / 1=Walk / 2=Attack
    float AnimTime;
};

class URTSAnimProcessor : public UMassProcessor
{
    void Execute(...) override
    {
        Query.ForEachEntityChunk(...) [&](FMassExecutionContext& Ctx)
        {
            auto Anims = Ctx.GetMutableFragmentView<FRTSAnimFragment>();
            const auto Reps = Ctx.GetFragmentView<FRTSRepresentationFragment>();
            const float DT = Ctx.GetDeltaTimeSeconds();
            
            for entity:
                Anims[i].AnimTime += DT;
                
                // 设 ISMC 的 PerInstanceCustomData
                ISMCPool->SetCustomData(Reps[i].InstanceID, /*Slot 0*/ Anims[i].CurrentAnimID);
                ISMCPool->SetCustomData(Reps[i].InstanceID, /*Slot 1*/ Anims[i].AnimTime);
        });
    }
};
```

ISMC 的 `NumCustomDataFloats = 2`(动画 ID + 时间),Material 读取播动画。

## 25.4.5 性能

```
VAT 性能:
   - 内存:每动画一张纹理(几 MB),共享给所有 instance
   - GPU:Vertex Shader 多两次纹理 sample / 顶点
   - DrawCall:仍是 1 / mesh
   
50K 单位各自动画:GPU 几 ms,完全可行
```
