## 10.5.1 RTS 输入的特殊性

```
FPS 输入: WASD → Pawn 移动 + 鼠标 → 视角

RTS 输入: 
   - WASD → 相机移动(Pawn)
   - 鼠标移动 → 屏幕边缘滚屏
   - 左键 → 选择 / 框选
   - 右键 → 移动 / 攻击命令
   - 中键 → 旋转视角
   - 数字键 → 编组(Ctrl+1 设组,1 选组)
   - F1-F12 → 大招快捷
```

每条都不直接对应 Pawn movement。RTS input 全是"指挥",最终目标是 **Mass entity**。

## 10.5.2 鼠标射线选择(单击)

```cpp
void ARTSPlayerController::OnSelect(const FInputActionValue& V)
{
    // 1. 屏幕坐标 → 世界射线
    FVector WorldOrigin, WorldDir;
    DeprojectMousePositionToWorld(WorldOrigin, WorldDir);
    
    // 2. 射线检测
    FHitResult Hit;
    FCollisionQueryParams Params;
    GetWorld()->LineTraceSingleByChannel(
        Hit,
        WorldOrigin,
        WorldOrigin + WorldDir * 100000.0f,
        ECC_Visibility,
        Params);
    
    if (Hit.bBlockingHit)
    {
        // 3. 检测命中的是 Mass entity 还是 Actor
        if (AActor* HitActor = Hit.GetActor())
        {
            // Hero / Building 用 Actor
            HandleActorSelection(HitActor);
        }
        else
        {
            // 否则:命中地面 → 询问 SpatialIndex 找最近 Mass entity
            FMassEntityHandle HitEntity = QuerySpatialIndex(Hit.Location);
            if (HitEntity.IsValid())
            {
                URTSSelectionSubsystem* Sel = GetLocalPlayer()->GetSubsystem<URTSSelectionSubsystem>();
                Sel->Select(HitEntity);
            }
        }
    }
}
```

### 10.5.2.1 Mass entity 的"碰撞体"

Mass entity 不自动有 UPrimitiveComponent → 不被 LineTrace 命中。两种解决:

**方案 A:Mass 自己的空间索引**

```cpp
// URTSSpatialIndexSubsystem 维护 entity 位置的 octree
URTSSpatialIndexSubsystem* SI = GetWorld()->GetSubsystem<URTSSpatialIndexSubsystem>();
FMassEntityHandle E = SI->QueryNearest(WorldLoc, /*Radius*/ 100.0f);
```

每帧 Mass `MovementProcessor` 末尾把更新的位置 write 到 octree。

**方案 B:Click 在 ISMC 实例上**

如果 Mass 用 ISMC 渲染,LineTrace 能命中 ISMC instance。需要从 instance index 反查 entity。

## 10.5.3 矩形框选(Marquee Selection)

```cpp
class ARTSPlayerController : public APlayerController
{
    bool bIsBoxSelecting = false;
    FVector2D BoxStartScreenPos;
    
    void OnSelectStart(const FInputActionValue& V)
    {
        // 鼠标左键按下
        bIsBoxSelecting = true;
        GetMousePosition(BoxStartScreenPos.X, BoxStartScreenPos.Y);
    }
    
    void OnSelectEnd(const FInputActionValue& V)
    {
        // 鼠标左键释放
        if (!bIsBoxSelecting) return;
        
        FVector2D BoxEnd;
        GetMousePosition(BoxEnd.X, BoxEnd.Y);
        
        // 1. 计算屏幕矩形
        FBox2D Rect(FVector2D::Min(BoxStartScreenPos, BoxEnd),
                    FVector2D::Max(BoxStartScreenPos, BoxEnd));
        
        // 2. 投影到世界(估算视锥)
        // 3. 询问 SpatialIndex 哪些 entity 在这个视锥内
        TArray<FMassEntityHandle> Selected = QueryEntitiesInScreenBox(Rect);
        
        // 4. 更新选择
        URTSSelectionSubsystem* Sel = GetLocalPlayer()->GetSubsystem<URTSSelectionSubsystem>();
        Sel->Set(Selected);
        
        bIsBoxSelecting = false;
    }
    
    void Tick(float DT) override
    {
        if (bIsBoxSelecting)
        {
            // 在屏幕画矩形(HUD 或 UMG)
            DrawSelectionBox();
        }
    }
};
```

### 10.5.3.1 视锥投影(从屏幕矩形 → 世界)

```cpp
TArray<FMassEntityHandle> ARTSPlayerController::QueryEntitiesInScreenBox(FBox2D ScreenRect)
{
    // 4 个角:屏幕坐标 → 世界射线
    FVector RayOrigin0, RayDir0, RayOrigin1, RayDir1, RayOrigin2, RayDir2, RayOrigin3, RayDir3;
    DeprojectScreenPositionToWorld(ScreenRect.Min.X, ScreenRect.Min.Y, RayOrigin0, RayDir0);
    DeprojectScreenPositionToWorld(ScreenRect.Max.X, ScreenRect.Min.Y, RayOrigin1, RayDir1);
    DeprojectScreenPositionToWorld(ScreenRect.Min.X, ScreenRect.Max.Y, RayOrigin2, RayDir2);
    DeprojectScreenPositionToWorld(ScreenRect.Max.X, ScreenRect.Max.Y, RayOrigin3, RayDir3);
    
    // 构造 4 面视锥(从相机出发,4 个角射线展开)
    FConvexVolume Frustum = MakeFrustum({ RayOrigin0, RayOrigin1, RayOrigin2, RayOrigin3 },
                                          { RayDir0, RayDir1, RayDir2, RayDir3 },
                                          MaxSelectionDistance);
    
    // SpatialIndex 查询
    URTSSpatialIndexSubsystem* SI = GetWorld()->GetSubsystem<URTSSpatialIndexSubsystem>();
    return SI->QueryFrustum(Frustum);
}
```

`FConvexVolume::IntersectBox` / `IntersectSphere` 是 UE 自带视锥检测。性能好,百万 entity 也能秒级完成。

## 10.5.4 选择 Subsystem

```cpp
UCLASS()
class URTSSelectionSubsystem : public ULocalPlayerSubsystem
{
    UPROPERTY()
    TArray<FMassEntityHandle> SelectedEntities;
    
public:
    void Select(FMassEntityHandle E)
    {
        SelectedEntities = { E };
        OnSelectionChanged.Broadcast();
    }
    
    void Set(const TArray<FMassEntityHandle>& Es)
    {
        SelectedEntities = Es;
        OnSelectionChanged.Broadcast();
    }
    
    void Add(FMassEntityHandle E)   // Shift+点击加选
    {
        SelectedEntities.AddUnique(E);
        OnSelectionChanged.Broadcast();
    }
    
    void Clear()
    {
        SelectedEntities.Empty();
        OnSelectionChanged.Broadcast();
    }
    
    DECLARE_MULTICAST_DELEGATE(FOnSelectionChanged);
    FOnSelectionChanged OnSelectionChanged;
};
```

### 10.5.4.1 编组(Ctrl+1 / 2 / ...)

```cpp
class URTSSelectionSubsystem : public ULocalPlayerSubsystem
{
    TMap<int32, TArray<FMassEntityHandle>> Groups;       // 1-9 编组
    
public:
    void SetGroup(int32 GroupID)    // Ctrl+1
    {
        Groups.Add(GroupID, SelectedEntities);
    }
    
    void RecallGroup(int32 GroupID) // 1
    {
        if (TArray<FMassEntityHandle>* G = Groups.Find(GroupID))
        {
            Set(*G);
        }
    }
};
```

## 10.5.5 命令派发

玩家选完 + 右键命令位置:

```cpp
void ARTSPlayerController::OnCommand(const FInputActionValue& V)
{
    URTSSelectionSubsystem* Sel = GetLocalPlayer()->GetSubsystem<URTSSelectionSubsystem>();
    if (Sel->SelectedEntities.IsEmpty()) return;
    
    // 射线检测目标
    FHitResult Hit;
    GetHitResultUnderCursor(ECC_Visibility, /*Trace*/false, Hit);
    if (!Hit.bBlockingHit) return;
    
    FRTSCommand Cmd;
    Cmd.Type = ECmdType::Move;
    Cmd.Targets = Sel->SelectedEntities;
    Cmd.TargetLocation = Hit.Location;
    Cmd.bQueue = IsShiftDown();    // Shift+右键 = 加入命令队列
    
    // 发到 server
    if (HasAuthority())
    {
        // 本地是 server
        ServerIssueCommand_Implementation(Cmd);
    }
    else
    {
        ServerIssueCommand(Cmd);   // RPC
    }
}

UFUNCTION(Server, Reliable, WithValidation)
void ServerIssueCommand(const FRTSCommand& Cmd);

void ARTSPlayerController::ServerIssueCommand_Implementation(const FRTSCommand& Cmd)
{
    // 验证(玩家是否拥有这些 entity?)
    if (!ValidateOwnership(Cmd, GetPlayerState())) return;
    
    // 入队 CommandSubsystem
    GetWorld()->GetSubsystem<URTSCommandSubsystem>()->Enqueue(Cmd);
}

bool ARTSPlayerController::ServerIssueCommand_Validate(const FRTSCommand& Cmd)
{
    return true;   // 实际可加合法性校验
}
```

## 10.5.6 命令队列

每个 entity 持有命令列表:

```cpp
USTRUCT()
struct FCommandQueueFragment : public FMassFragment
{
    GENERATED_BODY()
    
    TArray<FRTSCommand> Queue;
    
    int32 CurrentIndex = 0;
};
```

`URTSCommandProcessor` 消费队列:

```cpp
void URTSCommandProcessor::Execute(...)
{
    Query.ForEachEntityChunk(EntityManager, Context, [](FMassExecutionContext& Ctx)
    {
        TArrayView<FCommandQueueFragment> Queues = Ctx.GetMutableFragmentView<FCommandQueueFragment>();
        for (int32 i = 0; i < Ctx.GetNumEntities(); ++i)
        {
            FCommandQueueFragment& Q = Queues[i];
            if (Q.CurrentIndex < Q.Queue.Num())
            {
                FRTSCommand& C = Q.Queue[Q.CurrentIndex];
                // 执行当前命令
                if (IsCommandComplete(Ctx.GetEntity(i), C))
                {
                    Q.CurrentIndex++;
                }
            }
        }
    });
}
```

Shift+右键时:`Cmd.bQueue = true` → CommandSubsystem 把 cmd `Add` 而不是 `Set` 到 entity 的 FCommandQueueFragment。

## 10.5.7 输入数据流总图

```
玩家鼠标点击
   ↓
APlayerController::InputKey → UPlayerInput::ProcessInputStack
   ↓
EnhancedInput 触发 IA_Select / IA_Command
   ↓
ARTSPlayerController::OnSelect / OnCommand 被调
   ↓ (本地)
URTSSelectionSubsystem (ULocalPlayerSubsystem) 更新
   │
   │ (右键时)
   ↓
ARTSPlayerController::ServerIssueCommand RPC
   │
   ↓ (Server)
URTSCommandSubsystem (UWorldSubsystem) 入队
   │
   ↓ (下一帧 Mass tick)
URTSCommandProcessor 消费 → 修改 entity Fragment
```

7 步,每步在不同类。**纪律**:每步只做自己分内的事。
