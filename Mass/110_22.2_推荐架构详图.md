## 22.2.1 完整架构图

```
[进程层]
   GEngine(UGameEngine 默认 / 或自定义 UMyRTSGameEngine)
      └─ URTSAssetCacheSubsystem(UEngineSubsystem)

[一局游戏层]
   UGameInstance(默认 / 或 UMyRTSGameInstance)
      ├─ URTSPlayerProfileSubsystem
      ├─ URTSMatchmakingSubsystem
      └─ ULocalPlayer × N
            ├─ URTSSelectionSubsystem(本地选择)
            ├─ URTSUIStateSubsystem(UI / Mini-Map)
            └─ UEnhancedInputLocalPlayerSubsystem

[关卡 / World 层]
   UWorld(EWorldType::Game)
      ├─ ARTSGameMode(server only)
      │     - 决定胜负、玩家加入退出
      │     - 配置 GameStateClass / PCClass / PawnClass
      │
      ├─ ARTSGameState(replicated)
      │     - 当前阶段、全局倒计时
      │
      ├─ APlayerController × N(per player)
      │     ├─ ARTSPlayerState × N(replicated)
      │     │     - TeamID / Resources / Apm
      │     ├─ Possess → ARTSCameraPawn(per player)
      │     │     - 仅相机控制(WASD / 滚轮)
      │     ├─ 命令 RPC 入口(client → server)
      │     └─ 选择本地处理
      │
      └─ UWorldSubsystem ×多个:
            ├─ UMassEntitySubsystem(数据中枢)
            ├─ UMassSimulationSubsystem(Tick 调度)
            ├─ UMassReplicationSubsystem(网络)
            ├─ UMassRepresentationSubsystem(视觉)
            ├─ UMassSpawnerSubsystem(生成)
            ├─ URTSCombatSubsystem(server)
            ├─ URTSCommandSubsystem(命令路由)
            ├─ URTSEconomySubsystem(server,经济)
            ├─ URTSFogOfWarSubsystem(雾战)
            ├─ URTSPathfindingSubsystem(寻路)
            └─ URTSSpatialIndexSubsystem(空间索引)

[Mass entity 层 — 数据 + 逻辑]
   50K Mass Entity(8 字节句柄)
      ├─ Fragment 数据(Position/Velocity/Health/...)
      ├─ Tag 状态(Active/Dead/Burning)
      ├─ ConstSharedFragment(单位类型配置)
      └─ SharedFragment(类型级 mesh 引用)
   
   Processor(数十个):
      PrePhysics:
         ├─ URTSCommandProcessor      消费命令队列
         ├─ URTSAIProcessor            StateTree tick
         ├─ URTSMovementProcessor     移动意图
      DuringPhysics:
         └─ URTSCombatProcessor        与物理并行
      PostPhysics:
         ├─ URTSSteeringProcessor      避障调整
         └─ URTSDeathProcessor         死亡处理
      FrameEnd:
         ├─ UMassLODProcessor
         ├─ UMassRepresentationProcessor
         └─ UMassReplicationProcessor

[特殊 Actor 层 — 数量少]
   AHero × 玩家数(继承 ACharacter)
      - 完整 ASC + GAS 技能
      - SkeletalMesh + 动画蓝图
      - 重要 BP 逻辑
   
   ABuilding × 几十(继承 AActor)
      - 玩家建造的关键建筑
      - 复杂交互(资源点、生产队列)
   
   ADecorationActor × 几十(关卡装饰)
      - 大型山脉、石头组(用 Landscape / WP cell)
```

---

## 22.2.2 架构哲学

```
"重要的少 → 用 Actor"
"大量的多 → 用 Mass"
"稳定的状态 → 用 Subsystem"
"规则的全局 → 用 GameMode + GameState"
"本地的玩家 → 用 PC + LocalPlayerSubsystem"
```

---

## 22.2.3 各层职责墙

```
GameMode:           游戏规则(server)
GameState:          全局可见状态(replicated)
PlayerController:   玩家本地输入 + 命令派发(per player)
PlayerState:        玩家档案数据(replicated)
CameraPawn:          仅视角控制
Hero(Actor):       重要单位(BP + 完整功能)
Mass entity:        大量单位(性能 + 简化)
Subsystem:          管理类共享逻辑
```
