## 7.8.1 全景图

```
[Network 字节流]
       │
       ▼ Netty pipeline (or asio handler chain)
┌─────────────────────────────────────────┐
│ inbound (decoder side)                  │
│   ↓                                     │
│ SPLITTER (Varint21FrameDecoder)         │
│   把 VarInt 长度前缀的包切出来          │
│   ↓                                     │
│ DECRYPT (CipherDecoder, AES-CFB8)       │
│   ↓                                     │
│ DECOMPRESS (CompressionDecoder, zlib)   │
│   ↓                                     │
│ DECODER (PacketDecoder + StreamCodec)   │
│   读 VarInt id + 反序列化               │
│   ↓                                     │
│ UNBUNDLER                                │
│   拆 BundlePacket                        │
│   ↓                                     │
│ PACKET_HANDLER (Connection)              │
│   packet.handle(listener) 双分派        │
│   ↓                                     │
│ Listener.handleX(packet)                 │
│   ensureRunningOnSameThread → server tick│
│   ↓ 在主 tick 处理                       │
│ 业务逻辑                                 │
└─────────────────────────────────────────┘

[Server tick 主循环]
       │
       ▼
游戏状态变化（setBlock / move / damage）
       │
       ▼
  Connection.send(packet)
       │
       ▼ outbound pipeline
┌─────────────────────────────────────────┐
│ outbound (encoder side)                 │
│   ↓                                     │
│ BUNDLER → 包装 BundlePacket              │
│   ↓                                     │
│ ENCODER (PacketEncoder + StreamCodec)   │
│   写 VarInt id + 序列化                  │
│   ↓                                     │
│ ENCRYPT                                  │
│   ↓                                     │
│ COMPRESS                                 │
│   ↓                                     │
│ PREPENDER (Varint21LengthFieldPrepender)│
│   写 VarInt 长度前缀                     │
│   ↓                                     │
│ Network                                  │
└─────────────────────────────────────────┘

[连接状态机]
HANDSHAKING → STATUS / LOGIN / TRANSFER
              ↓ login
              CONFIGURATION (registry/tags 同步)
              ↓
              PLAY (200+ 包，正常游戏)

[同步模型]
- 客户端预测 (移动 / 挖 / 放) + 服务端 ack
- 实体增量 (VecDeltaCodec 1/4096 精度)
- partialTick 客户端帧间插值
- ChunkMap + DistanceManager 流式发 chunk
```

## 7.8.3 库选择对比

| 库 | 优势 | 劣势 |
|---|------|------|
| **boost::asio** | 跨平台 / 文档丰富 / 现代 C++ / 可与 SSL 集成 | 学习曲线陡 / 依赖大 |
| **standalone asio** | 同 boost::asio 但独立 | 同上 |
| **enet** | 简单 / 自带可靠 UDP / 适合游戏 | 不是 TCP（vanilla 协议要求 TCP）|
| **手写 epoll/IOCP** | 极致性能 / 无依赖 | 工作量大 / 跨平台麻烦 |
| **libuv** | Node.js 同源 / C 简单 | 比 asio 抽象低一档 |
| **QUIC (msquic / lsquic)** | 现代 / 自带加密 / 多路复用 | 协议不兼容 vanilla |

**推荐**：

- **想兼容 vanilla 客户端**：`boost::asio` + 自己实现协议层。
- **想自定义协议**：`enet` 或 `quic`（不兼容 vanilla 但工程量小）。

## 7.8.6 性能 / 带宽 target

```
单 100 玩家服务端：
- 上行: ~1 KB/s/玩家 × 100 = 100 KB/s
- 下行: ~150 KB/s/玩家 × 100 = 15 MB/s（chunk burst 期间更高）
- 主线程：~30-40 ms/tick (TPS ~25-33)
- IO 线程：~20-40% 单核
- RAM：~2-4 GB（视距 32 时）

合理硬件：
- 4-8 核 CPU
- 8-16 GB RAM
- 50 Mbps 上行带宽
```

## 7.8.7 与 modder 协议兼容性

如果想支持 Forge / Fabric mod 客户端：

- **协议层兼容**：完全照搬 vanilla 协议——可。
- **Plugin Channels**：mod 用自定义 ResourceLocation 频道发包（`fml:loginwrapper`、`forge:registry`）—— 需要实现 `ClientboundCustomPayloadPacket` / `ServerboundCustomPayloadPacket`。
- **Mod 完整支持**：需实现 Forge / Fabric 的 server-side mod loading 协议——巨大工程量，不推荐。

**推荐策略**：

- 第一版仅支持 vanilla 客户端。
- 加 Plugin Channels（Bukkit 风格的 mod 通讯抽象）。
- 不实现 Forge / Fabric 复杂协议。

## 7.8.9 一句话总结

第 7 部分讲清楚 Minecraft 网络协议的全栈——Netty pipeline 把 TCP 字节流分帧 → 解压 → 解密 → 反序列化 → 派发到 PacketListener；5 阶段连接状态机（HANDSHAKE / STATUS / LOGIN / CONFIGURATION / PLAY），1.20.2 引入 CONFIGURATION 让 PLAY 中能切回同步新 registry；StreamCodec + FriendlyByteBuf 提供 record-style packet 序列化；AES-CFB8 加密 + zlib 压缩 (阈值 256) + Mojang sessionserver 在线模式 auth；客户端乐观预测 + 服务端权威 + sequence ack 机制；ChunkMap + DistanceManager 流式发 chunk，ChunkHolder 4 阶 FullChunkStatus（INACCESSIBLE / FULL / BLOCK_TICKING / ENTITY_TICKING）；C++ 移植推荐 boost::asio + zlib + OpenSSL，约 12000 行 packet 类 + 几千行 protocol / chunk 调度，单人工程量 6-12 个月。
