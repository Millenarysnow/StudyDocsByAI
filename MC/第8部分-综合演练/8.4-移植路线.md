# 8.4 移植路线：M0-M9 里程碑

## 8.4.0 你将在本节学到什么

读完这一节你应当能：

1. 清楚整个 C++ 移植工程的**完整路线图**——从 M0 到 M9 共 10 个里程碑。
2. 每个里程碑的目标 / 涉及模块 / 工作量估算。
3. 在不同里程碑可获得的"可运行 demo"。
4. 决定项目优先级：先做联机互通还是先做完整 vanilla 兼容。

---

## 8.4.1 总体路线

```
M0 基础设施（坐标 / 注册表）        ─ 1 周
M1 NBT + BlockState                 ─ 2-3 周
M2 Region 文件 / Chunk 持久化       ─ 2 周
M3 单 biome 平坦世界                ─ 3-4 周
M4 完整 worldgen                    ─ 8-12 周（最大头）
M5 方块更新 + 红石                  ─ 4-6 周
M6 流体                              ─ 2-3 周
M7 网络协议                          ─ 6-8 周
M8 客户端渲染（如果做 client）       ─ 8-12 周
M9 与 vanilla 互联                   ─ 2-4 周

总（仅服务端）：~30 周 ≈ 7 个月（单人）
总（含客户端）：~50 周 ≈ 1 年（单人）
```

## 8.4.12 工作量总估

```
单人全职:
- 仅服务端 (M0-M7, M9):  ~30 周 ≈ 7 个月
- 含客户端 (M0-M9):       ~50 周 ≈ 1 年
- 兼职 (10 hr/week):       2-4 倍

代码量估计:
- 服务端：~50,000 行 C++
- 客户端：~30,000 行 C++ + GLSL/HLSL
- 总：~80,000 行
```

**对比 vanilla**：vanilla 总代码 ~500,000 行 Java。**C++ 移植可压缩到 ~80,000 行**因为：

- 不实现完整 GUI / model loading / 多语言。
- 跳过 DataFixerUpper（仅当前版本）。
- 简化粒子系统 / 音效。
- 跳过 mod loader 兼容。

但**核心算法 1:1 复刻**——确保种子兼容、行为一致。

## 8.4.13 优先级建议

**目标 1：自有引擎（不需要 vanilla 兼容）**：

- M0 → M1 → M2 → M3 → M5 → M6 → 自定义网络层 → 自定义客户端
- 跳过 M4（完整 vanilla worldgen）—— 用自己的简单 worldgen
- 跳过 M9
- 工作量：~20 周

**目标 2：vanilla 兼容服务端**：

- M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M9
- 跳过 M8（用 vanilla 客户端）
- 工作量：~30 周

**目标 3：完整 vanilla 替代品**：

- 全部 M0 → M9
- 工作量：~50 周

## 8.4.15 工程化建议

### 1. 测试驱动

每个模块都对照 vanilla 做 bitwise 测试。**不要先写完所有再测**——一处 bug 会向下游 chain 难以定位。

### 2. 参考实现

- **Cubitect cubiomes**（github.com/Cubitect/cubiomes）：C 实现的 vanilla biome / 噪声复刻——优秀参考。
- **Misode worldgen visualizer**（misode.github.io/worldgen）：在线对照工具。
- **Minecraft Wiki**：协议详细文档（wiki.vg）。

### 3. 不要过度优化

第一版**简单实现 + 对齐 vanilla**——SoA / SIMD / GPU 等优化等性能瓶颈再做。

### 4. 增量发布

每个里程碑完成后**写测试 + 发 demo**。让自己看到进度。

### 5. 选好基础库

- **NBT**：手写 + zlib。
- **JSON**：nlohmann::json。
- **网络**：boost::asio。
- **加密**：OpenSSL。
- **数学**：glm。

## 8.4.16 一句话总结

C++ 移植路线 M0-M9：M0 基础工具（坐标 / 注册表）1 周 → M1 NBT + BlockState 2-3 周 → M2 Region 文件 + Chunk 持久化 2 周 → M3 单 biome 平坦世界 3-4 周 → M4 完整 vanilla worldgen 8-12 周（**最大头**）→ M5 方块更新 + 红石 4-6 周 → M6 流体 2-3 周 → M7 网络协议 6-8 周（200+ packet 是大头）→ M8 客户端渲染 8-12 周（可选，可用 vanilla 客户端代替）→ M9 与 vanilla 互联 2-4 周；总共 ~30 周（仅服务端）/ ~50 周（含客户端）/ ~50000 行 C++（仅服务端）/ ~80000 行（含客户端）；关键纪律是**每里程碑 bitwise 对齐 vanilla**——cubiomes / wiki.vg 是黄金参考。
