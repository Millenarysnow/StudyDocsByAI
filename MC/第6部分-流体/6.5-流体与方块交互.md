## 6.5.2 LiquidBlockContainer 接口

```java
public interface LiquidBlockContainer {
    boolean canPlaceLiquid(@Nullable Player player, BlockGetter level, BlockPos pos, BlockState state, Fluid fluid);
    boolean placeLiquid(LevelAccessor level, BlockPos pos, BlockState state, FluidState fluidState);
}
```

**实现 SimpleWaterloggedBlock 接口（继承 LiquidBlockContainer）**：

```java
public interface SimpleWaterloggedBlock extends LiquidBlockContainer {
    @Override
    default boolean canPlaceLiquid(@Nullable Player player, BlockGetter level, BlockPos pos, BlockState state, Fluid fluid) {
        return !state.getValue(BlockStateProperties.WATERLOGGED) && fluid == Fluids.WATER;
    }
    
    @Override
    default boolean placeLiquid(LevelAccessor level, BlockPos pos, BlockState state, FluidState fluidState) {
        if (!state.getValue(BlockStateProperties.WATERLOGGED) && fluidState.getType() == Fluids.WATER) {
            if (!level.isClientSide()) {
                level.setBlock(pos, state.setValue(BlockStateProperties.WATERLOGGED, true), 3);
                level.scheduleTick(pos, fluidState.getType(), fluidState.getType().getTickDelay(level));
            }
            return true;
        }
        return false;
    }
    
    default ItemStack pickupBlock(@Nullable Player player, LevelAccessor level, BlockPos pos, BlockState state) {
        if (state.getValue(BlockStateProperties.WATERLOGGED)) {
            level.setBlock(pos, state.setValue(BlockStateProperties.WATERLOGGED, false), 3);
            if (!state.canSurvive(level, pos)) level.destroyBlock(pos, true);
            return new ItemStack(Items.WATER_BUCKET);
        }
        return ItemStack.EMPTY;
    }
}
```

**3 个核心方法**：

- `canPlaceLiquid`：能不能放水？检查 WATERLOGGED 不为 true + fluid 是水。
- `placeLiquid`：实际放水——把 WATERLOGGED 改 true + schedule fluid tick。
- `pickupBlock`：水桶舀水——把 WATERLOGGED 改 false + 返回 water_bucket。

**注意**：waterloggable 方块**只支持水**，不支持熔岩。`fluid == Fluids.WATER` 硬编码。

## 6.5.3 海绵吸水

打开 `net.minecraft.world.level.block.SpongeBlock`：

```java
public class SpongeBlock extends Block {
    public SpongeBlock(BlockBehaviour.Properties props) { super(props); }
    
    @Override
    public void onPlace(BlockState state, Level level, BlockPos pos, BlockState oldState, boolean movedByPiston) {
        if (!oldState.is(state.getBlock())) {
            this.tryAbsorbWater(level, pos);
        }
    }
    
    @Override
    public void neighborChanged(BlockState state, Level level, BlockPos pos, ...) {
        this.tryAbsorbWater(level, pos);
        super.neighborChanged(state, level, pos, ...);
    }
    
    private void tryAbsorbWater(Level level, BlockPos pos) {
        if (this.removeWaterBreadthFirstSearch(level, pos)) {
            level.setBlock(pos, Blocks.WET_SPONGE.defaultBlockState(), 2);
            level.playSound(null, pos, SoundEvents.SPONGE_ABSORB, SoundSource.BLOCKS, 1.0F, 1.0F);
        }
    }
    
    private boolean removeWaterBreadthFirstSearch(Level level, BlockPos pos) {
        Queue<Pair<BlockPos, Integer>> queue = Lists.newLinkedList();
        queue.add(new Pair<>(pos, 0));
        int absorbedCount = 0;
        
        while (!queue.isEmpty()) {
            Pair<BlockPos, Integer> entry = queue.poll();
            BlockPos curPos = entry.getFirst();
            int distance = entry.getSecond();
            
            for (Direction dir : Direction.values()) {
                BlockPos neighborPos = curPos.relative(dir);
                BlockState neighborState = level.getBlockState(neighborPos);
                FluidState neighborFluid = level.getFluidState(neighborPos);
                
                if (neighborFluid.is(FluidTags.WATER)) {
                    // 吸掉这格水
                    if (neighborState.getBlock() instanceof BucketPickup pickup &&
                        !pickup.pickupBlock(null, level, neighborPos, neighborState).isEmpty()) {
                        absorbedCount++;
                        if (distance < 6) queue.add(new Pair<>(neighborPos, distance + 1));
                    } else if (neighborState.getBlock() instanceof LiquidBlock) {
                        level.setBlock(neighborPos, Blocks.AIR.defaultBlockState(), 3);
                        absorbedCount++;
                        if (distance < 6) queue.add(new Pair<>(neighborPos, distance + 1));
                    } else if (neighborState.is(Blocks.KELP) || neighborState.is(Blocks.KELP_PLANT) || ...) {
                        // 吸海带 / 海草等水生植物
                        BlockEntity be = neighborState.hasBlockEntity() ? level.getBlockEntity(neighborPos) : null;
                        dropResources(neighborState, level, neighborPos, be);
                        level.setBlock(neighborPos, Blocks.AIR.defaultBlockState(), 3);
                        absorbedCount++;
                        if (distance < 6) queue.add(new Pair<>(neighborPos, distance + 1));
                    }
                }
            }
            
            if (absorbedCount > 64) break;     // 上限 64 格
        }
        
        return absorbedCount > 0;
    }
}
```

**算法**：

1. 从海绵位置出发 BFS。
2. 每个位置扫 6 邻居：
   - 含水 → 吸掉（setBlock 改 air / waterlogged false）。
   - 距离 ≤ 6：把这位置入队继续扩展。
3. 最多吸 64 格水。
4. 吸到 ≥ 1 格水：海绵变 wet_sponge + 播声。

**视觉效果**：玩家在水池里放干海绵 → 一瞬间周围 ~64 格水消失 → 海绵变蓝色（湿）。

**用途**：玩家清理水底建筑 / 创造时打扫海洋。

**性能**：`removeWaterBreadthFirstSearch` 一次性 BFS 6+1 个 entry × ~5 邻居 = ~300+ 次 setBlock。**~5-50 ms**——单帧可见卡顿。但海绵很少同时放多个。

## 6.5.5 灵魂土水柱

**1.16 引入"bubble column"**：

- **灵魂土（Soul Sand）下方有水**：水中产生**向上**气泡柱（ascending）。
- **岩浆块（Magma Block）下方有水**：水中产生**向下**气泡柱（descending）。

```java
// BubbleColumnBlock
public class BubbleColumnBlock extends Block {
    public static final BooleanProperty DRAG_DOWN = BlockStateProperties.DRAG;
    
    public static void updateColumn(LevelAccessor level, BlockPos pos, BlockState fluidState, BlockState blockBelow) {
        if (canExistIn(fluidState)) {
            BlockState newColumn = getColumnState(blockBelow);
            level.setBlock(pos, newColumn, 2);
            BlockPos.MutableBlockPos cursor = pos.mutable().move(Direction.UP);
            while (canExistIn(level.getBlockState(cursor))) {
                if (!level.setBlock(cursor, newColumn, 2)) return;
                cursor.move(Direction.UP);
            }
        }
    }
    
    public static BlockState getColumnState(BlockState belowState) {
        if (belowState.is(Blocks.BUBBLE_COLUMN)) return belowState;     // 继承
        if (belowState.is(Blocks.SOUL_SAND)) return Blocks.BUBBLE_COLUMN.defaultBlockState().setValue(DRAG_DOWN, false);
        if (belowState.is(Blocks.MAGMA_BLOCK)) return Blocks.BUBBLE_COLUMN.defaultBlockState().setValue(DRAG_DOWN, true);
        return Blocks.WATER.defaultBlockState();
    }
}
```

**关键**：`bubble_column` 是**独立方块类型**——它"看起来"是水但实际是 bubble_column。视觉上有气泡粒子动画。

**玩家行为**：

- 玩家进入 ascending（灵魂土上方） → 被向上推（水中"电梯"）。
- 玩家进入 descending（岩浆块上方） → 被向下推 + 受少量伤害。

## 6.5.6 流体破坏方块

**水流过/落在某方块 → 该方块掉落**：

- 火 (FireBlock)：被水浇灭。
- 红石线？不破坏，但水会通过它流过。
- 旗帜 (BannerBlock)：被水冲掉。
- 大部分植物（草、花、苗、树叶下的果实）：被水冲掉。
- 落沙、砾石：在水中下落到地面。

实现：

```java
// FlowingFluid.beforeDestroyingBlock
@Override
protected void beforeDestroyingBlock(LevelAccessor level, BlockPos pos, BlockState state) {
    BlockEntity be = state.hasBlockEntity() ? level.getBlockEntity(pos) : null;
    Block.dropResources(state, level, pos, be);
}
```

水流 spreadTo 时如果目标是非 air 方块（且不是 LiquidBlockContainer）→ `beforeDestroyingBlock` → 调 dropResources → 玩家可拾取。

```java
    // 否则正常 fire neighbor 处理

```

## 6.5.8 Aquifer vs FlowingFluid 对比

回顾 3.9 节的 Aquifer 系统。

**关键差异**：

| 特征 | Aquifer | FlowingFluid |
|------|---------|--------------|
| 阶段 | 生成期（NOISE step） | 运行期（每 tick） |
| 频率 | 每 chunk 一次 | 每 setBlock / scheduledTick |
| 数据结构 | 16×12×16 grid 流体粒子 | LEVEL / FALLING 属性 |
| 算法 | 三粒子加权 + barrier noise | 8 邻居距离场 BFS |
| 持久化 | 通过 ProtoChunk | chunk NBT 内 LiquidBlock |
| 维度差异 | 主世界 only | 主世界 / 下界（ultraWarm）|

**视觉差异**：

- Aquifer 创建的水**永久静止**——它们在 NOISE 阶段被铺好，运行时不流动（除非玩家挖到）。
- FlowingFluid 是动态——玩家放水桶 → 流。

**协同**：

- Aquifer 让 1.18+ 洞穴里有水。
- 玩家挖该水池下方一个洞 → 转入 FlowingFluid 系统 → 水流出。
- 玩家放水桶在挖出的洞里 → 也是 FlowingFluid 系统。

## 6.5.10 流体推动实体

`Entity.tick` 内：

```java
public void tick() {
    super.tick();
    Vec3 vec3 = this.getDeltaMovement();
    
    if (this.isInWater()) {
        FluidState fluid = this.level.getFluidState(this.blockPosition());
        Vec3 flow = fluid.getFlow(this.level, this.blockPosition());
        this.setDeltaMovement(vec3.add(flow.scale(0.014)));
    }
    
    if (this.isInLava()) {
        // ⋯ 类似但 lava 推力小 ⋯
    }
    
    // ⋯ apply gravity / friction ⋯
}
```

**水推力 = 0.014 / tick × Vec3.flow**——玩家被水流缓慢推动。

**实体物品**（ItemEntity）也被推——可玩家把物品放水流上"运输"到漏斗。

## 6.5.11 一个完整交互场景

**玩家在沙漠造小水池给作物浇灌**：

```
1. 玩家挖一个 9 格洞 (3x3x1)
2. 中心放水桶 → 水源
3. water.tick → spreadToSides
   → getSpread 算 4 方向的距离场
   → 4 方向都没洞（周围都是沙地） → 4 方向都流（distance 1000 全等）
   → spreadTo 4 邻居 → setBlock(level=7)
4. 4 邻居进入水域 → 它们各自 tick → spread →继续扩散
5. 水扩散到 9 格全部充满（distance 全 1000，无洞）→ 平衡

[作物在水池附近]
6. 作物 (CropBlock).randomTick
   → 检查附近 4 格内的水（getGrowthSpeed 用）
   → 含水 → 速度 ×4
7. 作物长得快
```

## 6.5.12 一句话总结

waterloggable 通过 `SimpleWaterloggedBlock` 接口实现——60+ vanilla 方块（栅栏 / 楼梯 / 半砖 / 玻璃板 / 营火 / 树叶等）能"内部含水"，本质是 BlockState 的 WATERLOGGED 属性 + getFluidState 返水；海绵 BFS 吸水半径 6 距离 + 64 格上限，吸水后变 wet_sponge；soul_sand / magma_block 下方水中产生 bubble_column 上 / 下推动玩家；流体扩散到非 LiquidBlockContainer 方块时调 `beforeDestroyingBlock` 让方块掉物品（草 / 花 / 苗）；火接触水自动消失；水接触熔岩反应（黑曜石 / 圆石 / 石头 + fizz 声）；下界水立刻蒸发；Aquifer（生成期一次铺）和 FlowingFluid（运行期持续流）是两套独立系统——玩家挖到 Aquifer 水池后转入 FlowingFluid 处理。
