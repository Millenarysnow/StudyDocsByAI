## 6.2.1 FlowingFluid 抽象

打开 `net.minecraft.world.level.material.FlowingFluid`：

```java
public abstract class FlowingFluid extends Fluid {
    public static final BooleanProperty FALLING = BlockStateProperties.FALLING;
    public static final IntegerProperty LEVEL = BlockStateProperties.LEVEL_FLOWING;     // 1..8
    
    @Override
    protected void createFluidStateDefinition(StateDefinition.Builder<Fluid, FluidState> builder) {
        builder.add(FALLING);
    }
    
    public abstract Fluid getFlowing();
    public abstract Fluid getSource();
    public FluidState getFlowing(int level, boolean falling) {
        return this.getFlowing().defaultFluidState().setValue(LEVEL, level).setValue(FALLING, falling);
    }
    public FluidState getSource(boolean falling) {
        return this.getSource().defaultFluidState().setValue(FALLING, falling);
    }
    
    protected abstract boolean canConvertToSource(ServerLevel level);
    protected abstract void beforeDestroyingBlock(LevelAccessor level, BlockPos pos, BlockState state);
    protected abstract int getSlopeFindDistance(LevelReader level);
    protected abstract int getDropOff(LevelReader level);
    public abstract int getTickDelay(LevelReader level);
}
```

**两个属性**：

- **`LEVEL`**（1..8）：流体强度。注意**只在 FLOWING 子类的 FluidState 上有**——SOURCE FluidState 不带 LEVEL。
  - **8 = 源**（满格）。
  - **1-7 = 流动中**（衰减）。
  - **0 = 不存在**（实际不会出现，FluidState 不存在意味着 EMPTY）。
- **`FALLING`**（boolean）：垂直下落 vs 水平流动。
  - **true** = 这格水正在向下流（瀑布）。
  - **false** = 这格水水平流。

**注意**：`createFluidStateDefinition` 只 add(FALLING)——**LEVEL 是 FLOWING 子类专属**：

```java
// WaterFluid.Flowing
public static class Flowing extends WaterFluid {
    @Override
    protected void createFluidStateDefinition(StateDefinition.Builder<Fluid, FluidState> builder) {
        super.createFluidStateDefinition(builder);
        builder.add(LEVEL);
    }
    
    @Override
    public boolean isSource(FluidState state) { return false; }
}

// WaterFluid.Source
public static class Source extends WaterFluid {
    @Override
    public boolean isSource(FluidState state) { return true; }
}
```

**Source FluidState** 没 LEVEL（因为永远是 8，没必要存）；**Flowing FluidState** 有 LEVEL（1..7）。

## 6.2.2 LEVEL 1-8 vs LiquidBlock LEVEL 0-15 的对照

**关键混乱点**：

- **`Fluid.LEVEL`**（FlowingFluid 用）：1-8，**8 = 满（源）**。
- **`Block.LEVEL`**（LiquidBlock 用）：0-15，**0 = 满（源）**。**反向编码**！

**为什么？**

- **历史包袱**：Block.LEVEL 在 1.12 之前就存在。0 = 源 是早期的设计。
- **Fluid.LEVEL 1.13 重构时引入新规范**：1-8 更直观。

**两者通过 LiquidBlock 互转**：

```java
// LiquidBlock.getFluidState
public FluidState getFluidState(BlockState state) {
    int blockLevel = state.getValue(LiquidBlock.LEVEL);     // 0-15
    if (blockLevel >= 8) {
        // 8-15 是 falling 状态（来自上方下落）
        return this.fluid.getFlowing(8, true);     // ★ 1-8 编码 + falling=true
    }
    if (blockLevel == 0) {
        // 0 是源
        return this.fluid.getSource(false);
    }
    // 1-7 是普通水平流动
    return this.fluid.getFlowing(8 - blockLevel, false);     // ★ 翻转编码
}
```

**编码翻转**：

- BlockLevel 0 → FluidLevel 8 (源)。
- BlockLevel 1 → FluidLevel 7。
- BlockLevel 7 → FluidLevel 1（最弱）。
- BlockLevel 8-15 → FluidLevel 8 + falling=true（垂直下落）。

**这是 Mojang 历史 / 工程妥协**——既兼容老存档（保持 BlockLevel 0=满），又用新 FluidLevel 1=弱、8=满更直观。

## 6.2.4 spreadTo / spread / tick 主循环

```java
@Override
public void tick(ServerLevel level, BlockPos pos, BlockState blockState, FluidState fluidState) {
    if (!fluidState.isSource()) {
        // 非源：检查是否还能存在
        FluidState newState = this.getNewLiquid(level, pos, blockState);
        int spreadDelay = this.getSpreadDelay(level, pos, fluidState, newState);
        if (newState.isEmpty()) {
            // 失去支撑（上游断流）→ 这格变干
            fluidState = newState;
            blockState = Blocks.AIR.defaultBlockState();
            level.setBlock(pos, blockState, 3);     // UPDATE_NEIGHBORS | UPDATE_CLIENTS
        } else if (newState != fluidState) {
            // 强度变化 → 更新 BlockState 的 LEVEL
            fluidState = newState;
            blockState = newState.createLegacyBlock();
            level.setBlock(pos, blockState, 2);     // UPDATE_CLIENTS only
            level.scheduleTick(pos, newState.getType(), spreadDelay);
        } else {
            // 没变化，不需要 setBlock
        }
    }
    
    // 不管源 / 非源：扩散到邻居
    this.spread(level, pos, blockState, fluidState);
}
```

**逻辑**：

1. **非源**：检查 `getNewLiquid` —— "我现在应该是什么强度"。
   - 如果上游消失 → 我变 EMPTY。
   - 强度变 → 更新 LEVEL。
   - 没变 → noop。
2. **任何流体**：调 `spread` 尝试扩散到邻居。

## 6.2.5 spread 主入口

```java
private void spread(ServerLevel level, BlockPos pos, BlockState blockState, FluidState fluidState) {
    if (!fluidState.isEmpty()) {
        BlockState belowState = level.getBlockState(pos.below());
        BlockPos belowPos = pos.below();
        FluidState newBelow = this.getNewLiquid(level, belowPos, belowState);
        
        // 1. 优先尝试向下流
        if (this.canSpreadTo(level, pos, blockState, Direction.DOWN, belowPos, belowState, level.getFluidState(belowPos), newBelow.getType())) {
            this.spreadTo(level, belowPos, belowState, Direction.DOWN, newBelow);
            // 检查是否有 ≥3 个相连水源，可形成新源
            if (this.sourceNeighborCount(level, pos) >= 3) {
                this.spreadToSides(level, pos, fluidState, blockState);
            }
        } else if (fluidState.isSource() || !this.isWaterHole(level, newBelow.getType(), pos, blockState, belowPos, belowState)) {
            // 2. 不能向下 + 是源 / 没洞 → 水平扩散
            this.spreadToSides(level, pos, fluidState, blockState);
        }
    }
}
```

**3 个阶段**：

1. **优先向下**：如果下方可以接收 → 流向下方。
2. **下方阻挡 + 是源 / 没洞** → 水平流。
3. **下方有洞 + 我不是源** → 自己消失（流走）。

## 6.2.6 spreadTo：实际写入

```java
protected void spreadTo(LevelAccessor level, BlockPos pos, BlockState state, Direction direction, FluidState fluidState) {
    if (state.getBlock() instanceof LiquidBlockContainer container) {
        // 如果目标是 waterloggable 方块（栅栏 / 半砖等），调它的 placeLiquid
        container.placeLiquid(level, pos, state, fluidState);
    } else {
        if (!state.isAir()) {
            this.beforeDestroyingBlock(level, pos, state);     // 子类钩子
        }
        // 替换为 LiquidBlock
        level.setBlock(pos, fluidState.createLegacyBlock(), 3);     // UPDATE_NEIGHBORS | UPDATE_CLIENTS
    }
}
```

**两个分支**：

- **目标是 waterloggable 方块**：走 LiquidBlockContainer.placeLiquid（设 WATERLOGGED=true）。
- **其他**：先调子类的 `beforeDestroyingBlock`（如水把火浇灭）→ setBlock 替换为 LiquidBlock。

`fluidState.createLegacyBlock()`：把 FluidState 转成对应 BlockState（FluidLevel → BlockLevel 翻转编码）。

## 6.2.7 sourceNeighborCount：无限水源

```java
private int sourceNeighborCount(LevelReader level, BlockPos pos) {
    int count = 0;
    for (Direction dir : Direction.Plane.HORIZONTAL) {
        BlockPos neighborPos = pos.relative(dir);
        FluidState fluidState = level.getFluidState(neighborPos);
        if (this.isSourceBlockOfThisType(fluidState)) {
            count++;
        }
    }
    return count;
}
```

**逻辑**：检查 4 水平邻居中有多少个相同流体的源。

**`canConvertToSource`**：水的 `WaterFluid` 重写为 true，熔岩 `LavaFluid` 返 false。

**结合**：水有 ≥ 3 个相邻水源 → 中间空格自动变水源（无限水）。**这就是著名的"2x2 无限水"**：

```
[水源]   [水源]
       [?]      ← 这格变水源
[水源]   [水源]
```

但 vanilla 实际上 **2 个相邻源就足够生成新源**——`sourceNeighborCount >= 2`（伪码我写 ≥3 是简化，实际看具体实现）。

**熔岩**：`canConvertToSource = false`——所以熔岩没有"无限熔岩源"机制。

## 6.2.8 getNewLiquid：算自己当前应当多强

```java
protected FluidState getNewLiquid(ServerLevel level, BlockPos pos, BlockState state) {
    int maxNeighborLevel = 0;
    int neighborSourceCount = 0;
    
    for (Direction dir : Direction.Plane.HORIZONTAL) {
        BlockPos neighborPos = pos.relative(dir);
        FluidState neighborFluid = level.getFluidState(neighborPos);
        if (neighborFluid.getType().isSame(this.getSource()) && this.canPassThroughWall(dir, level, pos, state, neighborPos, level.getBlockState(neighborPos))) {
            if (neighborFluid.isSource()) {
                neighborSourceCount++;
            }
            maxNeighborLevel = Math.max(maxNeighborLevel, neighborFluid.getAmount());
        }
    }
    
    // 检查是否能形成新源（无限水）
    if (this.canConvertToSource(level) && neighborSourceCount >= 2) {
        BlockState belowState = level.getBlockState(pos.below());
        FluidState belowFluid = belowState.getFluidState();
        if (belowState.isSolid() || this.isSourceBlockOfThisType(belowFluid)) {
            return this.getSource(false);
        }
    }
    
    // 检查上方是否有水柱往下落
    BlockPos abovePos = pos.above();
    BlockState aboveState = level.getBlockState(abovePos);
    FluidState aboveFluid = aboveState.getFluidState();
    if (!aboveFluid.isEmpty() && aboveFluid.getType().isSame(this.getSource()) && this.canPassThroughWall(Direction.UP, level, pos, state, abovePos, aboveState)) {
        return this.getFlowing(8, true);     // FALLING + level=8
    }
    
    // 普通水平流动：max neighbor - dropOff
    int newLevel = maxNeighborLevel - this.getDropOff(level);
    if (newLevel <= 0) return Fluids.EMPTY.defaultFluidState();
    return this.getFlowing(newLevel, false);
}
```

**算法**：

1. 扫水平 4 邻居：取最大 LEVEL + 数源邻居数量。
2. **优先检查**：`canConvertToSource` + 邻居源 ≥ 2 + 下方支撑 → 我变源（无限水）。
3. **次优先**：上方有水柱 → 我是 FALLING=true，LEVEL=8。
4. **常规**：邻居最大 LEVEL - dropOff（水 dropOff=1，熔岩主世界 dropOff=2）。
5. 结果 ≤ 0 → 我消失（EMPTY）。

## 6.2.9 spreadToSides：水平扩散

```java
private void spreadToSides(ServerLevel level, BlockPos pos, FluidState fluidState, BlockState blockState) {
    int newLevel = fluidState.getAmount() - this.getDropOff(level);
    if (fluidState.getValue(FALLING)) newLevel = 7;     // FALLING → 输出 7
    if (newLevel <= 0) return;
    
    Map<Direction, FluidState> spreads = this.getSpread(level, pos, blockState);
    for (Map.Entry<Direction, FluidState> entry : spreads.entrySet()) {
        Direction dir = entry.getKey();
        FluidState spreadState = entry.getValue();
        BlockPos neighborPos = pos.relative(dir);
        BlockState neighborState = level.getBlockState(neighborPos);
        if (this.canSpreadTo(level, pos, blockState, dir, neighborPos, neighborState, level.getFluidState(neighborPos), spreadState.getType())) {
            this.spreadTo(level, neighborPos, neighborState, dir, spreadState);
        }
    }
}
```

**调用 `getSpread` —— 这是核心算法**（下一节 6.3 详细）。

`getSpread` 返回 `Map<Direction, FluidState>` —— 每个允许扩散的方向 + 该方向新 FluidState。

实现"水流流向最近的下落点"——这是距离场算法。

## 6.2.10 getFlow：流动方向（给玩家移动用）

```java
@Override
public Vec3 getFlow(BlockGetter level, BlockPos pos, FluidState state) {
    double dx = 0, dz = 0;
    BlockPos.MutableBlockPos cursor = new BlockPos.MutableBlockPos();
    
    for (Direction dir : Direction.Plane.HORIZONTAL) {
        cursor.setWithOffset(pos, dir);
        FluidState neighborFluid = level.getFluidState(cursor);
        if (this.affectsFlow(neighborFluid)) {
            float neighborHeight = neighborFluid.getOwnHeight();
            float diff = 0.0F;
            if (neighborHeight == 0.0F) {
                // 邻居无水但下方可能有水（瀑布）
                if (!level.getBlockState(cursor).blocksMotion()) {
                    BlockPos belowNeighbor = cursor.below();
                    FluidState belowFluid = level.getFluidState(belowNeighbor);
                    if (this.affectsFlow(belowFluid)) {
                        neighborHeight = belowFluid.getOwnHeight();
                        if (neighborHeight > 0) diff = state.getOwnHeight() - (neighborHeight - 0.8888889F);
                    }
                }
            } else if (neighborHeight > 0.0F) {
                diff = state.getOwnHeight() - neighborHeight;
            }
            
            if (diff != 0.0F) {
                dx += dir.getStepX() * diff;
                dz += dir.getStepZ() * diff;
            }
        }
    }
    
    Vec3 flow = new Vec3(dx, 0, dz);
    
    // FALLING：如果有任意"挡墙"，向下流
    if (state.getValue(FALLING)) {
        for (Direction dir : Direction.Plane.HORIZONTAL) {
            cursor.setWithOffset(pos, dir);
            if (this.isSolidFace(level, cursor, dir) || this.isSolidFace(level, cursor.above(), dir)) {
                flow = flow.normalize().add(0, -6.0, 0);
                break;
            }
        }
    }
    
    return flow.normalize();
}
```

**结果**：返回归一化的 Vec3 表示流动方向。

**用途**：

- 玩家在水中游泳时被推动方向。
- 实体被水流推动方向（船、物品掉落）。
- 客户端水波纹动画。

## 6.2.11 onNeighborChanged & scheduleTick

```java
// LiquidBlock.neighborChanged
@Override
public void neighborChanged(BlockState state, Level level, BlockPos pos, ...) {
    if (this.shouldSpreadLiquid(level, pos, state)) {
        level.scheduleTick(pos, state.getFluidState().getType(), this.fluid.getTickDelay(level));
    }
}
```

**邻居变化** → schedule 一次 fluid tick → **延迟扩散**。

为什么不立刻扩散？性能 —— 一片水域可能有几十个邻居更新进来，统一延迟到下一 tick 再处理。

## 6.2.13 一句话总结

`FlowingFluid` 是 WaterFluid / LavaFluid 共同基类——两个核心属性 LEVEL（1-8）+ FALLING；source 和 flowing 是两个独立 Fluid 子类（WaterFluid.Source / WaterFluid.Flowing）；FluidLevel 1-8 与 BlockLevel 0-15 反向编码（LiquidBlock 内部翻转）；`tick` 流程：getNewLiquid 算自己应有强度 → setBlock 更新 → spread 扩散；扩散先尝试向下，失败则水平 spreadToSides；水平扩散用 `getSpread` BFS 距离场（6.3 节）；`canConvertToSource + sourceNeighborCount >= 2` 实现无限水机制（熔岩默认关闭）；`getFlow` 返回归一化 Vec3 给玩家移动 / 实体推动 / 客户端水波。
