## 6.1.1 Fluid 与 FluidState：与 Block 平行的体系

打开 `net.minecraft.world.level.material.Fluid`：

```java
public abstract class Fluid {
    public static final IdMapper<FluidState> FLUID_STATE_REGISTRY = new IdMapper<>();
    protected final StateDefinition<Fluid, FluidState> stateDefinition;
    private FluidState defaultFluidState;
    
    protected Fluid() {
        StateDefinition.Builder<Fluid, FluidState> builder = new StateDefinition.Builder<>(this);
        this.createFluidStateDefinition(builder);
        this.stateDefinition = builder.create(Fluid::defaultFluidState, FluidState::new);
        this.registerDefaultState(this.stateDefinition.any());
    }
    
    public abstract Item getBucket();
    
    protected void tick(ServerLevel level, BlockPos pos, BlockState blockState, FluidState fluidState) {}
    protected void randomTick(ServerLevel level, BlockPos pos, FluidState fluidState, RandomSource random) {}
    
    protected abstract Vec3 getFlow(BlockGetter level, BlockPos pos, FluidState state);
    public abstract int getTickDelay(LevelReader level);
    
    public abstract BlockState createLegacyBlock(FluidState state);
    
    // ⋯
}
```

**关键观察**：`Fluid` 的设计**几乎完全镜像** `Block`：

| Block 体系 | Fluid 体系 |
|-----------|-----------|
| `Block` 抽象 | `Fluid` 抽象 |
| `BlockState` 不可变状态 | `FluidState` 不可变状态 |
| `StateDefinition<Block, BlockState>` | `StateDefinition<Fluid, FluidState>` |
| `BLOCK_STATE_REGISTRY` 全局 ID | `FLUID_STATE_REGISTRY` 全局 ID |
| `Property<T>`（AGE / FACING ⋯） | 同 Property<T>（LEVEL / FALLING） |
| `Block.tick / randomTick / neighborChanged` | `Fluid.tick / randomTick` |

**这是 Mojang 1.13"流体重构"的成果**——之前流体是嵌入在 Block 里的特殊字段，1.13 拆出独立 Fluid 抽象。

## 6.1.2 5 种内置 Fluid

```java
// Fluids.java
public class Fluids {
    public static final Fluid EMPTY = register("empty", new EmptyFluid());
    public static final FlowingFluid FLOWING_WATER = register("flowing_water", new WaterFluid.Flowing());
    public static final FlowingFluid WATER = register("water", new WaterFluid.Source());
    public static final FlowingFluid FLOWING_LAVA = register("flowing_lava", new LavaFluid.Flowing());
    public static final FlowingFluid LAVA = register("lava", new LavaFluid.Source());
}
```

**5 个 vanilla Fluid**：

- **`EMPTY`** ：表示"无流体"——就像 `Blocks.AIR` 之于方块。
- **`WATER`** / **`FLOWING_WATER`**：水。WATER = 源头（无限），FLOWING_WATER = 流动状态。
- **`LAVA`** / **`FLOWING_LAVA`**：熔岩。同上。

**注意 source / flowing 是不同 Fluid 实例**——这是 1.13 重构的设计选择。**为什么不在同一个 Fluid 内用 LEVEL 区分**？

因为 `Fluid` 实例本身代表"流体的物理性质"——source 和 flowing 在算法上有微妙不同（source 不会衰减、flowing 会）。**用不同的 Fluid 子类让逻辑分离**——比 if 判断 LEVEL == 8 清晰。

## 6.1.3 FluidState 类

```java
public final class FluidState extends StateHolder<Fluid, FluidState> {
    public static final Codec<FluidState> CODEC = ...;
    
    public FluidState(Fluid fluid, Reference2ObjectArrayMap<Property<?>, Comparable<?>> values, MapCodec<FluidState> propertiesCodec) {
        super(fluid, values, propertiesCodec);
    }
    
    public Fluid getType() { return this.owner; }
    
    public boolean isSource() { return this.getType().isSource(this); }
    
    public boolean isSourceOfType(Fluid fluid) {
        return this.owner == fluid && this.owner.isSource(this);
    }
    
    public boolean isEmpty() { return this.getType().isEmpty(); }
    
    public float getHeight(BlockGetter level, BlockPos pos) {
        return this.getType().getHeight(this, level, pos);
    }
    
    public float getOwnHeight() { return this.getType().getOwnHeight(this); }
    
    public int getAmount() { return this.getType().getAmount(this); }
    
    public boolean shouldRenderBackwardUpFace(BlockGetter level, BlockPos pos) { ... }
    
    public Vec3 getFlow(BlockGetter level, BlockPos pos) {
        return this.getType().getFlow(level, pos, this);
    }
    
    public boolean is(TagKey<Fluid> tag) {
        return this.getType().builtInRegistryHolder().is(tag);
    }
    
    public boolean is(Fluid fluid) { return this.getType() == fluid; }
}
```

**继承 `StateHolder<Fluid, FluidState>`** —— 与 BlockState 用同一个 StateHolder 抽象。属性查询、cycle、setValue 全部走 1.2 节同一套机制。

**关键 API**：

- `isSource()`：是不是源方块（不衰减）。
- `getOwnHeight()`：本格在垂直方向的"水柱高度"（0..8/9）。
- `getAmount()`：水量（1-8 → 1-8，源 → 8，FALLING → 8）。
- `getFlow(level, pos)`：返回 Vec3 流向（给玩家移动 / 实体推动用）。

## 6.1.4 同一格如何同时有 BlockState 和 FluidState

**关键事实**：`LevelChunkSection` 内部只存 BlockState（PalettedContainer），**不直接存 FluidState**。

```java
// LevelChunkSection
public BlockState getBlockState(int x, int y, int z) {
    return this.states.get(x, y, z);
}

public FluidState getFluidState(int x, int y, int z) {
    return this.states.get(x, y, z).getFluidState();    // ★ 从 BlockState 派生
}
```

**`BlockState.getFluidState()` 由 BlockBehaviour 决定**：

```java
// BlockBehaviour
public FluidState getFluidState(BlockState state) {
    return Fluids.EMPTY.defaultFluidState();        // 默认无流体
}

// LiquidBlock 重写
public class LiquidBlock extends Block implements BucketPickup {
    protected final FlowingFluid fluid;
    
    @Override
    public FluidState getFluidState(BlockState state) {
        return state.getValue(LEVEL) == 0 ? this.fluid.getSource(false) : this.fluid.getFlowing(state.getValue(LEVEL), false);
    }
}
```

**两种 BlockState 有 fluidState**：

1. **`LiquidBlock`**（水方块 / 熔岩方块本身）：getFluidState 直接返回对应 FluidState。
2. **waterloggable BlockState**（栅栏 / 楼梯 / 半砖等含水）：getFluidState 返 water。

## 6.1.5 waterloggable：方块"内部含水"

很多方块允许"既是方块又含水"：

```java
// FenceBlock, StairBlock, SlabBlock, FenceGateBlock, WallBlock,
// LeavesBlock（1.13+ 部分）, SignBlock, LadderBlock,
// IronBarsBlock, GlassPaneBlock, ChainBlock, ⋯
//   全部含 WATERLOGGED 属性

public class FenceBlock extends Block implements SimpleWaterloggedBlock {
    public static final BooleanProperty WATERLOGGED = BlockStateProperties.WATERLOGGED;
    
    @Override
    public FluidState getFluidState(BlockState state) {
        return state.getValue(WATERLOGGED) ? Fluids.WATER.getSource(false) : super.getFluidState(state);
    }
}
```

**视觉效果**：

- 玩家用水桶把水浇到栅栏 → 栅栏 WATERLOGGED=true → 视觉上"栅栏内有水"，鱼能游进去。
- 玩家用桶舀水 → WATERLOGGED=false。

**实现机制**：

- 玩家放水桶 → `BucketItem.use` 调 `LiquidBlock.tryEmptyContainerAndSetBlock`。
- 检查目标方块是否实现 `LiquidBlockContainer`（接口，包括 `SimpleWaterloggedBlock`）。
- 是 → 调 `place(level, pos, state, water)` → 替换为 WATERLOGGED=true。

**WATERLOGGED 不是流动**——它就是个 boolean 标志。流体逻辑（扩散）走标准 FluidState 逻辑，但底层方块仍是栅栏 / 楼梯。

## 6.1.6 LiquidBlock：流体的方块包装

```java
public class LiquidBlock extends Block implements BucketPickup {
    public static final IntegerProperty LEVEL = BlockStateProperties.LEVEL;     // 0..15
    protected final FlowingFluid fluid;
    
    public LiquidBlock(FlowingFluid fluid, BlockBehaviour.Properties props) {
        super(props);
        this.fluid = fluid;
        this.registerDefaultState(this.stateDefinition.any().setValue(LEVEL, 0));
    }
    
    @Override
    public FluidState getFluidState(BlockState state) {
        int level = state.getValue(LEVEL);
        return level == 0 ? this.fluid.getSource(false) : this.fluid.getFlowing(level, false);
    }
    
    @Override
    public boolean isPathfindable(BlockState state, PathComputationType type) {
        return !this.fluid.is(FluidTags.LAVA);     // 水可寻路（鱼游），熔岩不可
    }
    
    @Override
    public void neighborChanged(BlockState state, Level level, BlockPos pos, ...) {
        if (this.shouldSpreadLiquid(level, pos, state)) {
            level.scheduleTick(pos, state.getFluidState().getType(), this.fluid.getTickDelay(level));
        }
    }
}
```

**`Blocks.WATER` / `Blocks.LAVA` 是 LiquidBlock 实例**（持有对应 FlowingFluid）。

**注意**：`Blocks.WATER` 的 BlockState 持有 `LEVEL` 属性（0..15）。LEVEL=0 = 源，LEVEL>0 = flowing。

**`getFluidState`** 从 LEVEL 派生 FluidState：

- LEVEL=0 → `fluid.getSource()` ——源方块。
- LEVEL>0 → `fluid.getFlowing(level)` ——流动方块。

## 6.1.7 EmptyFluid

```java
public class EmptyFluid extends Fluid {
    @Override public Item getBucket() { return Items.AIR; }
    @Override public Vec3 getFlow(BlockGetter level, BlockPos pos, FluidState state) { return Vec3.ZERO; }
    @Override public int getTickDelay(LevelReader level) { return 0; }
```

**`Fluids.EMPTY`** 是 air 的流体等价物——所有"非水非熔岩"格子的 FluidState。

`FluidState.isEmpty()` 判断"这格有没有流体"——大部分世界格子返 true。

## 6.1.8 ChunkSection.tickingFluidCount

## 6.1.10 FluidTags

```java
public class FluidTags {
    public static final TagKey<Fluid> WATER = create("water");
    public static final TagKey<Fluid> LAVA = create("lava");
}
```

**WATER tag 含**：`FLOWING_WATER` + `WATER`（同时）。

**LAVA tag 含**：`FLOWING_LAVA` + `LAVA`。

**用途**：`fluidState.is(FluidTags.WATER)` 判断"这是不是水（任意状态）"。比 `is(Fluids.WATER) || is(Fluids.FLOWING_WATER)` 简洁。

## 6.1.11 内存预算

**Fluid 实例**（5 个）：每个 ~100 字节 = 500 字节，可忽略。

**FluidState 实例**：

- WATER (source)：1 个 BlockState。
- FLOWING_WATER：8 个 LEVEL × 2 个 FALLING = 16 个。
- LAVA / FLOWING_LAVA：同。
- EMPTY：1 个。

**总 FluidState ~50 个** × 200 字节 = 10 KB。

**关键**：FluidState 不存在 chunk section 内（1.4 节）—— 每格的 fluidState 从 blockState 派生。**chunk 实际不为流体增加内存**。

## 6.1.12 实战：waterlogged fence 完整流程

```
1. 玩家用水桶对栅栏右键
   → BucketItem.use → LiquidBlockContainer.placeLiquid(level, pos, state, water)
2. 栅栏的 placeLiquid 实现：
   level.setBlock(pos, state.setValue(WATERLOGGED, true), UPDATE_ALL)
3. setBlock 触发邻居更新
4. 栅栏 BlockState 现在 WATERLOGGED=true
   → BlockState.getFluidState(state) 返 Fluids.WATER.getSource()
5. ChunkSection 仍只存这一个栅栏的 BlockState
6. 视觉：栅栏内显示水（客户端渲染时检查 fluidState）
7. 行为：鱼可在栅栏内游、水流可从栅栏内流出（因为 fluidState 非空）
```

**不需要新数据结构**——所有信息都在 BlockState 的 WATERLOGGED 属性里。

## 6.1.13 C++ 移植

```cpp
namespace mc::fluid {

class Fluid {
public:
    Fluid();
    virtual ~Fluid() = default;
    
    const FluidState& defaultFluidState() const { return *defaultState_; }
    const StateDefinition<Fluid, FluidState>& stateDefinition() const { return *states_; }
    
    virtual Item* getBucket() const = 0;
    virtual void tick(ServerLevel& level, BlockPos pos, const BlockState& blockState, const FluidState& fluidState) {}
    virtual void randomTick(ServerLevel& level, BlockPos pos, const FluidState& fluidState, RandomSource& random) {}
    virtual Vec3 getFlow(BlockGetter& level, BlockPos pos, const FluidState& state) const = 0;
    virtual int getTickDelay(const LevelReader& level) const = 0;
    virtual const BlockState* createLegacyBlock(const FluidState& state) const = 0;
    
    virtual bool isEmpty() const { return false; }
    virtual bool isRandomlyTicking() const { return false; }
    virtual bool isSource(const FluidState& state) const = 0;
    
protected:
    std::unique_ptr<StateDefinition<Fluid, FluidState>> states_;
    const FluidState* defaultState_;
};

class FluidState {
public:
    Fluid* getType() const { return owner_; }
    bool isSource() const { return owner_->isSource(*this); }
    bool isEmpty() const { return owner_->isEmpty(); }
    float getOwnHeight() const;
    int getAmount() const;
    Vec3 getFlow(BlockGetter& level, BlockPos pos) const { return owner_->getFlow(level, pos, *this); }
    
private:
    Fluid* owner_;
    boost::container::flat_map<const Property*, std::any> values_;
    int32_t globalId_;
};

namespace Fluids {
    extern Fluid* EMPTY;
    extern FlowingFluid* WATER;
    extern FlowingFluid* FLOWING_WATER;
    extern FlowingFluid* LAVA;
    extern FlowingFluid* FLOWING_LAVA;
}

}

namespace mc::block {

class BlockBehaviour {
public:
    virtual const FluidState& getFluidState(const BlockState& state) const {
        return Fluids::EMPTY->defaultFluidState();
    }
};

class LiquidBlock : public Block, public BucketPickup {
public:
    static const IntegerProperty LEVEL;
    
    LiquidBlock(FlowingFluid* fluid, BlockBehaviour::Properties props);
    
    const FluidState& getFluidState(const BlockState& state) const override {
        int level = state.getValue(LEVEL);
        return level == 0 ? fluid_->getSource() : fluid_->getFlowing(level);
    }
    
private:
    FlowingFluid* fluid_;
};

class SimpleWaterloggedBlock {
public:

    // ⋯
};

}
```

## 6.1.14 一句话总结

Fluid 体系完全镜像 Block 体系——`Fluid` / `FluidState` / `StateDefinition<Fluid, FluidState>` / `FLUID_STATE_REGISTRY` 与 Block 平行；5 个 vanilla Fluid（EMPTY / WATER / FLOWING_WATER / LAVA / FLOWING_LAVA）—— source 和 flowing 是不同 Fluid 实例（让算法分离）；同一格的 FluidState 从 BlockState 派生（`BlockState.getFluidState()`）—— LiquidBlock 直接持有 fluidState，waterloggable 方块通过 WATERLOGGED 属性返水；FluidState 不直接存在 chunk 内，但 chunk section 维护 `tickingFluidCount` 计数器；流体 tick 通过 `LevelTicks<Fluid>` 独立调度（与 Block tick 并列）；`FluidTags.WATER` / `FluidTags.LAVA` 标识 source 与 flowing 都属于水 / 熔岩家族。
