## 6.4.1 WaterFluid 参数

打开 `net.minecraft.world.level.material.WaterFluid`：

```java
public abstract class WaterFluid extends FlowingFluid {
    @Override public Fluid getFlowing() { return Fluids.FLOWING_WATER; }
    @Override public Fluid getSource() { return Fluids.WATER; }
    @Override public Item getBucket() { return Items.WATER_BUCKET; }
    
    @Override
    protected boolean canConvertToSource(ServerLevel level) {
        return level.getGameRules().getBoolean(GameRules.RULE_WATER_SOURCE_CONVERSION);
    }
    
    @Override
    protected void beforeDestroyingBlock(LevelAccessor level, BlockPos pos, BlockState state) {
        BlockEntity be = state.hasBlockEntity() ? level.getBlockEntity(pos) : null;
        Block.dropResources(state, level, pos, be);     // 水流冲走方块掉物品（如 sapling）
    }
    
    @Override protected int getSlopeFindDistance(LevelReader level) { return 4; }
    @Override protected int getDropOff(LevelReader level) { return 1; }
    
    @Override
    public int getTickDelay(LevelReader level) {
        return 5;     // 5 tick (250 ms)
    }
    
    @Override
    public boolean canBeReplacedWith(FluidState state, BlockGetter level, BlockPos pos, Fluid otherFluid, Direction direction) {
        return direction == Direction.DOWN && !otherFluid.is(FluidTags.WATER);
    }
    
    @Override
    public ParticleOptions getDripParticle() {
        return ParticleTypes.DRIPPING_WATER;
    }
}
```

**水的关键参数**：

| 参数 | 值 | 含义 |
|------|----|----|
| `getSlopeFindDistance` | 4 | 水平扩散搜索深度 4 格 |
| `getDropOff` | 1 | 每水平流动 -1 强度 |
| `getTickDelay` | 5 | tick 间隔 250 ms |

**有效水平扩散距离**：水源 LEVEL=8 → 流 1 格变 7 → 2 格变 6 → ⋯ → 7 格变 1（最远）→ 8 格变 0（消失）。**水从源向外蔓延 7 格**。

## 6.4.2 LavaFluid 参数

打开 `net.minecraft.world.level.material.LavaFluid`：

```java
public abstract class LavaFluid extends FlowingFluid {
    @Override public Fluid getFlowing() { return Fluids.FLOWING_LAVA; }
    @Override public Fluid getSource() { return Fluids.LAVA; }
    @Override public Item getBucket() { return Items.LAVA_BUCKET; }
    
    @Override
    protected boolean isRandomlyTicking() { return true; }     // ★ 熔岩参与 random tick
    
    @Override
    protected boolean canConvertToSource(ServerLevel level) {
        return level.getGameRules().getBoolean(GameRules.RULE_LAVA_SOURCE_CONVERSION);
        // 默认 false → 熔岩没有"无限源"
    }
    
    @Override
    protected int getSlopeFindDistance(LevelReader level) {
        return level.dimensionType().ultraWarm() ? 4 : 2;
        // 主世界 2，下界 4
    }
    
    @Override
    protected int getDropOff(LevelReader level) {
        return level.dimensionType().ultraWarm() ? 1 : 2;
        // 主世界 -2 / 格，下界 -1 / 格
    }
    
    @Override
    public int getTickDelay(LevelReader level) {
        return level.dimensionType().ultraWarm() ? 10 : 30;
        // 主世界 30 tick (1.5 秒)，下界 10 tick (0.5 秒)
    }
    
    @Override
    public ParticleOptions getDripParticle() {
        return ParticleTypes.DRIPPING_LAVA;
    }
    
    @Override
    public boolean isSame(Fluid fluid) {
        return fluid == Fluids.LAVA || fluid == Fluids.FLOWING_LAVA;
    }
    
    // ⋯ randomTick / 反应 / 自燃 ⋯
}
```

**熔岩的关键参数**（按维度区分）：

| 参数 | 主世界 | 下界 (ultraWarm) |
|------|--------|------------------|
| `getSlopeFindDistance` | 2 | 4 |
| `getDropOff` | 2 | 1 |
| `getTickDelay` | 30 (1.5s) | 10 (0.5s) |
| `isRandomlyTicking` | true | true |
| `canConvertToSource` | false (默认) | false |

**主世界熔岩有效扩散距离**：源 8 → 流 1 格 6 → 2 格 4 → 3 格 2 → 4 格 0。**主世界熔岩 4 格远**。

**下界熔岩有效扩散距离**：源 8 → 1 格 7 → 7 格 1 → 8 格 0。**下界熔岩 7 格远（和水一样）**。

**直观对比**：

```
主世界水：    7 格远，每 5 tick 一格 → 0.25s × 7 = 1.75 秒达 max
主世界熔岩：  4 格远，每 30 tick 一格 → 1.5s × 4 = 6 秒达 max
下界熔岩：    7 格远，每 10 tick 一格 → 0.5s × 7 = 3.5 秒达 max
```

熔岩在主世界**比水流动慢 6 倍 + 距离短 1.75 倍**。这是 vanilla 的视觉 / 玩法平衡——熔岩"危险但慢"。

## 6.4.3 ultraWarm dimension 标志

```java
// DimensionType
public boolean ultraWarm() {
    return this.ultraWarm;
}
```

**vanilla 维度**：

- 主世界：ultraWarm = false。
- 下界：ultraWarm = true。
- 末地：ultraWarm = false。

**ultraWarm 还影响其他**：

- 水在 ultraWarm 维度中**蒸发**（不存在）。
- 怪物受附近熔岩损伤更慢。

## 6.4.4 水在下界的蒸发

```java
// LiquidBlock 或 WaterFluid 的相关代码
@Override
public void tick(ServerLevel level, BlockPos pos, BlockState blockState, FluidState fluidState) {
    if (level.dimensionType().ultraWarm() && this.is(Fluids.WATER) ...) {
        // 蒸发
        level.setBlock(pos, Blocks.AIR.defaultBlockState(), Block.UPDATE_ALL);
        level.levelEvent(LevelEvent.LAVA_FIZZ, pos, 0);     // 蒸发声 + 粒子
        return;
    }
    super.tick(level, pos, blockState, fluidState);
}
```

**视觉**：玩家在下界放水桶 → 水立刻消失 + 蒸发声。

**这就是为什么下界传送门用水扑火不能在下界用水**——水永远不会在下界"形成"。

**例外**：

- **下界水 mod**（如 better_nether）改写这个行为。
- **conduit / 海洋之心**：1.21+ 通过 conduit 在下界保留水（特殊机制）。

## 6.4.5 熔岩 randomTick：自燃 / 点燃

```java
// LavaFluid
@Override
protected void randomTick(ServerLevel level, BlockPos pos, FluidState state, RandomSource random) {
    if (level.getGameRules().getBoolean(GameRules.RULE_DOFIRETICK)) {
        int randVal = random.nextInt(3);
        if (randVal > 0) {
            // 1/3 概率：检查邻居方块是否易燃
            BlockPos.MutableBlockPos cursor = new BlockPos.MutableBlockPos();
            cursor.set(pos);
            for (int i = 0; i < randVal; i++) {
                cursor.move(random.nextInt(3) - 1, 1, random.nextInt(3) - 1);
                if (!level.isLoaded(cursor)) return;
                BlockState neighborState = level.getBlockState(cursor);
                if (neighborState.isAir()) {
                    if (this.hasFlammableNeighbours(level, cursor)) {
                        level.setBlock(cursor, BaseFireBlock.getState(level, cursor), 11);
                        return;
                    }
                } else if (neighborState.blocksMotion()) {
                    return;     // 路径被阻 → 停止
                }
            }
        } else {
            // 2/3 概率：检查正下方 3x3 范围内某易燃方块
            for (int i = 0; i < 3; i++) {
                BlockPos randPos = pos.offset(random.nextInt(3) - 1, 0, random.nextInt(3) - 1);
                if (!level.isLoaded(randPos.above())) return;
                if (level.getBlockState(randPos.above()).isAir() && this.isFlammable(level, randPos)) {
                    level.setBlock(randPos.above(), BaseFireBlock.getState(level, randPos.above()), 11);
                }
            }
        }
    }
}
```

**算法**：

1. `randomTick` 抽中熔岩 → 1/3 概率向斜上扩展（最多 3 步）找空气格。
2. 找到空气格旁有易燃方块（木材、羊毛、叶子）→ 点燃。
3. 2/3 概率 → 在 3x3 范围内挑一格，如果它上方是空气 + 易燃 → 点燃。

**这就是熔岩"远距离引发火灾"的来源**——一格熔岩可以点燃 1-3 格外的木材。

## 6.4.6 水接触熔岩：石化反应

```java
// FlowingFluid.canBeReplacedWith 等检查
public boolean canBeReplacedWith(FluidState state, BlockGetter level, BlockPos pos, Fluid otherFluid, Direction direction) {
    return direction == Direction.DOWN && !otherFluid.is(FluidTags.WATER);
}
```

**碰撞规则**（实际在 LiquidBlock 内）：

| 情况 | 反应 |
|------|------|
| 水源 + 熔岩源 接触 | 熔岩源 → obsidian（黑曜石） |
| 水流 + 熔岩源 接触 | 熔岩源 → obsidian |
| 水源 + 熔岩流 接触 | 熔岩流 → cobblestone（圆石） |
| 水流 + 熔岩流 接触 | 熔岩流 → cobblestone |
| 水流 + 熔岩流（一方 falling） | stone（光滑石） |

**实现**（FlowingFluid.spreadTo 内或 LiquidBlock.checkAndSpread）：

```java
private static void fizz(LevelAccessor level, BlockPos pos) {
    level.levelEvent(LevelEvent.LAVA_FIZZ, pos, 0);    // 蒸发声 + 烟雾
}

protected void shouldHardenFluidOnContact(LevelAccessor level, BlockPos pos, BlockState state) {
    if (state.is(Blocks.LAVA) || state.is(Blocks.FLOWING_LAVA)) {
        // 检查 6 邻居有没有水
        boolean hasWater = false;
        for (Direction dir : Direction.values()) {
            if (level.getFluidState(pos.relative(dir)).is(FluidTags.WATER)) {
                hasWater = true;
                break;
            }
        }
        if (hasWater) {
            int level_value = state.getValue(LiquidBlock.LEVEL);
            if (level_value == 0) {
                level.setBlock(pos, Blocks.OBSIDIAN.defaultBlockState(), 3);
            } else if (level_value <= 4) {
                level.setBlock(pos, Blocks.COBBLESTONE.defaultBlockState(), 3);
            }
            fizz(level, pos);
        }
    }
}
```

**玩家利用这个机制**：

- **黑曜石生成器**：水源 + 熔岩源 → 反复生成 obsidian（玩家挖走）。
- **圆石生成器**：水源 + 熔岩流 → 反复生成 cobblestone。
- **石头生成器**（1.13+）：特殊布局 → 生成 stone。

## 6.4.7 熔岩与雪 / 冰

水在低温 biome 会冻结（IceBlock.randomTick）。**熔岩反向**：在主世界靠近雪 / 冰会快速融化它们。

```java
// SnowLayerBlock.randomTick
@Override
public void randomTick(BlockState state, ServerLevel level, BlockPos pos, RandomSource random) {
    if (level.getBrightness(LightLayer.BLOCK, pos) > 11) {
        dropResources(state, level, pos);
        level.removeBlock(pos, false);
    }
}
```

雪层在亮光（≥ 12）下融化——熔岩附近的"亮光"足够 → 雪化。

## 6.4.8 熔岩传送

下界传送门（NetherPortalBlock）触发条件之一是周围 obsidian 框架——所以**水 + 熔岩制造黑曜石** → 玩家可造下界门。

## 6.4.9 性能对比

```
单 chunk 水域 (50 x 50 = 2500 格水):
- 水扩散：每 5 tick 一次，每格 ~30 微秒
- 平均：2500 * 30us / 5tick = 15 ms / tick (满载，不可接受)
- 实际：稳态后大部分水是 source，无需 tick → < 1 ms

熔岩同等大小:
- 30 tick 一次
- 实际：< 0.5 ms（频率 1/6 of water）
```

水比熔岩在性能上**更"贵"**——因为 tick 频率 6 倍。

## 6.4.10 玩家与流体交互

**水**：

- 玩家进入 → 游泳模式（按 SHIFT 下沉）。
- 视野下沉 → 水下视觉效果（蓝色滤镜）。
- 玩家流体内 → `Player.maxAirSupply` 倒计时呼吸（300 → 0 即开始受伤）。

**熔岩**：

- 玩家进入 → 立刻火焰附身（`Entity.lavaHurt`）。
- 每 4 tick 4 点伤害。
- 浮在熔岩面（黏度高）—— `Entity.move` 检查流体类型决定下沉速度。

**实体推动**：所有非"PushReaction.IGNORE"实体都被流体推动。`Entity.tick` 内调 `getFlow` 计算推动力。

## 6.4.11 一句话总结

水在主世界扩散 7 格、每 5 tick 一格；熔岩主世界 4 格 / 30 tick / dropOff=2、下界 7 格 / 10 tick / dropOff=1（dimension.ultraWarm 控制）；水在 ultraWarm 维度（下界）立即蒸发；熔岩 randomTick 概率引发周围易燃方块起火（最远 3 格）；水接触熔岩源生成黑曜石、接触流动熔岩生成圆石、特殊条件生成石头（fizz 声 + 烟雾）；熔岩附近高亮光融化雪 / 冰；玩家在水中游泳 + 呼吸倒计时，在熔岩中受伤 + 着火。
