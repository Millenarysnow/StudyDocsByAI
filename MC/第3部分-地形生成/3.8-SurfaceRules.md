# 3.8 SurfaceRules

## 3.8.0 你将在本节学到什么

6. 我在 C++ 里复刻这套机制最简洁的设计是什么？

## 3.8.1 直觉：NOISE 后的世界长什么样

回顾 3.5、3.6：NOISE 阶段过后，每个方块的状态由"finalDensity > 0 ?"决定。Mojang 内部约定：

- finalDensity > 0 → 该格是 `defaultBlock`（主世界 = `Blocks.STONE`）。
- finalDensity ≤ 0 → 该格是 `defaultFluid`（如果在 aquifer 水位下 = `Blocks.WATER`）或 `Blocks.AIR`。

**所以 NOISE 后，整个世界只有 stone / water / air 三种方块**。所有山、平原、海洋的"形状"都在了，但全部是石头表面。**没有草、没有沙、没有雪、没有泥土**。

**SurfaceRules** 是在 SURFACE 阶段（NOISE 之后）跑的"地表覆盖"系统——把"地表那几格 stone"按 biome / 高度 / 噪声替换为合适方块。

## 3.8.2 一条规则的结构

打开 `net.minecraft.world.level.levelgen.SurfaceRules`：

整套 SurfaceRules 是个**条件 → 材料**的 DSL。两个核心抽象：

- **`RuleSource`** / `SurfaceRule`：一条规则。"如果某条件成立，铺某种方块"。
- **`ConditionSource`** / `Condition`：条件。"在 Y > 60 的位置"、"在 sand_biome"、"在地表向下第 1-3 格"等。

**典型一条规则**（伪码）：

```java
SurfaceRules.RuleSource rule = SurfaceRules.ifTrue(
    SurfaceRules.isBiome(Biomes.PLAINS),                  // condition
    SurfaceRules.ifTrue(
        SurfaceRules.ON_FLOOR,                              // condition
        SurfaceRules.state(Blocks.GRASS_BLOCK.defaultBlockState())   // RuleSource
    )
);
```

读法：

- 如果当前 biome 是 plains，并且这格是"地表那一格"（ON_FLOOR）→ 铺草方块。

## 3.8.3 RuleSource：规则节点

`RuleSource` 接口的实现：

```java
public sealed interface RuleSource extends Function<Context, SurfaceRule> permits
    BlockRuleSource,        // 铺一种方块
    SequenceRuleSource,     // 一组规则按序尝试
    TestRuleSource,         // 条件分支
    BandlandsRuleSource     // 恶地特殊
{
    KeyDispatchDataCodec<? extends RuleSource> codec();
}
```

**4 个具体实现**：

### `BlockRuleSource`：铺一种方块

```java
public static record BlockRuleSource(BlockState resultState) implements RuleSource {
    public SurfaceRule apply(Context ctx) {
        return ctx -> this.resultState;     // 永远返回这个方块
    }
}
```

最简单——返回固定 BlockState。

### `SequenceRuleSource`：序列尝试

```java
public static record SequenceRuleSource(List<RuleSource> sequence) implements RuleSource {
    public SurfaceRule apply(Context ctx) {
        return pos -> {
            for (RuleSource sub : sequence) {
                BlockState result = sub.apply(ctx).tryApply(pos);
                if (result != null) return result;
            }
            return null;     // 都没匹配 → 不铺（保持原 stone）
        };
    }
}
```

按序尝试每个子规则。第一个返回非 null 的就用。**这是规则集合的"最常见组合方式"**。

### `TestRuleSource`：条件分支

```java
public static record TestRuleSource(ConditionSource ifTrue, RuleSource thenRun) implements RuleSource {
    public SurfaceRule apply(Context ctx) {
        Condition cond = ifTrue.apply(ctx);
        SurfaceRule sub = thenRun.apply(ctx);
        return pos -> cond.test() ? sub.tryApply(pos) : null;
    }
}
```

如果条件成立 → 用子规则；否则返回 null（让外层 sequence 试下一条）。

### `BandlandsRuleSource`：恶地特殊

恶地（badlands biome）的复杂条带式赤土（terracotta）覆盖**用专门 hardcoded 节点**——因为它的逻辑（按 Y 选不同颜色赤土 + 噪声扰动）不适合通用 DSL 表达。

## 3.8.4 ConditionSource：条件节点

`ConditionSource` 接口的实现众多。按用途分类：

### 1. 地形位置类

| ConditionSource | 含义 |
|----------------|------|
| `ON_FLOOR` | 这格是 cave_surface FLOOR 上 1 格（地表那格）|
| `UNDER_FLOOR` | 这格在 FLOOR 下方 |
| `DEEP_UNDER_FLOOR` | FLOOR 下方且在更深范围（用于"5-6 格泥土"层）|
| `VERY_DEEP_UNDER_FLOOR` | 更深 |
| `ON_CEILING` / `UNDER_CEILING` | 洞顶（针对洞穴） |

`StoneDepthCheck` 类的实例。它内部需要知道"当前格在 cave_surface 距离表面多深"——`SurfaceSystem` 在执行规则前预算好。

### 2. Y 坐标类

| ConditionSource | 含义 |
|----------------|------|
| `yBlockCheck(anchor, surfaceDepthMultiplier)` | "Y > anchor + surfaceDepth × multiplier" 检查 |
| `yStartCheck` | 类似，但用 Y 起点（preliminarySurface 而不是当前 cell） |

例：`yBlockCheck(VerticalAnchor.absolute(63), 0)` = "Y > 63"（高于海平面）。

### 3. 水位类

`waterBlockCheck` / `waterStartCheck`：检查"距离最近水面多远"。给"沙滩"判定用——海岸 + 接近水面 → 沙。

### 4. Biome 类

| ConditionSource | 含义 |
|----------------|------|
| `isBiome(BIOME...)` | 当前 biome 在指定列表中 |
| `noiseCondition(noiseKey, min, max)` | 某 noise 在 [min, max) |

### 5. 物理类

| ConditionSource | 含义 |
|----------------|------|
| `steep` | 当前位置坡度陡（沿 X / Z 方向高度差大） |
| `hole` | 这格是"洞" |
| `abovePreliminarySurface` | 在预测的 surface 之上 |
| `temperature` | 当前温度 < 0.15（冷 → 雪 / 冰）|

### 6. 噪声扰动类

| ConditionSource | 含义 |
|----------------|------|
| `verticalGradient(name, fromY, toY)` | 沿 Y 渐变 + 噪声扰动 |

例：`verticalGradient("minecraft:bedrock_floor", VerticalAnchor.aboveBottom(0), VerticalAnchor.aboveBottom(5))` = "Y 在 0-5 之间，按高度梯度 + 噪声决定要不要铺基岩"。这是**底部基岩层的不规则"齿状"边界**的实现。

### 7. 复合

| ConditionSource | 含义 |
|----------------|------|
| `not(condition)` | 取反 |

注意 SurfaceRules **没有 `and` / `or`**。组合用 `TestRuleSource` 嵌套实现：

```java
// 等价于 (cond1 AND cond2) → result
ifTrue(cond1, ifTrue(cond2, result))

// 等价于 (cond1 OR cond2) → result
sequence(
    ifTrue(cond1, result),
    ifTrue(cond2, result)
)
```

## 3.8.5 SurfaceSystem：执行机制

打开 `net.minecraft.world.level.levelgen.SurfaceSystem`：

```java
public class SurfaceSystem {
    private final NoiseChunk noiseChunk;
    private final NormalNoise surfaceNoise;
    private final NormalNoise surfaceSecondaryNoise;
    private final RandomState randomState;
    private final BlockState defaultBlock;
    private final int seaLevel;
    
    public void buildSurface(
        RandomState randomState,
        BiomeManager biomeManager,
        Registry<Biome> biomeRegistry,
        boolean useLegacyRandomSource,
        WorldGenerationContext genCtx,
        ChunkAccess chunk,
        NoiseChunk noiseChunk,
        SurfaceRules.RuleSource ruleSource
    ) {
        BlockPos.MutableBlockPos pos = new BlockPos.MutableBlockPos();
        ChunkPos chunkPos = chunk.getPos();
        int chunkMinX = chunkPos.getMinBlockX();
        int chunkMinZ = chunkPos.getMinBlockZ();
        BlockColumn column = new BlockColumn(...);
        
        SurfaceRules.Context ctx = new SurfaceRules.Context(this, chunk, noiseChunk, biomeManager::getBiome, ...);
        SurfaceRules.SurfaceRule rule = ruleSource.apply(ctx);

        for (int x = 0; x < 16; x++) {
            for (int z = 0; z < 16; z++) {
                int absX = chunkMinX + x;
                int absZ = chunkMinZ + z;
                int surfaceY = chunk.getHeight(Heightmap.Types.WORLD_SURFACE_WG, x, z) + 1;
                ctx.updateXZ(absX, absZ);
                int stoneDepthAbove = 0;
                int stoneDepthBelow = Integer.MIN_VALUE;
                int waterHeight = Integer.MIN_VALUE;
                
                // 从顶向下逐格扫
                for (int y = surfaceY; y >= chunk.getMinY(); y--) {
                    BlockState curState = chunk.getBlockState(pos.set(absX, y, absZ));
                    
                    if (curState.isAir()) {
                        stoneDepthAbove = 0;
                        waterHeight = Integer.MIN_VALUE;
                        continue;
                    }
                    if (curState.getFluidState().is(FluidTags.WATER)) {
                        if (waterHeight == Integer.MIN_VALUE) waterHeight = y + 1;
                        continue;
                    }
                    
                    // 是固体 → 计算 stoneDepthAbove
                    stoneDepthAbove++;
                    if (stoneDepthBelow == Integer.MIN_VALUE) {
                        // 从这往下扫多少格还是固体
                        // ⋯ 计算 stoneDepthBelow ⋯
                    }
                    
                    ctx.updateY(stoneDepthAbove, waterHeight, y);
                    BlockState newState = rule.tryApply(absX, y, absZ);
                    if (newState != null) {
                        chunk.setBlockState(pos.set(absX, y, absZ), newState, false);
                    }
                }
            }
        }
    }
}
```

**关键流程**：

1. 对每个 (x, z) 列，从 `WORLD_SURFACE_WG` heightmap 取顶端 Y。
2. 从顶向下逐格扫。
3. 维护 `stoneDepthAbove`（已扫过几格固体）、`stoneDepthBelow`（向下还有几格固体）、`waterHeight`（最近水面 Y）。
4. 对每个固体格，更新 ctx，调 `rule.tryApply(x, y, z)`。
5. 如果 rule 返回非 null → 替换该格。

**核心**：rule 是个**纯函数 (x, y, z) → BlockState?`**。SurfaceSystem 只负责扫描循环 + 维护 context 字段。

## 3.8.7 案例 1：沙滩

沙滩（beach）的 surface rule（简化）：

```java
SurfaceRules.RuleSource beach = SurfaceRules.ifTrue(
    SurfaceRules.isBiome(Biomes.BEACH, Biomes.SNOWY_BEACH),
    SurfaceRules.sequence(
        SurfaceRules.ifTrue(
            SurfaceRules.ON_FLOOR,
            SAND
        ),
        SurfaceRules.ifTrue(
            SurfaceRules.UNDER_FLOOR,
            SANDSTONE
        )
    )
);
```

**含义**：在 beach biome：
- 地表那格（ON_FLOOR）= sand
- 地表下方（UNDER_FLOOR）= sandstone

**视觉效果**：沙滩边缘 1 格沙 + 几格沙石。

类似 `SNOWY_BEACH` biome：

```java
SurfaceRules.RuleSource snowy_beach = SurfaceRules.ifTrue(
    SurfaceRules.isBiome(Biomes.SNOWY_BEACH),
    SurfaceRules.sequence(
        SurfaceRules.ifTrue(
            SurfaceRules.ON_FLOOR,
            SurfaceRules.ifTrue(
                SurfaceRules.temperature(),     // T < 0.15
                SNOW_BLOCK
            )
        ),
        SAND
    )
);
```

**含义**：snowy_beach 的地表如果温度低（temperature condition）→ 雪块，否则 → 沙。

## 3.8.8 案例 2：雪线

主世界的"雪线"规则——高 Y 自动覆雪：

```java
SurfaceRules.RuleSource snow_layer = SurfaceRules.ifTrue(
    SurfaceRules.ON_FLOOR,
    SurfaceRules.ifTrue(
        SurfaceRules.yBlockCheck(VerticalAnchor.absolute(95), 0),    // Y > 95
        SurfaceRules.ifTrue(
            SurfaceRules.temperature(),                              // 冷 biome
            SNOW_LAYER
        )
    )
);
```

**含义**：地表那格 + Y > 95 + 冷 biome → 表面覆雪。

实际配方更复杂（结合 noise 扰动让雪线不是平直的）：

```java
SurfaceRules.RuleSource snow_layer_with_noise = SurfaceRules.ifTrue(
    SurfaceRules.verticalGradient("minecraft:snow_layer", VerticalAnchor.absolute(80), VerticalAnchor.absolute(120)),
    SurfaceRules.ifTrue(SurfaceRules.ON_FLOOR, SNOW_LAYER)
);
```

`verticalGradient` 在 Y=80 时返回 false（不下雪），Y=120 时一定 true（一定下雪），中间用 noise 扰动让雪线呈不规则锯齿。视觉上山脉雪线**自然弯曲**而不是水平直线。

SurfaceRules.RuleSource plains_surface = SurfaceRules.sequence(

## 3.8.12 性能

SurfaceRules 在 SURFACE 阶段执行，每 chunk 跑一次：

- 16×16 = 256 列。
- 每列从顶向下扫 ~80 格（surface 区域）。
- 每格调 rule.tryApply →  几次 condition 求值。
- 总：256 × 80 × ~5 condition = ~100K condition check。

时间：~10 ms / chunk（典型）。**远比 NOISE 阶段（80 ms）便宜**。

## 3.8.15 C++ 移植

```cpp
namespace mc::surface {

class Context {
public:
    int blockX, blockY, blockZ;
    int stoneDepthAbove;
    int stoneDepthBelow;
    int waterHeight;
    Holder<Biome> biome;
    int chunkSurfaceY;
    NormalNoise* surfaceNoise;
    NormalNoise* surfaceSecondaryNoise;
};

class ConditionSource {
public:
    virtual ~ConditionSource() = default;
    virtual bool test(const Context& ctx) const = 0;
};

class RuleSource {
public:
    virtual ~RuleSource() = default;
    // 返回 nullptr 表示规则未匹配
    virtual const BlockState* tryApply(const Context& ctx) const = 0;
};

class BlockRuleSource : public RuleSource {
    const BlockState* state_;
public:
    BlockRuleSource(const BlockState* s) : state_(s) {}
    const BlockState* tryApply(const Context&) const override { return state_; }
};

class SequenceRuleSource : public RuleSource {
    std::vector<std::unique_ptr<RuleSource>> sequence_;
public:
    const BlockState* tryApply(const Context& ctx) const override {
        for (auto& sub : sequence_) {
            if (auto* r = sub->tryApply(ctx)) return r;
        }
        return nullptr;
    }
};

class TestRuleSource : public RuleSource {
    std::unique_ptr<ConditionSource> ifTrue_;
    std::unique_ptr<RuleSource> thenRun_;
public:
    const BlockState* tryApply(const Context& ctx) const override {
        return ifTrue_->test(ctx) ? thenRun_->tryApply(ctx) : nullptr;
    }
};

// Conditions
class IsBiomeCondition : public ConditionSource {
    std::vector<ResourceKey<Biome>> biomes_;
public:
    bool test(const Context& ctx) const override {
        for (auto& key : biomes_) if (ctx.biome.is(key)) return true;
        return false;
    }
};

class StoneDepthCheckCondition : public ConditionSource {
    int offset_;
    bool addSurfaceDepth_;
    int secondaryDepth_;
    CaveSurface surface_;
public:
    bool test(const Context& ctx) const override {
        // 检查 stoneDepthAbove / stoneDepthBelow
        // ⋯
    }
};

// ⋯ 其他 condition ⋯

class SurfaceSystem {
public:
    void buildSurface(ChunkAccess& chunk, NoiseChunk& noiseChunk,
                      BiomeManager& biomeManager, RuleSource& rule);
};

}
```

**关键工程选择**：

1. **virtual function vs variant**：SurfaceRules 节点种类约 20 种，相对稳定。**第一版用 virtual function 简单可靠**；性能不是瓶颈。
2. **`const BlockState*` 返回**：BlockState 共享 immutable，零拷贝。
3. **`Context` 是栈对象**：避免堆分配。
4. **datagen**：先实现 SurfaceRuleData 的所有 hardcoded 规则（手动翻译 ~300 行 Java），datapack JSON parser 后续添加。

## 3.8.16 一句话总结

SurfaceRules 是个**条件 → 材料**的 DSL，把 NOISE 阶段填出来的"全 stone + water + air" 世界改成"草原 / 沙漠 / 雪原 / 沼泽 / 海岸 ⋯⋯" 视觉效果；`RuleSource` 4 实现（Block / Sequence / Test / Bandlands），`ConditionSource` 约 20 种（biome / Y / water / temperature / steep / hole / vertical_gradient ⋯）；规则没有 `and`/`or`，靠 TestRuleSource 嵌套 + Sequence 表达；`SurfaceSystem` 在 SURFACE 阶段对每 chunk 256 列从顶向下扫 + 维护 stoneDepth / waterHeight context；`SurfaceRuleData` ~300 行 Java 是主世界配方核心；性能 ~10 ms/chunk 远快于 NOISE。
