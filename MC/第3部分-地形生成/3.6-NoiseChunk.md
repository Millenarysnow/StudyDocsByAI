## 3.6.1 NoiseRouter vs NoiseChunk 的角色分工

**NoiseRouter（3.5 节）** 是**纯配方**：它描述"哪些算子怎么组合成 finalDensity"。它没有状态——你不能问 router "(100, 64, 100) 的密度是多少"，因为它不知道当前在哪个 chunk、cell 多大、Y 范围多少。

**NoiseChunk** 是**有状态的求值器**：

- 持有"当前 chunk 是哪个、cell 划分多大、Y 范围"的具体上下文。
- 持有 cell 角点的预计算密度数组（性能关键）。
- 持有 Aquifer / OreVeinifier / Beardifier 子系统引用。
- 实现 `DensityFunction.FunctionContext` 接口——求值时 NoiseChunk 自己作为 ctx 传入 router 的密度函数。

**类比**：

- NoiseRouter = 食谱（写在书上，不变）。
- NoiseChunk = 厨房里现做的"今天这盘菜"，记录当前火候、用了哪些食材、做到哪步了。

**生命周期**：每个 chunk 在 NOISE 阶段创建一个 NoiseChunk，跑完后丢弃。下次读这 chunk 不需要 NoiseChunk（数据已写到 PalettedContainer）。

## 3.6.2 NoiseSettings：cell 划分参数

打开 `net.minecraft.world.level.levelgen.NoiseSettings`：

```java
public record NoiseSettings(int minY, int height, int noiseSizeHorizontal, int noiseSizeVertical) {
    protected static final NoiseSettings OVERWORLD_NOISE_SETTINGS         = create(-64, 384, 1, 2);
    protected static final NoiseSettings NETHER_NOISE_SETTINGS            = create(0,   128, 1, 2);
    protected static final NoiseSettings END_NOISE_SETTINGS               = create(0,   128, 2, 1);
    protected static final NoiseSettings CAVES_NOISE_SETTINGS             = create(-64, 192, 1, 2);
    protected static final NoiseSettings FLOATING_ISLANDS_NOISE_SETTINGS  = create(0,   256, 2, 1);

    public int getCellHeight() { return QuartPos.toBlock(this.noiseSizeVertical()); }
    public int getCellWidth() { return QuartPos.toBlock(this.noiseSizeHorizontal()); }
}
```

**4 个字段**：

- **`minY`**：世界底部 Y。主世界 `-64`。
- **`height`**：世界总高度。主世界 `384` → maxY = -64 + 384 = 320。
- **`noiseSizeHorizontal`**：水平方向 cell 缩放因子（quart-pos 单位）。主世界 `1` → cellWidth = 4。
- **`noiseSizeVertical`**：垂直方向 cell 缩放因子。主世界 `2` → cellHeight = 8。

**`QuartPos.toBlock(n) = n << 2`**——quart-pos 是 4 格为单位的位置。

**主世界 cell 是 4×8×4 个方块**：

- XZ 方向 4 格一个 cell → 一个 chunk 16/4 = 4 cells/边 → 16 cells/chunk（XZ）。
- Y 方向 8 格一个 cell → 主世界 384/8 = 48 cells/列。

**总 cell 数**：4 × 48 × 4 = **768 cells/chunk**。**比方块数 (16 × 384 × 16 = 98304) 少 128×**。

**这就是 NoiseChunk 的性能秘密**——只在 cell 角点算密度，cell 内插值。

| 维度 | size | 主世界 |
|------|------|--------|
| chunk XZ | 16 格 | 16 |
| chunk Y | height | 384 |
| cellWidth | 4 (= 4 × size_horizontal) | 4 |
| cellHeight | 8 (= 4 × size_vertical) | 8 |
| cellCountXZ | chunk 边 / cellWidth | 4 |
| cellCountY | height / cellHeight | 48 |

每个 cell 是一个 4×8×4 的方块"小盒子"。

**几个关键字段**：

- **`interpolators` 列表**：每个 NoiseInterpolator 对应 NoiseRouter 一个通道（finalDensity / continents / erosion / depth ⋯⋯）的插值器。
- **`cellCaches` 列表**：cell 内全缓存（CacheAllInCell）的 ResourceLocation 子树。
- **`wrapped` map**：`mapAll(visitor)` 时的"原始 → 包装后" 映射，避免重复包装。
- **`preliminarySurfaceLevel`**：每列 (x, z) 的初步 surface Y。给 SurfaceRules 当快速参考。
- **`aquifer`**：1.18+ 含水层系统（3.9 节）。
- **`beardifier`**：结构对地形的反向"刮平"（3.6.7）。
- **`blender`**：与老地图边界融合（1.18 升级用）。
- **`interpolating` / `inCellX/Y/Z`**：当前求值的"位置游标"。NoiseChunk **同时是 ContextProvider 也是 FunctionContext**——它"自己作为 ctx 传给自己里面的 DensityFunction"。

## 3.6.4 NoiseInterpolator：单通道的角点 + 插值

每个 NoiseRouter 通道（如 finalDensity）被包成一个 `NoiseInterpolator`：

```java
class NoiseInterpolator implements DensityFunction {
    final DensityFunction noiseFiller;            // 实际密度函数（来自 router）
    double[] slice0;                               // 当前 X slice（cellCountY+1 × cellCountXZ+1）
    double[] slice1;                               // 下一个 X slice
    
    private double noise000, noise001, noise010, noise011;     // 当前 cell 8 角点
    private double noise100, noise101, noise110, noise111;
    
    double valueXZ00, valueXZ01, valueXZ10, valueXZ11;          // Y 维度上的 4 条边
    double valueZ0, valueZ1;                                    // YX 平面上的 2 条边
    double value;                                                // 最终插值结果
    
    @Override
    public double compute(FunctionContext ctx) {
        return NoiseChunk.this.interpolating ? this.value
             : NoiseChunk.this.fillingCell  ? Mth.lerp3(...)
             : this.noiseFiller.compute(ctx);
    }
}
```

**两种模式**：

- **interpolating 模式**：求 cell 角点时——`noiseFiller` 真正算 8 个角点。
- **fillingCell 模式**：求 cell 内任意点时——三线性插值角点。

**完整流程**：

```
1. NoiseChunk.advanceCellX(cellX):
   slice0 = slice1
   slice1 = compute next slice (cellCountY+1 × cellCountXZ+1 corner values)
2. for each cell in chunk:
   selectCellYZ(cellY, cellZ):
     从 slice0 / slice1 取出当前 cell 的 8 个角点 → noise000 .. noise111
   for each block in cell (4×8×4 = 128 blocks):
     fillingCell mode: 三线性插值得到 this.value
```

**性能**：

- **NoiseFiller 真正调用次数** = (cellCountXZ+1)² × (cellCountY+1) = 5×5×49 = 1225 次。
- **如果不插值**：16×384×16 = 98304 次。**80× 减少**。

## 3.6.5 三线性插值

代码（节选 `NoiseChunk.updateForCell` 等）：

```java
// 给定 cell 8 角点 noise000..noise111
// 内部 (inCellX, inCellY, inCellZ) ∈ [0, 1] × [0, 1] × [0, 1]

double dx = inCellX / cellWidth;     // [0, 1]
double dy = inCellY / cellHeight;
double dz = inCellZ / cellWidth;

// 沿 Y 插值（4 条边）
double valueXZ00 = lerp(dy, noise000, noise010);     // (X=0, Z=0) 沿 Y
double valueXZ01 = lerp(dy, noise001, noise011);
double valueXZ10 = lerp(dy, noise100, noise110);
double valueXZ11 = lerp(dy, noise101, noise111);

// 沿 X 插值（2 条边）
double valueZ0 = lerp(dx, valueXZ00, valueXZ10);     // (Z=0) 沿 X
double valueZ1 = lerp(dx, valueXZ01, valueXZ11);     // (Z=1) 沿 X

// 沿 Z 插值（最终 1 个值）
double value = lerp(dz, valueZ0, valueZ1);
```

**这就是经典三线性插值**——7 次 lerp、约 14 次乘加。比从零调用一次 finalDensity（几十微秒）便宜 1000×。

**Mojang 的优化**：`Mth.lerp3(dy, dx, dz, ...)` 把 7 次 lerp 内联到一个函数（行 16 步骤合并），避免栈调用开销。

**精度损失**：三线性插值是局部线性近似。在 cell 内 4 格水平 / 8 格垂直内的密度变化被假设为线性。**小尺度噪声细节会被抹掉**——这就是为什么 Mojang 把 cell 设得比较小（4×8×4 而不是 16×16×16）：保留足够细节。

## 3.6.6 主调用：fillFromNoise

`NoiseBasedChunkGenerator.doFill` 是 NOISE 阶段的入口（简化）：

```java
public ChunkAccess doFill(Blender blender, ChunkAccess chunk, RandomState randomState, int firstBlockX, int firstBlockZ) {
    NoiseSettings settings = ...;
    int cellWidth = settings.getCellWidth();        // 4
    int cellHeight = settings.getCellHeight();       // 8
    int cellCountY = noiseChunk.cellCountY;          // 48
    int cellCountXZ = noiseChunk.cellCountXZ;        // 4

    NoiseChunk noiseChunk = chunk.getOrCreateNoiseChunk(...);
    Heightmap oceanFloor = chunk.getOrCreateHeightmapUnprimed(Heightmap.Types.OCEAN_FLOOR_WG);
    Heightmap worldSurface = chunk.getOrCreateHeightmapUnprimed(Heightmap.Types.WORLD_SURFACE_WG);
    BlockPos.MutableBlockPos pos = new BlockPos.MutableBlockPos();

    noiseChunk.initializeForFirstCellX();

    for (int cellX = 0; cellX < cellCountXZ; cellX++) {
        noiseChunk.advanceCellX(cellX);

        for (int cellZ = 0; cellZ < cellCountXZ; cellZ++) {
            LevelChunkSection section = chunk.getSection(chunk.getSectionsCount() - 1);

            for (int cellY = cellCountY - 1; cellY >= 0; cellY--) {
                noiseChunk.selectCellYZ(cellY, cellZ);

                for (int inCellY = cellHeight - 1; inCellY >= 0; inCellY--) {
                    int blockY = (cellY + noiseChunk.cellNoiseMinY) * cellHeight + inCellY;
                    int sectionY = blockY & 15;
                    int sectionIdx = chunk.getSectionIndex(blockY);

                    if (chunk.getSectionIndex(section.bottomBlockY()) != sectionIdx) {
                        section = chunk.getSection(sectionIdx);
                    }

                    double dY = (double)inCellY / cellHeight;
                    noiseChunk.updateForY(blockY, dY);

                    for (int inCellX = 0; inCellX < cellWidth; inCellX++) {
                        int blockX = firstBlockX + cellX * cellWidth + inCellX;
                        int sectionX = blockX & 15;
                        double dX = (double)inCellX / cellWidth;
                        noiseChunk.updateForX(blockX, dX);

                        for (int inCellZ = 0; inCellZ < cellWidth; inCellZ++) {
                            int blockZ = firstBlockZ + cellZ * cellWidth + inCellZ;
                            int sectionZ = blockZ & 15;
                            double dZ = (double)inCellZ / cellWidth;
                            noiseChunk.updateForZ(blockZ, dZ);

                            BlockState state = noiseChunk.getInterpolatedState();    // ★ 拿到 BlockState

                            if (state == null) state = generatorSettings.defaultBlock();
                            if (state.isAir()) continue;

                            section.setBlockState(sectionX, sectionY, sectionZ, state, false);
                            oceanFloor.update(sectionX, blockY, sectionZ, state);
                            worldSurface.update(sectionX, blockY, sectionZ, state);
                        }
                    }
                }
            }
        }
        noiseChunk.swapSlices();
    }
    return chunk;
}
```

**4 层嵌套循环**：

1. 外层：`cellX` (4 次), `cellZ` (4 次), `cellY` (48 次) — 共 768 个 cell。
2. 内层：`inCellY` (8), `inCellX` (4), `inCellZ` (4) — 每 cell 128 个方块。

**对每个方块**调 `noiseChunk.getInterpolatedState()`：

- 内部走 `BlockStateFiller` 规则。
- 默认规则：`finalDensity > 0` → defaultBlock（stone）；否则空气；如果在 aquifer 水位下 → water。
- OreVeinifier 也在这里：检查 veinToggle / veinRidged / veinGap 决定要不要把 stone 替换成 raw_iron / raw_copper。

## 3.6.7 Beardifier：结构对地形的反向 carve

打开 `net.minecraft.world.level.levelgen.Beardifier`：

```java
public class Beardifier implements DensityFunctions.BeardifierOrMarker {
    static final int BEARD_KERNEL_RADIUS = 12;
    static final int BEARD_KERNEL_SIZE = 24;
    private static final float[] BEARD_KERNEL = Util.make(new float[13824], arr -> {
        for (int x = 0; x < 24; x++) {
            for (int y = 0; y < 24; y++) {
                for (int z = 0; z < 24; z++) {
                    arr[x * 576 + y * 24 + z] = (float)computeBeardContribution(y - 12, z - 12, x - 12);
                }
            }
        }
    });
    
    private final ObjectListIterator<Rigid> rigidPieces;
    private final ObjectListIterator<JigsawJunction> junctions;
    
    public static Beardifier forStructuresInChunk(StructureManager mgr, ChunkPos pos) { ... }
    
    @Override
    public double compute(FunctionContext ctx) {
        int blockX = ctx.blockX();
        int blockY = ctx.blockY();
        int blockZ = ctx.blockZ();
        double sum = 0.0;
        
        while (rigidPieces.hasNext()) {
            Rigid piece = rigidPieces.next();
            BoundingBox box = piece.box();
            int groundLevelDelta = piece.groundLevelDelta();
            int dx = Math.max(0, Math.max(box.minX() - blockX, blockX - box.maxX()));
            int dz = Math.max(0, Math.max(box.minZ() - blockZ, blockZ - box.maxZ()));
            int targetY = box.minY() + groundLevelDelta;
            int dy = blockY - targetY;
            // 一个 bell-shaped 加性函数，让 box 内地形被"刮平"到 targetY
            sum += computeBeardContributionForPiece(dx, dy, dz);
        }
        rigidPieces.back(savedSize);
        return sum;
    }
}
```

**目的**：当一个结构（如村庄房屋）的 BoundingBox 触及当前 chunk 时，让 chunk 在房屋下方的地形"被刮平到房屋底部 Y"。

**实现**：把 Beardifier 作为 `finalDensity` 的一项加成。它返回正值（让密度变正 = 让那里变成固体）以"填平地基下的空洞"，或返回负值（让地表上方变空气 = 给房屋让出空间）。

**BEARD_KERNEL** 是一个 24×24×24 = 13824 元素的 3D 高斯核——预计算"距离 (dx, dy, dz) 处的密度修正"，避免运行时算指数。

**视觉效果**：村庄、要塞、堡垒的"地面看起来很自然"，没有"房屋悬空"或"地面塞住门"的尴尬。

**JigsawJunction**：jigsaw 系统拼接时的衔接点修正。让相邻 piece 之间的地形也跟着平整。

**这是 1.18 引入的相对新机制**——之前版本的结构生成有著名的"村庄生成在悬崖上"问题。Beardifier 大幅改善了这点。

## 3.6.8 NoiseChunk 创建与生命周期

```java
// 入口（NoiseBasedChunkGenerator.doFill 中）
NoiseChunk noiseChunk = chunk.getOrCreateNoiseChunk(...);

// ChunkAccess.getOrCreateNoiseChunk:
public NoiseChunk getOrCreateNoiseChunk(Function<ChunkAccess, NoiseChunk> factory) {
    if (this.noiseChunk == null) {
        this.noiseChunk = factory.apply(this);
    }

}
```

**懒创建**——首次需要时才构造。

**生命周期**：NoiseChunk 在 ChunkAccess 字段持有，**直到 chunk 升级到 FULL 时丢弃**：


worldgen 后续 step（SURFACE / CARVERS）也用同一个 NoiseChunk（因为它持有 surfaceLevel 缓存等）。

升级到 FULL 时 LevelChunk 不持有 NoiseChunk——已经不需要了。

## 3.6.9 性能 profile

单 chunk NOISE 阶段时间分配（典型 SSD + 5950X 单线程）：

| 阶段 | 时间 | 备注 |
|------|------|------|
| NoiseChunk 构造 + interpolators 初始化 | ~5 ms | 约 15 个通道 |
| Cell 角点求值 (1225 次 × 15 通道) | ~30-50 ms | 主战场 |
| Cell 内插值 + BlockStateFiller (98K 次) | ~20 ms | |
| Aquifer 求值 | ~10 ms | |
| OreVeinifier 求值 | ~5 ms | |
| Beardifier（如果有结构） | ~5 ms | |
| **总** | **~80 ms** | |

**Cell 角点求值是主头**——这是 DensityFunction 树里 60+ 节点 × 1225 次的计算量。要进一步优化，要么 reduce cell 角点数（精度下降），要么优化具体 DensityFunction 的实现（C++ 里更容易）。

## 3.6.10 内存预算

```
NoiseChunk:
├── interpolators[~15] × NoiseInterpolator          ~15 × 1 KB = 15 KB
│   每个：slice0[5×49] + slice1[5×49] + 8 corner doubles ≈ 1 KB
├── cellCaches[~5] × CacheAllInCell                 ~5 × 1 KB = 5 KB
├── preliminarySurfaceLevel (Long2IntMap, 256 列)   ~5 KB
├── Aquifer 状态                                    ~5 KB
├── Beardifier (kernel 共享)                        ~10 字节
└── 各种缓存 / 标志                                 ~2 KB

总: ~30 KB / chunk
```

视距 32×32 同时 worldgen 时 peak ~10 MB。可控。

`BEARD_KERNEL` 是 static final，13824 × 4 字节 = ~55 KB，**全局共享**。

## 3.6.11 C++ 移植

```cpp
namespace mc::worldgen {

struct NoiseSettings {
    int minY;
    int height;
    int noiseSizeHorizontal;     // 1
    int noiseSizeVertical;       // 2
    
    int cellWidth() const { return noiseSizeHorizontal * 4; }
    int cellHeight() const { return noiseSizeVertical * 4; }
};

class NoiseChunk : public DensityFunction::FunctionContext, public DensityFunction::ContextProvider {
public:
    NoiseChunk(int cellCountXZ, RandomState& randomState,
               int firstBlockX, int firstBlockZ,
               const NoiseSettings& settings,
               BeardifierOrMarker* beardifier,
               const NoiseGeneratorSettings* genSettings,
               Aquifer::FluidPicker fluidPicker,
               Blender* blender);

    // 主入口
    const BlockState* getInterpolatedState();

    // Slice 推进
    void initializeForFirstCellX();
    void advanceCellX(int cellX);
    void selectCellYZ(int cellY, int cellZ);
    void updateForY(int y, double dy);
    void updateForX(int x, double dx);
    void updateForZ(int z, double dz);
    void swapSlices();

    // Surface level 缓存
    int preliminarySurfaceLevel(int x, int z);

    // FunctionContext 实现
    int blockX() const override { return cellStartBlockX_ + inCellX_; }
    int blockY() const override { return cellStartBlockY_ + inCellY_; }
    int blockZ() const override { return cellStartBlockZ_ + inCellZ_; }
    Blender* getBlender() const override { return blender_; }

private:
    NoiseSettings settings_;
    int cellCountXZ_, cellCountY_, cellNoiseMinY_;
    int firstCellX_, firstCellZ_;
    int firstNoiseX_, firstNoiseZ_;

    std::vector<std::unique_ptr<NoiseInterpolator>> interpolators_;
    std::vector<std::unique_ptr<CacheAllInCell>> cellCaches_;
    std::unordered_map<int64_t, int> preliminarySurface_;
    std::unique_ptr<Aquifer> aquifer_;
    DensityFunction* initialDensityNoJaggedness_;
    BlockStateFiller blockStateRule_;
    Blender* blender_;
    BeardifierOrMarker* beardifier_;

    int cellStartBlockX_, cellStartBlockY_, cellStartBlockZ_;
    int inCellX_, inCellY_, inCellZ_;
    bool interpolating_ = false;
    bool fillingCell_ = false;
    long interpolationCounter_ = 0;
};

class NoiseInterpolator : public DensityFunction {
public:
    explicit NoiseInterpolator(DensityFunction* noiseFiller, NoiseChunk* parent);
    
    double compute(const FunctionContext& ctx) const override {
        if (parent_->interpolating()) return value_;
        if (parent_->fillingCell()) return trilerp(...);
        return noiseFiller_->compute(ctx);
    }
    
    void selectCell(int cellY, int cellZ);

private:
    DensityFunction* noiseFiller_;
    NoiseChunk* parent_;
    std::vector<double> slice0_, slice1_;
    double n000_, n001_, n010_, n011_, n100_, n101_, n110_, n111_;
    mutable double value_;
};

}
```

**关键工程选择**：

1. **NoiseChunk 同时 inherit 两个接口**——照搬 Mojang。模式古怪但实用。
2. **interpolators 用 `std::vector<std::unique_ptr<NoiseInterpolator>>`**：异构持有。
3. **slices 用 `std::vector<double>`**：动态大小（取决于 cellCountXZ * cellCountY）。
4. **Beardifier kernel 用 `static const std::array`**：编译期常量。
5. **SIMD**：cell 角点求值可以**并行化为 SIMD**——同一 X-slice 的 5×49 = 245 个角点一次算。AVX2 一次 4 个 double，60+ 倍加速可能。

## 3.6.12 一句话总结

NoiseChunk 是 NoiseRouter 的"求值容器"——持有 chunk 上下文 + cell 划分 + 预计算 cell 角点 + 三线性插值；主世界 cell 是 4×8×4 个方块，整 chunk 768 个 cell，密度函数实际只在 (cellCountXZ+1)² × (cellCountY+1) = 1225 个角点上算（vs 朴素 98304 次，**80× 减少**）；NoiseInterpolator 是单通道的"角点 + 插值"包装；cell 内点用三线性插值（7 次 lerp）；Beardifier 用 24³ kernel 让结构 BoundingBox 处的地形被"刮平"到结构基底 Y；性能瓶颈是 cell 角点的 DensityFunction 求值（约 60% NOISE 阶段时间）。
