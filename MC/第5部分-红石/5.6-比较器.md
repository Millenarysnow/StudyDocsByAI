## 5.6.1 ComparatorBlock 属性

打开 `net.minecraft.world.level.block.ComparatorBlock`：

```java
public class ComparatorBlock extends DiodeBlock implements EntityBlock {
    public static final EnumProperty<ComparatorMode> MODE = BlockStateProperties.MODE_COMPARATOR;
    
    @Override
    protected int getDelay(BlockState state) { return 2; }     // ★ 比较器固定延迟 2 tick
}

public enum ComparatorMode { COMPARE, SUBTRACT }
```

**3 个属性**（含继承）：

- **`FACING`** (Direction)：朝向。
- **`POWERED`** (boolean)：是否激活。
- **`MODE`** (COMPARE / SUBTRACT)：比较 vs 减法模式。

**总状态数**：4 × 2 × 2 = **16 个 BlockState**。

**注意**：比较器**没有 LOCKED 属性**——比较器不能被侧向锁存（与中继器不同）。

**`@implements EntityBlock`**：比较器有 BlockEntity（`ComparatorBlockEntity`）—— 用于持久化"上次输出强度"。

---

## 5.6.2 两种模式

### COMPARE 模式

视觉：顶部红色"前 LED" 不亮。

逻辑："输出 = 主输入" if 主输入 ≥ 侧输入 else 0。

```
主输入 = 后方信号
侧输入 = 两侧信号 max
output = 主输入 ≥ 侧输入 ? 主输入 : 0
```

**用途**：比较两个信号源 —— 类似"通过/阻断"开关。

### SUBTRACT 模式

视觉：顶部红色"前 LED" 亮。

逻辑：

```
主输入 = 后方信号
侧输入 = 两侧信号 max
output = max(0, 主输入 - 侧输入)
```

**用途**：信号减法 —— 实现复杂电路（加法器、计数器）。

## 5.6.3 主要钩子

```java
@Override
public boolean isSignalSource(BlockState state) { return true; }

@Override
public int getDirectSignal(BlockState state, BlockGetter level, BlockPos pos, Direction direction) {
    return getSignal(state, level, pos, direction);
}

@Override
public int getSignal(BlockState state, BlockGetter level, BlockPos pos, Direction direction) {
    if (!state.getValue(POWERED)) return 0;
    if (state.getValue(FACING) != direction) return 0;
    return this.getOutputSignal(level, pos, state);
}

@Override
protected int getOutputSignal(BlockGetter level, BlockPos pos, BlockState state) {
    BlockEntity be = level.getBlockEntity(pos);
    return be instanceof ComparatorBlockEntity comparator ? comparator.getOutputSignal() : 0;
}
```

**关键**：`getSignal` 实际从 `ComparatorBlockEntity.outputSignal` 取——这是**持久化字段**（写盘）。

## 5.6.4 ComparatorBlockEntity

```java
public class ComparatorBlockEntity extends BlockEntity {
    private int outputSignal;
    
    public ComparatorBlockEntity(BlockPos pos, BlockState state) {
        super(BlockEntityType.COMPARATOR, pos, state);
    }
    
    public int getOutputSignal() { return this.outputSignal; }
    public void setOutputSignal(int sig) { this.outputSignal = sig; }
    
    @Override
    protected void saveAdditional(CompoundTag tag, HolderLookup.Provider registries) {
        super.saveAdditional(tag, registries);
        tag.putInt("OutputSignal", this.outputSignal);
    }
    
    @Override
    protected void loadAdditional(CompoundTag tag, HolderLookup.Provider registries) {
        super.loadAdditional(tag, registries);
        this.outputSignal = tag.getInt("OutputSignal");
    }
}
```

**为什么需要 BlockEntity 持久化 outputSignal**？因为比较器的输出取决于**复杂瞬时输入**（容器内容、阳光、距离原点等）—— chunk 加载时这些可能不可立即查询。先用上次保存的 outputSignal，等 tick 时再重算。

## 5.6.5 比较器算法

```java
@Override
public void tick(BlockState state, ServerLevel level, BlockPos pos, RandomSource random) {
    refreshOutputState(level, pos, state);
}

private void refreshOutputState(ServerLevel level, BlockPos pos, BlockState state) {
    int newOutput = this.calculateOutputSignal(level, pos, state);
    BlockEntity be = level.getBlockEntity(pos);
    int oldOutput = be instanceof ComparatorBlockEntity comp ? comp.getOutputSignal() : 0;
    
    boolean shouldBePowered = newOutput > 0;
    boolean wasPowered = state.getValue(POWERED);
    
    if (oldOutput != newOutput || wasPowered != shouldBePowered) {
        if (be instanceof ComparatorBlockEntity comparator) {
            comparator.setOutputSignal(newOutput);
        }
        BlockState newState = state.setValue(POWERED, shouldBePowered);
        level.setBlock(pos, newState, Block.UPDATE_ALL);
    }
}

private int calculateOutputSignal(ServerLevel level, BlockPos pos, BlockState state) {
    int input = this.getInputSignal(level, pos, state);
    if (input == 0) return 0;
    
    int sideSignal = this.getAlternateSignal(level, pos, state);
    int mainSignal = Math.max(input, this.getInputSignalSpecial(level, pos, state));    // 容器读取
    
    if (state.getValue(MODE) == ComparatorMode.SUBTRACT) {
        return Math.max(0, mainSignal - sideSignal);
    } else {
        return mainSignal >= sideSignal ? mainSignal : 0;
    }
}

protected int getInputSignalSpecial(Level level, BlockPos pos, BlockState state) {
    Direction facing = state.getValue(FACING);
    BlockPos behindPos = pos.relative(facing.getOpposite());
    BlockState behindState = level.getBlockState(behindPos);
    
    // 检查容器
    if (behindState.hasAnalogOutputSignal()) {
        return behindState.getAnalogOutputSignal(level, behindPos);
    }
    
    // 检查"特殊源"——通过 1 格空气间接读容器
    if (input < 15 && behindState.isRedstoneConductor(level, behindPos)) {
        BlockPos farPos = behindPos.relative(facing.getOpposite());
        BlockState farState = level.getBlockState(farPos);
        if (farState.hasAnalogOutputSignal()) {
            return farState.getAnalogOutputSignal(level, farPos);
        }
    }
    
    return 0;
}
```

**算法**：

1. 取**后方信号** `input`（getInputSignal 同中继器）。
2. 取**侧向信号** `sideSignal`（同中继器的 alternate signal）。
3. 取**特殊后方信号** `getInputSignalSpecial`（容器 / 阳光检测器 / 唱片机）。
4. **主输入** = max(input, special)。
5. 按 MODE：
   - COMPARE：main ≥ side ? main : 0
   - SUBTRACT：max(0, main - side)

## 5.6.6 BlockBehaviour.hasAnalogOutputSignal

```java
public boolean hasAnalogOutputSignal(BlockState state) { return false; }
public int getAnalogOutputSignal(BlockState state, Level level, BlockPos pos) { return 0; }
```

**子类重写**：

```java
// ChestBlock
@Override
public boolean hasAnalogOutputSignal(BlockState state) { return true; }

@Override
public int getAnalogOutputSignal(BlockState state, Level level, BlockPos pos) {
    return AbstractContainerMenu.getRedstoneSignalFromBlockEntity(level.getBlockEntity(pos));
}

// AbstractContainerMenu
public static int getRedstoneSignalFromBlockEntity(BlockEntity be) {
    return be instanceof Container container ? getRedstoneSignalFromContainer(container) : 0;
}

public static int getRedstoneSignalFromContainer(Container container) {
    int filledSlots = 0;
    float fillFactor = 0.0f;
    for (int slot = 0; slot < container.getContainerSize(); slot++) {
        ItemStack stack = container.getItem(slot);
        if (!stack.isEmpty()) {
            fillFactor += (float)stack.getCount() / Math.min(container.getMaxStackSize(), stack.getMaxStackSize());
            filledSlots++;
        }
    }
    fillFactor /= container.getContainerSize();
    return Mth.floor(fillFactor * 14.0F) + (filledSlots > 0 ? 1 : 0);
}
```

**算法**：

- 完全空 → 0。
- 有 1 个物品 → ≥ 1。
- 装满（所有槽 full stack）→ 15。
- 中间状态 → 1-14（按填充率）。

**典型读数**：

- 27 槽箱子，1 槽 1 个物品：填充率 ~0.0014 → output 1。
- 27 槽箱子，27 槽 1 个物品：填充率 ~0.038 → output 1。
- 27 槽箱子，1 槽 64 个物品：填充率 ~0.037 → output 1。
- 27 槽箱子，27 槽满（27 × 64 = 1728）：填充率 1.0 → output 15。

**用途**：

- 检测仓库满 / 空。
- 渐进式信号源。
- 计数器内核（容器作"位"存储）。

## 5.6.7 其他特殊"hasAnalogOutputSignal"方块

- **CommandBlock**：返回 successCount。
- **NoteBlock**：返回 NOTE 属性 0-24（24 个音符）。
- **DaylightDetector**：返回阳光强度 0-15。
- **JukeboxBlock**：返回唱片对应数值。
- **CauldronBlock**：返回水位 0-3 → 0/5/10/15。
- **ItemFrame**：返回旋转 0-7（最多 8 种朝向）→ 0-15。

每种都有自定义 getAnalogOutputSignal 实现。

## 5.6.8 完整时序

```
[Tick 0]
玩家放一个物品到箱子
  → ChestBlockEntity.setItem
  → 触发 setChanged()
  → 间接触发 comparator 的邻居更新
  → comparator.neighborChanged
  → checkTickOnNeighbor → schedule tick delay=2

[Tick 2]
comparator.tick → refreshOutputState
  → calculateOutputSignal:
    input = 0 (没有后方信号)
    sideSignal = 0
    special = getRedstoneSignalFromBlockEntity(chest) = 1（有 1 个物品）
    mainSignal = max(0, 1) = 1
    SUBTRACT: max(0, 1 - 0) = 1
  → newOutput = 1
  → 不同于旧值 0
  → ComparatorBlockEntity.setOutputSignal(1)
  → setBlock(POWERED=true, UPDATE_ALL)
  → 邻居更新 → 下游 wire 收到 sig=1
```

**总延迟**：2 tick（比较器固定 delay=2）。

## 5.6.9 比较器右键交互

```java
@Override
public InteractionResult use(BlockState state, Level level, BlockPos pos, Player player, ...) {
    if (!player.getAbilities().mayBuild) return InteractionResult.PASS;
    state = state.cycle(MODE);     // COMPARE → SUBTRACT → COMPARE
    level.playSound(...);
    level.setBlock(pos, state, Block.UPDATE_ALL);
    refreshOutputState(level, pos, state);     // 立刻用新模式重算
    return InteractionResult.sidedSuccess(level.isClientSide);
}
```

玩家右键切换 COMPARE / SUBTRACT —— 立刻重算输出。

## 5.6.10 性能

```
单 comparator.tick：
- calculateOutputSignal：~200 ns（含容器扫描）
- 容器扫描：~50 ns / slot × 27 slots = ~1.5 微秒（大型箱子）
- 总：~1-2 微秒
```

比较器**对容器内容变化敏感** —— 每次容器内物品变化都会通过 `setChanged → neighborUpdate` 让 comparator 重算。**装载频繁的容器（漏斗系统）**会让相连 comparator 反复 tick。

## 5.6.11 C++ 移植

```cpp
namespace mc::block {

enum class ComparatorMode { COMPARE, SUBTRACT };

class ComparatorBlock : public DiodeBlock, public EntityBlock {
public:
    static const EnumProperty<ComparatorMode> MODE;
    
    int getDelay(const BlockState& state) const override { return 2; }
    
    bool isSignalSource(const BlockState& state) const override { return true; }
    
    int getSignal(const BlockState& state, BlockGetter& level, BlockPos pos, Direction dir) const override {
        if (!state.getValue(POWERED)) return 0;
        if (state.getValue(HorizontalDirectionalBlock::FACING) != dir) return 0;
        return getOutputSignal(level, pos, state);
    }
    
    int getOutputSignal(BlockGetter& level, BlockPos pos, const BlockState& state) const override {
        BlockEntity* be = level.getBlockEntity(pos);
        if (auto comp = dynamic_cast<ComparatorBlockEntity*>(be)) {
            return comp->getOutputSignal();
        }
        return 0;
    }
    
    void tick(const BlockState& state, ServerLevel& level, BlockPos pos, RandomSource& random) override {
        refreshOutputState(level, pos, state);
    }
    
    std::unique_ptr<BlockEntity> newBlockEntity(BlockPos pos, const BlockState* state) const override {
        return std::make_unique<ComparatorBlockEntity>(pos, state);
    }
    
private:
    void refreshOutputState(ServerLevel& level, BlockPos pos, const BlockState& state) {
        int newOutput = calculateOutputSignal(level, pos, state);
        ComparatorBlockEntity* be = dynamic_cast<ComparatorBlockEntity*>(level.getBlockEntity(pos));
        int oldOutput = be ? be->getOutputSignal() : 0;
        bool shouldBePowered = newOutput > 0;
        bool wasPowered = state.getValue(POWERED);
        
        if (oldOutput != newOutput || wasPowered != shouldBePowered) {
            if (be) be->setOutputSignal(newOutput);
            level.setBlock(pos, state.setValue(POWERED, shouldBePowered), BlockUpdateFlags::ALL);
        }
    }
    
    int calculateOutputSignal(ServerLevel& level, BlockPos pos, const BlockState& state) {
        int input = getInputSignal(level, pos, state);
        if (input == 0) return 0;
        int sideSignal = getAlternateSignal(level, pos, state);
        int special = getInputSignalSpecial(level, pos, state);
        int main = std::max(input, special);
        
        return state.getValue(MODE) == ComparatorMode::SUBTRACT
            ? std::max(0, main - sideSignal)
            : (main >= sideSignal ? main : 0);
    }
};

class ComparatorBlockEntity : public BlockEntity {
public:
    int getOutputSignal() const { return outputSignal_; }
    void setOutputSignal(int sig) { outputSignal_ = sig; }
    
    void saveAdditional(NbtCompound& tag, RegistryAccess& registries) const override {
        tag.put("OutputSignal", outputSignal_);
    }
    
    void loadAdditional(const NbtCompound& tag, RegistryAccess& registries) override {
        outputSignal_ = tag.getInt("OutputSignal").value_or(0);
    }
    
private:
    int outputSignal_ = 0;
};

}
```

## 5.6.12 一句话总结

比较器（ComparatorBlock）是 3 属性方块（FACING / POWERED / MODE）共 16 BlockState，固定 delay=2 tick；通过 `ComparatorBlockEntity.outputSignal` 持久化输出（让 chunk 加载后立刻有信号）；2 模式：COMPARE（main ≥ side ? main : 0）和 SUBTRACT（max(0, main - side)）；除了普通 wire 输入还能通过 `BlockBehaviour.hasAnalogOutputSignal` 读取后方容器（箱子 / 漏斗 / 唱片机 / 阳光感应器 / 命令方块）填充率作 0-15 信号；可"穿过 1 格 conductor"读取远端容器；玩家右键切换模式；scheduled tick 触发 `refreshOutputState` 重算 outputSignal。
