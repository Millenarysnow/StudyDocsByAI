## 5.9.2 数据流

```
玩家拉拉杆
   ↓
Lever.neighborChanged 不需要（自己是 source）
   ↓
玩家 use(lever) → LeverBlock.use → setBlock(POWERED 翻转, UPDATE_ALL)
   ↓ UPDATE_NEIGHBORS
NeighborUpdater (BFS):
   ↓ 6 邻居 + 周围辐射（看 wire 怎么传播）
RedStoneWireBlock.neighborChanged:
   ↓
RedstoneWireEvaluator.updatePowerStrength:
   ↓
calculateTargetStrength → setBlock(POWER, flags=2) + 7 邻居更新
   ↓
chained wire updates...

最终某 wire 触发 RepeaterBlock.neighborChanged:
   ↓
checkTickOnNeighbor:
   不在 willTickThisTick → schedule tick (delay=1, priority=HIGH)
   ↓
[下一 tick 第 6 步]
LevelTicks.tick → repeater.tick → setBlock(POWERED, UPDATE_ALL)
   ↓ UPDATE_NEIGHBORS
触发邻居 → 信号传到下游 wire

某 wire 邻居是 piston → piston.neighborChanged:
   ↓
checkIfExtend → 应当推 → level.blockEvent(pos, piston, TRIGGER_EXTEND, ...)
   ↓
[下一 tick 第 9 步]
ServerLevel.runBlockEvents → piston.triggerEvent → moveBlocks → PistonStructureResolver
   ↓
推动方块 + 创建 MovingPistonBlock + PistonMovingBlockEntity
   ↓ 广播 ClientboundBlockEventPacket

[2 tick 后]
PistonMovingBlockEntity.tick (progress=1.0) → finalTick → 把 movingBlock 实际变成目标方块
```

## 5.9.5 ECS vs OOP 选择

红石组件**多样性高 + 状态简单**，**OOP 更合适**：

- 1000+ Block 子类，每个状态简单（POWERED / DELAY / LOCKED 等）。
- 钩子方法少（neighborChanged / tick / triggerEvent / getSignal 等）。
- ECS 的 SoA 优势在大量同类实体——不适用于这种"少量但行为各异"的场景。

**例外**：

- `MovingPistonBlock` 的 progress 字段每 tick 都更新——SoA 友好。但单个 chunk 同时 ≤ 几个 piston 在 moving，差异不大。

## 5.9.6 实验红石的取舍

**实现方法**：

- 第一版：只实现 `DefaultRedstoneWireEvaluator`。
- 等系统稳定再加 `ExperimentalRedstoneWireEvaluator` + `Orientation`。

**支持范围**：

- 工程量约 +2000 行 C++（Orientation + 新 evaluator）。
- 性能提升 5-10x（大型电路）。
- 但电路兼容性问题——某些经典 BUD / 0-tick 电路可能失效。

**建议**：作为可选 feature flag 实现，玩家自选。

## 5.9.8 一句话总结

红石是**第 4 部分方块更新机制的具体应用层**——`isSignalSource / getSignal / getDirectSignal` 让方块作为信号源；`hasAnalogOutputSignal` 让容器作 0-15 信号源；wire / repeater / comparator 通过 neighborChanged → scheduled tick → setBlock 链传播；piston 通过 BlockEvent 4 阶段时序实现推动 + 0.5 秒动画；6 邻居 UPDATE_ORDER + TickPriority + subTickOrder 保证完全确定性时序；1.21 实验红石用 BFS 整网络更新 + Orientation 解决性能 + 位置依赖问题；C++ 实现选 OOP 而非 ECS，约 5000 行代码 + 100+ Block 子类 = 完整 vanilla 兼容红石系统。
