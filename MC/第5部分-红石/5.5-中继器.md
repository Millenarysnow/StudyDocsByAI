## 5.5.1 RepeaterBlock 属性

打开 `net.minecraft.world.level.block.RepeaterBlock`：

```java
public class RepeaterBlock extends DiodeBlock {
    public static final BooleanProperty LOCKED = BlockStateProperties.LOCKED;
    public static final IntegerProperty DELAY = BlockStateProperties.DELAY;     // 1..4
    
    @Override
    protected BlockState getStateForPlacement(BlockPlaceContext ctx) {
        return super.getStateForPlacement(ctx)
            .setValue(DELAY, 1)
            .setValue(LOCKED, false);
    }
    
    // 继承 DiodeBlock 的 FACING / POWERED 属性
}
```

**4 个属性**（含继承）：

- **`FACING`** (Direction)：中继器朝向（输出端方向）。4 个水平方向。
- **`POWERED`** (boolean)：当前输出是否激活。
- **`LOCKED`** (boolean)：是否被锁存（侧向中继器供电时）。
- **`DELAY`** (1-4)：玩家右键调节的延迟（tick）。

**总状态数**：4 × 2 × 2 × 4 = **64 个 BlockState**。

## 5.5.2 父类 DiodeBlock

```java
public abstract class DiodeBlock extends HorizontalDirectionalBlock {
    public static final BooleanProperty POWERED = BlockStateProperties.POWERED;
    
    protected abstract int getDelay(BlockState state);
    protected abstract int getOutputSignal(BlockGetter level, BlockPos pos, BlockState state);
    
    protected boolean shouldTurnOn(Level level, BlockPos pos, BlockState state) {
        return this.getInputSignal(level, pos, state) > 0;
    }
    
    protected int getInputSignal(Level level, BlockPos pos, BlockState state) {
        Direction facing = state.getValue(FACING);
        BlockPos behindPos = pos.relative(facing.getOpposite());
        BlockState behindState = level.getBlockState(behindPos);
        int sig = level.getSignal(behindPos, facing.getOpposite());
        if (sig >= 15) return sig;
        if (behindState.is(Blocks.REDSTONE_WIRE)) {
            return Math.max(sig, behindState.getValue(RedStoneWireBlock.POWER));
        }
        return sig;
    }
}
```

`DiodeBlock` 是中继器 / 比较器的共同基类——封装"二极管"行为：信号只能从后方进、前方出。

## 5.5.3 中继器的 4 钩子

```java
// RepeaterBlock 完整钩子（简化）

@Override
public boolean isSignalSource(BlockState state) { return true; }     // ★ 自身是信号源

@Override
public int getDirectSignal(BlockState state, BlockGetter level, BlockPos pos, Direction direction) {
    return state.getValue(POWERED) && state.getValue(FACING) == direction ? 15 : 0;
}

@Override
public int getSignal(BlockState state, BlockGetter level, BlockPos pos, Direction direction) {
    return getDirectSignal(state, level, pos, direction);
}

@Override
public void neighborChanged(BlockState state, Level level, BlockPos pos, Block neighborBlock,
                             @Nullable Orientation orientation, boolean movedByPiston) {
    if (!state.canSurvive(level, pos)) {
        // 下方支撑没了
        level.removeBlock(pos, true);
        return;
    }
    this.checkTickOnNeighbor(level, pos, state);
}

protected void checkTickOnNeighbor(Level level, BlockPos pos, BlockState state) {
    if (!this.isLocked(level, pos, state)) {
        boolean isPowered = state.getValue(POWERED);
        boolean shouldPower = this.shouldTurnOn(level, pos, state);
        if (isPowered != shouldPower && !level.getBlockTicks().willTickThisTick(pos, this)) {
            // 信号变了 → schedule tick
            TickPriority priority = TickPriority.HIGH;
            if (this.shouldPrioritize(level, pos, state)) priority = TickPriority.EXTREMELY_HIGH;
            else if (isPowered) priority = TickPriority.VERY_HIGH;
            level.scheduleTick(pos, this, this.getDelay(state), priority);
        }
    }
}

@Override
public void tick(BlockState state, ServerLevel level, BlockPos pos, RandomSource random) {
    // scheduled tick 触发：实际改变 POWERED
    if (this.isLocked(level, pos, state)) return;     // 锁存中，不变
    
    boolean isPowered = state.getValue(POWERED);
    boolean shouldPower = this.shouldTurnOn(level, pos, state);
    if (isPowered && !shouldPower) {
        level.setBlock(pos, state.cycle(POWERED), Block.UPDATE_ALL);
    } else if (!isPowered) {
        level.setBlock(pos, state.cycle(POWERED), Block.UPDATE_ALL);
        if (!shouldPower) {
            level.scheduleTick(pos, this, this.getDelay(state), TickPriority.VERY_HIGH);
        }
    }
}
```

**4 个钩子协同**：

1. **`getDirectSignal` / `getSignal`**：输出 15（如果 POWERED）。
2. **`neighborChanged`**：信号源变化时，调 `checkTickOnNeighbor` 决定是否 schedule tick。
3. **`tick`**：scheduled tick 触发，真正改 POWERED 属性。

## 5.5.4 输入信号检测

```java
protected int getInputSignal(Level level, BlockPos pos, BlockState state) {
    Direction facing = state.getValue(FACING);
    BlockPos behindPos = pos.relative(facing.getOpposite());
    int sig = level.getSignal(behindPos, facing.getOpposite());
    if (sig >= 15) return sig;
    
    BlockState behindState = level.getBlockState(behindPos);
    if (behindState.is(Blocks.REDSTONE_WIRE)) {
        return Math.max(sig, behindState.getValue(RedStoneWireBlock.POWER));
    }
    return sig;
}
```

**只检测后方一格**——中继器是"二极管"，信号只能从后进。

**两种情况**：

1. 后方是普通信号源（lever / 红石火把）→ `level.getSignal` 返 0 / 15。
2. 后方是 wire → 直接读 wire 的 POWER 属性。

**`shouldTurnOn = getInputSignal > 0`**：任何非零输入都让中继器输出 15。**不放大保留强度** —— 中继器是数字开关。

## 5.5.5 锁存（Latch）机制

中继器特殊行为：**侧向输入会"锁定"中继器状态**。

```java
public boolean isLocked(LevelReader level, BlockPos pos, BlockState state) {
    return this.getAlternateSignal(level, pos, state) > 0;
}

protected int getAlternateSignal(SignalGetter level, BlockPos pos, BlockState state) {
    Direction facing = state.getValue(FACING);
    Direction left = facing.getClockWise();
    Direction right = facing.getCounterClockWise();
    return Math.max(
        this.getAlternateSignalAt(level, pos.relative(left), left),
        this.getAlternateSignalAt(level, pos.relative(right), right)
    );
}

protected int getAlternateSignalAt(SignalGetter level, BlockPos pos, Direction dir) {
    BlockState state = level.getBlockState(pos);
    if (this.isAlternateInput(state)) {
        if (state.is(Blocks.REDSTONE_BLOCK)) return 15;
        if (state.is(Blocks.REDSTONE_WIRE)) return state.getValue(RedStoneWireBlock.POWER);
        return level.getDirectSignal(pos, dir);
    }
    return 0;
}

protected boolean isAlternateInput(BlockState state) {
    return state.isSignalSource() || state.is(Blocks.REDSTONE_BLOCK) || state.is(Blocks.REDSTONE_WIRE);
}
```

**逻辑**：

- 检查中继器的"左 / 右"两侧（FACING 的 clockwise / counter-clockwise）。
- 如果某侧有"alternate signal"（中继器 / 比较器 / 红石火把 / 红石线 / 红石块）→ 锁存。

**视觉**：

- 中继器侧面接一个红石信号源 → 顶部出现"锁存指示标志"（一个石条）。
- 锁存中：中继器 POWERED 不会变——锁住了输出当前状态。

**用途**：搭建只读存储（D-flip-flop）—— 信号到来时设值，之后侧向锁存让数据保留。

## 5.5.6 完整时序

### Case A：信号到来

```
[Tick 0]
  玩家把 lever 拉开
  → lever.setBlock(POWERED=true, UPDATE_ALL)
  → lever 邻居更新链
  
  → 中继器（在 lever 的 facing 方向）的 neighborChanged
  → checkTickOnNeighbor:
    isPowered = false, shouldPower = true（lever 输出 15）
    → !isLocked
    → !willTickThisTick → schedule tick with delay=1, priority=HIGH

[Tick 1] (delay=1)
  scheduled tick 触发 → 中继器.tick
  → !isLocked
  → isPowered=false, shouldPower=true
  → setBlock(POWERED=true, UPDATE_ALL)
  → 触发输出端方块的 neighborChanged
  → 信号传到下游
```

**总延迟**：1 tick（DELAY=1）。

### Case B：信号消失

```
[Tick 0]
  玩家关 lever
  → 链式 neighborChanged 到中继器
  → checkTickOnNeighbor:
    isPowered = true, shouldPower = false
    → schedule tick with delay=1, priority=VERY_HIGH (不同优先级)

[Tick 1]
  中继器.tick
  → isPowered=true, shouldPower=false
  → setBlock(POWERED=false, UPDATE_ALL)
```

**注意**：信号消失用 `VERY_HIGH` priority，信号到来用 `HIGH` priority。原因：让"关"操作比"开"操作先处理——某些电路依赖这个时序。

### Case C：DELAY=4 + 锁存

```
[Tick 0] lever ON 
  → 中继器 schedule tick delay=4

[Tick 1] 邻居中继器（侧向）也 ON
  → 我的 isLocked 现在 = true

[Tick 4] 我的 scheduled tick 触发
  → 进 tick() 
  → if (isLocked) return; ← 直接返回，不 setBlock POWERED
  
我的 POWERED 仍 = false（保留输入前状态）
```

锁存有效。直到侧向锁存源消失：

```
[Tick 10] 侧向锁存源消失
  → 我的 neighborChanged
  → 不再 isLocked
  → 这时如果输入信号还在 → schedule tick → POWERED 变 true
```

## 5.5.7 willTickThisTick 防重复 schedule

```java
if (!level.getBlockTicks().willTickThisTick(pos, this)) {
    level.scheduleTick(pos, this, ...);
}
```

**防止短时间内多次 schedule**：

- 玩家快速翻转 lever 几次 → 多次 neighborChanged 进来。
- 每次都查 `willTickThisTick(pos, RepeaterBlock)`：如果已经有 scheduled tick → 不重复 schedule。

回顾 4.3：`LevelChunkTicks.hasScheduledTick` 通过 ticksPerPosition HashSet 实现 O(1) 检查。

## 5.5.8 Priority

```java
TickPriority priority;
if (this.shouldPrioritize(level, pos, state)) priority = TickPriority.EXTREMELY_HIGH;
else if (isPowered) priority = TickPriority.VERY_HIGH;     // 关闭
else priority = TickPriority.HIGH;                          // 打开
```

**3 种优先级**：

- `EXTREMELY_HIGH (-3)`：当前 tick 内**前面已经有信号源** → 强制最优先（避免被覆盖）。
- `VERY_HIGH (-2)`：信号关闭 → 比信号开打高一档（防止"开关同 tick 时优先关"）。
- `HIGH (-1)`：信号打开 → 普通优先级。

**这就是为什么红石电路有"复杂的边界 case"** —— Mojang 用细粒度 priority 控制时序，让某些经典电路稳定工作。

## 5.5.9 中继器与红石线的交互

```
[lever] - [wire] - [wire] - [repeater] - [wire] - [wire] - ...
                              FACING ↗
```

链式时序：

```
Tick 0: lever ON
  → wire₀.POWER = 15
  → wire₁.POWER = 14
  
Tick 0: repeater.neighborChanged from wire₁:
  shouldPower = true (wire₁.POWER > 0)
  → schedule tick delay=1

Tick 0: 后续 wire 不接收信号（repeater 还没 POWERED）
  → wire₂.POWER = 0
  → wire₃.POWER = 0

Tick 1: repeater.tick → POWERED=true
  → setBlock(UPDATE_ALL) → 触发邻居
  → wire₂ 收到 repeater 的 strong signal 15
  → wire₂.POWER = 15
  → wire₃.POWER = 14
  → ...

Tick 1 结束：信号已经传到 repeater 后第 4 wire
```

**总延迟（lever 到 repeater 后）= 1 tick**（最小 delay 设置时）。

## 5.5.10 中继器锁存状态的视觉

```java
@Override
public BlockState getStateForPlacement(BlockPlaceContext ctx) {
    return super.getStateForPlacement(ctx)
        .setValue(LOCKED, this.isLocked(ctx.getLevel(), ctx.getClickedPos(), this.defaultBlockState()));
}
```

放置时检查锁存——如果旁边已有 source → LOCKED=true 立刻显示锁存视觉。

`updateShape`（继承的）触发 LOCKED 重计算：

```java
@Override
public BlockState updateShape(BlockState state, LevelReader level, ScheduledTickAccess access,
                                BlockPos pos, Direction dir, BlockPos neighborPos, BlockState neighborState, RandomSource random) {
    return dir.getAxis().isHorizontal() ? state.setValue(LOCKED, this.isLocked(level, pos, state)) : super.updateShape(...);
}
```

侧向邻居变化 → 重新检查 LOCKED → LOCKED 属性同步。

## 5.5.11 调节延迟（玩家右键）

```java
@Override
public InteractionResult use(BlockState state, Level level, BlockPos pos, Player player, BlockHitResult hit) {
    if (!player.getAbilities().mayBuild) return InteractionResult.PASS;
    level.setBlock(pos, state.cycle(DELAY), Block.UPDATE_ALL);
    level.playSound(...);
    return InteractionResult.sidedSuccess(level.isClientSide);
}
```

**`state.cycle(DELAY)`**：DELAY 1 → 2 → 3 → 4 → 1 循环（IntegerProperty 1-4）。

回顾 1.2.7：`cycle` 内部用 `setValue` 在邻居 BlockState 数组里 O(1) 跳转。

## 5.5.12 性能

中继器实现非常轻量：

- `neighborChanged`：~50 ns（几次邻居信号查询）。
- `tick`：~100 ns（setBlock + 邻居更新链）。

每 tick 中继器数量 × 几个 ns 几乎无感。

## 5.5.13 C++ 移植

```cpp
namespace mc::block {

class DiodeBlock : public HorizontalDirectionalBlock {
public:
    static const BooleanProperty POWERED;
    
    virtual int getDelay(const BlockState& state) const = 0;
    virtual int getOutputSignal(BlockGetter& level, BlockPos pos, const BlockState& state) const = 0;
    
    bool shouldTurnOn(Level& level, BlockPos pos, const BlockState& state) const {
        return getInputSignal(level, pos, state) > 0;
    }
    
    int getInputSignal(Level& level, BlockPos pos, const BlockState& state) const {
        Direction facing = state.getValue(HorizontalDirectionalBlock::FACING);
        BlockPos behindPos = pos.relative(facing.getOpposite());
        int sig = level.getSignal(behindPos, facing.getOpposite());
        if (sig >= 15) return sig;
        const BlockState* behindState = level.getBlockState(behindPos);
        if (behindState->is(Blocks::REDSTONE_WIRE)) {
            return std::max(sig, behindState->getValue(RedStoneWireBlock::POWER));
        }
        return sig;
    }
};

class RepeaterBlock : public DiodeBlock {
public:
    static const BooleanProperty LOCKED;
    static const IntegerProperty DELAY;
    
    int getDelay(const BlockState& state) const override {
        return state.getValue(DELAY);
    }
    
    bool isSignalSource(const BlockState& state) const override { return true; }
    
    int getDirectSignal(const BlockState& state, BlockGetter& level, BlockPos pos, Direction dir) const override {
        return state.getValue(POWERED) && state.getValue(HorizontalDirectionalBlock::FACING) == dir ? 15 : 0;
    }
    
    int getSignal(const BlockState& state, BlockGetter& level, BlockPos pos, Direction dir) const override {
        return getDirectSignal(state, level, pos, dir);
    }
    
    bool isLocked(LevelReader& level, BlockPos pos, const BlockState& state) const {
        return getAlternateSignal(level, pos, state) > 0;
    }
    
    void neighborChanged(const BlockState& state, Level& level, BlockPos pos,
                          Block* neighborBlock, std::optional<Orientation> orient, bool movedByPiston) override {
        if (!state.canSurvive(level, pos)) {
            level.removeBlock(pos, true);
            return;
        }
        checkTickOnNeighbor(level, pos, state);
    }
    
    void tick(const BlockState& state, ServerLevel& level, BlockPos pos, RandomSource& random) override {
        if (isLocked(level, pos, state)) return;
        
        bool isPowered = state.getValue(POWERED);
        bool shouldPower = shouldTurnOn(level, pos, state);
        if (isPowered != shouldPower) {
            level.setBlock(pos, state.cycle(POWERED), BlockUpdateFlags::ALL);
            if (!isPowered && !shouldPower) {
                level.scheduleTick(pos, this, getDelay(state), TickPriority::VERY_HIGH);
            }
        }
    }
    
private:
    void checkTickOnNeighbor(Level& level, BlockPos pos, const BlockState& state) {
        if (isLocked(level, pos, state)) return;
        bool isPowered = state.getValue(POWERED);
        bool shouldPower = shouldTurnOn(level, pos, state);
        if (isPowered != shouldPower && !level.getBlockTicks().willTickThisTick(pos, this)) {
            TickPriority priority = isPowered ? TickPriority::VERY_HIGH : TickPriority::HIGH;
            level.scheduleTick(pos, this, getDelay(state), priority);
        }
    }
};

}
```

## 5.5.14 一句话总结

中继器（RepeaterBlock）是 4 属性方块（FACING / POWERED / LOCKED / DELAY 1-4）共 64 BlockState；通过 `isSignalSource = true` + `getDirectSignal/getSignal` 在 FACING 方向给 strong+weak signal 15；输入信号通过 `getInputSignal` 仅检测后方（二极管行为）；信号变化触发 `scheduledTick` 延迟 1-4 tick 后实际翻转 POWERED；`LOCKED` 由侧向中继器 / 比较器 / 火把 / 线供电时锁存输出当前状态；`shouldPrioritize` / `isPowered` 决定 `TickPriority`（EXTREMELY_HIGH / VERY_HIGH / HIGH）让信号"关"先于"开"处理；`willTickThisTick` 防止重复 schedule。
