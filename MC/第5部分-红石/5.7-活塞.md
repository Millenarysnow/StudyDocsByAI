## 5.7.1 PistonBaseBlock

打开 `net.minecraft.world.level.block.piston.PistonBaseBlock`：

```java
public class PistonBaseBlock extends DirectionalBlock {
    public static final BooleanProperty EXTENDED = BlockStateProperties.EXTENDED;
    public static final int TRIGGER_EXTEND = 0;
    public static final int TRIGGER_CONTRACT = 1;
    public static final int TRIGGER_DROP = 2;
    public static final float PLATFORM_THICKNESS = 4.0F;
    public static final int PUSH_LIMIT = 12;     // ★ 单次推动方块上限
    
    private final boolean isSticky;
    
    public PistonBaseBlock(boolean isSticky, BlockBehaviour.Properties props) {
        super(props);
        this.isSticky = isSticky;
        this.registerDefaultState(this.defaultBlockState().setValue(FACING, Direction.NORTH).setValue(EXTENDED, false));
    }
}
```

**3 个常量**：

- **`PUSH_LIMIT = 12`**：单次推动最多 12 个方块。
- **`TRIGGER_EXTEND` / `TRIGGER_CONTRACT` / `TRIGGER_DROP`**：BlockEvent 的 eventId。

**属性**：

- `FACING` (Direction)：6 方向。
- `EXTENDED` (boolean)：是否伸出。

`isSticky`：构造时区分 PISTON / STICKY_PISTON。**这不是 BlockState 属性**——是 Block 级别的标志（不同 Block 实例）。

## 5.7.2 完整 4 阶段时序

活塞推动是 Mojang 整个红石系统**最复杂**的多阶段过程：

```
[Tick 0 - 玩家给信号]
玩家拉杆 → wire 链 → 活塞 neighborChanged
  ↓
piston.checkIfExtend(level, pos, state):
  hasNeighborSignal? Y
  isExtended? N
  → 应当推
  → setBlock(state.setValue(EXTENDED, true), Block.UPDATE_KNOWN_SHAPE)  // 仅改属性，不触发邻居
  → level.blockEvent(pos, this, TRIGGER_EXTEND, facing.ordinal())  // 排 BlockEvent

[Tick 1 - runBlockEvents 执行]
piston.triggerEvent(state, level, pos, TRIGGER_EXTEND, paramB):
  ↓
moveBlocks(level, pos, facing, true):
  ↓
PistonStructureResolver resolver = new PistonStructureResolver(level, pos, facing, true);
resolver.resolve():
  - 扫描前方方块链
  - 决定推哪些（toPush）+ 销毁哪些（toDestroy）
  ↓
真正执行：
  - 销毁要销毁的方块（如脆弱方块）
  - 把可推方块移到新位置（特殊：变成 MovingPistonBlock + BlockEntity）
  - 在活塞前方放 PistonHeadBlock
  - 邻居更新等
  ↓
广播 ClientboundBlockEventPacket

[Tick 1.x - 客户端动画]
客户端 triggerEvent 启动 0.5 秒动画
  - 推动方块从原位置 lerp 到新位置
  - PistonHead 也 lerp
  
[Tick 1.5 - 动画完成]
PistonMovingBlockEntity 在动画完成时调 finalTick
  → 把"动画期间 movingBlock"实际转为目标方块
  → 移除 MovingPistonBlock + PistonMovingBlockEntity
```

## 5.7.3 checkIfExtend：决定是否推

```java
private boolean checkIfExtend(Level level, BlockPos pos, BlockState state) {
    Direction facing = state.getValue(FACING);
    boolean hasSignal = this.getNeighborSignal(level, pos, facing);
    
    if (hasSignal && !state.getValue(EXTENDED)) {
        // 应当推
        if (new PistonStructureResolver(level, pos, facing, true).resolve()) {
            level.blockEvent(pos, this, TRIGGER_EXTEND, facing.ordinal());
            return true;
        }
    } else if (!hasSignal && state.getValue(EXTENDED)) {
        // 应当缩
        BlockPos blockpos = pos.relative(facing, 2);
        BlockState blockstate1 = level.getBlockState(blockpos);
        int trigger = TRIGGER_CONTRACT;
        if (blockstate1.is(Blocks.MOVING_PISTON) ...) {
            trigger = TRIGGER_DROP;
        }
        level.blockEvent(pos, this, trigger, facing.ordinal());
    }
    
    return true;
}

private boolean getNeighborSignal(Level level, BlockPos pos, Direction facing) {
    for (Direction dir : Direction.values()) {
        if (dir != facing && level.hasSignal(pos.relative(dir), dir)) return true;
    }
    if (level.hasSignal(pos, Direction.DOWN)) return true;
    BlockPos abovePos = pos.above();
    for (Direction dir : Direction.values()) {
        if (dir != Direction.DOWN && level.hasSignal(abovePos.relative(dir), dir)) return true;
    }
    return false;
}
```

**`getNeighborSignal`**：检查 6 邻居 + 上方一格 周围 5 邻居 = **共 11 个方向**。这是为什么"在活塞上方供电也能激活"——**Bud 现象的官方支持**。

**注意排除 facing 方向**——避免活塞自己被自己的输出激活。

## 5.7.4 PistonStructureResolver：决定推哪些

打开 `net.minecraft.world.level.block.piston.PistonStructureResolver`：

```java
public class PistonStructureResolver {
    public static final int MAX_PUSH_DEPTH = 12;
    private final Level level;
    private final BlockPos pistonPos;
    private final boolean extending;
    private final BlockPos startPos;
    private final Direction pushDirection;
    private final List<BlockPos> toPush = Lists.newArrayList();
    private final List<BlockPos> toDestroy = Lists.newArrayList();
    private final Direction pistonDirection;
    
    public PistonStructureResolver(Level level, BlockPos pos, Direction direction, boolean extending) {
        this.level = level;
        this.pistonPos = pos;
        this.pistonDirection = direction;
        this.extending = extending;
        this.pushDirection = extending ? direction : direction.getOpposite();
        this.startPos = pos.relative(direction, extending ? 1 : 2);
    }
    
    public boolean resolve() {
        this.toPush.clear();
        this.toDestroy.clear();
        BlockState startState = this.level.getBlockState(this.startPos);
        if (!PistonBaseBlock.isPushable(startState, this.level, this.startPos, this.pushDirection, false, this.pistonDirection)) {
            // 起点直接不可推 - 但起点有可能是粘性活塞缩回时拉的方块
            if (this.extending && startState.getPistonPushReaction() == PushReaction.DESTROY) {
                this.toDestroy.add(this.startPos);
                return true;
            }
            return false;
        }
        
        // 1. 沿推方向扫描，加入要推的方块列表
        if (!this.addBlockLine(this.startPos, this.pushDirection)) return false;
        
        // 2. 检查所有要推的方块的"粘连方块"（slime / honey）
        for (int i = 0; i < this.toPush.size(); i++) {
            BlockPos pos = this.toPush.get(i);
            if (this.level.getBlockState(pos).is(Blocks.SLIME_BLOCK) && !this.addBranchingBlocks(pos)) return false;
        }
        
        return true;
    }
    
    private boolean addBlockLine(BlockPos startPos, Direction expansionDir) {
        BlockState state = this.level.getBlockState(startPos);
        if (state.isAir()) return true;
        if (!PistonBaseBlock.isPushable(state, this.level, startPos, this.pushDirection, false, expansionDir)) return true;
        if (startPos.equals(this.pistonPos)) return true;
        if (this.toPush.contains(startPos)) return true;
        
        int distance = 1;
        if (distance + this.toPush.size() > MAX_PUSH_DEPTH) return false;
        
        // 沿反向 expansionDir 扫描——找出"前面顶着"这条线的所有方块
        while (state.is(Blocks.SLIME_BLOCK) || state.is(Blocks.HONEY_BLOCK)) {
            BlockPos behind = startPos.relative(this.pushDirection.getOpposite(), distance);
            BlockState behindState = this.level.getBlockState(behind);
            if (behindState.isAir() || ...) break;
            // ⋯ 复杂逻辑 ⋯
            distance++;
        }
        
        // 加入 toPush
        // 检查超出 12 限额
        // 递归处理 slime / honey 粘连
        return true;
    }
}
```

**算法**（高层）：

1. 从起点（推动方向第 1 格）沿推动方向扫描。
2. 每个方块检查 `getPistonPushReaction`：
   - **NORMAL**：可推。
   - **DESTROY**：推不动（火、植被）但被销毁。
   - **BLOCK**：不可推（基岩、obsidian）。整个推动失败。
   - **PUSH_ONLY**：可推但不能拉（梨形物体？）。
   - **IGNORE**：不影响推动（air）。
3. 累计 toPush 列表，**最多 12 个方块**（PUSH_LIMIT）。
4. 处理 slime / honey 粘连——这些方块连接相邻方块，需要"分支"扩展 toPush。
5. 检查 toPush 大小不超 12。

## 5.7.5 推动的视觉 / 数据机制

实际推动时（在 triggerEvent 内 moveBlocks）：

```java
// 简化伪码
private boolean moveBlocks(Level level, BlockPos pos, Direction facing, boolean extending) {
    PistonStructureResolver resolver = new PistonStructureResolver(level, pos, facing, extending);
    if (!resolver.resolve()) return false;
    
    Map<BlockPos, BlockState> moves = Maps.newHashMap();
    List<BlockPos> toPush = resolver.getToPush();
    List<BlockState> states = Lists.newArrayList();
    
    for (BlockPos p : toPush) {
        BlockState state = level.getBlockState(p);
        moves.put(p, state);
        states.add(state);
    }
    
    // 1. 销毁要销毁的方块
    for (int i = resolver.getToDestroy().size() - 1; i >= 0; i--) {
        BlockPos p = resolver.getToDestroy().get(i);
        BlockState state = level.getBlockState(p);
        BlockEntity be = state.hasBlockEntity() ? level.getBlockEntity(p) : null;
        dropResources(state, level, p, be);
        level.setBlock(p, Blocks.AIR.defaultBlockState(), Block.UPDATE_ALL | Block.UPDATE_MOVE_BY_PISTON);
    }
    
    // 2. 移动可推方块（变成 MovingPistonBlock）
    BlockPos[] aBlockPos = new BlockPos[resolver.getToPush().size()];
    BlockState[] aBlockState = new BlockState[resolver.getToPush().size()];
    Direction pushDir = extending ? facing : facing.getOpposite();
    int idx = 0;
    for (int i = resolver.getToPush().size() - 1; i >= 0; i--) {
        BlockPos srcPos = resolver.getToPush().get(i);
        BlockState srcState = level.getBlockState(srcPos);
        BlockEntity be = srcState.hasBlockEntity() ? level.getBlockEntity(srcPos) : null;
        clearBlock(srcPos, false);     // 把源位置变 air
        BlockPos dstPos = srcPos.relative(pushDir);
        moves.remove(dstPos);
        BlockState newState = Blocks.MOVING_PISTON.defaultBlockState().setValue(MovingPistonBlock.FACING, facing);
        level.setBlock(dstPos, newState, ...);
        // 创建 PistonMovingBlockEntity 持有原 srcState
        level.setBlockEntity(MovingPistonBlock.newMovingBlockEntity(dstPos, newState, srcState, facing, extending, false));
        aBlockPos[idx] = srcPos;
        aBlockState[idx++] = srcState;
    }
    
    // 3. 活塞前方放 PistonHead
    if (extending) {
        BlockState head = Blocks.PISTON_HEAD.defaultBlockState()
            .setValue(PistonHeadBlock.FACING, facing)
            .setValue(PistonHeadBlock.TYPE, isSticky ? PistonType.STICKY : PistonType.DEFAULT);
        BlockPos headPos = pos.relative(facing);
        // ⋯ 类似 setBlock + 创建 PistonMovingBlockEntity ⋯
    }
    
    return true;
}
```

**关键技巧**：被推方块**不直接变成"前移一格"** —— 而是先变成 **`MovingPistonBlock`**（半空气状态），由 `PistonMovingBlockEntity` 持有原 BlockState 和动画进度。

## 5.7.6 PistonMovingBlockEntity

```java
public class PistonMovingBlockEntity extends BlockEntity {
    private BlockState movedState;
    private Direction direction;
    private boolean extending;
    private boolean isSourcePiston;
    private float progress;          // 0..1，动画进度
    private float progressO;         // 上一 tick 进度（partial tick 用）
    private long lastTicked;
    private int deathTicks;
    
    public PistonMovingBlockEntity(BlockPos pos, BlockState state, BlockState movedState, Direction dir, boolean extending, boolean isSourcePiston) {
        super(BlockEntityType.PISTON, pos, state);
        this.movedState = movedState;
        this.direction = dir;
        this.extending = extending;
        this.isSourcePiston = isSourcePiston;
    }
    
    public static void tick(Level level, BlockPos pos, BlockState state, PistonMovingBlockEntity be) {
        be.lastTicked = level.getGameTime();
        be.progressO = be.progress;
        if (be.progressO >= 1.0F) {
            // 动画完成，把 movingBlock 实际变成目标方块
            be.finalTick();
            return;
        }
        float newProgress = be.progress + 0.5F;     // 每 tick 进度 +0.5
        be.moveCollidedEntities(level, pos, newProgress - be.progress);
        be.progress = newProgress;
        if (be.progress >= 1.0F) be.progress = 1.0F;
    }
    
    public void finalTick() {
        Level level = this.getLevel();
        if (level != null && (this.progressO < 1.0F || level.isClientSide)) {
            this.progress = 1.0F;
            this.progressO = this.progress;
            level.removeBlockEntity(this.worldPosition);
            this.setRemoved();
            
            // 把目标位置实际变成 movedState
            if (level.getBlockState(this.worldPosition).is(Blocks.MOVING_PISTON)) {
                BlockState finalState = Block.updateFromNeighbourShapes(this.movedState, level, this.worldPosition);
                if (finalState.isAir()) {
                    level.setBlock(this.worldPosition, this.movedState, Block.UPDATE_KNOWN_SHAPE | Block.UPDATE_MOVE_BY_PISTON);
                    Block.updateOrDestroy(this.movedState, finalState, level, this.worldPosition, ...);
                } else {
                    if (finalState.hasProperty(BlockStateProperties.WATERLOGGED) && finalState.getValue(BlockStateProperties.WATERLOGGED)) {
                        finalState = finalState.setValue(BlockStateProperties.WATERLOGGED, false);
                    }
                    level.setBlock(this.worldPosition, finalState, Block.UPDATE_ALL | Block.UPDATE_MOVE_BY_PISTON);
                    level.neighborChanged(this.worldPosition, finalState.getBlock(), this.worldPosition);
                }
            }
        }
    }
}
```

**关键**：`progress` 从 0 增加到 1（每 tick +0.5，2 tick 完成）。

**`progressO`** 是上一 tick 进度——客户端渲染用 partial tick 在 progress 和 progressO 之间插值，达到丝滑动画。

## 5.7.7 客户端动画

客户端的 PistonMovingBlockEntity 负责渲染：

```java
// PistonMovingBlockEntityRenderer
public void render(PistonMovingBlockEntity be, float partialTick, ...) {
    float progress = be.getProgress(partialTick);     // 插值
    Direction dir = be.getDirection();
    BlockState movedState = be.getMovedState();
    
    poseStack.pushPose();
    Vec3 offset = Vec3.atCenterOf(BlockPos.ZERO).add(
        dir.getStepX() * progress,
        dir.getStepY() * progress,
        dir.getStepZ() * progress
    );
    poseStack.translate(offset.x, offset.y, offset.z);
    
    blockRenderer.renderBlockState(movedState, ...);     // 渲染移动中的方块
    
    poseStack.popPose();
}
```

**`getProgress(partialTick)`**：

```java
public float getProgress(float partialTick) {
    return partialTick > 1.0F ? this.progress : this.progressO + (this.progress - this.progressO) * partialTick;
}
```

服务端 progress 跳变 0 → 0.5 → 1，客户端用 partial tick 在 0、0.5、1 之间平滑插值——视觉上推动连续。

## 5.7.8 PistonPushReaction

```java
public enum PushReaction {
    NORMAL,        // 可推 - 多数方块
    DESTROY,       // 被销毁 - 火、植被、雪
    BLOCK,         // 阻挡 - 基岩、obsidian、bedrock_anchor
    IGNORE,        // 忽略 - air
    PUSH_ONLY      // 可推不可拉 - 一些特殊方块
}
```

**注册方式**：

```java
// BlockBehaviour.Properties
public Properties pushReaction(PushReaction reaction) {
    this.pushReaction = reaction;
    return this;
}
```

**默认 NORMAL**。

**典型 BLOCK**：

- `Blocks.OBSIDIAN`
- `Blocks.BEDROCK`
- `Blocks.RESPAWN_ANCHOR`
- `Blocks.SPAWNER`
- `Blocks.END_PORTAL_FRAME`

**典型 DESTROY**：

- `Blocks.FIRE`
- `Blocks.TORCH`
- `Blocks.GRASS`（不是 grass_block）
- `Blocks.RAIL`（部分）
- 大部分植物

**典型 IGNORE**：

- `Blocks.AIR`
- `Blocks.STRUCTURE_VOID`

## 5.7.9 粘性活塞的"拉"

```java
@Override
public boolean triggerEvent(BlockState state, Level level, BlockPos pos, int eventId, int eventParam) {
    Direction direction = state.getValue(FACING);
    if (eventId == TRIGGER_EXTEND) {
        // 推
        if (this.moveBlocks(level, pos, direction, true)) {
            level.setBlock(pos, state.setValue(EXTENDED, true), 67);
            level.playSound(...);
            return true;
        }
    } else if (eventId == TRIGGER_CONTRACT || eventId == TRIGGER_DROP) {
        // 缩
        BlockPos beyondHeadPos = pos.relative(direction, 2);
        BlockState beyondHeadState = level.getBlockState(beyondHeadPos);
        boolean shouldDrop = false;
        // ⋯ 检查粘性 + 决定是否拉回方块 ⋯
        
        if (this.isSticky && !shouldDrop) {
            // 粘性活塞：拉回 head 前面那格方块
            this.moveBlocks(level, pos, direction, false);
        } else {
            // 普通活塞：仅缩回 head，不拉
            BlockPos headPos = pos.relative(direction);
            level.setBlock(headPos, Blocks.AIR.defaultBlockState(), 67);
        }
        // ⋯
    }
    return false;
}
```

**`moveBlocks(level, pos, direction, false)`**：`extending = false` 触发缩回逻辑——`pushDirection = facing.getOpposite()`，从 head 前方拉一格方块回来。

## 5.7.10 实体推动

`PistonMovingBlockEntity.moveCollidedEntities` 负责"推动期间把站在方块上的实体也跟着移动"：

```java
private void moveCollidedEntities(Level level, BlockPos pos, float deltaProgress) {
    Direction direction = this.getMovementDirection();
    double distance = deltaProgress;
    AABB box = ...;     // 当前推动方块的 AABB
    
    List<Entity> entities = level.getEntities(null, box);
    for (Entity entity : entities) {
        if (entity.getPistonPushReaction() != PushReaction.IGNORE) {
            entity.move(MoverType.PISTON, new Vec3(
                direction.getStepX() * distance,
                direction.getStepY() * distance,
                direction.getStepZ() * distance
            ));
        }
    }
}
```

**实体 PushReaction**：玩家、生物、物品 = NORMAL；末影龙、boss = IGNORE（不能被推）。

**`MoverType.PISTON`** 是 Entity.move 的特殊调用——告诉 Entity"被活塞推"导致与普通 move 不同的碰撞处理（推到墙时被压扁致死）。

## 5.7.11 性能

```
单 piston extend:
- checkIfExtend：~5 微秒
- PistonStructureResolver.resolve：~10-100 微秒（取决于推链长度）
- moveBlocks：~50 微秒（12 个 setBlock）
- BlockEvent 排队：~1 微秒

总：~70-200 微秒 / piston
```

**带粘性 + 大 chain（12 个 slime block 链）**：可达 ~500 微秒。

每 tick 几个 piston 不是问题。但**红石计算机的 piston 频繁动作**（每秒数十个 piston 操作）需要高效——1.21 实验红石对此优化。

## 5.7.12 C++ 移植

```cpp
namespace mc::block::piston {

class PistonStructureResolver {
public:
    static constexpr int MAX_PUSH_DEPTH = 12;
    
    PistonStructureResolver(Level& level, BlockPos pistonPos, Direction direction, bool extending);
    
    bool resolve() {
        toPush_.clear();
        toDestroy_.clear();
        
        const BlockState* startState = level_->getBlockState(startPos_);
        if (!isPushable(startState, *level_, startPos_, pushDirection_, false, pistonDirection_)) {
            if (extending_ && startState->getPistonPushReaction() == PushReaction::DESTROY) {
                toDestroy_.push_back(startPos_);
                return true;
            }
            return false;
        }
        
        if (!addBlockLine(startPos_, pushDirection_)) return false;
        
        // 处理 slime / honey 粘连
        for (size_t i = 0; i < toPush_.size(); i++) {
            BlockPos p = toPush_[i];
            if (level_->getBlockState(p)->is(Blocks::SLIME_BLOCK)) {
                if (!addBranchingBlocks(p)) return false;
            }
        }
        return true;
    }
    
    const std::vector<BlockPos>& getToPush() const { return toPush_; }
    const std::vector<BlockPos>& getToDestroy() const { return toDestroy_; }

private:
    Level* level_;
    BlockPos pistonPos_;
    BlockPos startPos_;
    Direction pistonDirection_;
    Direction pushDirection_;
    bool extending_;
    std::vector<BlockPos> toPush_;
    std::vector<BlockPos> toDestroy_;
    
    bool addBlockLine(BlockPos pos, Direction expansionDir);
    bool addBranchingBlocks(BlockPos pos);
};

class PistonBaseBlock : public DirectionalBlock {
public:
    static constexpr int PUSH_LIMIT = 12;
    static constexpr int TRIGGER_EXTEND = 0;
    static constexpr int TRIGGER_CONTRACT = 1;
    static constexpr int TRIGGER_DROP = 2;
    
    bool isSticky_;
    
    void neighborChanged(const BlockState& state, Level& level, BlockPos pos, ...) override {
        if (!level.isClientSide()) {
            checkIfExtend(level, pos, state);
        }
    }
    
    bool triggerEvent(const BlockState& state, Level& level, BlockPos pos, int eventId, int eventParam) override {
        Direction direction = state.getValue(DirectionalBlock::FACING);
        if (eventId == TRIGGER_EXTEND) {
            return moveBlocks(level, pos, direction, true);
        } else if (eventId == TRIGGER_CONTRACT || eventId == TRIGGER_DROP) {
            return moveBlocks(level, pos, direction, false);
        }
        return false;
    }
    
private:
    void checkIfExtend(Level& level, BlockPos pos, const BlockState& state) {
        Direction facing = state.getValue(DirectionalBlock::FACING);
        bool hasSignal = getNeighborSignal(level, pos, facing);
        bool extended = state.getValue(EXTENDED);
        
        if (hasSignal && !extended) {
            if (PistonStructureResolver(level, pos, facing, true).resolve()) {
                level.blockEvent(pos, this, TRIGGER_EXTEND, int(facing));
            }
        } else if (!hasSignal && extended) {
            level.blockEvent(pos, this, TRIGGER_CONTRACT, int(facing));
        }
    }
    
    bool moveBlocks(Level& level, BlockPos pos, Direction facing, bool extending);
};

}
```

## 5.7.13 一句话总结

活塞推动是 Mojang 红石**最复杂的 4 阶段过程**：(1) `neighborChanged` 检测信号变化 + 调 `checkIfExtend` 决定是否推 → (2) `level.blockEvent(pos, piston, TRIGGER_EXTEND, facing)` 排 BlockEvent → (3) 下一 tick `runBlockEvents` → `triggerEvent` → `moveBlocks` → `PistonStructureResolver.resolve` 决定推 12 个方块 + 销毁 / 粘性扩展 → 把每方块改成 `MovingPistonBlock` + `PistonMovingBlockEntity`（持有原 BlockState）→ (4) 客户端 / 服务端 0.5 秒动画（progress 0→0.5→1），动画结束 `finalTick` 把 movingBlock 实际变成目标方块；活塞上方 1 格也能供电（11 个供电方向）；`PistonPushReaction`（NORMAL/DESTROY/BLOCK/IGNORE/PUSH_ONLY）决定方块如何反应；slime / honey 块连接相邻方块作"分支推动"；粘性活塞缩回时拉一格。
